# 나무꾼의 절단기 높이 설정! 매개변수 탐색 (Parametric Search)

### 문제 설명
친환경 목재소 소장 상우는 숲속의 $N$그루 나무를 베어 목재를 마련하려고 합니다.  
절단기는 땅으로부터 높이 $H$미터로 설정하여 일직선으로 지나가며, 나무의 높이가 $H$보다 높은 부분만 잘라내어 상우가 가져갑니다.  
(나무의 높이가 $H$ 이하인 나무는 전혀 잘리지 않습니다.)

예를 들어 높이가 `20, 15, 10, 17`인 나무 4그루가 있고 절단기 높이를 $H = 15$로 맞추면:
- 각각 `5, 0, 0, 2`미터가 잘려 총 7미터의 목재를 얻을 수 있습니다.

상우는 집을 짓기 위해 **적어도 $M$미터**의 나무가 필요합니다.  
환경을 보호하기 위해 나무를 필요한 만큼만 아껴 베고자 할 때,  
적어도 $M$미터의 나무를 챙기기 위해 설정할 수 있는 **절단기의 최대 높이 $H$**를 구하세요.

---

### 입력 형식
- 첫째 줄에 나무의 수 $N$ ($1 \le N \le 1000$)과 필요한 나무의 길이 $M$ ($1 \le M \le 10^9$)이 공백으로 주어집니다.
- 둘째 줄에 $N$개 나무의 높이가 공백으로 주어집니다. ($1 \le \text{높이} \le 10^9$)
- 적어도 $M$미터의 나무를 가져갈 수 있는 입력만 주어집니다.

---

### 출력 형식
- 적어도 $M$미터의 나무를 가져가기 위해 설정할 수 있는 절단기 높이 $H$의 최댓값을 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
4 7
20 15 10 17
```

**출력**
```
15
```

#### 예시 2
**입력**
```
5 20
4 42 40 26 46
```

**출력**
```
36
```
