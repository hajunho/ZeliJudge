# 매개변수 탐색(Parametric Search)과 최적화의 결정 문제 변환

### 1. 매개변수 탐색이란?
> **"최댓값(최솟값)을 찾는 최적화 문제" $\longrightarrow$ "이 높이 $H$로 $M$미터 이상을 얻을 수 있는가? (Yes/No)"**

높이 $H$가 높아질수록 얻을 수 있는 나무의 양은 단조 감소(Monotonic Decrease)합니다.  
이 단조성을 활용하여, $0$부터 $\max(Tree)$까지의 범위에서 **이진 탐색(Binary Search)**을 돌려 $O(N \log(\max(Tree)))$에 $H$의 최댓값을 즉시 찾아냅니다!

---

### 2. 이진 탐색 루프의 조건
- `wood >= M` (조건 만족): 절단기를 더 높여도 되는지 확인하기 위해 `ans = mid`, `low = mid + 1`로 범위를 올립니다.
- `wood < M` (나무 부족): 절단기를 낮춰야 하므로 `high = mid - 1`로 범위를 내립니다.
