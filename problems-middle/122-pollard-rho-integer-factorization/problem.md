# 거대한 합성수를 두 조각으로! 폴라드-로(Pollard's Rho) 소인수분해

### 문제 설명
자연수 $N$이 주어집니다.  
이 $N$을 소인수분해하여 **모든 소인수를 오름차순**으로 공백으로 구분하여 출력하는 프로그램을 작성하세요.

$N$이 $10^{14}$ 이상인 거대한 합성수일 때, 2부터 $\sqrt{N}$까지 소수를 나눠보는 전통적인 방식은 시간 초과가 발생합니다.  
존 폴라드(John Pollard)의 **폴라드-로(Pollard's Rho)** 알고리즘은:
- 의사난수 다항식 $f(x) = (x^2 + c) \pmod N$을 반복 생성하여,
- 생일 역설(Birthday Paradox)의 원리에 의해 작은 소인수 $p$에 대해 $O(\sqrt{p}) \approx O(N^{1/4})$ 걸음 만에 사이클을 형성하고,
- $\gcd(|x - y|, N)$ 연산으로 $N$의 비자명한 진짜 약수를 분해해 냅니다!

---

### 입력 형식
- 첫째 줄에 소인수분해할 자연수 $N$ ($2 \le N \le 10^{15}$)이 주어집니다.

---

### 출력 형식
- $N$의 모든 소인수를 오름차순으로 공백으로 구분하여 출력합니다. (중복되는 소인수는 등장하는 횟수만큼 모두 출력합니다.)

---

### 입출력 예시

#### 예제 입력 1
```
180
```

#### 예제 출력 1
```
2 2 3 3 5
```
- 설명: $180 = 2^2 \times 3^2 \times 5$입니다.
