# 신비로운 삼각형의 수열! 파스칼의 삼각형과 이항계수 (nCr)

### 문제 설명
프랑스의 천재 수학자 블레즈 파스칼(Blaise Pascal)은 조합론과 확률론의 기초가 되는 아름다운 삼각형 모양의 수 배열을 정리했습니다:
```
       1
      1 1
     1 2 1
    1 3 3 1
   1 4 6 4 1
```

이 삼각형의 각 숫자는 바로 **이항계수(Binomial Coefficient)** $\binom{N}{K}$ (조합 $_N C_K$)를 나타냅니다:
- $\binom{N}{0} = \binom{N}{N} = 1$
- $\binom{N}{K} = \binom{N-1}{K-1} + \binom{N-1}{K}$ ($0 < K < N$)

팩토리얼($N!$)로 직접 계산하면 숫자가 너무 커져 오버플로우가 발생합니다.  
동적 계획법(DP)을 사용하여 파스칼의 항등식으로 $\binom{N}{K}$를 구하고,  
결과를 $1,000,000,007$로 나눈 나머지를 출력하세요.

---

### 입력 형식
- 첫째 줄에 두 정수 $N, K$ ($0 \le K \le N \le 1000$)가 공백으로 주어집니다.

---

### 출력 형식
- $\binom{N}{K} \pmod{1000000007}$을 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
5 2
```

**출력**
```
10
```

#### 예시 2
**입력**
```
10 5
```

**출력**
```
252
```
