# 길치 탈출! 다익스트라(Dijkstra) 최단 경로

### 문제 설명
중학교 로봇 동아리 민우는 학교 축제에서 길 안내 자율주행 로봇을 만들기로 했습니다.  
학교에는 $V$개의 주요 장소(정점)가 있고, 장소들을 잇는 $E$개의 양방향 통로(간선)가 있습니다. 각 통로를 지나가는 데는 일정한 시간(가중치)이 걸립니다.

로봇은 1번 장소(정문)에서 출발하여 각 장소로 이동해야 합니다.  
네덜란드의 전설적인 컴퓨터 과학자 **에츠허르 다익스트라(Edsger W. Dijkstra)**가 고안한 최단 경로 알고리즘을 구현하여,  
1번 장소에서 출발하여 $1$번부터 $V$번까지의 모든 장소로 가는 **최단 소요 시간**을 각각 구하세요.

---

### 입력 형식
- 첫째 줄에 장소의 수 $V$ ($1 \le V \le 100$)와 통로의 수 $E$ ($0 \le E \le 500$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 각 통로가 연결하는 두 장소 번호 $u, v$와 이동 시간 $w$ ($1 \le u, v \le V, 1 \le w \le 100$)가 주어집니다.
- 통로는 양방향으로 이동할 수 있습니다.

---

### 출력 형식
- 1번 장소부터 $V$번 장소까지, 각 장소로 가는 최단 시간을 $1$번 장소부터 순서대로 공백으로 구분하여 한 줄에 출력합니다.
- 만약 어떤 장소로 가는 길이 끊겨 있어 도달할 수 없다면, 해당 장소의 거리는 `-1`로 출력합니다. (1번 장소 자기 자신으로의 거리는 `0`입니다.)

---

### 입출력 예시

#### 예시 1
**입력**
```
5 6
1 2 2
1 3 3
2 4 5
3 4 1
3 5 7
4 5 2
```

**출력**
```
0 2 3 4 6
```
*설명:*
- 1번: 출발지이므로 0
- 2번: 1->2 (비용 2)
- 3번: 1->3 (비용 3)
- 4번: 1->3->4 (비용 3+1 = 4)
- 5번: 1->3->4->5 (비용 3+1+2 = 6)
