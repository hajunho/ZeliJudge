# 2ᵏ 조상으로 점프! 이진 리프팅(Binary Lifting) 최소 공통 조상 (LCA)

### 문제 설명
1번 노드를 루트로 하는 $N$개의 노드로 이루어진 트리가 주어집니다.  
임의의 두 노드 $u$와 $v$의 **최소 공통 조상(LCA)**을 구하는 질의가 총 $Q$개 주어질 때 이를 처리하는 프로그램을 작성하세요.

단순히 한 칸씩 부모로 올라가는 선형 탐색($O(N)$) 대신,  
각 노드의 $2^k$번째 조상을 희소 배열 `up[k][u]`로 전처리하는 **이진 리프팅(Binary Lifting)** 기법을 사용하면:
1. 두 노드의 깊이 차이를 이진수 비트 단위로 점프시켜 깊이를 맞추고,
2. $2^{17}, 2^{16}, \dots, 2^0$ 순서로 조상이 일치하지 않는 한 가장 높은 높이로 동시 점프하여,  
**질의당 단 $O(\log N)$**에 LCA를 초고속으로 찾아낼 수 있습니다!

---

### 입력 형식
- 첫째 줄에 노드의 수 $N$ ($1 \le N \le 50000$)과 질의의 수 $Q$ ($1 \le Q \le 50000$)가 공백으로 주어집니다.
- 둘째 줄부터 $N-1$개의 줄에 걸쳐 트리의 간선 $u, v$ ($1 \le u, v \le N$)가 주어집니다.
- 그 다음 $Q$개의 줄에 걸쳐 질의 노드 쌍 $u, v$가 주어집니다.

---

### 출력 형식
- 각 질의마다 두 노드의 LCA 노드 번호를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5 3
1 2
1 3
2 4
2 5
4 5
4 3
2 4
```

#### 예제 출력 1
```
2
1
2
```
