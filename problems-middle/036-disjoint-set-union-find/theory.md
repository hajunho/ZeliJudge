# 서로소 집합(Disjoint Set)과 유니온 파인드

### 1. 서로소 집합이란?
공통 원소가 없는 상호 배타적인 집합들을 의미합니다.  
소셜 네트워크 친구 그룹, 네트워크 통신망 연결 여부, 이미지 분할 등 수많은 알고리즘의 기초가 됩니다.

---

### 2. 2대 핵심 연산
- **Find(x)**: 원소 $x$가 속한 집합의 대표 번호(루트, Root)를 찾습니다.
- **Union(a, b)**: $a$의 대표와 $b$의 대표를 연결하여 두 집합을 하나로 병합합니다.

---

### 3. 경로 압축(Path Compression)의 마법
단순히 부모를 가리키게만 하면 트리가 한 줄로 길어져 최악의 경우 $O(N)$이 걸릴 수 있습니다.  
이를 방지하는 핵심 비결이 바로 **경로 압축(Path Compression)**입니다:

```python
def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])  # 부모를 직접 루트로 갱신!
    return parent[x]
```
루트를 찾아 올라가면서 거치는 모든 노드의 부모를 단숨에 최종 루트로 직접 연결해 버립니다.  
이 최적화를 적용하면 연산당 시간 복잡도가 사실상 상수 시간에 가까운 **$O(\alpha(N))$**(아커만 역함수)으로 비약적으로 빨라집니다!
