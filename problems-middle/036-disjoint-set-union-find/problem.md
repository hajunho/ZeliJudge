# 우리는 한 팀! 유니온 파인드(Union-Find) 서로소 집합

### 문제 설명
체육대회를 맞아 $1$번부터 $N$번까지의 학생들이 모였습니다. 처음에는 모든 학생이 각각 1인 팀을 이루고 있습니다.  
선생님은 다음 두 종류의 연산을 순서대로 지시합니다:

1. `0 a b`: $a$번 학생이 속한 팀과 $b$번 학생이 속한 팀을 하나로 합칩니다 (**Union**).
2. `1 a b`: $a$번 학생과 $b$번 학생이 현재 같은 팀에 속해 있는지 확인합니다 (**Find**).

효율적인 집합 판별 자료구조인 **유니온 파인드(서로소 집합 / Disjoint Set)**를 구축하여,  
`1 a b` 연산이 주어질 때마다 두 사람이 같은 팀이면 `YES`, 다른 팀이면 `NO`를 출력하세요.

---

### 입력 형식
- 첫째 줄에 학생의 수 $N$ ($1 \le N \le 100$)과 연산의 수 $M$ ($1 \le M \le 100$)이 공백으로 주어집니다.
- 둘째 줄부터 $M$개 줄에 걸쳐 연산 정보 `cmd a b`가 주어집니다.  
  (`cmd`는 0 또는 1, $1 \le a, b \le N$)

---

### 출력 형식
- `1 a b` 연산이 주어질 때마다, 두 학생이 같은 팀이면 `YES`, 아니면 `NO`를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
7 8
0 1 3
1 1 7
0 7 6
1 7 1
0 3 7
1 4 2
0 4 2
1 1 1
```

**출력**
```
NO
NO
NO
YES
```
*설명:*
- `1 1 7`: 1번은 {1,3}, 7번은 {7}이므로 NO
- `1 7 1`: 7번은 {6,7}, 1번은 {1,3}이므로 NO
- `0 3 7`: 이제 {1,3}과 {6,7}이 합쳐져 {1,3,6,7}이 됨
- `1 4 2`: 4번과 2번은 아직 따로이므로 NO
- `0 4 2`: 4와 2가 한 팀 {2,4}이 됨
- `1 1 1`: 자기 자신과는 무조건 같은 팀이므로 YES
