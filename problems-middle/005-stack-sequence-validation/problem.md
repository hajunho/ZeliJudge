# 스택으로 수열 만들기! (Stack Sequence Validator)

## 📖 문제 설명
스택(Stack)은 접시 쌓기처럼 맨 위에 넣고 맨 위에서만 꺼내는 자료구조입니다. 1부터 N까지의 숫자가 순서대로 주어질 때, push와 pop 연산을 적절히 섞어 원하는 목표 수열을 만들 수 있을까요? 예를 들어 [4, 3, 5, 1, 2]는 1을 먼저 꺼내고 2를 나중에 꺼내는 것이 불가능합니다! 목표 수열이 스택으로 만들 수 있는 올바른 수열인지 판별해주세요.

## 📥 입력 형식
첫 줄에 수열의 길이 N (1 <= N <= 10,000)이 주어집니다.\n둘째 줄에 1부터 N까지의 수가 중복 없이 임의의 순서로 공백으로 주어집니다.

## 📤 출력 형식
스택으로 만들 수 있다면 YES, 불가능하다면 NO를 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
8
4 3 6 8 7 5 2 1
```
**출력**
```text
YES
```

## 힌트
1부터 N까지의 수를 오름차순으로 스택에 push하면서 pop 연산으로 주어진 목표 수열을 만들 수 있는지 판별합니다.
