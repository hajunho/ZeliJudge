# 연속된 글자들의 완벽한 일치! 최장 공통 부분 문자열 (Longest Common Substring)

### 문제 설명
두 문자열 $S_1$과 $S_2$가 주어집니다.  
두 문자열 모두에 **연속해서 그대로 등장하는 가장 긴 부분 문자열(Longest Common Substring)**의 길이와 그 실제 문자열을 구하는 프로그램을 작성하세요.

최장 공통 **부분 수열(LCS, Subsequence)**은 글자들이 떨어져 있어도 순서만 맞으면 되지만,  
최장 공통 **부분 문자열(Substring)**은 반드시 **빈틈없이 연속**되어 있어야 합니다!

예를 들어 $S_1 = $ `"ABCDGH"`, $S_2 = $ `"ACDGHR"`일 때:
- 공통 부분 문자열 중 가장 긴 것은 `"CDGH"`이며, 길이는 4입니다.

만약 가장 긴 공통 부분 문자열이 여러 개 존재한다면, $S_1$에서 **가장 먼저 등장하는 것**을 출력합니다.

---

### 입력 형식
- 첫째 줄에 첫 번째 문자열 $S_1$이 주어집니다. ($1 \le |S_1| \le 2000$)
- 둘째 줄에 두 번째 문자열 $S_2$가 주어집니다. ($1 \le |S_2| \le 2000$)
- 문자열은 알파벳 대문자로만 구성됩니다.

---

### 출력 형식
- 첫째 줄에 최장 공통 부분 문자열의 길이를 출력합니다.
- 둘째 줄에 해당 최장 공통 부분 문자열을 출력합니다. (길이가 0이면 둘째 줄은 출력하지 않습니다.)

---

### 입출력 예시

#### 예제 입력 1
```
ABCDGH
ACDGHR
```

#### 예제 출력 1
```
4
CDGH
```
