# 유니온-파인드 (Union-Find) 기반 무방향 그래프 사이클 판별

### 1. 사이클 발생 조건
무방향 그래프에서 새로운 간선 $(u, v)$를 연결하려 할 때:
- 만약 $u$와 $v$가 이미 같은 연결 컴포넌트(즉, `find(u) == find(v)`)에 속해 있다면,
- 이미 두 정점 사이에 어떤 경로가 존재한다는 의미이므로, 이번 간선 $(u, v)$를 연결하는 순간 **닫힌 루프(사이클)**가 완성됩니다!

### 2. 효율성
경로 압축(Path Compression)을 적용한 유니온-파인드는 각 연산을 거의 $O(1)$(아커만 역함수 $\alpha(V)$)에 처리하므로, $E$개의 간선에 대해 총 $O(E \alpha(V))$ 시간에 사이클 발생 순간을 즉시 포착할 수 있습니다.
