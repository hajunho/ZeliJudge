# 순환 도로의 형성! 유니온-파인드 사이클 판별 (Cycle Detection)

### 문제 설명
$V$개의 마을과 두 마을을 잇는 도로 공사 계획 $E$개가 시간 순서대로 주어집니다.  
도로는 양방향 통행이 가능합니다.

공사가 하나씩 진행되다가, 어느 순간 **새로운 도로를 추가함으로써 사이클(순환 도로망)이 처음으로 발생하는 시점**이 언제인지 알아내려고 합니다.  
서로소 집합(Disjoint Set / Union-Find) 자료구조를 활용하여:
- 사이클이 최초로 형성되는 도로의 번호(1-indexed)를 찾아 `CYCLE K` 형식으로 출력하세요.
- 모든 $E$개의 도로를 다 지을 때까지 사이클이 단 한 번도 생기지 않는다면 `NO CYCLE`을 출력하세요.

---

### 입력 형식
- 첫째 줄에 마을의 수 $V$ ($2 \le V \le 100000$)와 도로 공사 계획의 수 $E$ ($1 \le E \le 200000$)가 주어집니다.
- 둘째 줄부터 $E$개의 줄에 걸쳐 공사 순서대로 연결할 두 마을의 번호 $u, v$ ($1 \le u, v \le V, u \neq v$)가 주어집니다.

---

### 출력 형식
- 사이클이 최초로 발생하는 도로의 순번 $K$에 대해 `CYCLE K`를 출력합니다.
- 사이클이 발생하지 않으면 `NO CYCLE`을 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4 4
1 2
2 3
3 4
4 1
```

#### 예제 출력 1
```
CYCLE 4
```
