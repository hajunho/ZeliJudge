# 2차원 누적합과 포함-배제 원리

### 1. 2차원 누적합 배열 $S[r][c]$의 정의
$S[r][c]$는 원본 격자의 $(1, 1)$부터 $(r, c)$까지의 모든 원소를 더한 직사각형 합입니다.

$$S[r][c] = A[r][c] + S[r-1][c] + S[r][c-1] - S[r-1][c-1]$$

위쪽 직사각형 합($S[r-1][c]$)과 왼쪽 직사각형 합($S[r][c-1]$)을 더하면 대각선 왼쪽 위 영역($S[r-1][c-1]$)이 두 번 더해지므로,  
한 번 빼주는 **포함-배제의 원리(Inclusion-Exclusion Principle)**가 적용됩니다.

---

### 2. 임의의 직사각형 구간합을 O(1)에 구하기
구하고자 하는 영역이 $(r_1, c_1)$부터 $(r_2, c_2)$라면:

$$\text{Sum} = S[r_2][c_2] - S[r_1-1][c_2] - S[r_2][c_1-1] + S[r_1-1][c_1-1]$$

1. 전체 큰 직사각형 $S[r_2][c_2]$를 잡습니다.
2. 윗부분 $S[r_1-1][c_2]$을 도려냅니다.
3. 왼쪽 부분 $S[r_2][c_1-1]$을 도려냅니다.
4. 두 번 도려내진 좌상단 겹친 모서리 $S[r_1-1][c_1-1]$을 다시 더해줍니다!

이 전처리 한 번이면 아무리 거대한 행렬이라도 단 4번의 사칙연산($O(1)$)으로 구간합을 구합니다.
