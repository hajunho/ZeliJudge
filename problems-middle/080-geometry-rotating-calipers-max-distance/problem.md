# 평면 위 가장 먼 두 은하의 거리! 회전하는 캘리퍼스 (Rotating Calipers)

### 문제 설명
평면 위에 $N$개의 점(좌표)이 주어집니다.  
이 $N$개의 점 중에서 **서로의 거리가 가장 먼 두 점 사이의 거리의 제곱**을 구하는 프로그램을 작성하세요.

단순히 모든 점 쌍의 거리를 비교하는 방법은 $O(N^2)$이 걸려 $N$이 커지면 시간 초과가 발생합니다.  
하지만 **가장 먼 두 점은 반드시 볼록 껍질(Convex Hull)의 꼭짓점 중 하나**라는 기하학적 성질이 있습니다!
볼록 껍질을 구한 뒤, 두 평행선으로 볼록 껍질을 캘리퍼스처럼 돌려가며 탐색하는 **회전하는 캘리퍼스(Rotating Calipers)** 알고리즘을 사용하면 $O(N \log N)$ 시간에 평면의 지름(최대 거리)을 구할 수 있습니다.

---

### 입력 형식
- 첫째 줄에 점의 개수 $N$ ($2 \le N \le 50000$)이 주어집니다.
- 둘째 줄부터 $N$개의 줄에 걸쳐 각 점의 정수 좌표 $x, y$ ($-10^4 \le x, y \le 10^4$)가 공백으로 주어집니다.

---

### 출력 형식
- 가장 먼 두 점 사이의 유클리드 거리의 제곱(즉, $(x_1 - x_2)^2 + (y_1 - y_2)^2$)을 정수로 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5
0 0
10 0
0 10
10 10
5 5
```

#### 예제 출력 1
```
200
```
- 설명: 점 $(0, 0)$과 $(10, 10)$ 사이의 거리 제곱 $(10-0)^2 + (10-0)^2 = 100 + 100 = 200$이 최댓값입니다.
