# 레이저 광선의 충돌! CCW 선분 교차 판별 (Line Intersection)

### 문제 설명
SF 우주 기지 방어벽에는 침입자를 감지하기 위해 두 개의 레이저 광선 선분이 설치되어 있습니다.  
- 1번 레이저: 점 $A(x_1, y_1)$부터 점 $B(x_2, y_2)$까지의 선분
- 2번 레이저: 점 $C(x_3, y_3)$부터 점 $D(x_4, y_4)$까지의 선분

두 레이저 광선이 도중에 서로 교차하는지(끝점에서 만나는 경우 포함) 확인해야 합니다.  
앞서 배운 세 점의 회전 방향을 나타내는 **CCW 알고리즘**을 활용하여,  
두 선분이 교차하면 `1`, 교차하지 않으면 `0`을 출력하세요.

---

### 입력 형식
- 첫째 줄에 1번 선분의 양 끝점 $x_1, y_1, x_2, y_2$와 2번 선분의 양 끝점 $x_3, y_3, x_4, y_4$가 공백으로 주어집니다.  
  ($-10000 \le x_i, y_i \le 10000$, 모든 좌표는 정수)

---

### 출력 형식
- 두 선분이 교차하면 `1`, 교차하지 않으면 `0`을 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
1 1 5 5 1 5 5 1
```

**출력**
```
1
```
*설명:*
- 대각선 $X$자 모양으로 (3,3)에서 교차합니다.

#### 예시 2
**입력**
```
1 1 5 5 6 10 10 6
```

**출력**
```
0
```
