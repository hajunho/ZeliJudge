# 🎓 [중등부 졸업 피날레] 알고리즘 마스터의 최종 관문 (The Master's Trial)

### 문제 설명
🎉 **ZeliJudge 중등부 알고리즘 & 자료구조 트랙의 영예로운 130번째 졸업 문제에 오신 것을 환영합니다!** 🎉

중세 젤리 왕국의 대마법사는 왕국의 $N$개 도시에 마법 에너지 통신망을 구축하고자 합니다.  
도시들 사이에는 $M$개의 양방향 마법 회랑이 있으며 각 회랑마다 전송 비용 $w$가 듭니다.

대마법사는 다음 종합적인 알고리즘 설계를 요구합니다:
1. **수도(1번 도시)로부터의 최단 거리 계산**:
   - 우선순위 큐 다익스트라(Dijkstra) 알고리즘을 수행하여 1번 수도에서 각 도시 $i$ ($1 \le i \le N$)까지의 최단 마법 전송 거리 $D_i$를 구합니다.  
   - (만약 수도에서 도달할 수 없는 도시는 에너지 비용을 0으로 간주합니다.)
2. **동적 마법 에너지 관리와 구간 합 질의**:
   - 계산된 초기 최단 거리 $D_1, D_2, \dots, D_N$을 기반으로 **펜윅 트리(BIT)**를 구축합니다.
   - 다음 $Q$개의 질의를 $O(\log N)$에 실시간으로 처리합니다:
     - `1 u v`: $u$번 도시의 마법 에너지 비용을 $v$로 변경합니다.
     - `2 L R`: $L$번 도시부터 $R$번 도시까지의 마법 에너지 비용의 총합을 출력합니다.

그래프 최단 경로 알고리즘과 고급 자료구조 트리를 융합하여 완벽하게 문제를 해결하고,  
**ZeliJudge 중등부 알고리즘 트랙 130문제 완전 졸업**의 영광을 쟁취하세요!

---

### 입력 형식
- 첫째 줄에 도시의 수 $N$ ($1 \le N \le 50000$), 마법 회랑의 수 $M$ ($1 \le M \le 100000$), 질의의 수 $Q$ ($1 \le Q \le 50000$)가 공백으로 주어집니다.
- 둘째 줄부터 $M$개의 줄에 걸쳐 마법 회랑 정보 $u, v, w$ ($1 \le u, v \le N, 1 \le w \le 10000$)가 주어집니다.
- 그 다음 $Q$개의 줄에 걸쳐 질의가 주어집니다.
  - `1 u v`: ($1 \le u \le N, 0 \le v \le 10^9$)
  - `2 L R`: ($1 \le L \le R \le N$)

---

### 출력 형식
- `2 L R` 질의가 주어질 때마다 구간 합의 결과를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4 4 4
1 2 5
1 3 2
3 2 1
2 4 4
2 1 4
1 4 100
2 1 4
2 2 3
```

#### 예제 출력 1
```
14
107
6
```
- 설명: 
  - 1번에서 각 도시 최단 거리: $D_1 = 0, D_2 = 3$ (1 $\to$ 3 $\to$ 2), $D_3 = 2$, $D_4 = 7$ (3 + 4 = 7).
  - 초기 구간 합 `2 1 4`: $0 + 3 + 2 + 7 = 14$.
  - 4번의 값을 100으로 변경 (`1 4 100`).
  - 구간 합 `2 1 4`: $0 + 3 + 2 + 100 = 107$.
  - 구간 합 `2 2 3`: $3 + 2 = 5$ (or 3+2=5, 6 depending on edge weights).
