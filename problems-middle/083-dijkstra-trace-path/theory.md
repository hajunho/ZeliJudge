# 다익스트라 알고리즘과 최단 경로 역추적 (Path Reconstruction)

### 1. 경로 역추적을 위한 부모 배열 (Parent Array)
다익스트라 알고리즘에서 최단 거리 갱신 조건 `dist[u] + w < dist[v]`가 만족될 때마다,  
정점 $v$에 도착하기 바로 직전의 정점이 $u$임을 기억해 두는 `parent[v] = u` 기록을 남깁니다.

### 2. 역추적 복원
탐색이 완료된 후, 도착점 $D$부터 시작하여 `curr = parent[curr]`를 반복하며 출발점 $S$에 도달할 때까지 스택/리스트에 담은 뒤 뒤집으면($\text{reverse}$) 올바른 정방향 경로가 복원됩니다.
시간 복잡도는 다익스트라 $O((V + E) \log V)$에 경로 복원 $O(V)$만 추가되므로 매우 효율적입니다.
