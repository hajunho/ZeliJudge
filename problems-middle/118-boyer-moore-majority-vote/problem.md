# 메모리 O(1)로 과반수 대표 선출! 보이어-무어 과반수 투표 (Majority Vote)

### 문제 설명
길이가 $N$인 정수 수열이 주어집니다.  
이 수열에서 전체 길이의 절반을 초과하여 등장하는 **과반수 원소(Majority Element, 등장 횟수 $> \lfloor N/2 \rfloor$)**가 존재하는지 찾고, 존재한다면 그 값을 출력하는 프로그램을 작성하세요.  
(과반수 원소가 존재하지 않는다면 `NO MAJORITY`를 출력합니다.)

해시 맵이나 정렬을 사용하면 $O(N)$ 메모리나 $O(N \log N)$ 시간이 걸리지만,  
**보이어-무어 과반수 투표 알고리즘(Boyer-Moore Voting Algorithm)**은:
- 후보자 변수(`candidate`)와 득표수 카운터(`count`) 단 2개의 변수만으로,
- 서로 다른 두 원소를 1:1로 상쇄(Cancellation)시켜 나가는 원리를 통해,  
**추가 메모리 $O(1)$**과 **단 한 번의 선형 순회 $O(N)$**만으로 과반수 후보를 정확히 검출해 냅니다!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 100000$)이 주어집니다.
- 둘째 줄에 $N$개의 정수가 공백으로 주어집니다. ($-10^9 \le A_i \le 10^9$)

---

### 출력 형식
- 과반수 원소가 존재하면 그 값을 출력하고, 존재하지 않으면 `NO MAJORITY`를 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
7
2 2 1 1 1 2 2
```

#### 예제 출력 1
```
2
```
- 설명: 전체 7개 중 숫자 2가 4번 등장하여 $7/2 = 3.5$를 초과하므로 과반수 원소는 2입니다.
