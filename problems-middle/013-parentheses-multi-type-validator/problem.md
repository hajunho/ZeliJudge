# 중첩된 괄호의 세계! 소/중/대괄호 짝 검사기 (Multi-Bracket Validator)

## 📖 문제 설명
중학교 수학에서 식을 계산할 때 소괄호 (), 중괄호 {}, 대괄호 [] 순으로 중첩하여 사용합니다. 컴파일러가 소스 코드를 읽을 때도 여는 괄호와 닫는 괄호의 종류가 완벽하게 일치해야 구문 오류를 일으키지 않습니다. 주어진 문자열에서 모든 괄호의 짝이 올바르게 닫혀있는지 YES 또는 NO로 판별해주세요!

## 📥 입력 형식
한 줄에 괄호로만 이루어진 문자열이 주어집니다. (길이 1 <= 10,000, '(', ')', '{', '}', '[', ']' 로만 구성)

## 📤 출력 형식
올바른 괄호 문자열이면 YES, 아니면 NO를 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
{[()]}
```
**출력**
```text
YES
```

## 힌트
소괄호(), 중괄호{}, 대괄호[]가 혼합된 수식에서 괄호의 짝과 중첩 순서가 올바른지 스택(Stack)으로 검증합니다.
