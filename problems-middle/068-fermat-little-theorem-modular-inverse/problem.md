# 모듈러 나눗셈의 열쇠! 페르마의 소정리와 거듭제곱 역원

### 문제 설명
컴퓨터 알고리즘에서 큰 수를 다룰 때 덧셈, 뺄셈, 곱셈은 모듈러 연산($\pmod P$)에 대해 자유롭게 분배할 수 있지만,  
**나눗셈 $(A / B) \pmod P$는 분수 형태로 나눌 수 없습니다!**

이때 프랑스의 위대한 수학자 피에르 드 페르마(Pierre de Fermat)의 소정리가 구원투수로 등장합니다:
> **"소수 $P$와 $P$의 배수가 아닌 정수 $B$에 대해, $B^{P-1} \equiv 1 \pmod P$가 성립한다."**

양변을 $B$로 나누면 놀라운 식을 얻을 수 있습니다:
$$B \times B^{P-2} \equiv 1 \pmod P$$
즉, 모듈러 세계에서 **$B$로 나누는 것은 $B^{P-2}$를 곱하는 것과 완벽하게 동일**합니다!

세 자연수 $A, B$와 소수 $P$가 주어졌을 때, 분할 정복 거듭제곱을 활용하여 $(A / B) \pmod P$를 구하세요.

---

### 입력 형식
- 첫째 줄에 $A, B, P$가 공백으로 주어집니다. ($P$는 소수, $1 \le A, B < P \le 10^9 + 7$)

---

### 출력 형식
- $(A / B) \pmod P$의 정수 값을 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
7 2 5
```

**출력**
```
1
```
*설명:*
- $P = 5$에서 $2$의 역원은 $2^{5-2} = 2^3 = 8 \equiv 3 \pmod 5$.
- 따라서 $7 / 2 \equiv 7 \times 3 = 21 \equiv 1 \pmod 5$.
- 검산: $1 \times 2 = 2 \equiv 7 \pmod 5$ (정답!).
