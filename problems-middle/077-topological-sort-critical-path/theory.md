# 위상 정렬과 DAG 최장 경로 (Critical Path Method, CPM)

### 1. 임계 경로 방법론 (Critical Path Method)
방향 비순환 그래프(DAG)에서 전체 공정의 완료 시간은 선행 제약이 걸린 경로들 중 **가장 긴 소요 시간(최장 경로, Longest Path)**에 의해 지배됩니다.
이 가장 긴 경로를 **임계 경로(Critical Path)**라고 부르며, 이 경로 상의 작업이 1초라도 지연되면 전체 프로젝트 출시가 지연됩니다.

### 2. 점화식과 위상 정렬
진입차수가 0인 노드부터 큐를 이용해 위상 정렬 순서대로 노드 $u$를 처리하며:
$$DP[v] = \max(DP[v], DP[u] + T_v)$$
를 갱신합니다. 모든 선행 노드가 처리되어 진입차수가 0이 되었을 때 큐에 들어가므로 올바른 최대 완료 시점이 보장됩니다.
