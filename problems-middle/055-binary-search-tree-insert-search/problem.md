# 나무를 따라 내려가는 탐색! 이진 검색 트리 (BST)

### 문제 설명
도서관 사서 준영이는 수많은 책 번호를 빠르게 찾기 위해 **이진 검색 트리(Binary Search Tree, BST)**를 구축하기로 했습니다.

BST는 다음과 같은 엄격한 규칙을 가진 이진 트리입니다:
1. 어떤 노드의 **왼쪽 서브트리**에 있는 모든 노드의 값은 현재 노드의 값보다 **작습니다**.
2. 어떤 노드의 **오른쪽 서브트리**에 있는 모든 노드의 값은 현재 노드의 값보다 **큽니다**.

$N$개의 정수가 주어지는 순서대로 빈 트리에 하나씩 삽입하여 BST를 완성한 후,  
찾고자 하는 목표 숫자 $X$를 검색하기 위해 **루트 노드부터 $X$까지 거쳐간 노드들의 경로**를 순서대로 출력하세요.  
(만약 트리에 $X$가 존재하지 않는다면 `-1`을 출력합니다.)

---

### 입력 형식
- 첫째 줄에 삽입할 숫자의 개수 $N$ ($1 \le N \le 100$)이 주어집니다.
- 둘째 줄에 $N$개의 서로 다른 정수가 삽입 순서대로 공백으로 주어집니다.
- 셋째 줄에 탐색할 숫자 $X$가 주어집니다.

---

### 출력 형식
- 루트 노드부터 시작하여 $X$에 도달할 때까지 방문한 모든 노드의 값을 공백으로 구분하여 출력합니다.  
  (트리에 $X$가 없다면 `-1`을 출력합니다.)

---

### 입출력 예시

#### 예시 1
**입력**
```
7
50 30 70 20 40 60 80
40
```

**출력**
```
50 30 40
```
*설명:*
- 루트 50에서 40 < 50이므로 왼쪽 30으로 이동
- 30에서 40 > 30이므로 오른쪽 40으로 이동하여 탐색 성공

#### 예시 2
**입력**
```
5
10 5 15 2 7
99
```

**출력**
```
-1
```
