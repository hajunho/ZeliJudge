# 이진 검색 트리(BST)의 탐색 속도와 특성

### 1. BST의 핵심 불변성(Invariant)
$$\text{Left Subtree} < \text{Node} < \text{Right Subtree}$$

이 성질 덕분에 값을 찾을 때마다 매번 탐색 대상이 절반으로 줄어들어,  
트리가 균형을 이룰 때 검색, 삽입, 삭제의 시간 복잡도는 **$O(\log N)$**이 됩니다!

---

### 2. 중위 순회(In-order Traversal)의 마법
BST를 중위 순회(Left $\to$ Node $\to$ Right)하면,  
**모든 원소가 오름차순으로 완벽하게 정렬**되어 출력됩니다!

---

### 3. 최악의 경우: 편향 트리(Skewed Tree)
만약 `1, 2, 3, 4, 5` 순서로 오름차순 정렬된 데이터가 들어오면,  
트리가 오른쪽으로만 길어지는 연결 리스트 모양이 되어 탐색 속도가 **$O(N)$**으로 퇴화합니다.  
이를 방지하기 위해 트리의 균형을 자동으로 맞추는 AVL 트리나 Red-Black 트리가 실무에서 널리 쓰입니다.
