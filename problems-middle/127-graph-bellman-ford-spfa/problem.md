# 벨만-포드의 번개 같은 진화! SPFA(Shortest Path Faster Algorithm)

### 문제 설명
음수 가중치 도로가 포함될 수 있는 유향 그래프가 주어집니다.  
출발 도시 $S$에서 다른 모든 도시까지의 최단 경로를 구하려고 합니다.

일반 벨만-포드 알고리즘은 매 라운드마다 모든 $E$개의 간선을 무조건 순회하므로 $O(V \times E)$가 걸려 느립니다.  
하지만 **SPFA (Shortest Path Faster Algorithm)**는:
- 최단 거리가 실제로 갱신(Relaxation)된 노드들만 큐에 넣고,
- 불리언 배열 `in_queue`로 중복 삽입을 방지함으로써,  
음수 가중치가 존재하더라도 평균 **$O(E)$**의 압도적인 속도로 최단 거리를 계산해 냅니다!
- 만약 어떤 노드가 큐에 $V$번 이상 들어간다면, 무한히 거리가 줄어드는 **음수 사이클(NEGATIVE CYCLE)**이 존재함을 즉시 감지할 수 있습니다.

---

### 입력 형식
- 첫째 줄에 정점 수 $V$ ($1 \le V \le 1000$), 간선 수 $E$ ($1 \le E \le 5000$), 출발점 $S$ ($1 \le S \le V$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개의 줄에 걸쳐 도로 정보 $u, v, w$ ($1 \le u, v \le V, -10000 \le w \le 10000$)가 주어집니다.

---

### 출력 형식
- 그래프에 출발점에서 도달 가능한 음수 사이클이 존재하면 `NEGATIVE CYCLE`을 출력합니다.
- 존재하지 않는다면 1번 정점부터 $V$번 정점까지의 최단 거리를 공백으로 구분하여 한 줄에 출력합니다. (도달 불가능한 정점은 `INF` 출력)

---

### 입출력 예시

#### 예제 입력 1
```
4 4 1
1 2 4
1 3 3
3 4 -2
2 4 1
```

#### 예제 출력 1
```
0 4 3 1
```
