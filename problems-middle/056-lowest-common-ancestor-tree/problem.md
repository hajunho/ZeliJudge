# 족보의 가장 가까운 공통 조상! 최소 공통 조상 (LCA)

### 문제 설명
왕실 역사학자 세린이는 $N$명의 왕실 가계도(트리 구조)를 연구하고 있습니다.  
시조 왕은 항상 1번 노드(루트)이며, 모든 인물은 부모-자식 관계로 연결되어 있습니다.

두 인물 $u$와 $v$가 주어졌을 때, 가계도에서 두 사람의 공통 조상 중 **가장 세대 차이가 적은(가장 가까운) 조상**을 **최소 공통 조상(Lowest Common Ancestor, LCA)**이라고 합니다.

트리의 깊이(Depth)와 부모 배열을 활용하여,  
$Q$개의 질문 $(u, v)$에 대해 각 쌍의 최소 공통 조상(LCA) 노드 번호를 구하세요.

---

### 입력 형식
- 첫째 줄에 트리의 노드 수 $N$ ($1 \le N \le 1000$)이 주어집니다.
- 둘째 줄부터 $N-1$개 줄에 걸쳐 트리 간선 $u, v$가 주어집니다.
- 그 다음 줄에 질문의 수 $Q$ ($1 \le Q \le 100$)가 주어집니다.
- 다음 $Q$개 줄에 걸쳐 두 노드 번호 $u, v$가 주어집니다. ($1 \le u, v \le N$)

---

### 출력 형식
- 각 질문마다 두 노드의 최소 공통 조상(LCA) 번호를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
7
1 2
1 3
2 4
2 5
3 6
3 7
2
4 5
4 7
```

**출력**
```
2
1
```
*설명:*
- 4번과 5번의 공통 부모는 바로 위 2번입니다.
- 4번과 7번은 서로 다른 가지에 있으므로 뿌리 조상인 1번에서 만납니다.
