# 최장 팰린드롬 부분 수열 (Longest Palindromic Subsequence) DP

### 1. 구간 DP 점화식
$DP[i][j]$를 부분 문자열 $S[i..j]$에서의 LPS 길이라고 정의합니다:

1. 양 끝 문자가 같은 경우 ($S[i] == S[j]$):
   $$DP[i][j] = DP[i+1][j-1] + 2$$
   (양 끝 문자를 팰린드롬의 앞뒤로 취할 수 있음)
2. 양 끝 문자가 다른 경우 ($S[i] \neq S[j]$):
   $$DP[i][j] = \max(DP[i+1][j], DP[i][j-1])$$
   (왼쪽을 버리거나 오른쪽을 버린 두 경우 중 최댓값 선택)

- 기저 조건: $DP[i][i] = 1$, $DP[i][i+1] = (S[i] == S[i+1] ? 2 : 1)$.
- 시간 복잡도: $O(N^2)$.
