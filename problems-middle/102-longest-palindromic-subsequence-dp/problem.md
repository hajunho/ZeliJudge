# 띄엄띄엄 읽어도 대칭! 최장 팰린드롬 부분 수열 (LPS DP)

### 문제 설명
문자열 $S$가 주어집니다.  
이 문자열에서 0개 이상의 문자를 골라내어 순서를 유지한 채 만들 수 있는 부분 수열(Subsequence) 중,  
**앞으로 읽으나 뒤로 읽으나 똑같은 대칭 회문(팰린드롬, Palindrome)이 되는 가장 긴 수열의 길이**를 구하는 프로그램을 작성하세요.

부분 문자열(Substring)과 달리 문자들이 연속해 있지 않고 서로 떨어져 있어도 됩니다.

예를 들어 $S = $ `"BBABCBCAB"`일 때:
- 가장 긴 팰린드롬 부분 수열은 `"BABCBAB"` 또는 `"BACBCAB"` 등이 될 수 있으며,
- 그 길이는 7입니다.

---

### 입력 형식
- 첫째 줄에 문자열 $S$가 주어집니다. ($1 \le |S| \le 1000$)
- 문자열은 알파벳 대문자로만 구성됩니다.

---

### 출력 형식
- 문자열 $S$의 최장 팰린드롬 부분 수열(LPS)의 길이를 정수로 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
BBABCBCAB
```

#### 예제 출력 1
```
7
```
