# 모든 부분집합을 펼쳐라! 2진수 비트마스크 (Bitmask Subsets)

## 📖 문제 설명
중학교 1학년 수학 시간에 배운 '집합의 부분집합'! 원소가 N개인 집합은 각 원소를 포함할지(1) 포함하지 않을지(0) 2가지 선택이 있으므로 총 2^N개의 부분집합을 가집니다. 컴퓨터에서는 이 0과 1의 선택을 2진수 비트(Bitmask)로 표현하여 모든 부분집합을 누락 없이 순회할 수 있습니다. N개의 원소가 주어질 때 비트마스크 순서(0부터 2^N - 1)로 모든 부분집합을 출력하세요!

## 📥 입력 형식
첫 줄에 집합의 원소 수 N (1 <= N <= 10)이 주어집니다.\n둘째 줄에 N개의 서로 다른 원소가 공백으로 주어집니다.

## 📤 출력 형식
2^N개의 줄에 걸쳐, 비트마스크 0부터 2^N - 1까지 각 부분집합에 포함된 원소들을 공백으로 구분하여 출력합니다. (공집합은 빈 줄로 출력합니다)

## 💡 입출력 예시
### 예시 1
**입력**
```text
2
A B
```
**출력**
```text
A
B
A B
```

## 힌트
원소 N개로 이루어진 집합의 모든 부분집합(2^N개)을 비트마스크(Bitmask)를 이용해 사전 순서로 생성합니다.
