# 텍스트 압축의 마법! 허프만 코딩 (Huffman Coding)

### 문제 설명
ZIP 파일, JPEG 이미지, MP3 오디오 등 컴퓨터 파일 압축의 핵심에는 **허프만 코딩(Huffman Coding)**이 자리잡고 있습니다.  
전통적인 아스키(ASCII) 코드는 모든 문자를 똑같이 8비트로 표현하지만,  
허프만 코딩은 **"자주 등장하는 문자는 짧은 비트(예: 1비트), 드물게 등장하는 문자는 긴 비트"**를 부여하는 탐욕적(Greedy) 가변 길이 압축 기법입니다.

허프만 트리를 만드는 과정:
1. 각 문자의 출현 빈도수들을 최소 힙(Min-Heap)에 넣습니다.
2. 빈도수가 가장 작은 두 노드를 꺼내 합친 뒤, 합쳐진 새 부모 노드를 다시 힙에 넣습니다.
3. 힙에 단 하나의 루트 노드만 남을 때까지 반복합니다.

$N$개 문자의 출현 빈도수가 주어졌을 때,  
허프만 코딩으로 문서를 압축했을 때 필요한 **총 비트 수**를 구하세요.  
(단, 문자가 1종류만 주어지면 각 문자는 1비트로 부호화됩니다.)

---

### 입력 형식
- 첫째 줄에 문자의 종류 수 $N$ ($1 \le N \le 100$)이 주어집니다.
- 둘째 줄에 $N$개 문자의 출현 빈도수 양의 정수가 공백으로 주어집니다. ($1 \le \text{빈도수} \le 10000$)

---

### 출력 형식
- 허프만 압축 후 전체 텍스트가 차지하는 총 비트 수를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
4
5 9 12 13
```

**출력**
```
77
```
*설명:*
- (5, 9) 합쳐서 14 (비트 수 += 14) -> 힙: [12, 13, 14]
- (12, 13) 합쳐서 25 (비트 수 += 25) -> 힙: [14, 25]
- (14, 25) 합쳐서 39 (비트 수 += 39)
- 총 비트 수 = 14 + 25 + 39 = 77 비트!
