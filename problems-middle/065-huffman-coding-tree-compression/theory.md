# 허프만 트리와 내부 노드의 합 정리

### 1. 허프만 트리의 총 비트 수 공식
각 문자 $i$의 빈도수를 $f_i$, 트리의 깊이(할당된 비트 수)를 $d_i$라 하면 총 비트 수는 다음과 같습니다:

$$\text{Total Bits} = \sum_{i=1}^N f_i \times d_i$$

---

### 2. 놀라운 수학적 성질: 내부 노드의 총합
트리의 가중치 경로 길이(Weighted Path Length)는 **"두 노드를 합칠 때 생성되는 모든 부모 노드들의 값의 총합"**과 정확히 같습니다!
- 매번 가장 빈도가 작은 두 노드를 합치는 과정 자체가 그 노드들의 깊이를 1씩 증가시키는 것과 동치이기 때문입니다.

따라서 트리를 직접 포인터로 구성할 필요 없이,  
최소 힙(`heapq`)에서 매번 두 최솟값을 더해 누적합하는 것만으로 **$O(N \log N)$**에 완벽하게 총 비트 수를 계산할 수 있습니다.
