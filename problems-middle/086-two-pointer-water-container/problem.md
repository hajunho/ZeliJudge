# 물을 가장 많이 담는 기둥 쌍을 찾아라! 양 끝단 투 포인터 수조 (Container With Most Water)

### 문제 설명
평면 위에 $N$개의 수직 기둥이 일정한 간격(1)으로 세워져 있습니다.  
각 기둥의 높이는 $H_1, H_2, \dots, H_N$입니다.

임의의 두 기둥 $i$와 $j$ ($i < j$)를 선택하여 수조의 양쪽 벽으로 삼을 때, 담을 수 있는 물의 양(넓이)은 다음과 같습니다:
$$\text{담수량} = (j - i) \times \min(H_i, H_j)$$

모든 기둥 쌍 중에서 **가장 많은 물을 담을 수 있는 최대 담수량**과, 그때 선택한 **두 기둥의 번호(1-indexed)**를 구하는 프로그램을 작성하세요.  
(최대 넓이를 만드는 기둥 쌍이 여러 개라면, 폭 $(j - i)$가 가장 넓은 것을 출력합니다.)

모든 쌍을 비교하는 $O(N^2)$ 방식 대신, 양 끝에서 시작하여 더 낮은 기둥 쪽 포인터를 안쪽으로 좁혀가는 **투 포인터(Two-Pointer)** 알고리즘을 사용하면 **$O(N)$** 시간에 해결할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 기둥의 개수 $N$ ($2 \le N \le 100000$)이 주어집니다.
- 둘째 줄에 $N$개의 기둥 높이가 공백으로 구분되어 주어집니다. ($1 \le H_i \le 10000$)

---

### 출력 형식
- 첫째 줄에 담을 수 있는 최대 물의 양을 출력합니다.
- 둘째 줄에 그때 선택한 두 기둥의 번호 $i, j$ ($1 \le i < j \le N$)를 공백으로 구분하여 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
9
1 8 6 2 5 4 8 3 7
```

#### 예제 출력 1
```
49
2 9
```
- 설명: 2번 기둥(높이 8)과 9번 기둥(높이 7)을 선택하면 너비는 $9 - 2 = 7$, 높이는 $\min(8, 7) = 7$이 되어 담수량 $7 \times 7 = 49$로 최대가 됩니다.
