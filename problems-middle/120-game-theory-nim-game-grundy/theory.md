# 님(Nim) 게임과 스프라그-그런디(Sprague-Grundy) 정리

### 1. 부턴의 정리 (Bouton's Theorem, 1901)
돌무더기 크기열 $A_1, A_2, \dots, A_N$의 XOR 합을 **Nim-Sum**이라 합니다:
$$S = A_1 \oplus A_2 \oplus \dots \oplus A_N$$

- **$S \neq 0$ (P-포지션 / 선공 필승)**: 항상 적절한 돌무더기 하나에서 돌을 덜어내어 다음 사람에게 $S = 0$인 상태를 넘겨줄 수 있습니다.
- **$S = 0$ (N-포지션 / 후공 필승)**: 어떤 돌무더기에서 몇 개의 돌을 가져가든, 다음 상태의 Nim-Sum은 무조건 $0$이 아닌 상태($S \neq 0$)가 됩니다!
- 게임 종료 상태는 모든 돌이 0개인 상태로, $0 \oplus \dots \oplus 0 = 0$이므로 마지막 돌을 가져간 사람이 항상 $S=0$을 상대에게 주며 승리하게 됩니다.
