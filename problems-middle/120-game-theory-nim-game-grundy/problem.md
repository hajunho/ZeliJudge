# 돌무더기 게임의 필승 전략! 님(Nim) 게임과 스프라그-그런디 정리 (Game Theory Nim)

### 문제 설명
두 플레이어(선공 A와 후공 B)가 $N$개의 돌무더기를 두고 흥미진진한 **님(Nim) 게임**을 진행합니다.  
각 돌무더기 $i$에는 $A_i$개의 돌이 쌓여 있습니다.

두 사람은 번갈아 가며 턴을 진행하며, 자신의 턴에:
1. 돌이 남아 있는 돌무더기 하나를 선택합니다.
2. 그 돌무더기에서 **1개 이상의 돌**을 원하는 만큼(전부 가져가는 것도 가능) 가져옵니다.
3. 자신의 턴에 가져갈 돌이 전혀 없는 플레이어(마지막 돌을 상대방이 가져간 후)가 패배합니다. (정규 플레이 규칙)

두 사람이 모두 최선의 수만 둔다고 가정할 때,  
**선공(FIRST)**이 반드시 이기는지, 아니면 **후공(SECOND)**이 반드시 이기는지 판별하는 프로그램을 작성하세요.

찰스 부턴(Charles Bouton)의 수학적 정리에 따르면,  
모든 돌무더기 크기를 이진수로 변환하여 비트 단위 XOR 연산을 수행한 **Nim-Sum($A_1 \oplus A_2 \oplus \dots \oplus A_N$)**이 $0$인지 아닌지만 검사하면 **$O(N)$**에 승패를 즉시 판정할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 돌무더기의 개수 $N$ ($1 \le N \le 100000$)이 주어집니다.
- 둘째 줄에 각 돌무더기에 쌓인 돌의 개수 $A_1, A_2, \dots, A_N$ ($1 \le A_i \le 10^9$)이 공백으로 주어집니다.

---

### 출력 형식
- 선공이 승리하면 `FIRST`, 후공이 승리하면 `SECOND`를 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
3
3 4 5
```

#### 예제 출력 1
```
FIRST
```
- 설명: $3 \oplus 4 \oplus 5 = 2 \neq 0$이므로 선공이 필승 전략을 가지며, `FIRST`가 승리합니다.
