# N-Queen 문제와 백트래킹(퇴각 검색)의 정수

### 1. 상태 공간 트리의 가지치기(Pruning)
$N \times N$ 체스판에서 $N$개의 칸을 고르는 모든 조합은 $_N^2 C_N$으로 $N=8$일 때 약 44억 가지나 됩니다.  
하지만 **"한 행에는 오직 하나의 퀸만 올 수 있다"**는 원리를 적용하면 탐색 공간이 $N^N$으로 줄어듭니다.

여기에 더해 **"퀸을 놓을 때마다 열과 대각선 공격 범위를 검사하여 유망하지 않은 가지는 즉시 잘라내는(Pruning)"** 백트래킹을 적용하면 탐색 횟수가 극적으로 줄어듭니다.

---

### 2. 대각선 판별의 아름다운 수학적 성질
$(r, c)$ 좌표에서:
1. **우상향 대각선 (/)**: 같은 대각선 상의 모든 칸은 **$r + c$의 값이 일정**합니다 ($0 \le r+c < 2N$).
2. **우하향 대각선 (\)**: 같은 대각선 상의 모든 칸은 **$r - c$의 값이 일정**합니다 ($r - c + N$으로 인덱싱).

이 세 개의 불리언 배열(`col`, `diag1`, `diag2`)을 사용하면 매 배치마다 $O(1)$ 상수 시간에 충돌 여부를 즉시 판별할 수 있습니다!
