# 체스판의 평화! N-Queen 경우의 수 (Backtracking)

### 문제 설명
체스에서 가장 강력한 기물인 **퀸(Queen)**은 가로, 세로, 대각선 모든 방향으로 거리 제한 없이 이동하며 다른 말을 공격할 수 있습니다.

크기가 $N \times N$인 정사각형 체스판 위에 $N$개의 퀸을 서로가 서로를 전혀 공격할 수 없도록 배치하고자 합니다.  
즉, 어떤 두 퀸도 **같은 행, 같은 열, 같은 대각선 상에 놓이지 않아야** 합니다.

자연수 $N$이 주어졌을 때, 퀸 $N$개를 서로 공격받지 않게 배치할 수 있는 **총 경우의 수**를 구하세요.

---

### 입력 형식
- 첫째 줄에 체스판의 크기 $N$ ($1 \le N \le 10$)이 주어집니다.

---

### 출력 형식
- $N$개의 퀸을 배치할 수 있는 총 경우의 수를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
4
```

**출력**
```
2
```
*설명:*
- $4 \times 4$ 체스판에서는 (2, 4, 1, 3)과 (3, 1, 4, 2)의 대칭적인 2가지 배치만 가능합니다.

#### 예시 2
**입력**
```
1
```

**출력**
```
1
```
