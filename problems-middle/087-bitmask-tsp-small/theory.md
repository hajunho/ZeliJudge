# 외판원 순회 문제 (TSP)와 비트마스크 DP (Held-Karp 알고리즘)

### 1. 상태 압축(Bitmask)의 설계
$N$개 도시의 방문 여부를 $N$비트 이진수로 표현합니다.  
예: $N=4$에서 0번과 2번을 방문했다면 비트마스크는 `101 (2)` = 5.

### 2. 점화식
$$DP[mask][u]: \text{방문한 도시 집합이 } mask\text{이고 현재 위치가 } u\text{일 때의 최소 누적 비용}$$
현재 위치 $u$에서 아직 방문하지 않은 도시 $v$ ($mask \mathrel{\&} (1 \ll v) == 0$)로 이동할 때:
$$DP[mask \mid (1 \ll v)][v] = \min\Big(DP[mask \mid (1 \ll v)][v], DP[mask][u] + W[u][v]\Big)$$

모든 도시를 방문한 상태 $mask = 2^N - 1$에서 마지막 도시 $u$에서 시작점 0으로 복귀하는 비용 $W[u][0]$을 더해 최솟값을 구합니다.
시간 복잡도는 $O(N^2 2^N)$으로 $N \le 12$에서 순식간에 작동합니다.
