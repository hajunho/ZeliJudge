# 사각부등식의 기적! 크누스 최적화 구간 DP (Knuth's Optimization)

### 문제 설명
크기가 $A_1, A_2, \dots, A_N$인 $N$개의 연속된 파일이 있습니다.  
인접한 두 파일을 하나로 합칠 때마다 두 파일 크기의 합만큼의 비용이 발생합니다.  
모든 파일을 최종적으로 단 하나의 파일로 합치려고 할 때, **필요한 최소 총비용**을 구하는 프로그램을 작성하세요.

일반적인 구간 DP는 점화식:
$$DP[i][j] = \min_{i \le k < j} \Big( DP[i][k] + DP[k+1][j] \Big) + \sum_{m=i}^j A_m$$
을 계산하는 데 3중 루프로 $O(N^3)$이 걸립니다.  
하지만 비용 함수가 사각부등식(Quadrangle Inequality)을 만족할 때 성립하는 **크누스 최적화(Knuth's Optimization)**를 사용하면:
$$opt[i][j-1] \le opt[i][j] \le opt[i+1][j]$$
최적 분할점 $k$의 탐색 범위가 좌우 구간의 최적점에 의해 완벽하게 제한되어, **전체 시간 복잡도가 $O(N^2)$**으로 획기적으로 단축됩니다!

---

### 입력 형식
- 첫째 줄에 파일의 개수 $N$ ($1 \le N \le 500$)이 주어집니다.
- 둘째 줄에 $N$개 파일의 크기가 공백으로 주어집니다. ($1 \le A_i \le 10000$)

---

### 출력 형식
- 모든 파일을 하나로 합치는 데 필요한 최소 비용을 정수로 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4
40 30 30 50
```

#### 예제 출력 1
```
300
```
- 설명: (30 + 30 = 60) $\to$ (40 + 60 = 100) $\to$ (100 + 50 = 150) 합산 비용 = $60 + 100 + 150 = 310$보다,  
  (40 + 30 = 70)과 (30 + 50 = 80)을 합친 후 (70 + 80 = 150)으로 합치면 $70 + 80 + 150 = 300$으로 최소가 됩니다.
