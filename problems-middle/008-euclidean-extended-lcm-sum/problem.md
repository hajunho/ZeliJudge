# 분수 통분의 달인! N개 분수의 통분과 덧셈

## 📖 문제 설명
중학교 수학에서 배우는 유리수의 덧셈! 분모가 서로 다른 N개의 분수를 더하려면 먼저 모든 분모들의 '최소공배수(LCM)'를 구하여 통분해야 합니다. 통분하여 분자들을 모두 더한 뒤, 다시 분자와 분모를 최대공약수(GCD)로 약분하여 가장 깔끔한 기약분수로 나타내는 만능 분수 계산기를 만들어보세요!

## 📥 입력 형식
첫 줄에 분수의 개수 N (1 <= N <= 50)이 주어집니다.\n다음 N개의 줄에 걸쳐 각 분수의 분자 a와 분모 b가 공백으로 주어집니다. (1 <= a, b <= 100)

## 📤 출력 형식
모든 분수의 합을 기약분수 형태(p/q)로 출력합니다. 만약 합이 자연수라면 p 형태로 정수만 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
3
1 2
1 3
1 6
```
**출력**
```text
1
```

## 힌트
N개의 단위 또는 일반 분수(ai/bi)의 합을 최소공배수(LCM)로 통분하여 계산하고 가장 간단한 기약분수 형태로 출력합니다.
