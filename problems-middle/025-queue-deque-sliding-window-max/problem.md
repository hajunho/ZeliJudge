# 움직이는 창문 속 최댓값! 슬라이딩 윈도우 덱 (Sliding Window Maximum)

## 📖 문제 설명
여름철 N일간의 기온 기록이 있습니다. 기상청에서는 연속 K일 동안의 기간 중 '가장 더웠던 날의 최고 기온'을 매일매일 연속으로 전광판에 표시하려고 합니다. 매 구간마다 K개의 값을 새로 훑으면 O(N * K)가 걸리지만, 양방향 큐(deque)를 활용하면 원소가 들어오고 나갈 때마다 O(1)에 항상 최댓값을 유지할 수 있습니다! 각 창문의 최댓값을 차례대로 출력하세요.

## 📥 입력 형식
첫 줄에 수열의 길이 N과 윈도우 크기 K가 공백으로 주어집니다. (1 <= K <= N <= 100,000)\n둘째 줄에 N개의 정수가 공백으로 주어집니다.

## 📤 출력 형식
윈도우가 이동할 때마다 각 윈도우 구간의 최댓값(총 N - K + 1개)을 공백으로 구분하여 한 줄에 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
8 3
1 3 -1 -3 5 3 6 7
```
**출력**
```text
3 3 5 5 6 7
```

## 힌트
길이 N의 수열에서 크기 K의 윈도우가 오른쪽으로 한 칸씩 이동할 때 각 윈도우 구간의 최댓값을 구합니다.
