# 비교 없이 정렬한다?! 계수 정렬 (Counting Sort)

## 📖 문제 설명
보통 두 수를 비교하며 정렬하면 아무리 빨라도 O(N log N)의 시간이 걸립니다. 하지만 중학교 1학년 때 배운 '도수분포표(Frequency Table)'처럼, 각 숫자가 몇 번 나왔는지만 카운트 배열에 센 다음 순서대로 출력하면 원소 간 비교 없이 O(N + K)만에 정렬을 끝낼 수 있습니다! 계수 정렬 알고리즘을 구현해보세요.

## 📥 입력 형식
첫 줄에 정수의 개수 N (1 <= N <= 100,000)이 주어집니다.\n둘째 줄에 0 이상 1,000 이하의 정수 N개가 공백으로 주어집니다.

## 📤 출력 형식
오름차순으로 정렬된 정수들을 공백으로 구분하여 한 줄에 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
5
5 2 3 1 4
```
**출력**
```text
1 2 3 4 5
```

## 힌트
0 이상 1,000 이하의 자연수 N개가 주어질 때 도수분포표 원리를 이용한 계수 정렬로 O(N + K)에 오름차순 정렬합니다.
