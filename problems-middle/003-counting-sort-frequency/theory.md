# 계수 정렬 (Counting Sort)

## 1. 비교 정렬 vs 계수 정렬
- 퀵 정렬이나 병합 정렬은 원소들을 **서로 크기 비교**하며 정렬하므로 최선이어도 $O(N \log N)$입니다.
- 하지만 값의 범위($K$)가 제한되어 있다면(예: 0 ~ 1,000), 값의 출현 횟수를 세는 **계수 정렬(Counting Sort)**로 $O(N + K)$만에 정렬할 수 있습니다!

## 2. 계수 정렬의 3단계
1. `count` 배열을 값의 최댓값 크기만큼 0으로 초기화합니다.
2. 입력 데이터를 하나씩 읽으며 `count[x] += 1`을 수행합니다 ($O(N)$).
3. `0`번 인덱스부터 최댓값까지 순회하며, 카운트된 횟수만큼 숫자를 차례대로 출력합니다 ($O(K)$).
