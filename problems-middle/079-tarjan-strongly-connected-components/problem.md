# 서로가 서로에게 닿는 단짝 그룹! 강한 연결 요소 (Tarjan SCC)

### 문제 설명
방향 그래프에서 두 정점 $u$와 $v$ 사이에 $u \to v$ 경로와 $v \to u$ 경로가 모두 존재할 때, 두 정점은 **상호 도달 가능**하다고 합니다.  
그래프 내에서 모든 정점 쌍이 서로 상호 도달 가능한 최대 부분 그래프들을 **강한 연결 요소(Strongly Connected Component, SCC)**라고 부릅니다.

방향 그래프의 정점 수 $V$와 간선 수 $E$가 주어질 때:
1. 그래프에 존재하는 **SCC의 총 개수**를 구하세요.
2. 각 SCC에 속한 정점들을 오름차순으로 정렬하고, 각 SCC의 가장 작은 정점 번호를 기준으로 SCC들을 오름차순 정렬하여 출력하세요.

타잔(Tarjan) 알고리즘을 사용하면 단 한 번의 깊이 우선 탐색(DFS) $O(V + E)$만으로 모든 SCC를 분해할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 정점의 수 $V$ ($1 \le V \le 1000$)와 방향 간선의 수 $E$ ($0 \le E \le 5000$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개의 줄에 걸쳐 방향 간선 $u, v$ ($1 \le u, v \le V$)가 주어집니다. ($u$에서 $v$로 가는 방향)

---

### 출력 형식
- 첫째 줄에 발견된 SCC의 총 개수를 출력합니다.
- 둘째 줄부터 각 SCC에 속한 정점 번호들을 공백으로 구분하여 한 줄에 하나씩 출력합니다. (각 줄의 정점들은 오름차순, 줄의 순서는 첫 번째 정점 번호 기준 오름차순)

---

### 입출력 예시

#### 예제 입력 1
```
5 5
1 2
2 3
3 1
3 4
4 5
```

#### 예제 출력 1
```
3
1 2 3
4
5
```
- 설명: 1, 2, 3은 서로 순환하므로 하나의 SCC `{1, 2, 3}`을 이룹니다. 4와 5는 되돌아오는 간선이 없으므로 각각 단독 SCC `{4}`, `{5}`가 됩니다.
