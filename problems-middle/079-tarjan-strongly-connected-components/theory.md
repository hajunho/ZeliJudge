# 타잔(Tarjan)의 강한 연결 요소 (SCC) 알고리즘

### 1. 강한 연결 요소 (SCC)의 개념
방향 그래프를 SCC 단위로 묶어 하나의 거대 정점으로 치환(Condensation)하면, 사이클이 완전히 사라진 **방향 비순환 그래프(DAG)**가 됩니다!
이를 통해 2-SAT 문제, 컴파일러의 순환 종속성 분석, 웹 페이지 클러스터링 등을 해결할 수 있습니다.

### 2. 타잔 알고리즘의 원리
DFS 트리에서 각 정점 $u$마다:
- `dfn[u]`: DFS 탐색 중 $u$를 처음 방문한 순번
- `low[u]`: $u$를 루트로 하는 서브트리에서 역방향 간선을 타고 도달할 수 있는 가장 작은 `dfn` 번호
- 노드를 방문할 때마다 스택에 넣고, 자식 탐색을 마친 뒤 `low[u] == dfn[u]`라면 $u$가 이 SCC의 루트 노드이므로, 스택에서 $u$가 나올 때까지 꺼내어 하나의 SCC로 묶습니다.
