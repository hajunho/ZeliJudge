# 트리 동적 계획법(Tree DP)의 기초

### 1. 트리와 서브트리의 재귀적 구조
트리는 **"루트 노드와 여러 개의 서브트리들의 결합"**으로 이루어져 있습니다.  
따라서 트리의 어떤 성질을 계산할 때는 **자식들의 결과를 먼저 모아 부모에게 전달하는 후위 순회(Post-order / Bottom-Up)** 방식이 가장 자연스럽습니다.

---

### 2. 점화식
노드 $u$의 서브트리 크기를 $Size(u)$라 하면:

$$Size(u) = 1 + \sum_{v \in Children(u)} Size(v)$$

- 리프 노드는 자식이 없으므로 $Size(leaf) = 1$.
- 부모 노드는 자식 노드들의 크기 합에 자기 자신(1)을 더합니다.

BFS 순서의 역순(아래에서 위로)으로 순회하면 재귀 콜 스택 오버플로우 걱정 없이 $O(N)$ 선형 시간에 완벽히 계산할 수 있습니다.
