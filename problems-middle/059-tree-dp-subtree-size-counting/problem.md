# 우리 부서 식구는 모두 몇 명? 트리의 서브트리 크기 (Tree DP)

### 문제 설명
어느 회사의 조직도는 1번 대표이사(루트)를 필두로 $N$명의 임직원이 트리 형태로 연결되어 있습니다.  
모든 직원은 자신을 루트로 하는 **하위 부서(서브트리, Subtree)**를 이끌고 있습니다.

각 직원 $i$에 대해, **자신을 포함하여 자신의 모든 직속 부하 및 부하의 부하들을 합친 총 인원수(서브트리의 노드 개수)**를 구해야 합니다.

1번 대표이사부터 시작하는 트리에서 후위 순회 또는 상향식 트리 DP(Tree DP)를 사용하여,  
$1$번 직원부터 $N$번 직원까지 각자의 서브트리 크기를 차례대로 출력하세요.

---

### 입력 형식
- 첫째 줄에 직원의 수 $N$ ($1 \le N \le 1000$)이 주어집니다.
- 둘째 줄부터 $N-1$개 줄에 걸쳐 회사 조직도의 연결 관계 $u, v$가 주어집니다. (1번이 루트)

---

### 출력 형식
- 1번 직원부터 $N$번 직원까지, 각 직원의 서브트리 크기를 공백으로 구분하여 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
5
1 2
1 3
2 4
2 5
```

**출력**
```
5 3 1 1 1
```
*설명:*
- 4번과 5번: 부하가 없으므로 자기 자신 1명
- 2번: 자신(1) + 4번(1) + 5번(1) = 3명
- 3번: 부하가 없으므로 1명
- 1번(대표): 전사 직원 총 5명
