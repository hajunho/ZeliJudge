# 어느 도시를 수도로 삼을까? 전방향 트리 DP (Tree Re-rooting DP)

### 문제 설명
$N$개의 도시와 도시들을 잇는 $N-1$개의 도로(모든 도로 길이 1)로 이루어진 트리가 있습니다.  
물류 효율을 위해, 왕국의 각 도시 $u$ ($1 \le u \le N$)마다 **그 도시에서 다른 모든 도시까지의 거리의 합($\sum_{v=1}^N \text{dist}(u, v)$)**을 모두 구하려고 합니다.

각 도시마다 BFS를 따로 돌리면 $O(N^2)$이 걸려 도시가 많아지면 비효율적입니다.  
하지만 **루트를 바꾸며 전이하는 전방향 트리 DP(Tree Re-rooting DP)**를 사용하면:
1. 1번 노드를 임시 루트로 삼아 서브트리 크기 $sz[v]$와 1번 노드의 총 거리 합을 구하고(1차 DFS),
2. 부모 $u$에서 인접한 자식 $v$로 루트를 옮길 때, $v$ 서브트리의 노드들은 거리가 1 가까워지고($-sz[v]$), 나머지 노드들은 거리가 1 멀어지는($+ (N - sz[v])$) 우아한 전이식:
   $$\text{ans}[v] = \text{ans}[u] - sz[v] + (N - sz[v])$$
을 통해 **단 두 번의 DFS 순회($O(N)$)**만으로 모든 노드의 전역 거리 합을 계산할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 노드의 수 $N$ ($1 \le N \le 100000$)이 주어집니다.
- 둘째 줄부터 $N-1$개의 줄에 걸쳐 트리의 간선 $u, v$ ($1 \le u, v \le N$)가 주어집니다.

---

### 출력 형식
- 1번 노드부터 $N$번 노드까지 각 노드에서 다른 모든 노드까지의 거리의 총합을 공백으로 구분하여 한 줄에 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4
1 2
2 3
2 4
```

#### 예제 출력 1
```
5 3 5 5
```
- 설명: 
  - 1번에서 거리 합: 2번(1) + 3번(2) + 4번(2) = 5
  - 2번에서 거리 합: 1번(1) + 3번(1) + 4번(1) = 3 (중심 도시)
  - 3번에서 거리 합: 2번(1) + 1번(2) + 4번(2) = 5
  - 4번에서 거리 합: 2번(1) + 1번(2) + 3번(2) = 5
