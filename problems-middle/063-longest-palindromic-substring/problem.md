# 회문 거울 문자열! 최장 팰린드롬 부분 문자열 (Palindrome)

### 문제 설명
앞으로 읽으나 뒤로 읽으나 똑같은 문자열을 **팰린드롬(Palindrome, 회문)**이라고 부릅니다.  
예를 들어 `racecar`, `noon`, `level` 등이 대표적인 팰린드롬입니다.

문자열 $S$가 주어졌을 때, $S$의 연속된 부분 문자열(Substring) 중에서 **가장 길이가 긴 팰린드롬의 길이**를 구하세요.

---

### 입력 형식
- 첫째 줄에 알파벳 소문자로 구성된 문자열 $S$가 주어집니다. ($1 \le |S| \le 1000$)

---

### 출력 형식
- 가장 긴 팰린드롬 부분 문자열의 길이를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
babad
```

**출력**
```
3
```
*설명:*
- `bab` 또는 `aba`가 길이 3의 가장 긴 팰린드롬입니다.

#### 예시 2
**입력**
```
cbbd
```

**출력**
```
2
```
*설명:*
- `bb`가 길이 2의 가장 긴 팰린드롬입니다.
