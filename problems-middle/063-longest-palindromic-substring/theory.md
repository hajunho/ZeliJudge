# 중심 확장법(Center Expansion)으로 팰린드롬 찾기

### 1. 팰린드롬의 대칭 중심
모든 팰린드롬은 반드시 어떤 "중심(Center)"을 기준으로 좌우 대칭을 이룹니다:
1. **홀수 길이 팰린드롬** (예: `aba`): 문자 1개가 중심 ($i$)
2. **짝수 길이 팰린드롬** (예: `abba`): 두 문자 사이가 중심 ($i, i+1$)

---

### 2. 중심 확장 알고리즘
길이 $N$의 문자열에는 총 $2N - 1$개의 대칭 중심 후보가 있습니다.  
각 중심에서 출발하여 좌우로 한 칸씩 벌려가며(`left -= 1, right += 1`) 글자가 일치하는 동안 확장합니다:

```python
def expand(left, right):
    while left >= 0 and right < n and s[left] == s[right]:
        left -= 1
        right += 1
    return right - left - 1
```
시간 복잡도는 $O(N^2)$이며, 별도의 추가 메모리 없이 $O(1)$ 공간으로 가장 직관적이고 빠르게 동작합니다.
