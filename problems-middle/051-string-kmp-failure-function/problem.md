# 패턴 매칭의 나침반! KMP 실패 함수 (Failure Function)

### 문제 설명
인터넷 검색 엔진 개발팀의 다은이는 방대한 문서에서 특정 검색어(패턴)를 초고속으로 찾는 **KMP(Knuth-Morris-Pratt)** 알고리즘을 공부하고 있습니다.

단순 비교 방식은 글자가 불일치할 때마다 처음으로 되돌아가 다시 비교하므로 최악의 경우 $O(N \times M)$의 오랜 시간이 걸립니다.  
하지만 KMP 알고리즘은 패턴 문자열 자체를 미리 분석해 두어, 불일치가 발생했을 때 **"어디까지 이미 일치했으므로 건너뛰어도 되는지"**를 알려주는 **실패 함수(Failure Function, $\pi$ 배열)**를 활용하여 $O(N + M)$ 선형 시간에 검색을 끝냅니다.

$\pi[i]$는 패턴의 $0$번째 문자부터 $i$번째 문자까지의 부분 문자열에서,  
**접두사(Prefix)이면서 동시에 접미사(Suffix)가 되는 가장 긴 문자열의 길이**를 의미합니다.  
(단, 자기 자신 전체는 제외합니다.)

예를 들어 패턴 `ABABC`의 실패 함수는 다음과 같습니다:
- `A` (i=0): 접두사=접미사 없음 $\to 0$
- `AB` (i=1): 일치 없음 $\to 0$
- `ABA` (i=2): `A` 일치 $\to 1$
- `ABAB` (i=3): `AB` 일치 $\to 2$
- `ABABC` (i=4): 일치 없음 $\to 0$
- 결과: `0 0 1 2 0`

패턴 문자열 $P$가 주어졌을 때, KMP의 핵심인 **실패 함수 배열 $\pi$**를 구하세요.

---

### 입력 형식
- 첫째 줄에 알파벳 대문자로 구성된 패턴 문자열 $P$가 주어집니다. ($1 \le |P| \le 1000$)

---

### 출력 형식
- $\pi[0]$부터 $\pi[|P|-1]$까지의 값을 공백으로 구분하여 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
ABABC
```

**출력**
```
0 0 1 2 0
```

#### 예시 2
**입력**
```
AAAA
```

**출력**
```
0 1 2 3
```
