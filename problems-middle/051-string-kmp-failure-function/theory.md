# KMP 알고리즘과 실패 함수(Failure Function)

### 1. 접두사(Prefix)와 접미사(Suffix)
- 문자열 $S = \text{"ABCAB"}$
  - 접두사: `A`, `AB`, `ABC`, `ABCA`
  - 접미사: `B`, `AB`, `CAB`, `BCAB`
  - 공통 부분: `AB` (길이 2)

### 2. 실패 함수의 점화식과 투 포인터
실패 함수 $\pi$를 구할 때도 KMP 자체의 원리를 사용합니다:
- 포인터 $i$는 1부터 $N-1$까지 전진하고, 포인터 $j$는 현재 일치하는 접두사의 길이를 가리킵니다.
- 만약 $P[i] \ne P[j]$ 라면, $j$를 이전 일치 위치인 $\pi[j-1]$로 되돌립니다 (점프!).
- 일치하면 $j$를 1 증가시키고 $\pi[i] = j$를 기록합니다.

```python
pi = [0] * n
j = 0
for i in range(1, n):
    while j > 0 and P[i] != P[j]:
        j = pi[j - 1]
    if P[i] == P[j]:
        j += 1
        pi[i] = j
```
이 전처리 과정은 패턴 길이 $M$에 대해 정확히 **$O(M)$** 시간에 완료됩니다.
