# 섬의 둘레 (Island Perimeter) 계산

각각의 육지 칸(`grid[r][c] == 1`)은 원래 **4개의 변**을 가지고 있습니다.

## 1. 변이 둘레로 카운트되는 조건
육지 칸 $(r, c)$의 상, 하, 좌, 우 4개 이웃 $(nr, nc)$에 대해:
- 이웃이 **지도 바깥(`nr < 0 or nr >= R or nc < 0 or nc >= C`)**이거나,
- 이웃이 **물(`grid[nr][nc] == 0`)**이라면
그 맞닿은 1개의 변은 **해안선 둘레**가 됩니다!

따라서 모든 육지 칸에 대해 상하좌우를 확인하고, 경계 밖이거나 물인 이웃의 개수만큼 둘레를 1씩 더해주면 완벽한 $O(R \times C)$에 계산할 수 있습니다!
