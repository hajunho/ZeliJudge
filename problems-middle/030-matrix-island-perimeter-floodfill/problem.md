# 호수 속 섬의 해안선 둘레! (Island Perimeter)

## 📖 문제 설명
지도 위에서 1은 육지 타일, 0은 호수 물 타일입니다. 각 육지 타일은 가로 1m x 세로 1m 크기의 정사각형입니다. 섬의 해안선 둘레는 육지 타일의 4개 변 중에서 '물과 맞닿아 있거나 지도의 가장자리 바깥과 맞닿아 있는 변의 총합'으로 정의됩니다. 인공위성 지도가 주어질 때 섬의 총 해안선 둘레(m)를 계산해주세요!

## 📥 입력 형식
첫 줄에 지도의 크기 행 R과 열 C가 공백으로 주어집니다. (1 <= R, C <= 100)\n다음 R개의 줄에 걸쳐 각 행의 C개 정수(0 또는 1)가 공백으로 주어집니다.

## 📤 출력 형식
섬의 총 둘레를 단일 정수로 출력합니다. (육지가 없으면 0을 출력합니다)

## 💡 입출력 예시
### 예시 1
**입력**
```text
4 4
0 1 0 0
1 1 1 0
0 1 0 0
1 1 0 0
```
**출력**
```text
16
```

## 힌트
R x C 격자 지도에서 육지(1)로 이루어진 섬의 총 둘레(물(0) 또는 지도 바깥과 맞닿은 변의 개수)를 계산합니다.
