# 고대 수학자의 암호 풀이! 중국인의 나머지 정리 (CRT)

### 문제 설명
고대 중국의 수학서 《손자산경》에는 다음과 같은 유명한 수수께끼가 적혀 있습니다:
> "3으로 나누었을 때 2가 남고, 5로 나누었을 때 3이 남는 가장 작은 양의 정수는 무엇인가?"

두 양의 정수 $m_1$과 $m_2$가 서로소($\gcd(m_1, m_2) = 1$)일 때, 다음 연립 합동식을 만족하는 **가장 작은 양의 정수 $X$**를 구하는 프로그램을 작성하세요:
$$X \equiv r_1 \pmod{m_1}$$
$$X \equiv r_2 \pmod{m_2}$$

중국인의 나머지 정리(Chinese Remainder Theorem, CRT)와 **확장 유클리드 호제법**을 활용하면, $m_1 \times m_2$의 크기가 아무리 커도 단 $O(\log(\min(m_1, m_2)))$만에 정확한 해를 도출할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 정수 $r_1, m_1, r_2, m_2$가 공백으로 주어집니다.  
  ($0 \le r_1 < m_1, 0 \le r_2 < m_2, 2 \le m_1, m_2 \le 10^9, \gcd(m_1, m_2) = 1$)

---

### 출력 형식
- 두 합동식을 동시에 만족하는 가장 작은 **양의 정수 $X$** ($1 \le X \le m_1 \cdot m_2$)를 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
2 3 3 5
```

#### 예제 출력 1
```
8
```
- 설명: $8 = 3 \times 2 + 2$ (3으로 나누면 2가 남음), $8 = 5 \times 1 + 3$ (5로 나누면 3이 남음). 가장 작은 양의 정수는 8입니다.
