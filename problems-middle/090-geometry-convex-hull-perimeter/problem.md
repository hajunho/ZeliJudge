# 점들을 둘러싸는 울타리의 총 둘레! 볼록 껍질 둘레 계산 (Convex Hull Perimeter)

### 문제 설명
평면 위에 $N$개의 점(기둥)이 위치해 있습니다.  
이 모든 점들을 내부에 완벽히 포함하도록 가장 바깥쪽 점들을 둘러싸는 **볼록 껍질(Convex Hull)** 형태의 울타리를 치려고 합니다.

이 울타리를 완성하는 데 필요한 **총 둘레의 길이(Perimeter)**를 구하는 프로그램을 작성하세요.

- 점들의 중복이 있을 수 있습니다.
- 결과는 소수점 둘째 자리까지 반올림하여 출력합니다. (예: `40.00`)

---

### 입력 형식
- 첫째 줄에 점의 개수 $N$ ($1 \le N \le 50000$)이 주어집니다.
- 둘째 줄부터 $N$개의 줄에 걸쳐 각 점의 정수 좌표 $x, y$ ($-10^4 \le x, y \le 10^4$)가 공백으로 주어집니다.

---

### 출력 형식
- 볼록 껍질의 총 둘레를 소수점 둘째 자리까지 형식화(`{perimeter:.2f}`)하여 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5
0 0
10 0
0 10
10 10
5 5
```

#### 예제 출력 1
```
40.00
```
- 설명: 외곽 꼭짓점은 $(0,0), (10,0), (10,10), (0,10)$의 정사각형(한 변 10)을 이루며 중심점 $(5,5)$는 내부에 포함됩니다. 둘레는 $10 \times 4 = 40.00$입니다.
