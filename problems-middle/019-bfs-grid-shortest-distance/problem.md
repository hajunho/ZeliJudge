# 2차원 미로 최단 탈출로! 너비 우선 탐색 (2D Grid BFS)

## 📖 문제 설명
비밀 미로에 갇힌 로봇 젤리가 출구를 찾아 탈출하려 합니다. 미로는 R x C 크기의 격자로, 0은 지나갈 수 있는 길이고 1은 막힌 벽입니다. 로봇은 상하좌우 인접한 길로 1칸씩 이동할 수 있습니다. 시작점 (0, 0)에서 출구 (R-1, C-1)까지 도달하기 위한 최소 이동 칸 수(시작 칸과 끝 칸 포함)를 구해주세요! 만약 도달할 수 없다면 -1을 출력합니다.

## 📥 입력 형식
첫 줄에 행의 수 R과 열의 수 C가 공백으로 주어집니다. (2 <= R, C <= 50)\n다음 R개의 줄에 걸쳐 공백 없이 0과 1로 이루어진 길이 C의 문자열이 주어집니다. (0: 길, 1: 벽. (0, 0)과 (R-1, C-1)은 항상 0입니다)

## 📤 출력 형식
시작점부터 출구까지 지나가는 최소 칸 수를 정수로 출력합니다. 탈출이 불가능하면 -1을 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
4 4
0000
1110
0000
0110
```
**출력**
```text
7
```

## 힌트
R x C 미로에서 시작점 (0, 0)부터 출구 (R-1, C-1)까지 도달하는 최단 이동 칸 수를 BFS로 구합니다.
