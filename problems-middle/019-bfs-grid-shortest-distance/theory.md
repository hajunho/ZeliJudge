# 너비 우선 탐색 (BFS, Breadth-First Search)

모든 간선의 이동 비용이 1로 동일한 미로에서는, **너비 우선 탐색(BFS)**을 사용해야 항상 최단 경로를 보장할 수 있습니다!

## 1. BFS가 최단 경로를 보장하는 이유
BFS는 시작점에서 **거리 1인 칸들을 모두 방문한 뒤, 거리 2인 칸들, 거리 3인 칸들...** 순서로 물결이 퍼져나가듯 큐에 넣고 탐색합니다. 따라서 목적지에 가장 먼저 도달했을 때의 거리가 무조건 최단 거리입니다!

## 2. 알고리즘
1. `dist[R][C]` 배열을 `-1`로 초기화하고, `dist[0][0] = 1`로 시작합니다.
2. 큐에 `(0, 0)`을 넣습니다.
3. 큐에서 현재 좌표 `(r, c)`를 꺼내 상하좌우 4방향을 확인합니다.
4. 다음 좌표 `(nr, nc)`가 격자 범위 안이고, 벽이 아니며(`grid[nr][nc] == '0'`), 아직 방문하지 않았다면(`dist[nr][nc] == -1`):
   - `dist[nr][nc] = dist[r][c] + 1`
   - 큐에 `(nr, nc)`를 추가합니다.
5. 출구에 도달하면 `dist[R-1][C-1]`을 출력합니다.
