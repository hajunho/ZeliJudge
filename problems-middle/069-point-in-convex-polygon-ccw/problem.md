# 안전 구역 안일까 밖일까? 볼록 다각형 내부 점 판별 (CCW)

### 문제 설명
게임 맵 상에 $N$개의 꼭짓점으로 이루어진 볼록 다각형 형태의 안전 구역(Safe Zone)이 설정되어 있습니다.  
꼭짓점들은 **반시계 방향(Counter-Clockwise)** 순서대로 주어집니다.

플레이어의 캐릭터 위치 좌표 $P(x, y)$가 주어졌을 때,  
플레이어가 **안전 구역의 내부(또는 테두리 경계선 위)에 있다면 `1`**,  
**안전 구역 바깥에 있다면 `0`**을 출력하는 프로그램을 작성하세요.

세 점의 방향성을 판별하는 CCW 알고리즘을 사용하면,  
다각형의 모든 변 벡터에 대해 점 $P$가 항상 왼쪽에 위치하는지(CCW $\ge 0$) 확인하여 판별할 수 있습니다.

---

### 입력 형식
- 첫째 줄에 볼록 다각형의 꼭짓점 개수 $N$ ($3 \le N \le 100$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 반시계 방향 순서대로 꼭짓점 좌표 $x_i, y_i$가 주어집니다.
- 마지막 줄에 점 $P$의 좌표 $x, y$가 주어집니다. (모든 좌표는 $-10000$ 이상 $10000$ 이하의 정수)

---

### 출력 형식
- 점 $P$가 볼록 다각형 내부 또는 경계선에 있으면 `1`, 바깥에 있으면 `0`을 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
4
0 0
4 0
4 4
0 4
2 2
```

**출력**
```
1
```
*설명:*
- (2, 2)는 가로세로 4인 정사각형의 정중앙 내부이므로 1입니다.

#### 예시 2
**입력**
```
3
0 0
5 0
0 5
6 6
```

**출력**
```
0
```
