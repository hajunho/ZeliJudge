# 참일까 거짓일까? 2-SAT과 함의 그래프 (2-Satisfiability via SCC)

### 문제 설명
$N$개의 불리언(Boolean) 변수 $x_1, x_2, \dots, x_N$과 이들로 이루어진 $M$개의 2-CNF 절(Clause)이 주어집니다.  
각 절은 $(u \lor v)$의 형태이며, 여기서 $u, v$는 변수 $x_i$ 또는 그 부정인 $\neg x_i$입니다.

모든 절을 동시에 참(True)으로 만족시키는 진리값 배정이 존재하는지 판별하는 문제를 **2-SAT (2-Satisfiability)**이라고 부릅니다.
- 3-SAT은 NP-완전 문제이지만, **2-SAT은 강한 연결 요소(SCC)를 이용해 $O(N + M)$ 선형 시간에 완벽히 해결**할 수 있습니다!

논리식 $(u \lor v)$는 두 개의 함의 관계와 동치입니다:
$$(\neg u \implies v) \quad \text{and} \quad (\neg v \implies u)$$
이 함의 관계를 방향 그래프의 간선으로 모델링한 뒤, **어떤 변수 $x_i$에 대해 $x_i$와 $\neg x_i$가 서로 같은 강한 연결 요소(SCC)에 속해 있다면**,  
$x_i \implies \neg x_i$와 $\neg x_i \implies x_i$가 모두 성립하여 모순이 발생하므로 만족이 불가능합니다!

---

### 입력 형식
- 첫째 줄에 변수의 개수 $N$ ($1 \le N \le 1000$)과 절의 개수 $M$ ($1 \le M \le 5000$)이 공백으로 주어집니다.
- 둘째 줄부터 $M$개의 줄에 걸쳐 각 절의 두 리터럴 $u, v$ ($-N \le u, v \le N, u, v \neq 0$)가 주어집니다.  
  (양수 $i$는 $x_i$를, 음수 $-i$는 $\neg x_i$를 의미합니다.)

---

### 출력 형식
- 만족시키는 진리값 배정이 존재하면:
  - 첫째 줄에 `1`을 출력합니다.
  - 둘째 줄에 $x_1, x_2, \dots, x_N$의 진리값을 0(거짓) 또는 1(참)로 공백으로 구분하여 출력합니다.
- 만족시키는 배정이 불가능하면 첫째 줄에 `0`만 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
3 4
1 2
-1 3
-2 -3
1 3
```

#### 예제 출력 1
```
1
1 0 1
```
