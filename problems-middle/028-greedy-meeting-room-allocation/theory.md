# 활동 선택 문제 (Activity Selection Problem)

## 1. 그리디 선택 기준: 왜 '끝나는 시간'일까요?
- 시작 시간이 빠른 순? $\rightarrow$ 회의가 새벽에 시작해서 밤늦게 끝나면 다른 회의를 하나도 못 합니다.
- 회의 시간이 짧은 순? $\rightarrow$ 반례가 존재합니다.
- **끝나는 시간이 가장 빠른 회의**를 고르면, **남은 시간이 가장 많이 확보**되므로 이후에 더 많은 회의를 선택할 가능성이 항상 극대화됩니다!

## 2. 알고리즘
1. 모든 회의를 **끝나는 시간(1차 오름차순)**, **시작 시간(2차 오름차순)** 기준으로 정렬합니다.
2. 이전 회의의 종료 시간 `last_end`를 0으로 둡니다.
3. 각 회의에 대해 `s >= last_end`라면 회의를 선택하고, `count += 1`, `last_end = e`로 갱신합니다.
