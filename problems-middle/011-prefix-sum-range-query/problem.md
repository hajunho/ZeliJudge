# 구간 합의 지름길! 1차원 누적합(Prefix Sum)과 O(1) 쿼리

## 📖 문제 설명
도서관 사서 젤리는 N일 동안 매일매일 대출된 도서 권수 기록을 관리하고 있습니다. 수시로 'L일부터 R일까지 총 몇 권이 대출되었나요?'라는 질문(Query)이 Q번 쏟아집니다. 매번 L부터 R까지 반복문으로 더하면 O(N * Q)로 시간이 너무 오래 걸리지만, 미리 누적합(Prefix Sum)을 구해두면 단 한 번의 뺄셈 O(1)으로 답할 수 있습니다! 구간 합을 출력해주세요.

## 📥 입력 형식
첫 줄에 수열의 길이 N과 쿼리의 수 Q가 공백으로 주어집니다. (1 <= N, Q <= 100,000)\n둘째 줄에 N개의 정수가 공백으로 주어집니다. (각 정수의 절댓값 <= 1,000)\n다음 Q개의 줄에 걸쳐 각 쿼리의 구간 시작일 L과 끝일 R이 1-based 인덱스로 공백으로 주어집니다. (1 <= L <= R <= N)

## 📤 출력 형식
각 쿼리마다 L번째부터 R번째까지의 원소 총합을 한 줄에 하나씩 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
5 3
10 20 30 40 50
1 3
2 4
3 5
```
**출력**
```text
60
90
120
```

## 힌트
길이 N의 수열에서 Q개의 구간 [L, R] 합 쿼리를 누적합 배열 S를 이용해 O(1)에 빠르게 계산하여 출력합니다.
