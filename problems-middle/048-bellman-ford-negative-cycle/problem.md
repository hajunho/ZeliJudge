# 타임머신과 시간 왜곡! 벨만-포드(Bellman-Ford) 최단 경로

### 문제 설명
SF 과학 탐험대 민서는 우주선 웜홀 항로를 연구하고 있습니다.  
$V$개의 우주 정거장 사이에 $E$개의 일방통행 웜홀이 존재합니다.  
특이하게도 어떤 웜홀은 통과할 때 시간이 오히려 과거로 되돌아가는 **음의 가중치(음수 시간 소요)**를 가지고 있습니다!

다익스트라 알고리즘은 음수 가중치가 있으면 오작동하지만,  
**벨만-포드(Bellman-Ford)** 알고리즘은 음수 가중치가 있어도 최단 거리를 정확하게 찾아낼 수 있으며,  
시간을 무한히 과거로 되돌릴 수 있는 **음수 사이클(Negative Cycle)**의 존재까지 감지할 수 있습니다.

1번 정거장에서 출발하여 각 정거장으로 가는 최단 시간을 구하세요.  
(단, 1번 정거장에서 도달할 수 있는 무한 루프 음수 사이클이 존재한다면 `CYCLE`을 출력합니다.)

---

### 입력 형식
- 첫째 줄에 정거장의 수 $V$ ($1 \le V \le 100$)와 웜홀의 수 $E$ ($0 \le E \le 500$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 웜홀 정보 $u, v, w$가 주어집니다. ($u$에서 $v$로 가는 소요 시간 $w$, $-1000 \le w \le 1000$)

---

### 출력 형식
- 1번 정거장에서 출발하는 경로 상에 음수 사이클이 있다면 첫째 줄에 `CYCLE`을 출력합니다.
- 그렇지 않다면 1번부터 $V$번 정거장까지의 최단 소요 시간을 공백으로 구분하여 출력합니다.  
  (도달할 수 없는 정거장은 `-1`로 출력합니다.)

---

### 입출력 예시

#### 예시 1
**입력**
```
3 4
1 2 4
1 3 3
2 3 -4
3 1 -2
```

**출력**
```
CYCLE
```
*설명:*
- 1 -> 2 (+4) -> 3 (-4) -> 1 (-2)를 돌면 한 바퀴 돌 때마다 비용이 -2씩 무한히 감소하는 음수 사이클이 발생합니다.
