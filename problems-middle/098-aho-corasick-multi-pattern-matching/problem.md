# 여러 단어를 동시에 한 번에 검색! 아호-코라식(Aho-Corasick) 다중 패턴 탐색

### 문제 설명
검색 엔진이나 침입 탐지 시스템(IDS)에서는 본문 텍스트에서 금칙어나 키워드 사전 속의 단어 $K$개가 총 몇 번 등장하는지 실시간으로 감지해야 합니다.

단어마다 KMP나 라빈-카프를 따로 돌리면 $O(K \times |Text|)$의 시간이 걸려 비효율적입니다.  
**아호-코라식(Aho-Corasick)** 알고리즘은:
1. 패턴 단어들로 **트라이(Trie)**를 구축하고,
2. KMP의 실패 함수 원리를 트라이 전체로 확장하여 BFS로 **실패 링크(Failure Link)**를 연결합니다.
3. 이후 긴 본문 텍스트를 **단 한 번만 순회($O(|Text|)$)**하여 모든 패턴의 등장 횟수 총합을 초고속으로 집계합니다!

키워드 사전의 $K$개 단어와 본문 텍스트 $T$가 주어질 때, 본문에서 사전 속 단어들이 등장한 **총 횟수**를 구하는 프로그램을 작성하세요. (중첩 등장도 각각 인정합니다.)

---

### 입력 형식
- 첫째 줄에 패턴 단어의 개수 $K$ ($1 \le K \le 100$)가 주어집니다.
- 둘째 줄에 $K$개의 단어가 공백으로 주어집니다. (각 단어 길이 $1 \le |P_i| \le 100$)
- 셋째 줄에 본문 텍스트 $T$가 주어집니다. ($1 \le |T| \le 50000$)
- 모든 문자열은 알파벳 소문자로만 구성됩니다.

---

### 출력 형식
- 본문 텍스트에서 사전 단어들이 등장한 총 횟수를 정수로 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4
he she his hers
ushers
```

#### 예제 출력 1
```
3
```
- 설명: `ushers`에서 `"she"` (위치 1..3), `"he"` (위치 2..3), `"hers"` (위치 2..5) 총 3번 매칭됩니다.
