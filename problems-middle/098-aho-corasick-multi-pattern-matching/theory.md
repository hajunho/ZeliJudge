# 아호-코라식 (Aho-Corasick) 알고리즘

### 1. 트라이와 KMP 실패 함수의 결합
단일 패턴 매칭의 KMP 실패 함수를 다중 패턴 트라이(Trie) 트리로 확장한 오토마톤입니다.
- **실패 링크(`fail`)**: 현재 노드에서 일치에 실패했을 때, 현재까지 일치한 접미사 중 트라이에 존재하는 **가장 긴 유효한 접두사 노드**로 건너뛰는 포인터입니다.
- BFS 레벨 순회로 부모의 `fail`을 따라가며 자식의 `fail`을 계산합니다.

### 2. 선형 시간 다중 검색
본문 텍스트의 각 문자를 따라 오토마톤의 상태를 전이하며, 도달한 노드 및 해당 노드의 실패 링크 체인 상에 존재하는 모든 단어 완료 마킹(`match_count`)을 누적합니다.  
시간 복잡도는 $O(|Text| + \sum |P_i|)$로 본문의 길이에만 비례합니다!
