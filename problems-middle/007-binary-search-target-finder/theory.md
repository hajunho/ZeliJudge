# 이진 탐색 (Binary Search)

데이터가 **이미 정렬되어 있을 때만** 사용할 수 있는 초고속 탐색 알고리즘입니다.

## 1. 동작 과정
1. 탐색 범위의 시작 `low = 0`, 끝 `high = N - 1`로 설정합니다.
2. `low <= high` 인 동안 가운데 위치 `mid = (low + high) // 2`를 계산합니다.
3. `arr[mid] == X` 라면 찾았으므로 인덱스를 반환합니다.
4. `arr[mid] < X` 라면 찾는 값이 오른쪽에 있으므로 `low = mid + 1` 로 절반을 버립니다.
5. `arr[mid] > X` 라면 찾는 값이 왼쪽에 있으므로 `high = mid - 1` 로 절반을 버립니다.
6. 범위를 모두 좁혀도 못 찾으면 `-1`입니다.

## 2. 시간 복잡도
매 단계마다 탐색 대상이 절반($1/2$)으로 줄어들기 때문에, $N = 1,000,000$ 개라도 약 20번의 비교($\log_2 10^6 \approx 20$)만에 찾을 수 있습니다!
