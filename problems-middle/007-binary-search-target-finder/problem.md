# 절반씩 싹둑! 정렬 배열에서의 이진 탐색 (Binary Search)

## 📖 문제 설명
도서관에 10만 권의 책이 번호순으로 완벽하게 정렬되어 있습니다. 책을 앞에서부터 한 권씩 찾는 선형 탐색은 최대 10만 번 검사해야 하지만, 가운데 책을 열어보는 '이진 탐색(Binary Search)'을 쓰면 단 17번 만에 원하는 책을 찾아낼 수 있습니다! 정렬된 배열에서 찾고자 하는 값 X의 위치(1번째부터 시작)를 구하세요. 만약 없다면 -1을 출력합니다.

## 📥 입력 형식
첫 줄에 정렬된 수열의 길이 N과 찾고자 하는 수 X가 공백으로 주어집니다. (1 <= N <= 100,000)\n둘째 줄에 오름차순으로 정렬된 서로 다른 N개의 정수가 공백으로 주어집니다. (각 정수 절댓값 <= 1,000,000,000)

## 📤 출력 형식
값 X가 위치한 1-based 인덱스를 출력합니다. 배열에 없다면 -1을 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
6 7
1 3 5 7 9 11
```
**출력**
```text
4
```

## 힌트
오름차순으로 정렬된 N개의 정수 배열에서 질문으로 주어지는 수 X의 인덱스(1-based)를 O(log N) 이진 탐색으로 찾습니다.
