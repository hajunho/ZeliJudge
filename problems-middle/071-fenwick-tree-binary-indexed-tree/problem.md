# 비트 트릭의 기적! 펜윅 트리와 구간 합 (Fenwick Tree / BIT)

### 문제 설명
길이가 $N$인 정수 수열 $A_1, A_2, \dots, A_N$이 주어집니다.  
다음 두 종류의 질의가 총 $Q$개 주어질 때, 질의를 순서대로 수행하는 프로그램을 작성하세요.

1. `1 i v`: $i$번째 원소의 값을 $v$로 변경합니다. ($1 \le i \le N$)
2. `2 L R`: $L$번째 원소부터 $R$번째 원소까지의 합($A_L + A_{L+1} + \dots + A_R$)을 출력합니다. ($1 \le L \le R \le N$)

수열의 크기와 질의의 개수가 많으므로 단순 반복문($O(N)$)으로 구간 합을 구하면 시간 초과가 발생합니다.  
**펜윅 트리(바이너리 인덱스 트리, BIT)**를 구축하여 갱신과 구간 합 질의를 모두 $O(\log N)$에 처리해 보세요!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 50000$)과 질의의 개수 $Q$ ($1 \le Q \le 50000$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, A_2, \dots, A_N$이 공백으로 주어집니다. ($-10^6 \le A_i \le 10^6$)
- 셋째 줄부터 $Q$개의 줄에 걸쳐 각 질의가 형식에 맞추어 주어집니다.
  - `1 i v`: ($-10^6 \le v \le 10^6$)
  - `2 L R`: ($1 \le L \le R \le N$)

---

### 출력 형식
- `2 L R` 질의가 주어질 때마다 구간 합의 결과를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5 5
1 2 3 4 5
2 1 5
1 3 10
2 1 5
2 2 4
2 3 3
```

#### 예제 출력 1
```
15
22
16
10
```
