# 하노이의 탑과 분할 정복 재귀의 미학

### 1. 하노이의 탑 규칙과 사고의 전환
$N$개의 원판을 1번에서 3번으로 옮기려면 어떻게 해야 할까요?
복잡해 보이지만, **가장 큰 맨 밑의 $N$번째 원판**에 집중하면 문제가 마법처럼 단순해집니다:

1. 맨 밑의 $N$번 원판을 3번 기둥으로 옮기려면, 그 위의 **$N-1$개 원판이 전부 2번 기둥(보조 기둥)**에 가 있어야 합니다.
2. 이제 자유로워진 $N$번 원판을 1번에서 3번 기둥으로 옮깁니다. (1회 이동)
3. 2번 기둥에 치워두었던 $N-1$개 원판을 다시 3번 기둥으로 옮겨옵니다.

---

### 2. 점화식과 이동 횟수
원판 $N$개를 옮기는 최소 이동 횟수를 $T(N)$이라 하면:
$$T(1) = 1$$
$$T(N) = 2 \times T(N-1) + 1$$

이 점화식을 풀면 다음과 같은 깔끔한 지수 공식을 얻을 수 있습니다:
$$T(N) = 2^N - 1$$

- $N = 3 \to 2^3 - 1 = 7$회
- $N = 10 \to 2^{10} - 1 = 1023$회
- $N = 64 \to 2^{64} - 1 \approx 1844$경 번! (초당 1개씩 옮겨도 우주의 나이보다 긴 5,849억 년이 걸립니다.)

### 3. 재귀 함수의 구조
```python
def hanoi(n, src, dst, aux):
    if n == 1:
        print(f"{src} {dst}")
        return
    hanoi(n - 1, src, aux, dst)  # 1) n-1개를 aux로
    print(f"{src} {dst}")         # 2) 가장 큰 원판을 dst로
    hanoi(n - 1, aux, dst, src)  # 3) n-1개를 dst로
```
