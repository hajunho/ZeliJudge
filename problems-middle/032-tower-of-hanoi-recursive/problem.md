# 전설의 원판 옮기기! 하노이의 탑(Tower of Hanoi)

### 문제 설명
인도의 고대 사원에는 3개의 다이아몬드 기둥과 크기가 서로 다른 64개의 황금 원판이 놓여 있다는 전설이 있습니다.  
세 개의 기둥(1번, 2번, 3번) 중 1번 기둥에 크기 순서대로 꽂혀 있는 $N$개의 원판을 3번 기둥으로 모두 옮겨야 합니다.

원판을 옮길 때는 다음 **두 가지 규칙**을 반드시 지켜야 합니다:
1. 한 번에 **오직 한 개의 원판**만 다른 기둥으로 옮길 수 있습니다.
2. **큰 원판은 절대로 작은 원판 위에 올릴 수 없습니다.**

$N$개의 원판이 주어졌을 때, 1번 기둥에서 3번 기둥으로 최소 횟수로 옮기는 과정 전체를 출력하세요.

---

### 입력 형식
- 첫째 줄에 1번 기둥에 꽂혀 있는 원판의 개수 $N$ ($1 \le N \le 10$)이 주어집니다.

---

### 출력 형식
- 첫째 줄에 원판을 옮긴 총 이동 횟수 $K$를 출력합니다.
- 둘째 줄부터 $K$개 줄에 걸쳐, 각 단계마다 원판을 옮긴 출발 기둥 번호와 도착 기둥 번호를 공백으로 구분하여 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
2
```

**출력**
```
3
1 2
1 3
2 3
```

#### 예시 2
**입력**
```
3
```

**출력**
```
7
1 3
1 2
3 2
1 3
2 1
2 3
1 3
```
