# 청팀 백팀 편 가르기! 이분 그래프(Bipartite Graph) 판별

### 문제 설명
체육대회를 앞두고 $V$명의 학생들이 모였습니다.  
학생들 사이에는 서로 친하지 않거나 경쟁 관계인 $E$개의 라이벌 쌍(간선)이 있습니다.

선생님은 학생들을 **청팀(1번 색)**과 **백팀(2번 색)** 두 팀으로 나누려고 합니다.  
단, 평화를 위해 **라이벌 관계인 두 학생은 절대로 같은 팀에 배정될 수 없습니다.**

이처럼 그래프의 모든 정점을 두 그룹으로 나누어, 모든 간선의 양 끝 정점이 서로 다른 그룹에 속하도록 만들 수 있는 그래프를 **이분 그래프(Bipartite Graph)**라고 합니다.  
주어진 학생들의 라이벌 관계 그래프가 이분 그래프인지 판별하여,  
두 팀으로 공평하게 나눌 수 있다면 `YES`, 불가능하다면 `NO`를 출력하세요.

---

### 입력 형식
- 첫째 줄에 학생 수 $V$ ($1 \le V \le 100$)와 라이벌 쌍의 수 $E$ ($0 \le E \le 500$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 라이벌인 두 학생 번호 $u, v$가 주어집니다. ($1 \le u, v \le V, u \ne v$)

---

### 출력 형식
- 이분 그래프이면 `YES`, 아니면 `NO`를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
4 4
1 2
2 3
3 4
4 1
```

**출력**
```
YES
```
*설명:*
- 짝수(4개) 노드 링 그래프는 1(청)-2(백)-3(청)-4(백)으로 완벽하게 두 색으로 칠할 수 있습니다.

#### 예시 2
**입력**
```
3 3
1 2
2 3
3 1
```

**출력**
```
NO
```
*설명:*
- 홀수(3개) 노드 사이클(삼각형)은 1(청)-2(백)으로 칠하고 나면 3번 학생이 청팀도 백팀도 될 수 없어 충돌이 일어납니다.
