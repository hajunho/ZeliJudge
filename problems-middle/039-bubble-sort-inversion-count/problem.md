# 옆 사람과 자리 바꾸기! 버블 정렬과 스왑 횟수

### 문제 설명
키 순서대로 줄을 서야 하는 체육 시간, $N$명의 학생들이 일렬로 서 있습니다.  
선생님은 가장 기초적인 정렬 방식인 **버블 정렬(Bubble Sort)** 규칙을 적용하기로 했습니다:

1. 줄의 맨 앞에서부터 출발하여 인접한 두 학생의 키를 비교합니다.
2. 만약 앞의 학생이 뒤의 학생보다 키가 더 크다면, 두 학생의 자리를 서로 바꿉니다 (**Swap**).
3. 줄의 끝까지 이 과정을 진행하면 가장 큰 학생이 맨 뒤로 밀려납니다 (마치 물속에서 거품이 수면으로 뽀글뽀글 떠오르듯).
4. 이미 정렬된 맨 뒤 학생들을 제외하고 이 과정을 반복합니다.

주어진 수열을 버블 정렬로 오름차순 정렬할 때 일어나는 **총 교환(Swap) 횟수**를 구하세요.

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 100$)이 주어집니다.
- 둘째 줄에 $N$개의 정수가 공백으로 구분되어 주어집니다. (원소의 크기는 $-1000$ 이상 $1000$ 이하)

---

### 출력 형식
- 정렬을 완료하기 위해 일어난 총 Swap 횟수를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
5
5 2 3 1 4
```

**출력**
```
6
```
*설명:*
- (5, 2) swap -> [2, 5, 3, 1, 4] (1회)
- (5, 3) swap -> [2, 3, 5, 1, 4] (2회)
- (5, 1) swap -> [2, 3, 1, 5, 4] (3회)
- (5, 4) swap -> [2, 3, 1, 4, 5] (4회, 1회전 완료)
- (3, 1) swap -> [2, 1, 3, 4, 5] (5회)
- (2, 1) swap -> [1, 2, 3, 4, 5] (6회, 정렬 완료)
