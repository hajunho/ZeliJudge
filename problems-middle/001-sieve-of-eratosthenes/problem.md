# 고대 그리스의 수학 체! 에라토스테네스의 체 (Sieve of Eratosthenes)

## 📖 문제 설명
중학교 수학 시간에 배운 소인수분해! 고대 그리스의 수학자 에라토스테네스는 2부터 시작하여 각 소수의 배수들을 모조리 지워나가는 기발한 '수학 체(Sieve)'를 발명했습니다. 자연수 N이 주어질 때, 에라토스테네스의 체 원리를 이용해 N 이하의 모든 소수를 오름차순으로 출력하는 고속 소수 추출기를 만들어보세요!

## 📥 입력 형식
한 줄에 자연수 N (2 <= N <= 10,000)이 주어집니다.

## 📤 출력 형식
N 이하의 모든 소수를 오름차순으로 공백으로 구분하여 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
10
```
**출력**
```text
2 3 5 7
```

## 힌트
N 이하의 모든 소수를 에라토스테네스의 체 알고리즘을 이용해 O(N log log N)으로 빠르게 찾아 공백으로 출력합니다.
