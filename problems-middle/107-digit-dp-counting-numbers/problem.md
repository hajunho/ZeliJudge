# 자릿수를 따라 결정되는 상태! 자릿수 동적 계획법 (Digit DP)

### 문제 설명
어떤 행운의 숫자 $D$ ($0 \le D \le 9$)가 주어집니다.  
$1$부터 $N$까지의 자연수 중에서, **십진수 표현에 숫자 $D$가 적어도 한 번 이상 포함된 수의 총 개수**를 구하는 프로그램을 작성하세요.

예를 들어 $N = 20, D = 7$이라면:
- 1부터 20까지 중 '7'을 포함하는 수는 `7, 17`의 2개입니다.

$N$이 $10^{15}$과 같이 매우 커지면 1부터 $N$까지 하나하나 검사하는 반복문은 절대 불가능합니다.  
하지만 숫자를 가장 높은 자릿수부터 한 자리씩 채워나가는 **자릿수 DP(Digit DP)**를 사용하면,  
- 현재 자릿수 위치(`pos`),
- 지금까지 숫자 $D$가 한 번이라도 등장했는지(`has_digit`),
- 지금까지 만든 앞부분이 $N$보다 엄격히 작아져서 남은 자리에 0~9를 자유롭게 쓸 수 있는지(`is_less`)  
단 3가지 불리언 상태만으로 $O(\text{자릿수} \times 10)$만에 거대한 범위의 카운팅을 끝낼 수 있습니다!

---

### 입력 형식
- 첫째 줄에 자연수 $N$ ($1 \le N \le 10^{15}$)과 찾고자 하는 한 자리 숫자 $D$ ($0 \le D \le 9$)가 공백으로 주어집니다.

---

### 출력 형식
- 1부터 $N$까지 중 숫자 $D$가 적어도 한 번 포함된 숫자의 총 개수를 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
20 7
```

#### 예제 출력 1
```
2
```
