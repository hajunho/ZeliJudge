# 방향 그래프 사이클 검출 (DFS 3-Coloring)

무방향 그래프와 달리, 방향 그래프에서는 단순히 '방문했던 점'을 다시 만났다고 해서 사이클이 아닙니다. **현재 DFS 재귀 호출 경로 상에 있는 조상 노드를 다시 만났을 때(역간선, Back-edge)** 비로소 사이클이 성립합니다!

## 1. 3가지 방문 상태
- `0 (White)`: 아직 한 번도 방문하지 않은 노드
- `1 (Gray)`: 현재 DFS 탐색 중이며 호출 스택에 머물러 있는 노드 (현재 경로)
- `2 (Black)`: 해당 노드로부터 출발하는 모든 하위 탐색이 완료된 노드

## 2. 사이클 판별
DFS 도중 다음 노드의 상태가:
- `1 (Gray)`라면 $\rightarrow$ 조상 노드로 되돌아가는 순환선 발견! 즉시 **YES**!
- `0 (White)`라면 $\rightarrow$ 재귀적으로 계속 탐색
- `2 (Black)`라면 $\rightarrow$ 이미 안전하게 탐색이 끝난 경로이므로 무시
