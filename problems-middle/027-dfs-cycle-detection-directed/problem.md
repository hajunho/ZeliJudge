# 끝없는 무한 루프를 찾아라! 방향 그래프 사이클 감지 (Cycle Detection)

## 📖 문제 설명
컴퓨터 프로그램의 함수 호출 관계나 작업(Task) 간의 의존 관계에 서로가 서로를 영원히 기다리는 순환 고리(Cycle)가 생기면 시스템이 멈추는 '데드락(교착상태)'이 발생합니다! V개의 작업과 단방향 의존 간선 E개가 주어질 때, 그래프에 순환 고리(사이클)가 존재하는지 YES 또는 NO로 진단해주세요!

## 📥 입력 형식
첫 줄에 정점의 수 V와 간선의 수 E가 공백으로 주어집니다. (1 <= V <= 10,000, 0 <= E <= 50,000)\n다음 E개의 줄에 걸쳐 단방향 간선 u -> v의 정보가 공백으로 주어집니다. (1 <= u, v <= V)

## 📤 출력 형식
사이클이 존재하면 YES, 사이클이 없는 DAG(유향 비순환 그래프)라면 NO를 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
3 3
1 2
2 3
3 1
```
**출력**
```text
YES
```

## 힌트
V개의 노드와 E개의 단방향 간선으로 이루어진 방향 그래프에 사이클(순환선)이 존재하는지 DFS로 감지합니다.
