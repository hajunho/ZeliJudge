# 2차원 평면 회전! 행렬의 회전 대칭성 판별 (Rotational Symmetry)

## 📖 문제 설명
중학교 2학년 기하 시간에 배우는 도형의 회전이동과 대칭! N x N 크기의 전통 문양 타일이 있습니다. 이 타일을 시계방향으로 90도 회전시켰을 때 원본과 똑같다면 '90도 대칭', 180도 회전시켰을 때 똑같다면 '180도 대칭'이라고 부릅니다. 주어진 타일이 각각 90도, 180도, 270도 회전했을 때 원본과 같은지 세 번의 YES/NO로 판정해주세요!

## 📥 입력 형식
첫 줄에 정사각형 행렬의 크기 N (1 <= N <= 50)이 주어집니다.\n다음 N개의 줄에 걸쳐 각 행의 N개 정수가 공백으로 주어집니다.

## 📤 출력 형식
한 줄에 공백으로 구분하여 90도 회전 대칭 여부, 180도 회전 대칭 여부, 270도 회전 대칭 여부를 YES 또는 NO로 출력합니다. (예: YES YES YES 또는 NO YES NO)

## 💡 입출력 예시
### 예시 1
**입력**
```text
2
1 1
1 1
```
**출력**
```text
YES YES YES
```

## 힌트
N x N 정사각형 행렬이 주어질 때 90도, 180도, 270도 회전했을 때 원래 행렬과 완전히 같은지(회전 대칭성)를 판별합니다.
