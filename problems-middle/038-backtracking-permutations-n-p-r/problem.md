# 마법의 비밀번호 후보! 순열(Permutation) 백트래킹

### 문제 설명
중학교 정보 탐정 동아리 지우는 보물 상자의 자물쇠 암호를 해독하고 있습니다.  
자물쇠는 $1$부터 $N$까지의 서로 다른 자연수 중 **$R$개를 뽑아 순서대로 나열한 순열($_N P_R$)**로 구성되어 있습니다.

예를 들어 $N=3, R=2$라면 만들 수 있는 암호는 다음과 같이 총 6개입니다:
- `1 2`, `1 3`, `2 1`, `2 3`, `3 1`, `3 2`

재귀 호출과 방문 체크 배열(`visited`), 그리고 원상 복구(Backtracking) 기법을 사용하여,  
$1$부터 $N$까지의 수 중에서 중복 없이 $R$개를 고른 모든 순열을 **사전 순(오름차순)**으로 출력하는 프로그램을 작성하세요.

---

### 입력 형식
- 첫째 줄에 두 자연수 $N$과 $R$ ($1 \le R \le N \le 8$)이 공백으로 주어집니다.

---

### 출력 형식
- 사전 순으로 앞서는 순열부터 한 줄에 하나씩, 각 숫자를 공백으로 구분하여 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
3 2
```

**출력**
```
1 2
1 3
2 1
2 3
3 1
3 2
```

#### 예시 2
**입력**
```
4 1
```

**출력**
```
1
2
3
4
```
