# 다리가 끊어지면 고립돼요! 그래프의 단절선 (Bridge)

### 문제 설명
통신망 인프라를 설계하는 나래는 $V$개의 기지국과 이들을 잇는 $E$개의 광케이블망(양방향 간선)을 점검하고 있습니다.  
네트워크에서 어떤 케이블 하나가 사고로 끊어졌을 때,  
**기지국들이 서로 통신할 수 없는 둘 이상의 분리된 네트워크로 쪼개지는 치명적인 간선**을 **단절선(Bridge, 다리)**이라고 부릅니다.

예를 들어 두 원형 통신망을 잇는 단 하나의 케이블이 있다면, 그 케이블이 바로 단절선입니다.

DFS 신장 트리와 타잔(Tarjan)의 방문 순서 번호 알고리즘을 구현하여,  
주어진 그래프에 존재하는 **단절선(Bridge)의 총 개수**를 구하세요.

---

### 입력 형식
- 첫째 줄에 기지국 수 $V$ ($1 \le V \le 100$)와 케이블 수 $E$ ($0 \le E \le 500$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 케이블 정보 $u, v$가 주어집니다. ($1 \le u, v \le V, u \ne v$)

---

### 출력 형식
- 그래프에 존재하는 단절선의 총 개수를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
4 4
1 2
2 3
3 1
3 4
```

**출력**
```
1
```
*설명:*
- (1, 2, 3)은 삼각형 사이클을 이루므로 어떤 간선이 끊겨도 서로 연결되어 있습니다.
- 하지만 (3, 4) 간선이 끊어지면 4번 기지국이 완전히 고립되므로 (3, 4)가 유일한 단절선입니다.
