# 무거운 체인을 타고 초고속 상승! HLD(Heavy-Light Decomposition) 최소 공통 조상

### 문제 설명
1번 노드를 루트로 하는 $N$개의 노드로 이루어진 트리가 주어집니다.  
임의의 두 노드 $u$와 $v$가 주어질 때마다 두 노드의 **가장 가까운 공통 조상(LCA, Lowest Common Ancestor)**을 구하는 질의가 총 $Q$개 주어집니다.

트리를 여러 개의 무거운 체인(Heavy Chain)으로 분해하는 **HLD(Heavy-Light Decomposition)** 기법을 사용하면:
- 자식들 중 서브트리의 크기가 가장 큰 자식으로 이어지는 간선을 **무거운 간선(Heavy Edge)**, 나머지를 **가벼운 간선(Light Edge)**으로 지정합니다.
- 루트에서 어떤 리프 노드까지 내려갈 때 가벼운 간선은 최대 $\log_2 N$개밖에 거치지 않습니다!
- 두 노드가 서로 다른 체인에 속해 있을 때 체인의 꼭대기(`head`)가 더 깊은 쪽을 체인 단위로 한 번에 건너뛰며 올려보냄으로써, **질의당 $O(\log N)$**에 초고속으로 LCA를 찾아낼 수 있습니다!

---

### 입력 형식
- 첫째 줄에 노드의 수 $N$ ($1 \le N \le 50000$)과 질의의 수 $Q$ ($1 \le Q \le 50000$)가 공백으로 주어집니다.
- 둘째 줄부터 $N-1$개의 줄에 걸쳐 트리의 간선 $u, v$ ($1 \le u, v \le N$)가 주어집니다.
- 그 다음 $Q$개의 줄에 걸쳐 LCA를 구할 두 노드 $u, v$가 주어집니다.

---

### 출력 형식
- 각 질의마다 두 노드의 최소 공통 조상(LCA) 노드 번호를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5 3
1 2
1 3
2 4
2 5
4 5
4 3
2 4
```

#### 예제 출력 1
```
2

2
```
