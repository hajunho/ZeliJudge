# 꼭짓점 좌표만으로 땅의 넓이 구하기! 신발끈 공식 (Shoelace Formula)

### 문제 설명
평면 위에 $N$개의 점으로 이루어진 단순 다각형(Simple Polygon)의 꼭짓점들이 둘레를 따라 순서대로 주어집니다.  
(볼록 다각형뿐만 아니라 안쪽으로 오목하게 들어간 오목 다각형도 포함됩니다.)

이 다각형의 **정확한 면적(넓이)**을 구하는 프로그램을 작성하세요.

가우스의 면적 공식으로도 불리는 **신발끈 공식(Shoelace Formula)**을 이용하면,  
꼭짓점들의 $x, y$ 좌표를 신발끈처럼 지그재그로 교차 곱하여 더하고 뺌으로써 다각형의 모양에 상관없이 **$O(N)$**에 완벽한 넓이를 계산할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 꼭짓점의 개수 $N$ ($3 \le N \le 10000$)이 주어집니다.
- 둘째 줄부터 $N$개의 줄에 걸쳐 다각형의 둘레를 따라 순서대로 꼭짓점의 정수 좌표 $x, y$ ($-10^4 \le x, y \le 10^4$)가 주어집니다.

---

### 출력 형식
- 다각형의 면적을 소수점 첫째 자리까지 형식화(`{area:.1f}`)하여 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4
0 0
4 0
4 4
0 4
```

#### 예제 출력 1
```
16.0
```
- 설명: 한 변의 길이가 4인 정사각형의 넓이는 $4 \times 4 = 16.0$입니다.
