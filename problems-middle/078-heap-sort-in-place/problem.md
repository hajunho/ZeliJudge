# 피라미드 구조의 정렬! 제자리 힙 정렬 (In-Place Heap Sort)

### 문제 설명
길이가 $N$인 정수 수열이 주어집니다. 추가적인 배열 공간 없이 기존 배열 내부에서 직접 트리를 구축하는 **제자리 힙 정렬(In-Place Heap Sort)** 과정을 수행하는 프로그램을 작성하세요.

힙 정렬은 다음 두 단계로 동작합니다:
1. **최대 힙(Max-Heap) 구축 단계**:
   - 배열 전체를 완전 이진 트리로 보고, 마지막 내부 노드($\lfloor N/2 \rfloor - 1$)부터 루트(0)까지 역순으로 내려가며 `sift_down`을 호출해 전체 배열을 최대 힙 상태로 만듭니다.
2. **반복 추출 및 정렬 단계**:
   - 루트 노드(배열의 최댓값 `arr[0]`)를 현재 힙의 마지막 원소(`arr[i]`)와 교환합니다.
   - 힙의 유효 크기를 1 줄이고, 루트에 대해 `sift_down`을 수행하여 힙 성질을 복원합니다.
   - 이 과정을 반복하면 배열이 완벽한 오름차순으로 정렬됩니다!

---

### 입력 형식
- 첫째 줄에 수열의 길이 $N$ ($1 \le N \le 50000$)이 주어집니다.
- 둘째 줄에 $N$개의 정수가 공백으로 주어집니다. ($-10^9 \le \text{원소} \le 10^9$)

---

### 출력 형식
- 첫째 줄에 1단계(최대 힙 구축 직후)의 배열 상태를 공백으로 구분하여 출력합니다.
- 둘째 줄에 2단계 완료 후 최종 오름차순으로 정렬된 배열을 공백으로 구분하여 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
6
4 10 3 5 1 2
```

#### 예제 출력 1
```
10 5 3 4 1 2
1 2 3 4 5 10
```
