# 숫자가 너무 커요! 1차원 좌표 압축 (Coordinate Compression)

## 📖 문제 설명
지도 위의 건물 좌표들이 [1000, 999999999, -1000000000]처럼 너무 거대합니다! 알고리즘을 풀 때 값의 절대적인 크기보다 '누가 더 작고 큰지' 상대적인 순서만 중요할 때가 많습니다. 중복을 제거하고 가장 작은 값부터 0, 1, 2... 순위를 부여하는 '좌표 압축(Coordinate Compression)' 기법을 적용해 숫자를 정규화해보세요!

## 📥 입력 형식
첫 줄에 수의 개수 N (1 <= N <= 100,000)이 주어집니다.\n둘째 줄에 N개의 정수 X1, X2, ..., XN이 공백으로 주어집니다. (|Xi| <= 1,000,000,000)

## 📤 출력 형식
각 숫자를 좌표 압축한 결과(0부터 시작하는 순위)를 원래 입력 순서대로 공백으로 구분하여 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
5
2 4 -10 4 -9
```
**출력**
```text
2 3 0 3 1
```

## 힌트
절댓값이 최대 10억에 달하는 N개의 정수를 중복을 제거한 오름차순 순위(0부터 시작)로 압축하여 변환합니다.
