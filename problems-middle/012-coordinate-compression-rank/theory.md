# 좌표 압축 (Coordinate Compression)

## 1. 왜 좌표 압축이 필요할까요?
숫자의 범위가 $-10^9 \sim 10^9$처럼 너무 크면 배열의 인덱스로 직접 사용할 수 없습니다 (메모리 초과).
하지만 등장하는 숫자의 종류($N$)가 많지 않다면, 값의 대소 관계를 유지한 채 **0부터 $K-1$까지의 작은 정수**로 변환할 수 있습니다!

## 2. 알고리즘 단계
1. 원본 배열의 복사본에서 중복을 제거합니다 (`set` 활용).
2. 중복이 제거된 고유한 값들을 오름차순으로 정렬합니다 (`sorted()`).
3. 정렬된 리스트에서 각 원소의 인덱스를 딕셔너리(`rank_map = {val: idx for idx, val in enumerate(sorted_unique)}`)로 매핑합니다.
4. 원본 배열의 원소들을 딕셔너리를 통해 변환하여 출력합니다! ($O(N \log N)$)
