# 여러 직선이 가르는 공통 영역! 반평면 교집합 (Half-Plane Intersection)

### 문제 설명
평면 위에 $N$개의 유향 직선(Directed Line)이 주어집니다.  
각 직선은 시작점 $(x_1, y_1)$에서 끝점 $(x_2, y_2)$로 향하며, 진행 방향의 **왼쪽 반평면(Left Half-plane, 즉 CCW $\ge 0$)**을 유효한 영역으로 지정합니다.

기본 안전 구역인 $[-1000, 1000] \times [-1000, 1000]$ 정사각형 내부에서,  
$N$개의 모든 반평면 조건들을 동시에 만족하는 **공통 교집합 다각형의 넓이**를 구하는 프로그램을 작성하세요.  
(교집합 영역이 존재하지 않거나 선분/점이라면 `0.0`을 출력합니다.)

서덜랜드-호지만(Sutherland-Hodgman) 폴리곤 클리핑 기법을 적용하여,  
각 직선마다 다각형의 변을 반평면 기준으로 잘라내며 $O(N^2)$에 공통 볼록 다각형 영역을 도출해 보세요!

- 결과는 소수점 첫째 자리까지 형식화(`{area:.1f}`)하여 출력합니다.

---

### 입력 형식
- 첫째 줄에 반평면을 정의하는 유향 직선의 개수 $N$ ($1 \le N \le 50$)이 주어집니다.
- 둘째 줄부터 $N$개의 줄에 걸쳐 직선의 시작점과 끝점 $x_1, y_1, x_2, y_2$ ($-1000 \le x_i, y_i \le 1000$)가 공백으로 주어집니다.

---

### 출력 형식
- 공통 반평면 교집합 영역의 면적을 소수점 첫째 자리까지 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4
0 0 10 0
10 0 10 10
10 10 0 10
0 10 0 0
```

#### 예제 출력 1
```
100.0
```
- 설명: $0 \le x \le 10, 0 \le y \le 10$의 한 변이 10인 정사각형 내부 영역이 되므로 넓이는 $100.0$입니다.
