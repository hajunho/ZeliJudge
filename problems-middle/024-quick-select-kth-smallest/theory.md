# 퀵 선택 (Quickselect)

배열에서 $K$번째 작은 원소를 찾는 알고리즘입니다.

## 1. 퀵정렬과의 차이점
- **퀵정렬**: 피벗을 정한 뒤 피벗보다 작은 쪽과 큰 쪽 **양쪽 모두**를 재귀 정렬합니다 ($O(N \log N)$).
- **퀵선택**: 피벗의 최종 위치가 $K$보다 크면 **왼쪽만**, 작으면 **오른쪽만** 탐색합니다! 한쪽 절반을 버리므로:
  $$N + \frac{N}{2} + \frac{N}{4} + \dots = 2N \rightarrow O(N)$$
  평균적으로 놀라운 선형 시간 $O(N)$에 해결할 수 있습니다!
