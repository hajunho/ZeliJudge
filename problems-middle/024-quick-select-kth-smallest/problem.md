# K번째 작은 수를 찾아라! 퀵 선택 (Quickselect)

## 📖 문제 설명
도서관에 있는 수만 권의 책 중에서 '두께가 5번째로 얇은 책'을 찾고 싶습니다. 책 전체를 정렬하면 O(N log N)의 시간이 걸리지만, 퀵소트의 분할 아이디어를 응용한 '퀵 선택(Quickselect)' 기법을 사용하면 전체를 다 정렬하지 않고도 평균 O(N)만에 정확히 K번째 작은 원소를 찾아낼 수 있습니다! K번째 작은 수를 구하세요.

## 📥 입력 형식
첫 줄에 배열의 크기 N과 찾고자 하는 순위 K (1 <= K <= N <= 100,000)가 공백으로 주어집니다.\n둘째 줄에 N개의 정수가 공백으로 주어집니다.

## 📤 출력 형식
K번째(1-based)로 작은 원소를 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
5 2
4 1 2 7 5
```
**출력**
```text
2
```

## 힌트
길이 N의 정렬되지 않은 배열에서 K번째(1-based)로 작은 원소를 평균 O(N)의 시간에 찾습니다.
