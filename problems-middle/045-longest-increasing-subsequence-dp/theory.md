# 최장 증가 부분 수열(LIS)의 기본 DP

### 1. LIS 문제란?
주어진 수열에서 몇몇 원소를 골라 순서를 유지했을 때, 원소들이 오름차순으로 엄격하게 증가하는 부분 수열 중 길이가 가장 긴 것을 찾는 문제입니다.

---

### 2. O(N^2) 동적 계획법 설계
`dp[i]`를 **"$i$번째 원소를 마지막 원소로 하는 LIS의 최장 길이"**라고 정의합니다.

1. **초기화**: 모든 원소는 자기 자신만으로 길이 1인 증가 수열이므로 `dp[i] = 1`.
2. **이전 원소 비교**: $i$보다 앞선 모든 $j$ ($0 \le j < i$)에 대해:
   - 만약 $A[j] < A[i]$ 라면, $j$번째 원소 뒤에 $A[i]$를 덧붙일 수 있습니다!
   $$\text{dp}[i] = \max(\text{dp}[i], \text{dp}[j] + 1)$$
3. **결과**: 전체 수열 중 `max(dp)`가 최종 정답입니다.

---

### 3. 복잡도와 발전
- 본 $O(N^2)$ 풀이는 중학생 수준에서 직관적으로 DP의 부분 문제 전이를 이해하는 데 가장 훌륭합니다.
- 고등/대회 과정에서는 이분 탐색(`bisect`)을 결합하여 $O(N \log N)$으로 최적화할 수 있습니다.
