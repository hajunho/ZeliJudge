# 플로이드의 토끼와 거북이 사이클 감지 (Floyd's Cycle-Finding Algorithm)

### 1. Phase 1: 만남의 장소
거북이는 1초에 1칸, 토끼는 1초에 2칸씩 이동합니다.  
둘 다 사이클에 진입한 이후에는 매 초마다 거리가 1칸씩 좁혀지므로, 사이클 길이 $\lambda$ 이내에 반드시 두 포인터가 일치(`tortoise == hare`)하게 됩니다.

### 2. Phase 2 & 3: $\mu$와 $\lambda$의 도출
- **꼬리 길이 $\mu$**: 거북이를 다시 시작점 $x_0$으로 보내고, 토끼는 만난 지점에 둔 채 둘 다 1칸씩 동시에 전진시키면, 두 포인터가 다시 만나는 지점이 정확히 **사이클의 시작점**이며 그때까지 걸린 걸음 수가 $\mu$입니다.
- **주기 $\lambda$**: 거북이를 멈춰두고 토끼를 1칸씩 전진시켜 다시 거북이를 만날 때까지의 걸음 수가 $\lambda$입니다.
공간 복잡도는 완벽한 **$O(1)$**입니다.
