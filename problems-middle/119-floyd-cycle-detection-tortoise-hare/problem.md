# 연결 리스트와 수열의 순환 탐지! 플로이드의 토끼와 거북이 (Tortoise and Hare)

### 문제 설명
초깃값 $x_0$에서 시작하여 다음 점화식으로 생성되는 의사난수 수열 $x_0, x_1, x_2, \dots$가 있습니다:
$$x_{i+1} = f(x_i) = (A \cdot x_i + B) \pmod M$$

$M$이 유한하므로 비둘기집의 원리에 의해 이 수열은 어느 시점부터 반드시 동일한 수열이 무한히 반복되는 **순환(사이클, Cycle)**에 빠지게 됩니다.  
수열의 형태는 $\rho$(로) 모양을 띠며:
- 처음 시작하여 사이클에 진입하기 전까지 거쳐가는 **꼬리의 길이 $\mu$** (최초로 사이클이 시작되는 인덱스),
- 반복되는 **사이클의 길이 $\lambda$** (주기)

이 두 핵심 값을 구하는 프로그램을 작성하세요.

방문한 모든 수를 해시 셋에 저장하면 메모리가 $O(M)$으로 폭발하지만,  
**플로이드의 토끼와 거북이 알고리즘(Floyd's Cycle Finding Algorithm)**을 사용하면  
한 번에 한 칸 가는 거북이(`slow`)와 두 칸 가는 토끼(`fast`) 포인터 단 2개만으로 **추가 메모리 $O(1)$**에 $\mu$와 $\lambda$를 모두 찾아낼 수 있습니다!

---

### 입력 형식
- 첫째 줄에 네 정수 $x_0, A, B, M$ ($0 \le x_0 < M, 0 \le A, B \le 10^9, 2 \le M \le 10^7$)이 공백으로 주어집니다.

---

### 출력 형식
- 꼬리의 길이 $\mu$와 사이클의 길이 $\lambda$를 공백으로 구분하여 한 줄에 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
2 2 -1 7
```

#### 예제 출력 1
```
0 3
```
- 설명: $f(x) = (2x - 1) \pmod 7$.
  - $x_0 = 2$
  - $x_1 = (4-1) \% 7 = 3$
  - $x_2 = (6-1) \% 7 = 5$
  - $x_3 = (10-1) \% 7 = 2$ ($x_0$으로 복귀!)
  꼬리 길이 $\mu = 0$, 사이클 주기 $\lambda = 3$입니다.
