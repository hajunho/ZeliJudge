# 겹치는 회의가 너무 많아요! 최소 회의실 개수 (Meeting Rooms II)

### 문제 설명
공유 오피스 매니저 도윤이는 오늘 진행될 $N$개의 팀 회의 일정표를 받았습니다.  
각 회의 $i$는 시작 시간 $s_i$와 종료 시간 $e_i$를 가집니다.

한 회의실에서는 같은 시간에 두 개 이상의 회의가 동시에 진행될 수 없습니다.  
(단, 한 회의가 끝나는 시간과 다음 회의가 시작하는 시간이 같은 경우, 같은 회의실을 바로 이어 쓸 수 있습니다. 예: 10시에 끝난 뒤 10시에 시작 가능)

모든 회의를 시간 지연 없이 차질 없이 진행하기 위해 준비해야 하는 **최소 회의실 개수**를 구하세요.

---

### 입력 형식
- 첫째 줄에 회의의 개수 $N$ ($1 \le N \le 500$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 각 회의의 시작 시간 $s_i$와 종료 시간 $e_i$ ($0 \le s_i < e_i \le 10^6$)가 주어집니다.

---

### 출력 형식
- 필요한 최소 회의실 개수를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
3
0 30
5 10
15 20
```

**출력**
```
2
```
*설명:*
- 회의실 1: (0, 30) 회의 진행
- 회의실 2: (5, 10) 진행 후 (15, 20) 진행
- 총 2개의 회의실이면 충분합니다.
