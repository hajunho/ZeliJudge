# 거울 속의 거울! 재귀 함수 호출과 깊이 추적 (Recursion Depth)

## 📖 문제 설명
마법의 거울 방에 들어가면 거울 속에 비친 내가 또 거울을 보고 있는 무한 반복이 일어납니다! 프로그래밍에서 함수가 자기 자신을 다시 호출하는 기법을 '재귀(Recursion)'라고 부릅니다. 재귀가 무한 루프에 빠지지 않으려면 반드시 멈추는 '기저 조건(Base Case)'이 필요합니다. 자연수 N이 주어졌을 때, 1까지 재귀적으로 내려가며 거치는 호출 횟수(호출 깊이)와 각 단계의 합계를 추적해보세요!

## 📥 입력 형식
한 줄에 자연수 N (1 <= N <= 100)이 주어집니다.

## 📤 출력 형식
첫 줄에 f(N)부터 f(1)까지 재귀 호출된 총 횟수(N)를 출력합니다.\n둘째 줄에 1부터 N까지의 자연수 총합을 재귀로 계산한 값을 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
3
```
**출력**
```text
3
6
```

## 힌트
재귀 함수가 기저 조건(Base Case)에 도달할 때까지 파라미터가 변화하며 호출되는 깊이와 최종 계산 값을 시뮬레이션합니다.
