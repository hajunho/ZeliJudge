# 재귀 함수 (Recursive Function)와 호출 스택

## 1. 재귀 함수의 필수 조건
1. **기저 조건 (Base Case)**: 더 이상 자신을 호출하지 않고 즉시 값을 반환하여 재귀를 멈추는 조건 (예: $N = 1$일 때 반환).
2. **재귀 단계 (Recursive Step)**: 문제를 더 작은 부분 문제로 쪼개어 자기 자신을 호출하는 단계 (예: $f(N) = N + f(N - 1)$).

## 2. 호출 스택 (Call Stack)의 마법
함수가 호출될 때마다 컴퓨터 메모리의 '호출 스택'에 실행 정보가 차곡차곡 쌓입니다. 기저 조건에 도달하면 스택의 맨 위에서부터 차례대로 반환값을 전달하며 스택이 풀려나옵니다.
