# 모든 점을 감싸는 마법의 고무줄! 볼록 껍질 (Convex Hull)

### 문제 설명
평면 위에 $N$개의 쇠못(점)이 박혀 있습니다.  
못들이 박힌 영역 바깥쪽에서 거대한 고무줄을 팽팽하게 놓으면, 가장 외곽에 있는 몇몇 못에만 고무줄이 걸리며 모든 점을 내부에 품는 볼록 다각형이 만들어집니다.

이 다각형을 계산 기하학에서 **볼록 껍질(Convex Hull)**이라고 부릅니다.  
세 점의 방향성을 판별하는 CCW 알고리즘과 정렬을 이용한 **모노톤 체인(Monotone Chain / Graham Scan 변형)** 알고리즘을 구현하여,  
볼록 껍질의 꼭짓점이 되는 점들의 **총 개수**를 구하세요.  
(단, 볼록 껍질의 변 위에 일직선으로 놓인 점은 꼭짓점에서 제외합니다.)

---

### 입력 형식
- 첫째 줄에 점의 개수 $N$ ($3 \le N \le 100$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 각 점의 정수 좌표 $x, y$가 공백으로 주어집니다.  
  ($-10000 \le x, y \le 10000$)

---

### 출력 형식
- 볼록 껍질을 구성하는 꼭짓점의 개수를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
8
1 1
1 2
2 2
2 1
0 0
0 3
3 3
3 0
```

**출력**
```
4
```
*설명:*
- 외곽의 네 점 (0,0), (0,3), (3,3), (3,0)이 고무줄에 걸려 정사각형을 이루고, 내부의 네 점은 완전히 감싸집니다.
