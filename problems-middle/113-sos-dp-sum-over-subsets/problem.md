# 모든 부분집합의 비밀 합계! SOS DP (Sum Over Subsets)

### 문제 설명
크기가 $2^N$인 정수 배열 $A$가 주어집니다. ($0$부터 $2^N - 1$까지 각 비트마스크에 대응하는 값 $A[mask]$)

모든 비트마스크 $mask$ ($0 \le mask < 2^N$)에 대해,  
$mask$의 **모든 부분 비트마스크(서브셋)**들의 원소 값의 합을 구하는 프로그램을 작성하세요:
$$F[mask] = \sum_{sub \subseteq mask} A[sub]$$

예를 들어 $mask = 3$ (이진수 `11`)의 부분집합은 `00, 01, 10, 11` (0, 1, 2, 3)이므로:
$$F[3] = A[0] + A[1] + A[2] + A[3]$$

각 마스크마다 서브셋을 직접 순회하면 $O(3^N)$이 걸리지만,  
각 비트 위치마다 한 비트씩 켜고 끄는 상태 전이를 누적하는 **SOS DP(Sum Over Subsets DP)**를 사용하면 **$O(N \times 2^N)$**에 모든 $F[mask]$를 동시에 계산할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 비트의 수 $N$ ($1 \le N \le 16$)이 주어집니다.
- 둘째 줄에 $2^N$개의 정수 $A[0], A[1], \dots, A[2^N - 1]$이 공백으로 주어집니다. ($-10^6 \le A[mask] \le 10^6$)

---

### 출력 형식
- $F[0], F[1], \dots, F[2^N - 1]$의 계산 결과를 공백으로 구분하여 한 줄에 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
2
1 2 3 4
```

#### 예제 출력 1
```
1 3 4 10
```
- 설명: 
  - $F[0] = A[0] = 1$
  - $F[1] = A[0] + A[1] = 1 + 2 = 3$
  - $F[2] = A[0] + A[2] = 1 + 3 = 4$
  - $F[3] = A[0] + A[1] + A[2] + A[3] = 1 + 2 + 3 + 4 = 10$
