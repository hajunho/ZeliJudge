# 빠른 거듭제곱 (Binary Exponentiation)

## 1. 분할 정복의 아이디어
- $B = 0$: $A^0 = 1$
- $B$가 짝수: $A^B = (A^{B/2})^2$
- $B$가 홀수: $A^B = A \times A^{B-1} = A \times (A^{(B-1)/2})^2$

## 2. 모듈러 연산의 분배 법칙
곱셈의 매 단계마다 $\% C$를 적용하여 숫자가 무한정 커져서 생기는 메모리/연산 지연을 완벽하게 방지합니다:
$$(X \times Y) \% C = ((X \% C) \times (Y \% C)) \% C$$
파이썬의 `pow(A, B, C)` 내장 함수도 이와 동일한 $O(\log B)$ 알고리즘으로 동작합니다!
