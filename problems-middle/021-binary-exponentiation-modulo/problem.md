# 빛의 속도로 거듭제곱하기! 빠른 거듭제곱과 모듈러 (A^B mod C)

## 📖 문제 설명
중학교 1학년 때 배운 거듭제곱의 거대한 마법! $A^B$에서 $B$가 10억처럼 엄청나게 클 때, $A$를 10억 번 곱하면 컴퓨터가 멈춰버립니다. 하지만 지수법칙 $A^{2k} = (A^k)^2$을 이용해 지수를 매번 반씩 쪼개면, 단 30번의 곱셈만으로 거듭제곱을 끝낼 수 있습니다! $A^B$를 $C$로 나눈 나머지를 구하는 고속 거듭제곱기를 만들어보세요!

## 📥 입력 형식
한 줄에 세 자연수 A, B, C가 공백으로 주어집니다. (1 <= A, B, C <= 2,000,000,000)

## 📤 출력 형식
A^B를 C로 나눈 나머지((A^B) % C)를 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
2 10 1000
```
**출력**
```text
24
```

## 힌트
거듭제곱 A^B mod C를 O(log B) 분할 정복 거듭제곱(Binary Exponentiation)으로 빠르게 계산합니다.
