# 최장 공통 접두사 (LCP, Longest Common Prefix)

### 1. LCP의 개념과 중요성
두 문자열 $A$와 $B$가 공유하는 가장 긴 앞부분 문자열을 최장 공통 접두사(LCP)라고 부릅니다.
문자열 집합을 사전순으로 정렬하면, 비슷한 접두사를 공유하는 문자열들이 반드시 서로 인접하게 모이게 됩니다.
따라서 인접한 원소들 사이의 LCP만 계산하면 집합 내의 반복 패턴과 중복도($O(N)$)를 효율적으로 파악할 수 있습니다.

### 2. 접미사 배열(Suffix Array)과의 연결
한 문자열의 모든 접미사를 사전순으로 정렬한 뒤 LCP 배열을 구하면:
- 서로 다른 부분 문자열의 총 개수 계산
- 가장 많이 반복되는 부분 문자열 탐색
등의 고급 문자열 문제들을 선형 시간에 해결할 수 있습니다.
