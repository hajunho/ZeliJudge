# 프림(Prim) 알고리즘과 최소 신장 트리(MST)

### 1. 크루스칼(Kruskal) vs 프림(Prim)
| 비교 항목 | 크루스칼 (Kruskal) | 프림 (Prim) |
|---|---|---|
| **중심 철학** | 간선 중심 (Edge-centric) | 정점 중심 (Vertex-centric) |
| **자료구조** | 유니온 파인드 (Union-Find) | **우선순위 큐 (Min-Heap)** |
| **동작 방식** | 숲(Forest)이 합쳐져 트리 완성 | 하나의 트리 덩어리가 자라남 |
| **추천 그래프** | 간선이 적은 희소 그래프 | 간선이 많은 **밀집 그래프(Dense)** |

---

### 2. 다익스트라와의 놀라운 유사성
프림 알고리즘의 뼈대는 다익스트라 최단 경로 알고리즘과 99% 일치합니다!  
- 다익스트라: `dist[u] + w` (출발점부터의 누적 거리)를 힙에 넣음
- **프림**: 오직 간선의 가중치 `w` 자체를 힙에 넣음 (트리에 새 노드를 편입시키는 비용)
