# 모든 회문을 선형 시간에! 매내처(Manacher) 알고리즘 (O(N) Palindrome)

### 문제 설명
문자열 $S$가 주어집니다.  
이 문자열의 연속된 부분 문자열 중에서 **가장 긴 팰린드롬(대칭 회문)의 길이**를 구하는 프로그램을 작성하세요.

중심 확장법이나 2차원 DP는 최악의 경우 $O(N^2)$의 시간이 걸려 $N=100,000$일 때 100억 번의 연산으로 시간 초과가 발생합니다.  
하지만 **매내처(Manacher) 알고리즘**을 사용하면:
1. 글자 사이에 더미 문자 `#`을 삽입하여 홀수/짝수 길이 회문을 한 번에 처리하고,
2. 이전에 발견한 가장 긴 회문의 대칭 중심($C$)과 우측 경계($R$)를 이용해 대칭점의 반지름을 그대로 재사용함으로써,  
단 한 번의 선형 순회 **$O(N)$**만에 최장 회문 길이를 초고속으로 계산해 냅니다!

---

### 입력 형식
- 첫째 줄에 문자열 $S$가 주어집니다. ($1 \le |S| \le 100000$)
- 문자열은 알파벳 소문자로만 구성됩니다.

---

### 출력 형식
- 가장 긴 팰린드롬 부분 문자열의 길이를 정수로 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
abacaba
```

#### 예제 출력 1
```
7
```
- 설명: 문자열 전체 `abacaba`가 길이 7의 완벽한 팰린드롬입니다.
