# 매내처(Manacher) 알고리즘 ($O(N)$)

### 1. 더미 문자 전처리
`"aba"` $\to$ `"#a#b#a#"` (길이 $2N + 1$).  
짝수 길이 회문(`"abba"`)도 `"#a#b#b#a#"`처럼 중심이 `#`인 홀수 길이 회문으로 통일됩니다.

### 2. 대칭성과 우측 경계 활용
현재 탐색 위치 $i$가 기존 회문의 우측 경계 $R$ 안쪽에 있다면($i < R$),  
대칭점 $i' = 2C - i$의 계산된 반지름 $P[i']$를 최소 보장 반지름으로 즉시 취할 수 있습니다:
$$P[i] = \min(R - i, P[i'])$$
이후 경계 밖의 문자들만 확장 비교하며, 우측 경계 $R$은 단조 증가하기 때문에 전체 문자 비교 횟수는 최대 $2N$번으로 제한되어 **엄격한 $O(N)$ 선형 시간**이 보장됩니다.
