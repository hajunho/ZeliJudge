# 한 번에 구간 전체에 점수 더하기! 차분 펜윅 트리 (Range Update Point Query)

### 문제 설명
길이가 $N$인 수열 $A_1, A_2, \dots, A_N$이 주어집니다.  
다음 두 종류의 질의가 총 $Q$개 주어질 때 이를 처리하는 프로그램을 작성하세요.

1. `1 L R v`: 구간 $[L, R]$에 속하는 모든 원소 $A_k$ ($L \le k \le R$)에 값 $v$를 더합니다.
2. `2 i`: 현재 $A_i$의 값을 출력합니다.

단순 배열로 구간 전체를 반복문으로 더하면 1번 질의마다 $O(N)$이 걸려 시간 초과가 발생합니다.  
**차분 배열(Difference Array)**의 성질과 **펜윅 트리(BIT)**를 결합하여,  
구간 갱신을 양 끝점 두 번의 점 갱신($+v, -v$)으로 변환하고, 점 질의를 누적 합 쿼리로 바꾸어 **모든 질의를 $O(\log N)$**에 초고속 처리해 보세요!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 50000$)과 질의의 개수 $Q$ ($1 \le Q \le 50000$)가 주어집니다.
- 둘째 줄에 $N$개의 초기 수열 정수 $A_1, \dots, A_N$이 주어집니다. ($-10^6 \le A_i \le 10^6$)
- 셋째 줄부터 $Q$개의 줄에 질의가 주어집니다.
  - `1 L R v`: ($1 \le L \le R \le N$, $-10^6 \le v \le 10^6$)
  - `2 i`: ($1 \le i \le N$)

---

### 출력 형식
- `2 i` 질의가 주어질 때마다 해당 위치의 최종 값을 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5 5
10 20 30 40 50
1 2 4 5
2 2
2 3
1 1 5 -10
2 3
```

#### 예제 출력 1
```
25
35
25
```
