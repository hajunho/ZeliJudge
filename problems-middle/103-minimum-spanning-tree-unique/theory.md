# 최소 신장 트리 (MST)의 유일성 판별

### 1. MST가 고유하지 않은 원인
서로 다른 간선들이 **동일한 가중치**를 가지면서 사이클을 이룰 때, 어느 간선을 선택하느냐에 따라 서로 다른 형태의 MST가 복수 개 생길 수 있습니다.

### 2. 제2 최소 신장 트리(Second-Best MST) 접근법
1. 크루스칼 알고리즘으로 기준 MST를 구하고 가중치 $W$와 사용된 $V-1$개의 간선 목록을 확보합니다.
2. MST에 포함된 $V-1$개의 간선 각각에 대해, 해당 간선 1개를 금지한 채 다시 스패닝 트리를 구성해 봅니다.
3. 그중 가중치 합이 여전히 $W$와 같은 트리가 단 하나라도 완성된다면 **`NOT UNIQUE`**, 모든 대체 트리의 비용이 $W$보다 크다면 **`UNIQUE`**로 확정됩니다.
