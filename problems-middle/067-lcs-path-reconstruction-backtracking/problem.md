# 사라진 DNA 조각 복원! 최장 공통 부분 수열(LCS) 문자열 복원

### 문제 설명
앞서 043번 문제에서는 두 문자열의 최장 공통 부분 수열(LCS)의 **길이**만을 구했습니다.  
하지만 생명정보학자들은 길이뿐만 아니라 **실제 일치하는 염기서열 문자열 자체**가 무엇인지 알고 싶어 합니다!

두 문자열 `ACAYKP`와 `CAPCAK`의 2차원 DP 테이블을 완성한 후,  
우하단 $(N, M)$에서부터 좌상단 $(0, 0)$으로 거슬러 올라가는 **역추적(Backtracking)** 기법을 사용하여  
실제 최장 공통 부분 수열 문자열을 복원하세요.  
(길이가 0인 경우 빈 줄을 출력합니다.)

---

### 입력 형식
- 첫째 줄과 둘째 줄에 각각 알파벳 대문자로 구성된 문자열이 한 줄에 하나씩 주어집니다. ($1 \le |S_1|, |S_2| \le 100$)

---

### 출력 형식
- 두 문자열의 최장 공통 부분 수열(LCS) 문자열을 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
ACAYKP
CAPCAK
```

**출력**
```
ACAK
```
