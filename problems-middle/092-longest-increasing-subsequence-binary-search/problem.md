# O(N²)의 한계를 넘어! 이분 탐색 최장 증가 부분 수열 (LIS O(N log N))

### 문제 설명
길이가 $N$인 정수 수열 $A$가 주어집니다.  
수열의 원소들 중에서 원소들이 **엄격하게 증가(오름차순)**하는 가장 긴 부분 수열(LIS, Longest Increasing Subsequence)을 찾는 프로그램을 작성하세요.

단순 $O(N^2)$ 동적 계획법은 $N=100,000$일 때 100억 번의 연산이 걸려 시간 초과가 발생합니다.  
하지만 각 길이별 LIS의 마지막 원소 최솟값을 관리하는 `tails` 배열에 **이진 탐색(`bisect_left`)**을 적용하면 **$O(N \log N)$**의 속도로 LIS의 최대 길이와 실제 수열을 복원할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 100000$)이 주어집니다.
- 둘째 줄에 $N$개의 정수가 공백으로 주어집니다. ($-10^9 \le A_i \le 10^9$)

---

### 출력 형식
- 첫째 줄에 최장 증가 부분 수열의 길이 $L$을 출력합니다.
- 둘째 줄에 복원된 최장 증가 부분 수열의 원소 $L$개를 공백으로 구분하여 출력합니다.  
  (가능한 LIS가 여러 개라면, 복원 알고리즘에 의해 역순 탐색에서 발견되는 유효한 LIS를 출력합니다.)

---

### 입출력 예시

#### 예제 입력 1
```
6
10 20 10 30 20 50
```

#### 예제 출력 1
```
4
10 20 30 50
```
