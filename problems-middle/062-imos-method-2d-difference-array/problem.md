# 색종이 겹쳐 붙이기! 2차원 차분 배열과 이모스법 (2D Imos Method)

### 문제 설명
미술 시간, 수아는 $N \times M$ 크기의 커다란 도화지 위에 $K$장의 직사각형 색종이를 겹쳐 붙였습니다.  
각 색종이 $i$는 좌상단 좌표 $(r_1, c_1)$부터 우하단 좌표 $(r_2, c_2)$까지 도화지 영역을 1겹씩 덮습니다.

도화지의 각 칸마다 색종이가 몇 장이나 겹쳐졌는지 구하고,  
도화지 전체에서 **가장 많이 겹쳐진 칸의 색종이 겹 수(최댓값)**를 구하세요.

색종이를 붙일 때마다 매번 $O(R \times C)$ 칸을 일일이 칠하면 시간 초과가 발생합니다.  
각 색종이의 4개 꼭짓점에만 $+1$과 $-1$을 기록하고 마지막에 단 한 번의 2차원 누적합으로 모든 영역을 복원하는 **2차원 이모스법(Imos Method / 차분 배열)**을 구현하세요!

---

### 입력 형식
- 첫째 줄에 도화지의 크기 $N, M$ ($1 \le N, M \le 100$)과 색종이의 수 $K$ ($1 \le K \le 1000$)가 공백으로 주어집니다.
- 둘째 줄부터 $K$개 줄에 걸쳐 색종이 영역 $r_1, c_1, r_2, c_2$가 주어집니다. ($1 \le r_1 \le r_2 \le N, 1 \le c_1 \le c_2 \le M$)

---

### 출력 형식
- 가장 많이 겹쳐진 칸의 색종이 장수를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
4 5 3
1 1 3 3
2 2 4 4
3 1 4 5
```

**출력**
```
3
```
*설명:*
- (3, 2)와 (3, 3) 구역에는 3장의 색종이가 모두 겹쳐집니다.
