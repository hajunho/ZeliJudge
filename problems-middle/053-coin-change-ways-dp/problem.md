# 동전 조합의 모든 길! 동전 교환 경우의 수 (Coin Change II)

### 문제 설명
마법 저금통을 가진 지민이는 $N$종류의 동전들을 가지고 있습니다.  
각 동전의 액면가는 서로 다르며, 저금통 안에는 각 종류의 동전이 무제한으로 들어있습니다.

지민이는 이 동전들을 조합하여 정확히 $K$원을 만드는 **서로 다른 방법의 총 가짓수**를 알고 싶습니다.  
(단, 동전의 순서만 다르고 구성이 같은 것은 같은 한 가지 방법으로 셉니다. 예: 1원+2원과 2원+1원은 동일)

동적 계획법(DP)을 사용하여 $K$원을 만드는 경우의 수를 구하세요.  
(단, 경우의 수가 매우 클 수 있으므로 $1,000,000,007$로 나눈 나머지를 출력합니다.)

---

### 입력 형식
- 첫째 줄에 동전의 종류 수 $N$ ($1 \le N \le 100$)과 목표 금액 $K$ ($1 \le K \le 10000$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개의 서로 다른 동전 가치가 오름차순 공백으로 주어집니다. ($1 \le \text{동전 가치} \le 10000$)

---

### 출력 형식
- $K$원을 만드는 조합의 총 가짓수를 $1,000,000,007$로 나눈 나머지를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
3 5
1 2 5
```

**출력**
```
4
```
*설명:*
- 5원을 만드는 4가지 조합:
  1. 1원 x 5
  2. 1원 x 3 + 2원 x 1
  3. 1원 x 1 + 2원 x 2
  4. 5원 x 1
