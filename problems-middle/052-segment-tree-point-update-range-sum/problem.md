# 번개 같은 구간 합과 수정! 세그먼트 트리 (Segment Tree)

### 문제 설명
주식 시장 시세 분석관 유진이는 매 순간 값이 바뀌는 $N$개의 주식 가격 데이터를 관리하고 있습니다.  
유진이는 다음 두 종류의 명령을 수없이 빠르게 처리해야 합니다:

1. `1 idx val`: $idx$번째 숫자를 $val$로 바꿉니다 (**단일 점 갱신**).
2. `2 left right`: $left$번째부터 $right$번째까지의 숫자들의 총합을 구합니다 (**구간 합 쿼리**).

일반 배열을 쓰면 구간 합에 $O(N)$이 걸리고, 누적합 배열을 쓰면 단일 값 갱신에 $O(N)$이 걸립니다.  
이 문제를 해결하기 위해 이진 트리 구조로 구간 정보를 저장하는 **세그먼트 트리(Segment Tree)**를 구축하여,  
두 연산 모두를 **$O(\log N)$**의 번개 같은 속도로 처리하세요!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 1000$)과 쿼리의 개수 $Q$ ($1 \le Q \le 1000$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개의 정수가 공백으로 주어집니다. (원소는 $0$ 이상 $10000$ 이하)
- 셋째 줄부터 $Q$개 줄에 걸쳐 명령이 주어집니다:
  - `1 idx val`: $idx$번째 수를 $val$로 갱신 ($1 \le idx \le N, 0 \le val \le 10000$)
  - `2 left right`: $left$부터 $right$까지의 합 ($1 \le left \le right \le N$)

---

### 출력 형식
- `2 left right` 명령이 주어질 때마다 구간 합을 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
5 5
1 2 3 4 5
2 1 5
2 2 4
1 3 10
2 2 4
2 1 5
```

**출력**
```
15
9
16
22
```
*설명:*
- 초기 합 1~5: 1+2+3+4+5 = 15
- 2~4: 2+3+4 = 9
- 3번째 수를 3에서 10으로 갱신: [1, 2, 10, 4, 5]
- 2~4: 2+10+4 = 16
- 1~5: 1+2+10+4+5 = 22
