# 미지수 x를 찾아라! 일차방정식 ax + b = c 풀이

## 📖 문제 설명
중학교 1학년 수학의 꽃, 일차방정식! $ax + b = c$ ($a \ne 0$) 형태의 방정식이 주어질 때, 이항과 등식의 성질을 이용해 미지수 $x$의 값을 완벽하게 풀어내는 인공지능 수학 튜터를 구현해보세요! 해가 딱 떨어지는 정수면 정수로, 나누어떨어지지 않는 분수면 기약분수 형태(`p/q`)로 출력해야 합니다.

## 📥 입력 형식
한 줄에 세 정수 a, b, c가 공백으로 주어집니다. (a != 0, -1,000 <= a, b, c <= 1,000)

## 📤 출력 형식
방정식의 해 x를 출력합니다. 정수면 정수(예: 3, -2, 0), 분수면 기약분수(예: 1/2, -3/4) 형태로 출력합니다. (분모는 항상 양수여야 합니다)

## 💡 입출력 예시
### 예시 1
**입력**
```text
2 3 7
```
**출력**
```text
2
```

## 힌트
일차방정식 ax + b = c (a != 0)의 해 x를 구합니다. 정수 해인 경우 정수로, 분수 해인 경우 기약분수 p/q 형태로 출력합니다.
