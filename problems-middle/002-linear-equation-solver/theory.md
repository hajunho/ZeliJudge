# 일차방정식의 풀이와 기약분수 표현

## 1. 이항과 등식의 성질
$ax + b = c$ 에서:
1. 상수항 $b$를 우변으로 이항: $ax = c - b$
2. 양변을 $x$의 계수 $a$로 나눔: $x = \frac{c - b}{a}$

## 2. 해의 정규화 (Normalization)
분자 $num = c - b$, 분모 $den = a$ 일 때:
1. **정수 해 판별**: $num \% den == 0$ 이면 정수 $num // den$ 을 출력합니다.
2. **분수 해 기약분수화**:
   - 분모 $den$이 음수라면 분자와 분모에 모두 $-1$을 곱해 **분모를 항상 양수**로 만듭니다.
   - 분자와 분모의 최대공약수 $g = GCD(|num|, |den|)$을 구합니다.
   - $num //= g$, $den //= g$ 로 약분한 뒤 `num/den` 문자열로 출력합니다.
