# 정렬된 두 배열의 병합 (Merge Algorithm)

병합 정렬(Merge Sort)의 가장 중요한 핵심 연산입니다.

## 1. 알고리즘
- 포인터 `p1 = 0`, `p2 = 0`으로 시작합니다.
- 둘 다 끝에 도달하지 않은 동안:
  - `A[p1] <= B[p2]` 이면 `A[p1]`을 결과에 넣고 `p1 += 1`
  - 그렇지 않으면 `B[p2]`를 결과에 넣고 `p2 += 1`
- 어느 한쪽 배열이 먼저 끝나면, 아직 남아있는 다른 쪽 배열의 원소들을 몽땅 결과 뒤에 이어 붙입니다.
- 각 원소를 최대 한 번씩만 확인하므로 시간 복잡도는 완벽한 $O(N + M)$입니다!
