# 그리디 알고리즘과 배수 동전 체계

## 1. 탐욕 선택 속성 (Greedy Choice Property)
지금 당장 가장 가치가 큰 동전을 최대한 많이 사용하는 선택이, 전체 문제를 해결하는 최적의 해로 이어집니다.

## 2. 왜 배수 관계일 때만 그리디가 통할까요?
예를 들어 동전이 [1원, 50원, 100원, 500원]처럼 큰 동전이 작은 동전의 배수라면, 작은 동전을 여러 개 모아서 큰 동전 1개로 바꾸는 것이 무조건 동전 개수를 줄여줍니다.
(반면 배수가 아닌 [1원, 4원, 5원]으로 8원을 만들 때는 그리디(5+1+1+1=4개)보다 DP(4+4=2개)가 최적입니다).
따라서 배수 조건이 보장될 때는 가장 큰 동전부터 `K // coin` 개수만큼 사용하고 `K %= coin` 하는 $O(N)$ 그리디가 가장 우아하고 빠릅니다!
