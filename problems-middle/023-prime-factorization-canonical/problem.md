# 소인수분해 표준 분해식! (Prime Factorization p^e)

## 📖 문제 설명
중학교 1학년 수학의 첫 단원! 1보다 큰 모든 자연수는 소수들의 곱으로 유일하게 나타낼 수 있다는 '산술의 기본정리'를 배웁니다. 예를 들어 72는 2^3 * 3^2 로, 12는 2^2 * 3 으로 깔끔하게 정리할 수 있습니다. 자연수 N이 주어질 때 소인수가 작은 순서대로 지수를 붙여(지수가 1이면 생략) 표준 분해식 문자열로 출력해주세요!

## 📥 입력 형식
한 줄에 자연수 N (2 <= N <= 10,000,000)이 주어집니다.

## 📤 출력 형식
소인수분해 표준 분해식을 공백과 '*'로 구분하여 출력합니다. (예: 72 -> 2^3 * 3^2, 12 -> 2^2 * 3, 7 -> 7)

## 💡 입출력 예시
### 예시 1
**입력**
```text
72
```
**출력**
```text
2^3 * 3^2
```

## 힌트
자연수 N을 소인수분해하여 작은 소인수부터 p 또는 p^e 형태의 곱으로 나타낸 표준 분해식을 출력합니다.
