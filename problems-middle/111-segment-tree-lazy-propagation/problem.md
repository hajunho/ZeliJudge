# 나중에 필요할 때 전파하자! 느리게 갱신되는 세그먼트 트리 (Lazy Propagation)

### 문제 설명
길이가 $N$인 수열 $A_1, A_2, \dots, A_N$이 주어집니다.  
다음 두 종류의 질의가 총 $Q$개 주어질 때 이를 순서대로 처리하는 프로그램을 작성하세요.

1. `1 L R v`: 구간 $[L, R]$에 속하는 모든 원소에 정수 $v$를 더합니다.
2. `2 L R`: 구간 $[L, R]$의 **원소들의 총합($\sum_{k=L}^R A_k$)**을 출력합니다.

일반 세그먼트 트리에서 구간 전체를 하나씩 리프까지 내려가 갱신하면 한 번에 $O(N)$이 걸려 시간 초과가 발생합니다.  
하지만 노드를 방문할 때까지 실제 갱신을 미루어 두는 **Lazy Propagation(느리게 갱신되는 세그먼트 트리)** 기법을 사용하면,  
**구간 갱신과 구간 합 질의 모두를 $O(\log N)$**에 완벽하게 처리할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 50000$)과 질의의 개수 $Q$ ($1 \le Q \le 50000$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, \dots, A_N$이 공백으로 주어집니다. ($-10^6 \le A_i \le 10^6$)
- 셋째 줄부터 $Q$개의 줄에 걸쳐 질의가 주어집니다.
  - `1 L R v`: ($1 \le L \le R \le N, -10^6 \le v \le 10^6$)
  - `2 L R`: ($1 \le L \le R \le N$)

---

### 출력 형식
- `2 L R` 질의가 주어질 때마다 구간 합의 결과를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5 4
1 2 3 4 5
2 1 5
1 2 4 10
2 1 5
2 2 3
```

#### 예제 출력 1
```
15
45
25
```
