# 느리게 갱신되는 세그먼트 트리 (Segment Tree with Lazy Propagation)

### 1. Lazy Propagation의 핵심 철학
구간 $[L, R]$에 값을 더할 때, 굳이 리프 노드까지 모든 자식을 일일이 갱신할 필요가 없습니다.  
현재 노드의 담당 구간이 $[L, R]$에 완전히 포함되면:
- 현재 노드의 `tree[node]`에 `(구간 길이) * v`를 바로 반영합니다.
- 자식들에게 전달할 갱신 값은 `lazy[node]`에 적어두기만 하고 탐색을 즉시 종료합니다!

### 2. 전파(Propagate) 시점
이후 임의의 질의나 갱신으로 자식 노드를 방문해야 할 때,  
비로소 부모 노드에 보관되어 있던 `lazy` 값을 두 자식에게 물려주는 `propagate` 함수를 호출합니다.  
이를 통해 구간 갱신 역시 트리 높이에만 비례하는 **$O(\log N)$** 시간에 완료됩니다.
