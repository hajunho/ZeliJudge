# 멱등성의 마법! 희소 배열(Sparse Table)과 O(1) 구간 최솟값 쿼리

### 문제 설명
길이가 $N$인 정적 정수 수열 $A_1, A_2, \dots, A_N$이 주어집니다.  
수열의 원소 값은 변경되지 않으며, 구간 $[L, R]$의 **최솟값($\min_{i=L}^R A_i$)**을 묻는 질의가 총 $Q$개 주어집니다.

세그먼트 트리는 질의마다 $O(\log N)$이 걸리지만, 원소가 수정되지 않는 정적 환경에서는  
최솟값 연산의 **멱등성(Idempotency: $\min(x, x) = x$)**을 활용하는 **희소 배열(Sparse Table)**을 사용하면:
- 전처리 시간: $O(N \log N)$
- 구간 최솟값 질의: **단 $O(1)$**
만에 단 한 번의 중첩 구간 연산으로 초고속 응답할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 100000$)과 질의의 수 $Q$ ($1 \le Q \le 100000$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, \dots, A_N$ ($-10^9 \le A_i \le 10^9$)이 공백으로 주어집니다.
- 셋째 줄부터 $Q$개의 줄에 걸쳐 질의 $L, R$ ($1 \le L \le R \le N$)이 주어집니다.

---

### 출력 형식
- 각 질의마다 구간 최솟값을 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
6 4
4 6 1 5 7 3
1 3
2 4
4 6
1 6
```

#### 예제 출력 1
```
1
1
3
1
```
