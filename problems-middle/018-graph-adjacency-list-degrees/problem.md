# SNS 친구 네트워크! 인접 리스트와 친구 수 (Graph Degree)

## 📖 문제 설명
소셜 네트워크 서비스(SNS)에서 V명의 사용자와 그들 사이의 양방향 친구 관계 E개가 주어집니다. 컴퓨터가 네트워크를 표현할 때 가장 많이 쓰는 방법은 각 사용자마다 친구 목록을 연결해두는 '인접 리스트(Adjacency List)'입니다. 네트워크가 주어질 때 1번 사용자부터 V번 사용자까지 각자가 가진 친구의 수(차수, Degree)를 차례대로 출력해주세요!

## 📥 입력 형식
첫 줄에 사용자의 수 V와 친구 관계의 수 E가 공백으로 주어집니다. (1 <= V <= 10,000, 0 <= E <= 100,000)\n다음 E개의 줄에 걸쳐 친구 관계인 두 사용자 번호 u와 v가 공백으로 주어집니다. (1 <= u, v <= V, u != v, 중복 간선 없음)

## 📤 출력 형식
1번 사용자부터 V번 사용자까지 각 사용자의 친구 수를 공백으로 구분하여 한 줄에 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
3 3
1 2
2 3
3 1
```
**출력**
```text
2 2 2
```

## 힌트
V명의 사람과 E개의 양방향 친구 관계가 주어질 때 인접 리스트를 구성하고 각 사람의 친구 수(차수, Degree)를 구합니다.
