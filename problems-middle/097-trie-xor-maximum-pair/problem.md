# 비트의 갈림길을 따라! 트라이를 이용한 두 수의 최대 XOR (Maximum XOR Pair)

### 문제 설명
$N$개의 0 이상의 정수로 이루어진 수열 $A_1, A_2, \dots, A_N$이 주어집니다.  
이 중에서 **서로 다른 두 수 $A_i, A_j$ ($i \neq j$)를 선택하여 비트 단위 XOR 연산($A_i \oplus A_j$)을 수행했을 때 얻을 수 있는 최댓값**을 구하는 프로그램을 작성하세요.

모든 쌍을 비교하는 $O(N^2)$ 방식은 $N=50,000$일 때 수십억 번의 연산으로 시간 초과가 발생합니다.  
각 수를 31자리 이진수 비트열로 보아 **이진 트라이(Binary Trie)**를 구축하면, 각 수마다 반대 비트(0이면 1, 1이면 0)를 최상위 비트(MSB)부터 탐욕적으로 따라 내려가며 **단 $O(N \times 30)$**만에 전역 최대 XOR을 초고속으로 찾아낼 수 있습니다!

---

### 입력 형식
- 첫째 줄에 정수의 개수 $N$ ($2 \le N \le 50000$)이 주어집니다.
- 둘째 줄에 $N$개의 0 이상의 정수가 공백으로 주어집니다. ($0 \le A_i \le 10^9$)

---

### 출력 형식
- 서로 다른 두 수의 XOR 연산 결과 중 최댓값을 정수로 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
6
3 10 5 25 2 8
```

#### 예제 출력 1
```
28
```
- 설명: $5 \oplus 25 = 28$ (이진수 `00101` $\oplus$ `11001` = `11100` = 28)이 최댓값입니다.
