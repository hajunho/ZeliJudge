# 슬라이딩 해시의 기적! 라빈-카프(Rabin-Karp) 부분 문자열 탐색

### 문제 설명
전체 문자열 $S$에서 찾고자 하는 패턴 문자열 $P$가 몇 번 등장하는지, 그리고 등장하는 시작 위치(1-indexed)를 모두 찾는 프로그램을 작성하세요.

단순 비교 방식은 최악의 경우 $O(N \times M)$의 시간이 걸려 문자열이 길어지면 비효율적입니다.  
**라빈-카프(Rabin-Karp)** 알고리즘은 윈도우를 한 글자씩 오른쪽으로 밀면서, **롤링 해시(Rolling Hash)**를 이용해 $O(1)$에 새로운 윈도우의 해시값을 갱신합니다.  
해시값이 일치할 때만 실제 문자열을 비교함으로써 평균 $O(N + M)$ 시간에 부분 문자열을 초고속으로 탐색할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 전체 문자열 $S$가 주어집니다. ($1 \le |S| \le 100000$)
- 둘째 줄에 패턴 문자열 $P$가 주어집니다. ($1 \le |P| \le 100000$)
- 두 문자열은 모두 알파벳 소문자/대문자 또는 숫자로만 이루어져 있습니다.

---

### 출력 형식
- 첫째 줄에 문자열 $S$ 내에서 패턴 $P$가 나타나는 횟수를 출력합니다.
- 둘째 줄에 $P$가 시작하는 위치(1-based 인덱스)를 오름차순으로 공백으로 구분하여 출력합니다. (등장하지 않으면 둘째 줄은 출력하지 않습니다.)

---

### 입출력 예시

#### 예제 입력 1
```
ababababa
aba
```

#### 예제 출력 1
```
4
1 3 5 7
```
