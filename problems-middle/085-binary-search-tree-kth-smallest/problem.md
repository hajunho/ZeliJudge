# 정렬 없이 K번째 순위 찾기! BST와 중위 순회 (In-Order Kth Smallest)

### 문제 설명
비어 있는 이진 검색 트리(BST)에 $N$개의 서로 다른 정수를 주어진 순서대로 차례차례 삽입합니다.

이진 검색 트리는 다음 규칙을 엄격히 따릅니다:
1. 삽입할 값이 현재 노드보다 작으면 **왼쪽 자식** 서브트리로 내려갑니다.
2. 삽입할 값이 현재 노드보다 크면 **오른쪽 자식** 서브트리로 내려갑니다.

모든 정수를 삽입한 후:
1. 트리를 **중위 순회(In-Order Traversal: 왼쪽 $\to$ 루트 $\to$ 오른쪽)**한 결과를 출력하세요.  
   (BST의 중위 순회 결과는 항상 완벽한 **오름차순 정렬**이 됩니다!)
2. 트리에서 **$K$번째로 작은 원소**를 찾아 출력하세요.

---

### 입력 형식
- 첫째 줄에 삽입할 정수의 개수 $N$ ($1 \le N \le 10000$)과 순위 $K$ ($1 \le K \le N$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개의 서로 다른 정수가 삽입 순서대로 공백으로 주어집니다. ($-10^9 \le \text{정수} \le 10^9$)

---

### 출력 형식
- 첫째 줄에 중위 순회 결과를 공백으로 구분하여 출력합니다.
- 둘째 줄에 $K$번째로 작은 원소의 값을 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
6 3
5 3 7 2 4 8
```

#### 예제 출력 1
```
2 3 4 5 7 8
4
```
- 설명: 중위 순회하면 오름차순 `2, 3, 4, 5, 7, 8`이 되며, 3번째로 작은 원소는 `4`입니다.
