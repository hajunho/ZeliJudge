# 검색창 자동완성의 비밀! 트라이(Trie) 접두사 사전

### 문제 설명
스마트폰 검색창에 단어의 앞 글자만 쳐도 연관 검색어들이 주르륵 뜨는 **자동완성(Autocomplete)** 기능은 어떤 자료구조로 만들어질까요?

바로 문자열 검색에 특화된 트리인 **트라이(Trie / 발음: '트라이')** 덕분입니다.  
트라이는 공통 접두사(Prefix)를 공유하는 트리 형태로 단어들을 저장하므로,  
사전에 수십만 개의 단어가 있어도 검색하려는 접두사의 길이 $L$만큼만 트리 간선을 따라 내려가면 **$O(L)$**의 눈 깜짝할 새에 검색을 마칩니다.

$N$개의 단어로 이루어진 사전을 트라이에 등록한 후,  
$Q$개의 접두사(Prefix) 질문에 대해 **해당 접두사로 시작하는 사전 단어의 총 개수**를 구하세요.

---

### 입력 형식
- 첫째 줄에 사전 단어 수 $N$ ($1 \le N \le 500$)과 질문 수 $Q$ ($1 \le Q \le 500$)가 공백으로 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 알파벳 소문자로 된 단어가 주어집니다.
- 그 다음 $Q$개 줄에 걸쳐 검색할 접두사(Prefix) 문자열이 주어집니다.

---

### 출력 형식
- 각 접두사마다 해당 접두사로 시작하는 단어의 개수를 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
5 3
apple
app
application
banana
band
app
ban
cat
```

**출력**
```
3
2
0
```
*설명:*
- `app`으로 시작하는 단어: `apple`, `app`, `application` (3개)
- `ban`으로 시작하는 단어: `banana`, `band` (2개)
- `cat`으로 시작하는 단어: 없음 (0개)
