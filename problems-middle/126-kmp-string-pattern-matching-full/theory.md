# KMP (Knuth-Morris-Pratt) 알고리즘의 완전 정복

### 1. 실패 함수 $\pi$의 진정한 의미
$\pi[i]$는 패턴 $P[0..i]$에서 접두사(Prefix)와 접미사(Suffix)가 일치하는 최대 길이입니다.  
불일치가 발생했을 때, 지금까지 일치했던 접두사의 접미사는 다시 새로운 접두사로 활용할 수 있으므로, 본문 포인터를 되감지 않고 $j = \pi[j-1]$로 이동할 수 있습니다.

### 2. 완전 일치 후의 처리
패턴의 마지막 글자까지 모두 일치($j == |P|-1$)하여 매칭을 하나 찾았을 때:
- 시작 인덱스 `i - |P| + 2`를 결과에 추가합니다.
- 다음 중첩 매칭을 찾기 위해 $j = \pi[j]$로 포인터를 이동시켜 계속 탐색합니다.
시간 복잡도는 엄격한 **$O(|T| + |P|)$**입니다.
