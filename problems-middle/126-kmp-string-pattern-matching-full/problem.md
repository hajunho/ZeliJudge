# 실패를 두려워하지 않는 검색! KMP 전체 일치 인덱스 탐색 (KMP Full Match)

### 문제 설명
본문 문자열 $T$와 찾고자 하는 패턴 문자열 $P$가 주어집니다.  
본문 $T$ 안에서 패턴 $P$가 등장하는 **총 횟수**와, 등장하는 모든 **시작 위치(1-indexed)**를 오름차순으로 출력하는 프로그램을 작성하세요.

**KMP (Knuth-Morris-Pratt)** 알고리즘은:
1. 패턴 문자열 $P$의 각 접두사에 대해 가장 긴 접두사-접미사 일치 길이 $\pi$ 배열(실패 함수)을 $O(|P|)$에 구축하고,
2. 본문 탐색 중 불일치가 발생하더라도 본문 포인터를 뒤로 되돌리지 않고, 패턴의 포인터만 $\pi[j-1]$로 건너뛰어 탐색을 이어갑니다.
3. 따라서 **단 한 번의 선형 탐색 $O(|T| + |P|)$**만에 모든 일치 위치를 완벽하게 수집합니다!

---

### 입력 형식
- 첫째 줄에 본문 문자열 $T$가 주어집니다. ($1 \le |T| \le 100000$)
- 둘째 줄에 패턴 문자열 $P$가 주어집니다. ($1 \le |P| \le 100000$)
- 문자열은 알파벳 대소문자 및 숫자로만 구성됩니다.

---

### 출력 형식
- 첫째 줄에 패턴이 등장한 총 횟수를 출력합니다.
- 둘째 줄에 패턴이 등장하는 시작 위치(1-based)들을 오름차순으로 공백으로 구분하여 출력합니다. (등장하지 않으면 둘째 줄은 출력하지 않습니다.)

---

### 입출력 예시

#### 예제 입력 1
```
ABC ABCDAB ABCDABCDABDE
ABCDABD
```

#### 예제 출력 1
```
1
16
```
