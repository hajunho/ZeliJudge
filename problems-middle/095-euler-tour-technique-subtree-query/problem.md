# 트리를 일렬로 펴서 배열로 만들기! 오일러 투어 테크닉 (Euler Tour Technique)

### 문제 설명
1번 노드를 루트로 하는 $N$개의 노드로 이루어진 트리가 있습니다.  
각 노드 $i$는 정수 값 $V_i$를 가지고 있습니다.

다음 두 종류의 질의가 총 $Q$개 주어질 때 이를 처리하는 프로그램을 작성하세요:
1. `1 u v`: 노드 $u$의 값을 $v$로 변경합니다.
2. `2 u`: 노드 $u$를 루트로 하는 **서브트리에 속한 모든 노드의 값의 합**을 출력합니다.

트리에서 서브트리의 합을 매번 탐색하면 $O(N)$이 걸리지만,  
**오일러 투어 테크닉(Euler Tour Technique, ETT)**을 사용하면 트리의 계층 구조를 **1차원 배열의 연속된 구간 $[in_u, out_u]$**으로 완벽하게 펼쳐놓을 수 있습니다!  
1차원 배열로 변환된 트리에 펜윅 트리를 결합하여 **모든 갱신과 서브트리 합 질의를 $O(\log N)$**에 해결해 보세요!

---

### 입력 형식
- 첫째 줄에 노드의 수 $N$ ($1 \le N \le 50000$)과 질의의 수 $Q$ ($1 \le Q \le 50000$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개 노드의 초기 값 $V_1, V_2, \dots, V_N$ ($-10^6 \le V_i \le 10^6$)이 공백으로 주어집니다.
- 셋째 줄부터 $N-1$개의 줄에 걸쳐 트리의 간선 $u, v$ ($1 \le u, v \le N$)가 주어집니다.
- 그 다음 $Q$개의 줄에 걸쳐 질의가 주어집니다.
  - `1 u v`: ($-10^6 \le v \le 10^6$)
  - `2 u`: ($1 \le u \le N$)

---

### 출력 형식
- `2 u` 질의가 주어질 때마다 서브트리의 총합을 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5 4
10 20 30 40 50
1 2
1 3
2 4
2 5
2 1
2 2
1 4 100
2 2
```

#### 예제 출력 1
```
150
110
170
```
- 설명: 1번 루트 트리의 전체 합은 $10+20+30+40+50 = 150$. 2번 노드의 서브트리는 `{2, 4, 5}`로 합은 $20+40+50 = 110$. 4번의 값을 100으로 바꾸면 2번 서브트리 합은 $20+100+50 = 170$이 됩니다.
