# 달팽이 수열 심화! R x C 직사각형 나선형 격자 채우기

## 📖 문제 설명
초등부에서 배운 정사각형 달팽이 수열을 넘어, 이번에는 가로와 세로의 길이가 서로 다른 직사각형(R x C) 모눈종이에 도전합니다! 젤리는 왼쪽 위 (0, 0)에서 출발하여 오른쪽(우), 아래(하), 왼쪽(좌), 위(상) 시계방향으로 회전하며 1부터 R*C까지 숫자를 채워 넣으려고 합니다. 직사각형 나선형 배열을 완성해주세요!

## 📥 입력 형식
한 줄에 행의 수 R과 열의 수 C가 공백으로 주어집니다. (1 <= R, C <= 50)

## 📤 출력 형식
R개의 줄에 걸쳐 각 행의 C개 정수를 공백으로 구분하여 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
2 3
```
**출력**
```text
1 2 3
6 5 4
```

## 힌트
R행 C열의 직사각형 모눈종이에 1부터 R*C까지의 숫자를 시계방향 나선형으로 채워 출력합니다.
