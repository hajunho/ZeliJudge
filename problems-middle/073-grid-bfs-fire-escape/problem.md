# 활활 타오르는 불길을 피해라! 다원 BFS와 격자 탈출 (Fire Escape)

### 문제 설명
미로에 갇힌 지훈이는 건물에 번지는 불길을 피해 가장자리로 탈출해야 합니다.
미로의 크기는 $R \times C$이며, 각 칸은 다음과 같이 표현됩니다:
- `#`: 벽 (통과 불가)
- `.`: 빈 공간 (이동 가능)
- `J`: 지훈이의 초기 위치 (1개 주어짐)
- `F`: 불이 난 위치 (0개 이상 주어질 수 있음)

매 분마다:
1. 지훈이는 상, 하, 좌, 우 인접한 빈 공간(`.`)으로 1칸 이동할 수 있습니다.
2. 불길은 상, 하, 좌, 우 인접한 모든 빈 공간으로 동시에 번져나갑니다.
3. 지훈이는 불이 도달하기 전(지훈이 도달 시간 < 불 도달 시간)에만 해당 칸으로 이동할 수 있습니다.
4. 지훈이가 미로의 가장 바깥 테두리 칸(0행, $R-1$행, 0열, $C-1$열)에 도달하면 다음 1분에 건물 밖으로 즉시 탈출할 수 있습니다. (즉, 가장자리 칸 도달 시간 + 1분)

지훈이가 불을 피해 무사히 탈출할 수 있는 최소 시간을 구하세요. 탈출할 수 없다면 `IMPOSSIBLE`을 출력합니다.

---

### 입력 형식
- 첫째 줄에 미로의 행 수 $R$과 열 수 $C$가 공백으로 주어집니다. ($1 \le R, C \le 500$)
- 둘째 줄부터 $R$개의 줄에 걸쳐 미로의 지도가 주어집니다.

---

### 출력 형식
- 지훈이가 탈출할 수 있다면 최소 탈출 시간을 출력하고, 탈출할 수 없다면 `IMPOSSIBLE`을 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
4 4
####
#JF#
#..#
#..#
```

#### 예제 출력 1
```
3
```
