# 포함-배제의 원리 (Principle of Inclusion-Exclusion, PIE)

### 1. 집합의 합집합 크기 공식
$K$개의 사건 $A_1, A_2, \dots, A_K$에 대해 합집합의 크기는:
$$|A_1 \cup \dots \cup A_K| = \sum_{i} |A_i| - \sum_{i < j} |A_i \cap A_j| + \sum_{i < j < k} |A_i \cap A_j \cap A_k| - \dots$$
- 1개 선택한 집합 크기 합산 ($+$)
- 2개 선택한 교집합 크기 감산 ($-$)
- 3개 선택한 교집합 크기 합산 ($+$) ...

### 2. 비트마스크 구현
$1$부터 $2^K - 1$까지의 비트마스크를 순회하며:
- 켜진 비트의 개수(`popcount`)가 홀수이면 `+ (N // prod)`
- 켜진 비트의 개수가 짝수이면 `- (N // prod)`
를 누적합니다. 소수들의 곱이 $N$을 초과하면 나눗셈 몫이 0이므로 조기 탈출할 수 있습니다.
