# 겹치는 건 빼고 빠진 건 더해라! 포함-배제의 원리 (Inclusion-Exclusion)

### 문제 설명
1 이상 $N$ 이하의 자연수 중에서, 주어진 $K$개의 서로 다른 소수 $p_1, p_2, \dots, p_K$ 중 **적어도 하나의 배수인 수의 총 개수**를 구하는 프로그램을 작성하세요.

예를 들어 $N = 20$, 소수가 `[2, 3]`이라면:
- 2의 배수의 개수: $\lfloor 20 / 2 \rfloor = 10$개
- 3의 배수의 개수: $\lfloor 20 / 3 \rfloor = 6$개
- 두 소수의 공배수(6의 배수): $\lfloor 20 / 6 \rfloor = 3$개
중복으로 두 번 세어진 공배수를 빼주면: $10 + 6 - 3 = 13$개가 됩니다.

$K$개의 소수에 대해서도 비트마스크를 활용한 **포함-배제의 원리(Principle of Inclusion-Exclusion)**를 적용하면:
- 홀수 개의 소수의 곱으로 나누어떨어지는 개수는 **더하고**,
- 짝수 개의 소수의 곱으로 나누어떨어지는 개수는 **빼는** 방식으로 정확한 개수를 $O(2^K)$에 계산할 수 있습니다!

---

### 입력 형식
- 첫째 줄에 자연수 $N$ ($1 \le N \le 10^9$)과 소수의 개수 $K$ ($1 \le K \le 10$)가 공백으로 주어집니다.
- 둘째 줄에 $K$개의 서로 다른 소수가 공백으로 주어집니다. ($2 \le p_i \le 100$)

---

### 출력 형식
- 1부터 $N$까지의 자연수 중 주어진 소수들 중 적어도 하나의 배수인 수의 총 개수를 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
20 2
2 3
```

#### 예제 출력 1
```
13
```
