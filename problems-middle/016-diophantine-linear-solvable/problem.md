# 정수해를 찾아라! 일차 디오판토스 방정식 Ax + By = C

## 📖 문제 설명
고대 수학자 디오판토스의 비밀 금고! A리터 물병과 B리터 물병만을 사용하여 물을 채우거나 비우면서 정확히 C리터의 물을 만들 수 있을까요? 이 문제는 일차 디오판토스 방정식 $Ax + By = C$의 정수해 $(x, y)$가 존재하는가와 정확히 같은 문제입니다. 베주 항등식에 따르면 C가 $\gcd(A, B)$의 배수일 때만 정수해가 존재합니다! 정수해가 존재하는지 YES 또는 NO로 판정해주세요.

## 📥 입력 형식
한 줄에 세 자연수 A, B, C가 공백으로 주어집니다. (1 <= A, B, C <= 1,000,000,000)

## 📤 출력 형식
정수해 (x, y)가 존재하면 YES, 불가능하면 NO를 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
6 9 12
```
**출력**
```text
YES
```

## 힌트
일차 부정방정식 Ax + By = C에서 정수해 (x, y)가 존재하는지 베주 항등식(Bézout's identity)으로 판별합니다.
