# 베주 항등식 (Bézout's Identity)과 디오판토스 방정식

## 1. 정리
정수 $A$와 $B$에 대하여:
$$Ax + By = C$$
를 만족하는 **정수 $(x, y)$가 존재할 필요충분조건**은 **$C$가 $\gcd(A, B)$의 배수**인 것입니다.

## 2. 물통 문제와의 연관성
- $A$리터 물통을 $x$번 채우고($x > 0$) 비우는($x < 0$) 과정은 $Ax$로 표현됩니다.
- 두 물통으로 측정 가능한 물의 양은 무조건 $\gcd(A, B)$의 배수일 수밖에 없습니다!
- 예: $A = 6, B = 9 \rightarrow \gcd(6, 9) = 3$.
  - $C = 12$: 3의 배수이므로 가능 (**YES**!)
  - $C = 5$: 3의 배수가 아니므로 불가능 (**NO**!)
