# 유전자 염기서열 비교! 최장 공통 부분 수열 (LCS)

### 문제 설명
생명과학 연구실 인턴 지수는 두 생물의 DNA 염기서열 유사도를 분석하고 있습니다.  
두 문자열이 주어졌을 때, 두 문자열 모두의 부분 수열(Subsequence)이 되는 수열 중 **가장 긴 것**을 **최장 공통 부분 수열(Longest Common Subsequence, LCS)**이라고 합니다.

예를 들어 `ACAYKP`와 `CAPCAK`의 LCS는 `ACAK`이며 그 길이는 4입니다:
- `A C A Y K P`
- `C A P C A K`
- 공통 부분 수열: `A`, `C`, `A`, `K`

2차원 동적 계획법(DP)을 사용하여 두 문자열의 **LCS 길이**를 계산하는 프로그램을 작성하세요.

---

### 입력 형식
- 첫째 줄과 둘째 줄에 각각 알파벳 대문자로 구성된 문자열이 한 줄에 하나씩 주어집니다.  
  (각 문자열의 길이는 1 이상 100 이하입니다.)

---

### 출력 형식
- 두 문자열의 최장 공통 부분 수열(LCS)의 길이를 한 줄에 출력합니다.

---

### 입출력 예시

#### 예시 1
**입력**
```
ACAYKP
CAPCAK
```

**출력**
```
4
```
