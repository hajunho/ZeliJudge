# 최장 공통 부분 수열(LCS)과 2차원 DP

### 1. 부분 문자열(Substring) vs 부분 수열(Subsequence)
- **부분 문자열 (Substring)**: 연속되어 끊기지 않은 글자 덩어리 (예: `ABC` in `XABCD`)
- **부분 수열 (Subsequence)**: 원래 문자열에서 몇몇 글자를 건너뛰고 순서만 유지한 것 (예: `AC` in `ABCD`)

---

### 2. LCS의 점화식 설계
두 문자열 $S_1$의 $i$번째 글자와 $S_2$의 $j$번째 글자를 비교할 때:

1. **글자가 같을 때 ($S_1[i] == S_2[j]$)**:
   이 글자는 LCS의 일원이 될 수 있습니다!
   $$DP[i][j] = DP[i-1][j-1] + 1$$

2. **글자가 다를 때 ($S_1[i] \ne S_2[j]$)**:
   둘 중 한 글자를 제외했을 때의 최댓값을 물려받습니다.
   $$DP[i][j] = \max(DP[i-1][j], DP[i][j-1])$$

---

### 3. 복잡도와 활용
- **시간 복잡도**: $O(N \times M)$
- **공간 복잡도**: $O(N \times M)$
- **활용**: Git diff (코드 변경점 추적), 유전자 서열 정렬(BLAST), 음성 인식 오차 검사 등 컴퓨터 과학 전 분야의 표준 알고리즘입니다.
