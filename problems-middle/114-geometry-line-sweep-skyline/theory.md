# 라인 스위핑과 스카이라인 (Skyline Problem)

### 1. 이벤트 기반 라인 스위핑
빌딩 $(L, R, H)$을 두 개의 수직선 이벤트로 분해합니다:
- 시작 이벤트 $(L, \text{높이 } H)$: 빌딩 등장
- 끝 이벤트 $(R, 0)$: 빌딩 퇴장
이벤트들을 $x$좌표 순서로 정렬하여 왼쪽에서 오른쪽으로 훑어 나갑니다.

### 2. 우선순위 큐(Max-Heap)를 이용한 실시간 최고 높이 추적
현재 $x$좌표를 덮고 있는 활성 빌딩들의 높이 중 최댓값을 항상 힙의 루트에서 $O(1)$에 얻습니다.  
오래되어 이미 지나간 빌딩($R \le x$)은 힙의 루트에서 지연 제거(Lazy Pop)합니다.  
현재 최고 높이가 이전 최고 높이와 달라지는 순간마다 새로운 스카이라인 꼭짓점이 탄생합니다!
총 시간 복잡도는 $O(N \log N)$입니다.
