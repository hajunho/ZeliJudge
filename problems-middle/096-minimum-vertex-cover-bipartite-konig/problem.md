# 감시 카메라 최소 설치! 이분 매칭과 쾨닉의 정리 (König's Theorem)

### 문제 설명
어느 미술관은 복도를 사이에 두고 왼쪽 구역($A$)에 $N$개의 방, 오른쪽 구역($B$)에 $M$개의 방이 있습니다.  
두 구역의 방을 잇는 통로가 총 $E$개 존재합니다. (모든 통로는 $A$ 구역의 방과 $B$ 구역의 방 사이만 연결합니다.)

미술관의 모든 통로를 감시하기 위해 방에 경비원을 배치하려고 합니다.  
통로의 양 끝 방 중 **적어도 한 곳**에 경비원이 배치되어 있다면 그 통로는 안전하게 감시됩니다.  
모든 통로를 빈틈없이 감시하기 위해 배치해야 하는 **경비원의 최소 인원수(최소 버텍스 커버, Minimum Vertex Cover)**를 구하는 프로그램을 작성하세요.

일반 그래프에서 최소 버텍스 커버는 악명 높은 NP-난해 문제이지만,  
**이분 그래프(Bipartite Graph)에서는 쾨닉의 정리(König's Theorem)**에 의해:
$$\text{최소 버텍스 커버의 크기} = \text{최대 이분 매칭(Max Bipartite Matching)의 크기}$$
가 완벽하게 성립합니다! 이분 매칭 알고리즘을 통해 최소 인원수를 구해보세요!

---

### 입력 형식
- 첫째 줄에 $A$ 구역 방의 수 $N$ ($1 \le N \le 1000$), $B$ 구역 방의 수 $M$ ($1 \le M \le 1000$), 통로의 수 $E$ ($0 \le E \le 5000$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개의 줄에 걸쳐 통로로 연결된 두 방의 번호 $u, v$ ($1 \le u \le N, 1 \le v \le M$)가 주어집니다.

---

### 출력 형식
- 모든 통로를 감시하기 위해 필요한 경비원의 최소 인원수를 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
3 3 4
1 1
1 2
2 2
3 3
```

#### 예제 출력 1
```
3
```
- 설명: 최대 매칭은 $(1-1), (2-2), (3-3)$의 3쌍이며, 쾨닉의 정리에 의해 필요한 최소 감시 정점 수도 3개입니다.
