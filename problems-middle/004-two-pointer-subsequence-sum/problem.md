# 두 포인터 협동 작전! (연속 부분 수열의 합 S)

## 📖 문제 설명
도서관 책장에 꽂힌 책들의 두께가 수열로 주어집니다. 젤리는 책꽂이에서 '연속으로 꽂힌 책들'을 골라 두께의 총합이 정확히 목표치 S가 되도록 포장 상자에 담으려고 합니다. 이중 반복문으로 모든 구간을 검사하면 O(N^2)으로 시간이 오래 걸리지만, 양 끝을 조절하는 '투 포인터(Two Pointers)' 기술을 쓰면 O(N)만에 해결할 수 있습니다! 경우의 수를 구하세요.

## 📥 입력 형식
첫 줄에 수열의 길이 N과 목표 합 S가 공백으로 주어집니다. (1 <= N <= 100,000, 1 <= S <= 1,000,000,000)\n둘째 줄에 양의 정수 N개가 공백으로 주어집니다. (각 정수 <= 10,000)

## 📤 출력 형식
연속 부분 수열의 합이 S가 되는 구간의 개수를 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
10 5
1 2 3 4 2 5 3 1 1 2
```
**출력**
```text
3
```

## 힌트
양의 정수로 이루어진 길이 N의 수열에서 연속된 구간의 합이 정확히 S가 되는 경우의 수를 투 포인터(Two Pointer)로 O(N)에 구합니다.
