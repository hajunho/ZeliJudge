# 최소 비용 전력망 연결! 크루스칼(Kruskal) 알고리즘

### 문제 설명
신도시 건설 본부장 준호는 $V$개의 마을에 전기를 공급하기 위한 송전선 설치 계획을 세우고 있습니다.  
마을들 사이에 송전선을 놓을 수 있는 후보 도로 $E$개가 있으며, 각 도로마다 설치 비용이 다릅니다.

모든 마을이 서로 전력망을 통해 연결되도록 하되, **송전선 설치 총비용을 최소**로 만들고자 합니다.  
단, 사이클(불필요하게 뱅뱅 도는 루프)이 생기면 예산이 낭비되므로, 정확히 $V-1$개의 도로만 선택해야 합니다.

간선들을 비용 순으로 탐욕적으로 선택하며 유니온 파인드로 사이클을 검사하는 **크루스칼(Kruskal) 알고리즘**을 구현하여,  
모든 마을을 연결하는 **최소 신장 트리(MST, Minimum Spanning Tree)**의 총 가중치 합을 구하세요.

---

### 입력 형식
- 첫째 줄에 마을의 수 $V$ ($1 \le V \le 100$)와 설치 가능한 도로의 수 $E$ ($0 \le E \le 500$)가 공백으로 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 도로 정보 $u, v, w$가 주어집니다. ($1 \le u, v \le V$, $1 \le w \le 1000$, $u \ne v$)

---

### 출력 형식
- 모든 마을을 연결하는 최소 비용을 한 줄에 출력합니다.  
  (만약 도로가 부족하여 모든 마을을 하나로 연결할 수 없다면 `-1`을 출력합니다. $V=1$인 경우 연결할 간선이 없으므로 `0`을 출력합니다.)

---

### 입출력 예시

#### 예시 1
**입력**
```
3 3
1 2 1
2 3 2
1 3 3
```

**출력**
```
3
```
*설명:*
- (1, 2) 비용 1 선택
- (2, 3) 비용 2 선택
- (1, 3) 비용 3은 1과 3이 이미 2를 통해 연결되어 사이클이 되므로 무시
- 총 비용 = 1 + 2 = 3
