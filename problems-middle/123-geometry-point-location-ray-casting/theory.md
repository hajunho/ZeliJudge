# 레이 캐스팅 (Ray Casting) 알고리즘과 점-다각형 포함 판정

### 1. 조던 곡선 정리 (Jordan Curve Theorem)
닫힌 평면 곡선으로 둘러싸인 영역에서, 내부의 한 점에서 무한대로 나아가는 임의의 반직선은 항상 곡선의 경계선을 **홀수 번** 교차합니다. 반대로 외부의 점에서 나아가는 반직선은 항상 **짝수 번** 교차합니다.

### 2. 예외 처리
- **둘레 위(ON)**: 점이 변의 외적($\text{cross} == 0$)과 바운딩 박스 내에 존재하면 `ON`으로 즉시 판정합니다.
- **꼭짓점 스치기 방지**: 반직선과 교차 판정 시 `(y1 > qy) != (y2 > qy)` 조건을 사용하여, 꼭짓점에 걸쳤을 때 위쪽 점만 교차로 세어 중복 카운트를 방지합니다.
