# 세그먼트 트리와 구간 최솟값 쿼리 (RMQ, Range Minimum Query)

### 1. 세그먼트 트리 노드의 의미
각 노드는 특정 구간 $[start, end]$의 정보를 담당합니다.
- `tree[node] = min(tree[2 * node], tree[2 * node + 1])`
- 리프 노드는 원본 배열의 단일 원소 값을 갖습니다.

### 2. 질의와 갱신의 $O(\log N)$ 복잡도
- **구간 최솟값 질의**: 구간이 완전히 포함되면 즉시 노드 값을 반환하고, 겹치지 않으면 무한대($\infty$)를 반환하여 두 자식의 최솟값을 취합니다. 트리의 깊이가 $\lceil \log_2 N \rceil$이므로 최대 $4 \log N$개의 노드만 방문합니다.
- **단일 원소 갱신**: 해당 원소를 포함하는 리프 노드까지 내려가 값을 바꾸고, 올라오면서 부모 노드들의 최솟값을 재계산합니다.
