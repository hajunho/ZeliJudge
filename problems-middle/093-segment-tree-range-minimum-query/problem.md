# 구간 내 최솟값을 한눈에! 세그먼트 트리 구간 최솟값 쿼리 (RMQ)

### 문제 설명
길이가 $N$인 수열 $A_1, A_2, \dots, A_N$이 주어집니다.  
다음 두 종류의 질의가 총 $Q$개 주어질 때 이를 순서대로 처리하는 프로그램을 작성하세요.

1. `1 i v`: $i$번째 원소의 값을 $v$로 변경합니다. ($1 \le i \le N$)
2. `2 L R`: 구간 $[L, R]$에 속한 원소들 중 **최솟값($\min_{k=L}^R A_k$)**을 출력합니다. ($1 \le L \le R \le N$)

단순 선형 탐색($O(N)$) 대신 **세그먼트 트리(Segment Tree)**를 구축하여 갱신과 구간 최솟값 질의(RMQ, Range Minimum Query)를 모두 **$O(\log N)$**에 해결해 보세요!

---

### 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 50000$)과 질의의 개수 $Q$ ($1 \le Q \le 50000$)가 공백으로 주어집니다.
- 둘째 줄에 $N$개의 정수가 공백으로 주어집니다. ($-10^9 \le A_i \le 10^9$)
- 셋째 줄부터 $Q$개의 줄에 걸쳐 질의가 주어집니다.
  - `1 i v`: ($-10^9 \le v \le 10^9$)
  - `2 L R`: ($1 \le L \le R \le N$)

---

### 출력 형식
- `2 L R` 질의가 주어질 때마다 구간 최솟값을 한 줄에 하나씩 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
5 5
5 3 7 9 1
2 1 5
1 2 10
2 1 3
2 4 5
2 2 4
```

#### 예제 출력 1
```
1
5
1
7
```
