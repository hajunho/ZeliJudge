# U자형 함수의 가장 낮은 바닥을 찾아라! 삼분 탐색 (Ternary Search)

### 문제 설명
아래로 볼록한 2차 다항 함수 $f(x) = a x^2 + b x + c$ ($a > 0$)가 주어집니다.  
이 함수는 하나의 극솟점을 기준으로 왼쪽은 단조 감소, 오른쪽은 단조 증가하는 **단봉 함수(Unimodal Function)**입니다.

주어진 정수 닫힌 구간 $[L, R]$ 내에서,  
$f(x)$의 값을 **최소로 만드는 정수 $x$**와 그때의 **최솟값 $f(x)$**를 구하는 프로그램을 작성하세요.  
(만약 최솟값을 만드는 정수 $x$가 2개라면, 더 작은 $x$를 출력합니다.)

이분 탐색은 단조 증가/감소하는 함수에 적용하지만,  
구간을 3등분($m_1, m_2$)하여 $f(m_1)$과 $f(m_2)$를 비교해 후보 구간의 $1/3$을 매번 버리는 **삼분 탐색(Ternary Search)**을 사용하면 $O(\log(R - L))$에 최솟값을 찾아낼 수 있습니다!

---

### 입력 형식
- 첫째 줄에 2차 함수 계수 $a, b, c$ ($1 \le a \le 1000, -10^6 \le b, c \le 10^6$)와 구간 $L, R$ ($-10^6 \le L \le R \le 10^6$)이 공백으로 주어집니다.

---

### 출력 형식
- 첫째 줄에 최솟값을 갖는 정수 $x$를 출력합니다.
- 둘째 줄에 그때의 최솟값 $f(x)$를 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
1 -4 4 0 5
```

#### 예제 출력 1
```
2
0
```
- 설명: $f(x) = x^2 - 4x + 4 = (x - 2)^2$. $x=2$일 때 최솟값 0을 갖습니다.
