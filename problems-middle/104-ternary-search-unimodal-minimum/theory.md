# 삼분 탐색 (Ternary Search)

### 1. 단봉 함수 (Unimodal Function)
함수가 감소하다가 증가하는 U자형 볼록 곡선일 때:
구간 $[L, R]$을 3등분하는 두 지점 $m_1 = L + (R - L)/3$, $m_2 = R - (R - L)/3$을 잡습니다.
- 만약 $f(m_1) < f(m_2)$라면, 최솟점은 절대 $[m_2, R]$ 구간에 있을 수 없으므로 오른쪽 $1/3$ 구간을 버립니다 ($R = m_2$).
- 만약 $f(m_1) > f(m_2)$라면, 최솟점은 절대 $[L, m_1]$ 구간에 있을 수 없으므로 왼쪽 $1/3$ 구간을 버립니다 ($L = m_1$).

### 2. 시간 복잡도
매 단계마다 탐색 대상 구간이 $2/3$로 줄어들므로, 복잡도는 $O(\log_{1.5}(R - L))$입니다.  
구간 폭이 작아졌을 때는 남은 몇 개의 정수점을 전수 비교하여 마무리합니다.
