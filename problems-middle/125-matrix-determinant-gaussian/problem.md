# 평행육면체의 부피와 행렬식! 가우스 소거법 행렬식 (Matrix Determinant)

### 문제 설명
$N \times N$ 크기의 정방행렬 $A$가 주어집니다.  
이 행렬의 **행렬식(디터미넌트, Determinant $\det(A)$)**을 구하는 프로그램을 작성하세요.

라플라스 전개(여인수 전개)는 $O(N!)$의 시간이 걸려 $N=10$만 되어도 멈춰버립니다.  
하지만 행렬식의 기본 성질을 이용하면:
1. 두 행을 교환하면 부호가 반전된다 ($\det \to -\det$).
2. 한 행에 다른 행의 상수배를 더해도 행렬식은 변하지 않는다.

**가우스 소거법**으로 행렬을 **상삼각 행렬(Upper Triangular Matrix)**로 변환한 후,  
**주대각선 원소들을 모두 곱하기만 하면 $O(N^3)$**에 정확한 행렬식을 구할 수 있습니다!

- 결과는 소수점 첫째 자리까지 형식화(`{ans:.1f}`)하여 출력합니다.

---

### 입력 형식
- 첫째 줄에 행렬의 크기 $N$ ($1 \le N \le 50$)이 주어집니다.
- 둘째 줄부터 $N$개의 줄에 걸쳐 각 행의 실수 원소 $N$개가 공백으로 주어집니다. ($-1000 \le A_{ij} \le 1000$)

---

### 출력 형식
- 행렬식 $\det(A)$의 값을 소수점 첫째 자리까지 출력합니다.

---

### 입출력 예시

#### 예제 입력 1
```
2
1 2
3 4
```

#### 예제 출력 1
```
-2.0
```
- 설명: $\det = 1 \times 4 - 2 \times 3 = 4 - 6 = -2.0$.
