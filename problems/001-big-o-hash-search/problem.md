## 📖 실무 버그 시나리오

AI 코딩 툴의 열렬한 신봉자인 주니어 개발자 민수는 신규 이벤트를 앞두고 다음과 같은 요구사항을 구현해야 했습니다:

> *"어제 로그인한 유저 목록(A)과 오늘 결제한 유저 목록(B)을 비교해서, **양쪽 모두에 존재하는 유저 ID**를 오름차순으로 추출해 주세요."*

민수는 고민 없이 AI 챗봇에게 프롬프트를 입력했고, AI는 3초 만에 아래와 같은 깔끔한 파이썬 코드를 작성해 주었습니다:

```python
# AI가 작성해 준 코드
def find_common_users(list_a, list_b):
    common = []
    for user in list_a:
        if user in list_b:       # <- 참사의 원인!
            common.append(user)
    return sorted(common)
```

민수는 개발 환경에서 더미 유저 50명을 넣고 테스트했습니다. **0.001초** 만에 완벽한 결과가 나왔습니다! 만족한 민수는 코드를 그대로 프로덕션 서버에 배포했습니다.

다음 날 오전 9시, 이벤트가 오픈되자 어제 로그인 유저 10만 명($N=100,000$), 오늘 결제 유저 10만 명($M=100,000$)이 들어왔습니다.
그리고 시스템은 **그대로 멈춰버렸습니다.**

CPU 사용률은 100%를 찍었고, 서버는 10분이 지나도 응답하지 않았습니다. 당황한 민수는 AI에게 *"서버가 왜 멈추지?"*라고 물었지만, AI는 엉뚱하게 메모리 증설이나 멀티스레딩 타령만 늘어놓았습니다.

도대체 민수의 코드에는 무슨 문제가 있었던 걸까요?

## 🎯 문제 설명

두 정수 리스트 $A$와 $B$가 주어집니다.
두 리스트에 **동시에 존재하는 원소(교집합)**들을 찾아 **오름차순으로 정렬**하여 출력하는 고성능 프로그램을 작성하세요.

* $A$와 $B$에는 각각 최대 $100,000$개의 정수가 주어집니다.
* $O(N \times M)$의 비효율적인 탐색으로는 시간 초과(Time Limit Exceeded) 판정을 받게 됩니다.
* 반드시 **시간 복잡도 $O(N + M)$ 또는 $O((N + M) \log(N + M))$** 이내로 해결해야 합니다.

---

## 📥 입력 형식 (Input)

* **첫째 줄**: 리스트 $A$의 크기 $N$과 리스트 $B$의 크기 $M$이 공백으로 구분되어 주어집니다. ($1 \le N, M \le 100,000$)
* **둘째 줄**: 리스트 $A$의 원소 $N$개가 공백으로 구분되어 주어집니다.
* **셋째 줄**: 리스트 $B$의 원소 $M$개가 공백으로 구분되어 주어집니다.
* 원소의 값은 $-1,000,000,000$ 이상 $1,000,000,000$ 이하의 정수입니다. 각 리스트 내부에는 중복된 값이 존재할 수 있습니다.

---

## 📤 출력 형식 (Output)

* 두 리스트에 공통으로 존재하는 원소들을 **중복 없이, 오름차순(작은 수부터)으로 정렬**하여 첫째 줄에 공백으로 구분하여 출력합니다.
* 공통 원소가 하나도 없다면 아무것도 출력하지 않거나 빈 줄을 출력합니다.
