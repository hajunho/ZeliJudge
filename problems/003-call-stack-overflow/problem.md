## 📖 실무 버그 시나리오

사내 파일 시스템 백업 및 조직도 인덱싱 도구를 만들던 주니어 엔지니어 하준이는 계층형 트리(Tree) 구조를 탐색하는 기능을 맡았습니다.
하준이는 AI 코딩 툴에게 다음과 같이 요청했습니다:

> *"루트 폴더(1번)부터 시작해서 하위 폴더들을 깊이 우선 탐색(DFS)하며, 각 폴더의 깊이(Depth)와 파일 용량(가중치)을 곱한 총 관리 비용을 계산해 줘."*

AI는 아름답고 우아한 10줄짜리 재귀(Recursion) 함수를 짜주었습니다:

```python
# AI가 작성해 준 코드
def calculate_cost(node, depth, adj, weights):
    cost = depth * weights[node]
    for child in adj[node]:
        if not visited[child]:
            visited[child] = True
            cost += calculate_cost(child, depth + 1, adj, weights)  # <- 재귀 호출!
    return cost
```

하준이는 폴더 50개짜리 테스트 환경에서 실행해 보았습니다. 코드는 너무나 깔끔하게 동작했고, 재귀의 우아함에 감탄하며 프로덕션에 배포했습니다.

하지만 다음 날, 사내 아카이브 서버의 거대한 디렉토리를 스캔하자마자 시스템이 **비명도 지르지 못하고 터져버렸습니다**:

```text
RecursionError: maximum recursion depth exceeded while calling a Python object
```

당황한 하준이가 AI에게 해결책을 묻자, AI는 다음과 같은 위험천만한 팁을 알려주었습니다:
> *"파이썬의 기본 재귀 제한은 1,000회입니다. `sys.setrecursionlimit(1000000)`을 코드 맨 위에 추가하세요!"*

하준이는 그대로 적용했습니다. 하지만 이번에는 `RecursionError`도 없이, **운영체제(OS)가 파이썬 프로세스를 강제로 사살(Segmentation Fault / STATUS_STACK_OVERFLOW)**해 버렸습니다!

AI는 언어의 문법은 알았지만, **운영체제가 프로세스에 할당하는 물리적 '스택 메모리'의 한계(보통 1MB~8MB)**는 전혀 몰랐던 것입니다.

## 🎯 문제 설명

$N$개의 노드로 이루어진 트리(계층 구조)가 주어집니다.  
각 노드는 $1$번부터 $N$번까지 번호가 매겨져 있으며, **루트 노드는 항상 $1$번 노드**입니다.

각 노드 $i$는 고유한 가중치(파일 크기) $W_i$를 가지고 있습니다.  
루트 노드($1$번)의 깊이를 **$1$**이라 하고, 자식 노드로 한 칸 내려갈 때마다 깊이가 $1$씩 증가합니다.

모든 노드 $i$ ($1 \le i \le N$)에 대해 **(노드의 깊이 $\times$ 노드의 가중치 $W_i$)** 의 총합을 계산하여 출력하세요:

$$\text{총 비용} = \sum_{i=1}^{N} (\text{depth}_i \times W_i)$$

### ⚠️ 주의 사항
* 트리는 균형 잡힌 트리뿐만 아니라, 한 줄로 길게 늘어선 **편향 트리(Skewed Tree / 최대 깊이 $100,000$)** 형태로 주어질 수 있습니다.
* 단순 재귀 함수나 무분별한 `sys.setrecursionlimit()`을 사용하면 채점 시스템에서 **런타임 에러(RTE - RecursionError 또는 Stack Overflow)**를 받게 됩니다.
* **시스템 콜 스택 대신 힙(Heap) 메모리를 활용하는 명시적 스택(Explicit Stack)이나 큐(Queue)를 사용한 반복문으로 작성해야 합니다.** ([theory.md](theory.md) 참고)

---

## 📥 입력 형식 (Input)

* **첫째 줄**: 트리의 노드 개수 $N$ ($1 \le N \le 100,000$)
* **둘째 줄**: $1$번 노드부터 $N$번 노드까지의 가중치 $W_1, W_2, \dots, W_N$이 공백으로 구분되어 주어집니다. ($1 \le W_i \le 1,000$)
* **셋째 줄부터 $N-1$개의 줄**: 트리의 간선을 연결하는 두 정수 $u, v$가 공백으로 구분되어 주어집니다. ($1 \le u, v \le N, u \ne v$)
  * 트리의 루트는 항상 $1$번 노드입니다.

---

## 📤 출력 형식 (Output)

* 모든 노드에 대한 $(\text{depth}_i \times W_i)$ 의 총합을 첫째 줄에 정수로 출력합니다.

---

## 💡 예제 1

### 입력
```text
4
10 20 30 40
1 2
1 3
2 4
```

### 출력
```text
230
```

### 힌트
* 노드 1 (루트): 깊이 1, 가중치 10 $\rightarrow 1 \times 10 = 10$
* 노드 2: 깊이 2, 가중치 20 $\rightarrow 2 \times 20 = 40$
* 노드 3: 깊이 2, 가중치 30 $\rightarrow 2 \times 30 = 60$
* 노드 4 (노드 2의 자식): 깊이 3, 가중치 40 $\rightarrow 3 \times 40 = 120$
* 총 비용: $10 + 40 + 60 + 120 = 230$

---

## 💡 예제 2 (깊이 5 편향 트리)

### 입력
```text
5
1 2 3 4 5
1 2
2 3
3 4
4 5
```

### 출력
```text
55
```

### 힌트
* 1번(깊이 1): $1 \times 1 = 1$
* 2번(깊이 2): $2 \times 2 = 4$
* 3번(깊이 3): $3 \times 3 = 9$
* 4번(깊이 4): $4 \times 4 = 16$
* 5번(깊이 5): $5 \times 5 = 25$
* 합계: $1 + 4 + 9 + 16 + 25 = 55$

## 🔍 채점 엣지케이스 안내
1. **$N = 100,000$ 완전 편향 트리 (Linear Chain)**: 깊이가 10만인 일직선 트리. 단순 재귀를 사용할 경우 반드시 크래시 발생.
2. $N = 1$ 인 단일 노드 트리
3. 루트 노드에 모든 자식이 직접 연결된 스타형(Star) 트리 (깊이 2)
4. 완전 이진 트리 (Balanced Binary Tree)
