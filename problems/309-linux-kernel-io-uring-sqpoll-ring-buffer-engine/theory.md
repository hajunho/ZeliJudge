# 기술 이론: 리눅스 커널 io_uring 아키텍처 및 제로 시스콜 I/O 메커니즘

## 1. 개요 및 I/O 시스템 콜의 한계
리눅스에서 1회 시스템 콜(`read`, `write`, `epoll_wait`)을 호출하는 비용은 다음과 같습니다:
- CPU 유저 모드 $\to$ 커널 모드 진입 및 복귀 (약 100~150 사이클).
- Spectre v2 완화 패치(KPTI, Retpoline)로 인한 페이지 테이블 스왑 및 분기 예측 버퍼 플러시 (약 200~400 사이클).
- 초당 100만 회 I/O 발생 시 순수 시스템 콜 진입 오버헤드만으로 CPU 코어 1~2개가 완전히 낭비됩니다.

2019년 리눅스 커널 5.1에 도입된 **`io_uring`**은 I/O 제출과 완료를 커널 공간과 유저 공간이 `mmap()`으로 공유하는 2개의 락리스 순환 큐(Circular Ring Buffer)로 분리하여 이 문제를 완벽히 해결했습니다.

```
 [ 유저 애플리케이션 (Tokio / RocksDB) ]
        │                            ▲
        │ mmap() 공유 메모리         │ mmap() 공유 메모리
        ▼                            │
 ┌──────────────────────┐    ┌──────────────────────┐
 │  Submission Queue    │    │  Completion Queue    │
 │  (SQ Ring Buffer)    │    │  (CQ Ring Buffer)    │
 └──────────┬───────────┘    └──────────▲───────────┘
            │                           │
            ▼                           │
 ┌──────────────────────────────────────┴───────────┐
 │ 리눅스 커널 fs/io_uring.c                        │
 │                                                  │
 │   [ io_uring-sq 커널 스레드 (SQPOLL 모드) ]      │
 │   - 시스템 콜 없이 SQ tail 변경 감지             │
 │   - 비동기 NVMe 블록 드라이버 직접 디스패치      │
 └──────────────────────────────────────────────────┘
```

---

## 2. SQPOLL (Submission Queue Polling)과 제로 시스콜

- **일반 모드**: 유저 공간이 SQ 링에 SQE를 채운 후, 커널에 이를 알리기 위해 `io_uring_enter()` 시스템 콜을 1회 호출해야 함.
- **SQPOLL 모드 (`IORING_SETUP_SQPOLL`)**:
  - 전용 커널 스레드가 실시간으로 `sq_ring->tail`을 모니터링하므로, 유저는 메모리에 쓰기만 하면 끝남.
  - 시스템 콜 호출 횟수 = **0회 (Zero-Syscall)**!
  - 유휴 상태에서는 전력 절약을 위해 수면하며, `IORING_SQ_NEED_WAKEUP` 비트를 세팅하여 필요 시에만 유저가 1회 `enter`로 깨우도록 협력적 전력 제어 수행.

## 3. IOSQE_IO_LINK 체인과 연쇄 취소

복잡한 데이터베이스 트랜잭션(WAL 기록 $\to$ 체크포인트 fsync $\to$ 테이블스페이스 업데이트)을 비동기로 실행할 때, 애플리케이션이 중간 결과를 기다리지 않고 한 번에 체인으로 제출할 수 있습니다:
$$\text{SQE}_1 \xrightarrow{\text{LINK}} \text{SQE}_2 \xrightarrow{\text{LINK}} \text{SQE}_3$$
- 커널이 자체적으로 의존성을 해결하며, 만약 $\text{SQE}_1$이 디스크 풀(ENOSPC)이나 불량 섹터로 실패하면, 커널이 $\text{SQE}_2, \text{SQE}_3$의 I/O 발송을 즉시 중단하고 `-ECANCELED`로 안전하게 롤백합니다.
