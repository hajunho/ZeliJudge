## 📖 실무 버그 시나리오

커뮤니티 서비스의 댓글 관리 기능을 개발하던 주니어 개발자 유나는 운영팀으로부터 긴급 요청을 받았습니다:

> *"특정 스팸 키워드(예: `광고`)가 포함된 불량 단어들을 댓글 단어 목록에서 모두 삭제해 주세요."*

유나는 AI 코딩 도구에게 *"파이썬 리스트를 돌면서 금지어 단어를 삭제하는 코드를 짜줘"*라고 부탁했습니다.  
AI는 너무나 직관적으로 보이는 코드를 제안했습니다:

```python
# AI가 작성해 준 코드 (치명적인 건너뛰기 버그)
def filter_spam(words, spam_word):
    for word in words:
        if word == spam_word:
            words.remove(word)  # <- 참사의 원인!
    return words
```

유나는 단어 4개짜리 샘플로 테스트를 해보았습니다:
```python
words = ["좋은글", "광고", "광고", "감사합니다"]
result = filter_spam(words, "광고")
print(result)
```

유나는 두 눈을 의심했습니다. 분명 두 번째와 세 번째 단어가 둘 다 `"광고"`였는데, 결과는 다음과 같았습니다:

```python
["좋은글", "광고", "감사합니다"]  # 어?! 왜 광고 1개가 뻔뻔하게 살아남았지?!
```

유나는 코드를 다시 들여다보았습니다.  
`for word in words:`로 모든 단어를 돌렸고, `if word == spam_word:`로 비교해서 분명 `remove()`를 호출했는데, **왜 연속으로 붙어있는 금지어는 하나를 쏙 건너뛰고 절반만 지워진 걸까요?**

도대체 유나의 코드에서는 무슨 일이 일어난 걸까요?

AI는 파이썬 문법의 겉모습만 알려주었을 뿐, **컴퓨터 메모리에서 배열(Array)의 원소가 삭제될 때 뒤쪽 데이터가 앞으로 당겨지는 '인덱스 시프트(Index Shift)'의 물리적 원리**는 전혀 설명해주지 않았던 것입니다.

## 🎯 문제 설명

$N$개의 단어로 이루어진 텍스트 리스트와 제거해야 할 금지어 단어 $B$가 주어집니다.
리스트에서 금지어 $B$와 정확히 일치하는 단어들을 **단 하나도 빠짐없이 모두 제거**한 후, 남은 단어들을 원래 순서대로 출력하세요.

### ⚠️ 주의 사항
* 단어의 개수 $N$은 최대 $100,000$개입니다.
* 금지어가 2개, 3개, 혹은 수십 개씩 **연속으로 나란히 붙어있는 경우**에도 건너뛰지 않고 100% 모두 제거되어야 합니다.
* 순진하게 `for word in words: words.remove(word)`를 사용하면, 원소가 건너뛰어지는 **오답(Wrong Answer)**이 발생할 뿐만 아니라, `remove()`의 내부 동작으로 인해 **$O(N^2)$ 시간 복잡도(100억 번 연산)로 시간 초과(TLE)**가 발생합니다.
* 반드시 **새로운 리스트에 모으는 리스트 컴프리헨션($O(N)$)이나 안전한 필터링 기법**을 적용하여 해결해야 합니다. ([theory.md](theory.md) 참고)

---

## 📥 입력 형식 (Input)

* **첫째 줄**: 단어의 총 개수 $N$ ($1 \le N \le 100,000$)
* **둘째 줄**: $N$개의 단어가 공백으로 구분되어 주어집니다. (각 단어는 알파벳 소문자로만 구성되며 길이는 $1$ 이상 $20$ 이하)
* **셋째 줄**: 제거해야 할 금지어 단어 $B$가 주어집니다. (알파벳 소문자, 길이 $1$ 이상 $20$ 이하)

---

## 📤 출력 형식 (Output)

* 금지어 $B$를 모두 제거하고 남은 단어들을 원래 순서대로 첫째 줄에 공백으로 구분하여 출력합니다.
* 모든 단어가 제거되어 남은 단어가 하나도 없다면 아무것도 출력하지 않거나 빈 줄을 출력합니다.

---

## 💡 예제 1 (연속된 금지어 저격)

### 입력
```text
4
hello spam spam world
spam
```

### 출력
```text
hello world
```

### 힌트
* `words = ["hello", "spam", "spam", "world"]`
* `spam` 2개가 나란히 붙어있습니다.
* 나이브하게 `for` 문 안에서 `remove()`를 돌리면 1번째 `spam`이 지워지면서 2번째 `spam`이 앞으로 당겨져 건너뛰어지지만, 올바른 코드는 2개의 `spam`을 모두 완벽하게 제거하여 `hello world`를 출력합니다.
