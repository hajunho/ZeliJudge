# [배경 이론] 정규식 하나 검사했더니 CPU 100%로 서버가 영구 동결?!: ReDoS와 NFA 백트래킹 폭발 (Regular Expression Denial of Service)

## 1. 현실 비유: 열쇠 꾸러미와 10억 개의 미로 방

자물쇠가 달린 문이 있고, 여러분에게 **열쇠 30개**가 주어졌습니다.

- **DFA (결정적 유한 오토마타 / Thompson NFA)**:
  - 스마트 마스터키입니다. 열쇠 구멍에 대면 단 한 번(선형 시간 $O(N)$)에 문이 열리는지 아닌지 즉시 판별합니다.
- **NFA 백트래킹 엔진 (전통적 정규식 엔진: Python `re`, Java, PCRE, JavaScript)**:
  - 1번 열쇠를 꽂아봅니다. 안 맞으면 뒤로 돌아가서(Backtrack) "1번 열쇠를 반쯤 돌린 상태에서 2번을 꽂아볼까?", "아니면 1번을 3번 돌리고 2번을 꽂아볼까?"를 고민합니다.
  - 가능한 모든 조합을 하나하나 다 시도해 보느라, 글자 수가 1글자 늘어날 때마다 **시도해야 할 조합의 수가 2배($O(2^N)$)로 폭증**합니다!
  - 30글자짜리 문자열 하나를 검사하는 데 무려 **$2^{30} = 10억$ 번 이상의 헛발질(Backtracking)**을 하느라 서버 CPU가 100%로 치솟고 프로세스가 영구히 얼어붙습니다.

> **실제 역사적 사건 (2019년 7월 2일 클라우드플레어 전 세계 장애)**:  
> Cloudflare의 WAF(웹 방화벽) 룰에 `.*.*=.*` 형태의 불량 정규식이 배포되자마자, 전 세계 수만 대의 엣지 서버 CPU가 100%를 찍으며 구글, 디스코드, 쇼피파이 등 전 세계 인터넷 트래픽의 상당수가 30분간 올스톱되는 역사상 최대 규모의 ReDoS 장애가 발생했습니다.

## 2. 왜 백트래킹(Backtracking)이 폭발하는가?

### 취약한 악마의 패턴 (Evil Patterns)
가장 대표적인 취약 패턴은 **중첩된 수량자(Nested Quantifiers)**입니다:

$$\text{Regex: } \mathbf{(a+)+}\$$$

이 정규식은 "하나 이상의 `a`"를 다시 "하나 이상 반복"한 뒤, 문자열 끝(`$`)을 찾는 패턴입니다.

문자열 `"aaaaX"`를 검사할 때 정규식 엔진의 내부 동작:
1. `(a+)`가 앞의 `aaaa`를 전부 탐욕적(Greedy)으로 먹습니다.
2. 뒤에 `$`(끝)을 기대했는데 불청객 `'X'`가 나타납니다! 일치 실패!
3. **백트래킹 시작**:
   - *"혹시 첫 번째 `a+`가 `aaa`만 먹고, 두 번째 `a+`가 `a`를 먹으면 맞을까?"*
   - *"아니면 첫 번째가 `aa`, 두 번째가 `aa`를 먹으면 맞을까?"*
   - *"아니면 `[a, a, aa]`, `[a, aa, a]`, `[aa, a, a]`, `[a, a, a, a]` 일까?"*
4. 길이 $N$인 문자열을 양의 정수의 합으로 분할하는 경우의 수(정수 분할)는 정확히 **$2^{N-1}$가지**입니다!
   - $N=10 \implies 512$번 탐색
   - $N=20 \implies 524,288$번 탐색 (수십만 번)
   - $N=30 \implies 536,870,912$번 탐색 (5억 번 $\to$ 수 분간 CPU 100%)
   - $N=40 \implies 549,755,813,888$번 탐색 (5천억 번 $\to$ 서버 영구 멈춤)

## 3. 해결책: 구글 RE2와 선형 시간 오토마타 (Thompson NFA / DFA)

컴퓨터 과학의 거장 켄 톰슨(Ken Thompson)은 1968년 논문에서 이미 **"백트래킹 없이 모든 정규식을 입력 문자열 길이 $O(N)$만에 검사하는 Thompson NFA 알고리즘"**을 증명했습니다.

```
[비교: 입력 문자열 길이가 늘어날 때 실행 시간]
실행 시간 (Time)
   ▲
   │        /  (전통적 NFA 백트래킹: O(2^N) 지수 폭발!) 💥 ReDoS
   │       /
   │      /
   │     /
   │    /
   │   /
   │  /
   │ /_____________________ (Google RE2 / Thompson NFA: O(N) 완벽한 선형 시간) ✅
   └────────────────────────────────────────► 문자열 길이 (N)
```

- **Google RE2 (Go 언어 표준 `regexp`, Rust `regex`)**:
  - 백트래킹을 원천 배제하고 톰슨 NFA / DFA 시뮬레이션을 사용하여 **입력값이 아무리 악의적이더라도 항상 $O(N)$ 시간**을 보장합니다.
  - ReDoS 공격이 물리적으로 불가능합니다.
- **방어 대책**:
  1. 사용자 입력 정규식에 대해 **백트래킹 최대 단계(Max Steps) 또는 타임아웃**을 강제 설정합니다.
  2. 정적 분석기(Static Analyzer)를 통해 중첩 수량자(`(a+)+`, `(a|aa)+`)를 배포 전에 사전 차단합니다.
