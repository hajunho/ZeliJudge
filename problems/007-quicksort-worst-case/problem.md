# 007. 정렬의 배신과 최악의 분할: 퀵소트 O(N²) 함정과 Timsort

* **난이도**: Lv.2 (실무 필수 / 알고리즘 핵심)
* **카테고리**: 정렬 알고리즘, 분할 정복(Divide & Conquer), 최악 시간 복잡도, Timsort
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 CS 이론**: [theory.md 읽으러 가기](theory.md)

## 📖 실무 버그 시나리오

핀테크 거래소에서 실시간 체결가 및 주문 호가 데이터를 처리하는 엔진을 개발하던 주니어 엔지니어 준혁이는 대용량 시계열 가격 데이터를 정렬하는 모듈을 맡았습니다.

"세상에서 평균적으로 가장 빠른 정렬은 퀵소트(QuickSort)다"라는 전공 수업의 한 구절을 기억한 준혁이는 AI에게 다음과 같이 요청했습니다:

> *"가장 빠른 퀵정렬(QuickSort) 알고리즘을 파이썬으로 구현해 줘."*

AI는 교과서에 나오는 가장 전형적인 퀵소트 코드를 3초 만에 작성해 주었습니다:

```python
# AI가 작성해 준 교과서식 퀵소트
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]  # <- 참사의 원인: 첫 번째 원소를 무조건 피벗으로 선택!
    left = [x for x in arr[1:] if x <= pivot]
    right = [x for x in arr[1:] if x > pivot]
    return quicksort(left) + [pivot] + quicksort(right)
```

준혁이는 무작위 난수 10,000개를 생성하여 테스트했습니다. **단 0.02초** 만에 빛의 속도로 정렬되었습니다! 준혁이는 확신을 가지고 실시간 거래소 서버에 배포했습니다.

하지만 다음 날, **"이미 시간 순서대로 정렬되어 들어오는 체결 데이터 50,000건"**이 들어오자 시스템이 **그대로 멈춰버렸습니다**:

```text
RecursionError: maximum recursion depth exceeded while calling a Python object
```

당황한 준혁이가 재귀 제한을 늘리자, 이번에는 에러도 없이 **CPU 100%를 찍으며 10분이 지나도 정렬이 끝나지 않았습니다.**

무작위 데이터에서는 0.02초 만에 돌던 퀵소트가, **왜 "이미 정렬된 데이터"나 "모두 같은 값인 데이터"가 들어오자 10분 동안 멈춰버렸을까요?**

AI는 평균 시간 복잡도 $O(N \log N)$이라는 장밋빛 환상만 알려주었을 뿐, **피벗(Pivot)이 최악으로 쏠릴 때 발생하는 $O(N^2)$의 추락과 스택 깊이 폭발**은 전혀 고려하지 않았던 것입니다.

## 🎯 문제 설명

$N$개의 정수로 이루어진 수열이 주어집니다.
이 수열을 **오름차순(작은 수부터 큰 수 순서)**으로 정렬하여 출력하세요.

### ⚠️ 주의 사항
* 데이터의 크기 $N$은 최대 $100,000$입니다.
* 테스트 데이터에는 **"이미 오름차순으로 정렬된 배열"**, **"역순으로 정렬된 배열"**, **"모든 원소가 동일한 배열"** 등 퀵소트의 피벗을 저격하는 최악의 엣지케이스가 대거 포함되어 있습니다.
* 첫 번째 원소를 고정 피벗으로 잡는 나이브한 퀵소트는 $O(N^2)$ 시간 복잡도(약 50억 번 연산)로 인해 **100% 시간 초과(TLE)** 또는 **런타임 에러(RecursionError)**를 받게 됩니다.
* 반드시 **최악의 경우에도 $O(N \log N)$을 보장하는 정렬 기법(Timsort, Median-of-Three 3-Way 퀵소트, 병합 정렬, 힙 정렬 등)**을 사용하여 1.0초 이내에 해결해야 합니다. ([theory.md](theory.md) 참고)

---

## 📥 입력 형식 (Input)

* **첫째 줄**: 정수의 개수 $N$ ($1 \le N \le 100,000$)
* **둘째 줄**: $N$개의 정수 $X_1, X_2, \dots, X_N$이 공백으로 구분되어 주어집니다.
  * $-1,000,000,000 \le X_i \le 1,000,000,000$ (32비트 부호 있는 정수 범위)

---

## 📤 출력 형식 (Output)

* 오름차순으로 정렬된 $N$개의 정수를 첫째 줄에 공백으로 구분하여 출력합니다.

---

### 입력

```text
5

```

### 출력
```text
2 3 4 5 8
```

## 🔍 채점 엣지케이스 안내
1. **$N = 100,000$ 이미 완전 오름차순 정렬된 배열**: 나이브 퀵소트 시 분할이 $1$개와 $N-1$개로 쏠려 $O(N^2)$ 타임아웃
2. **$N = 100,000$ 완전 역순 정렬된 배열**
3. **$N = 100,000$ 모든 원소가 0으로 동일한 중복 배열**
4. V자형(앞 절반 내림차순, 뒤 절반 오름차순) 및 산 모양(A자형) 배열
5. $N = 1$ 인 단일 원소 배열
