# 📘 [ZeliJudge Junior #032] 줄을 서시오!: 큐(Queue)와 선입선출(FIFO)의 원리

---

## 1. 큐(Queue)는 양쪽이 뚫린 파이프관!

앞서 배운 스택(Stack)은 입구가 하나뿐인 프링글스 통 같았습니다.
반면에 **큐(Queue)**는 양쪽이 뻥 뚫린 미끄럼틀 파이프관 같습니다:
* **뒤쪽(Rear)**으로 새로운 사람이 줄을 서고 (`Enqueue`)
* **앞쪽(Front)**에서 기다리던 사람이 먼저 빠져나갑니다 (`Dequeue`)

## 2. 실생활과 컴퓨터 속의 큐

* **프린터 인쇄 대기열**: 먼저 인쇄 버튼을 누른 문서가 먼저 출력됩니다!
* **네트워크 패킷 버퍼**: 유튜브 동영상을 볼 때 인터넷 데이터가 들어온 순서대로 화면에 재생됩니다!
* **키보드 버퍼**: 타자를 빠르게 칠 때 컴퓨터가 입력된 글자 순서대로 화면에 찍어줍니다.

컴퓨터가 세상의 순서를 지켜주는 가장 공평한 자료구조가 바로 큐랍니다!
