# 058. 디지털 미술관의 16진수(HEX) 색상 코드 변환기

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 진법 변환, 16진수(Hexadecimal), 서식 지정자
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

컴퓨터 화면이나 스마트폰 모니터는 빛의 3원색인 **빨강(Red), 초록(Green), 파랑(Blue)** 세 가지 빛을 섞어서 수천만 가지 색깔을 만듭니다.
각 색상은 $0$부터 $255$까지의 10진수 숫자로 밝기를 나타냅니다.

하지만 웹 디자이너들과 프로그래머들은 HTML이나 CSS 웹 문서를 작성할 때 이 세 숫자를 **6자리 16진수 색상 코드 (`#RRGGBB`)**로 바꾸어 씁니다!

16진수 변환 규칙:
* 10진수 $0 \sim 255$ 숫자를 **2자리 대문자 16진수**로 변환합니다.
* 16진수에서는 10은 `A`, 11은 `B`, 12는 `C`, 13은 `D`, 14는 `E`, 15는 `F`로 나타냅니다.
* 만약 16진수로 바꾼 결과가 1자리라면, 앞에 `0`을 붙여 반드시 **2자리**로 맞춥니다! (예: 5 -> `05`, 10 -> `0A`)
* 맨 앞에 샵(`#`) 기호를 붙여 7글자로 완성합니다.

예를 들어:
* `R = 255, G = 0, B = 128` 이라면 -> `#FF0080`
* `R = 0, G = 0, B = 0` (검은색) 이라면 -> `#000000`
* `R = 255, G = 255, B = 255` (하얀색) 이라면 -> `#FFFFFF`

세 개의 10진수 $R, G, B$ 값이 주어졌을 때, 멋진 16진수 웹 컬러 코드로 변환해 주는 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 빨강, 초록, 파랑의 밝기를 나타내는 세 정수 $R, G, B$가 공백으로 구분되어 주어집니다. ($0 \le R, G, B \le 255$)

---

## 📤 출력 형식

`#RRGGBB` 형식의 7자리 16진수 색상 코드를 대문자로 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
255 0 128
```

**출력**
```text
#FF0080
```

### 예제 2

**입력**
```text
0 0 0
```

**출력**
```text
#000000
```

### 예제 3

**입력**
```text
255 255 255
```

**출력**
```text
#FFFFFF
```
