# 📘 [ZeliJudge Junior #009] 원하는 데이터만 쏙쏙 골라내기: 필터링(Filtering)과 카운터(Counter)

---

## 1. 모래사장에서 보석만 골라내는 마법: 필터링(Filtering)

스마트폰 앨범에서 '동영상만 보기'를 누르거나, 쇼핑몰에서 '무료 배송 상품만 보기'를 누를 때 컴퓨터 속에서는 무슨 일이 일어날까요?
수많은 데이터 중에서 **내가 정한 조건에 맞는 것만 남기는 작업**을 **필터링(Filtering)**이라고 부릅니다.

파이썬에서는 `for` 반복문으로 데이터를 하나씩 꺼내며 `if` 조건문으로 검사하면 됩니다:
```python
if min_ok <= weight <= max_ok:
    # 합격!
```
파이썬은 수학 책처럼 `A <= X <= B` 형태의 부등식을 그대로 쓸 수 있어서 아주 읽기 편하답니다!

## 2. 하나, 둘, 셋... 개수를 세는 계수기(Counter) 변수

컴퓨터가 물건 개수를 셀 때는 처음에 `0`으로 시작하는 바구니 변수를 하나 만듭니다:
```python
count = 0
```
그리고 조건에 맞는 물건을 발견할 때마다 1씩 더해줍니다:
```python
count = count + 1  # 또는 count += 1
```

이 간단한 원리로 공장의 품질 검사 로봇부터 유튜브 조회수 측정기까지 모두 작동한답니다!
