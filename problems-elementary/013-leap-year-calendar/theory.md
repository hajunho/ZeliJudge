---

## 1. 4의 배수이면서 100의 배수가 아니거나 400의 배수?

말이 조금 복잡해 보이지만, 천천히 쪼개어 보면 컴퓨터 논리식으로 아주 깔끔하게 바꿀 수 있습니다:

1. **4의 배수인가?**: `year % 4 == 0`
2. **100의 배수가 아닌가?**: `year % 100 != 0`
3. **400의 배수인가?**: `year % 400 == 0`

---

## 2. 괄호와 and, or의 만남

* `(year % 4 == 0 and year % 100 != 0)` : 4년마다 돌아오지만 100년마다는 건너뛰어라!
* `or (year % 400 == 0)` : 하지만 400의 배수라면 무조건 살려주어라!

```python
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print("LEAP")
else:
    print("COMMON")
```

수학에서 곱셈을 덧셈보다 먼저 계산하듯이, 컴퓨터에서는 **`and`가 `or`보다 먼저** 계산됩니다.
그래서 괄호 `()`를 알맞게 씌워주면 내가 의도한 순서대로 컴퓨터가 완벽하게 계산해 낸답니다!
