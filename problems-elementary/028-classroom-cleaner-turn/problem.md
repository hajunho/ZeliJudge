# 028. 매일매일 돌아가는 청소 당번 시계

* **난이도**: 초급 (초등학생 / 코딩 입문)

* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB

## 📖 재미있는 이야기 시나리오

새 학기가 시작되어 반 친구들 $N$명이 매일매일 번호 순서대로 교실 바닥을 쓰는 청소 당번을 맡기로 했습니다.
친구들의 이름은 1번부터 $N$번까지 정해져 있습니다.

청소 규칙은 다음과 같습니다:
* 1일차: 1번 친구
* 2일차: 2번 친구
* ...
* $N$일차: $N$번 친구
* $N+1$일차: 다시 맨 처음 **1번 친구**로 돌아와 빙글빙글 순환합니다!

친구 $N$명의 이름 목록과 확인하고 싶은 날짜 $D$가 주어졌을 때,
$D$일째 되는 날 청소를 맡게 되는 당번 친구의 이름을 찾아주는 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 청소 당번 친구 수 $N$이 주어집니다. ($2 \le N \le 20$)
둘째 줄에 1번부터 $N$번 친구의 이름(영어 소문자 단어)이 공백으로 구분되어 주어집니다.
셋째 줄에 알고 싶은 날짜 정수 $D$가 주어집니다. ($1 \le D \le 1,000$)

---

## 📤 출력 형식

$D$일째 되는 날 청소 당번 친구의 이름을 한 줄에 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
3

5
```

**출력**
```text
jiyoung
```

### 예제 2

**입력**
```text
4
a b c d
4
```

**출력**
```text
d
```

### 예제 3

**입력**
```text
4
a b c d
8
```

**출력**
```text
d
```
