# 📘 [ZeliJudge Junior #034] 가로, 세로, 대각선을 샅샅이 뒤지는 2차원 리스트 탐색

---

## 1. 2차원 리스트의 행(Row)과 열(Column)

빙고판이나 틱택토(Tic-Tac-Toe) 게임판은 2차원 리스트 `grid[r][c]`로 나타냅니다:
* `grid[r]` : $r$번째 가로줄
* `grid[r][c]` : $r$번째 행의 $c$번째 칸

---

## 2. 대각선의 특별한 위치 공식

* **주대각선 (`\`)**: 행과 열의 번호가 똑같다!
  * `(0, 0)`, `(1, 1)`, `(2, 2)` -> `r == c`
* **부대각선 (`/`)**: 행과 열의 번호를 더하면 항상 $N-1$이다!
  * `(0, 2)`, `(1, 1)`, `(2, 0)` -> `r + c == 2`

이 위치 규칙을 기억하면 오목, 틱택토, 체스 게임의 인공지능도 직접 만들 수 있답니다!
