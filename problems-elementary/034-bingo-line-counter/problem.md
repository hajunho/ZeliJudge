# 034. 교실 빙고 게임! 몇 줄 완성했니?

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 2차원 배열 순회, 격자 탐색, 빙고 줄 카운팅
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

비 오는 날 쉬는 시간, 젤리와 친구들은 3x3 칸의 미니 빙고 게임을 하고 있습니다!
사회자가 부른 번호가 적힌 칸에는 동그라미(`O`)가 쳐져 있고, 아직 불리지 않은 칸은 엑스(`X`)로 남아있습니다.

빙고 줄이 완성되는 규칙:
* **가로 3줄**: 1행, 2행, 3행 중 한 줄이 전부 `O`로 채워지면 1줄 인정!
* **세로 3줄**: 1열, 2열, 3열 중 한 줄이 전부 `O`로 채워지면 1줄 인정!
* **대각선 2줄**:
  * 왼쪽 위에서 오른쪽 아래로 이어지는 대각선(`\` 모양)이 전부 `O`이면 1줄 인정!
  * 오른쪽 위에서 왼쪽 아래로 이어지는 대각선(`/` 모양)이 전부 `O`이면 1줄 인정!

현재 3x3 빙고판의 상태가 주어졌을 때, 완성된 빙고 줄의 총개수를 세어 출력하는 심판 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

총 3개의 줄에 걸쳐 각 줄마다 공백으로 구분된 3개의 문자(`O` 또는 `X`)가 주어집니다.

---

## 📤 출력 형식

완성된 빙고 줄의 총개수(0부터 8 사이의 정수)를 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
O O O
X O X
X X O
```

**출력**
```text
2
```

### 예제 2

**입력**
```text
O X O
X O X
O X O
```

**출력**
```text
2
```

### 예제 3

**입력**
```text
X X X
X X X
X X X
```

**출력**
```text
0
```
