# 021. 보물찾기 카드 짝 맞추기와 중복 제거

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 집합(Set), 중복 제거(Deduplication), 정렬
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

동네 놀이터에서 친구들과 포켓몬 카드 교환 파티를 열었습니다!
도윤이는 주머니에서 모아둔 카드 $N$장을 꺼내 바닥에 펼쳐놓았습니다.

그런데 친구들과 카드를 바꾸다 보니 똑같은 카드가 여러 장 섞여 있었습니다!
도윤이는 자신이 **총 몇 종류의 서로 다른 카드**를 모았는지 궁금해졌습니다.
그리고 도감에 정리하기 위해 중복된 카드는 딱 1장만 남기고,
카드 이름들을 **알파벳 사전 순서대로** 예쁘게 줄 세워 보려고 합니다.

도윤이가 가진 카드 목록이 주어졌을 때:
1. 첫 번째 줄에 모은 서로 다른 카드의 종류 수를 출력하고,
2. 두 번째 줄에 중복을 제외하고 알파벳 사전 순서대로 정렬된 카드 이름들을 공백으로 구분하여 출력해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 가진 카드의 총 장수 $N$이 주어집니다. ($1 \le N \le 100$)
둘째 줄에 $N$개 카드의 이름(영어 소문자 단어)이 공백으로 구분되어 주어집니다.

---

## 📤 출력 형식

첫째 줄에 중복을 제외한 고유한 카드의 종류 수를 출력합니다.
둘째 줄에 사전 순서로 정렬된 카드 이름을 공백으로 구분하여 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
5
pikachu eevee pikachu charmander eevee
```

**출력**
```text
3
charmander eevee pikachu
```

### 예제 2

**입력**
```text
3
mewtwo mewtwo mewtwo
```

**출력**
```text
1
mewtwo
```
