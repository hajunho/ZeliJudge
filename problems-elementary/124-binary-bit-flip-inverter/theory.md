# 2진수 비트 반전과 보수(Complement)

컴퓨터는 모든 데이터를 0과 1의 비트(Bit)로 저장합니다.

## 1. 2진수 변환
파이썬에서 `bin(N)`을 호출하면 `'0b...'` 형태의 문자열로 변환됩니다.
앞의 `'0b'` 접두사를 떼어내면 순수한 2진 비트열을 얻을 수 있습니다.
- 예: `bin(5)` -> `'0b101'` -> 비트열 `'101'`

## 2. 비트 반전 (Invert / Flip)
각 글자를 확인하여:
- `'1'` 이면 `'0'`으로 교체
- `'0'` 이면 `'1'`로 교체
- 예: `'101'` -> `'010'`

## 3. 다시 10진수로 복원하기
파이썬의 `int(binary_string, 2)` 함수를 사용하면 2진수 문자열을 손쉽게 10진수 정수로 변환할 수 있습니다!
- 예: `int('010', 2)` -> `2`
