# 전구 스위치 반전 마법! (2진수 비트 반전)

## 📖 문제 설명
마법 성의 스위치 방에는 0과 1로 표현되는 신비한 전구들이 켜져 있습니다. 마법사 젤리가 반전 마법 주문을 외우면 켜진 전구('1')는 꺼지고('0'), 꺼진 전구('0')는 켜집니다('1')! 예를 들어 숫자 5는 2진수로 101인데, 마법을 걸면 010(즉 2진수 10)이 되어 10진수 2가 됩니다. N이 주어질 때 반전 마법을 거친 결과를 구해주세요!

## 📥 입력 형식
한 줄에 자연수 N (1 <= N <= 100,000)이 주어집니다.

## 📤 출력 형식
2진수 비트를 모두 반전시킨 후의 10진수 값을 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
5
```
**출력**
```text
2
```

## 힌트
자연수 N을 2진수로 변환한 후 유효 비트의 0과 1을 모두 반전시킨 새로운 10진수 값을 구합니다.
