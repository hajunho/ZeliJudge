# 📘 [ZeliJudge Junior #046] 특정 구간의 합을 구하는 비결: 슬라이싱과 누적합(Prefix Sum)

---

## 1. 1부터 시작하는 날짜와 0부터 시작하는 컴퓨터 리스트

* 사람이 말하는 $L$일차는 리스트의 `l - 1`번째 칸입니다!
* 사람이 말하는 $R$일차까지 포함하려면 파이썬 슬라이싱 끝 번호는 `r`이 됩니다!
```python
sub_array = money[l - 1 : r]
total = sum(sub_array)
```

## 2. 매번 더하지 않고 한 번에 빼기: 누적합(Prefix Sum)

만약 날마다 조회를 100만 번씩 해야 한다면 매번 루프를 돌리는 건 너무 느립니다.
이때 선배 프로그래머들은 미리 1일부터 누적된 합계를 구해둡니다:
$$\text{구간합}(L, R) = \text{누적합}(R) - \text{누적합}(L - 1)$$
단 한 번의 뺄셈으로 구간합을 구하는 이 마법을 **누적합(Prefix Sum)**이라고 부릅니다!
