# [초등] #116 컴퓨터 전구 켜진 개수! 2진수 1의 개수 세기

## 📖 문제 줄거리 & 상황
컴퓨터 내부의 칩에는 0과 1을 저장하는 수많은 전구 스위치가 있습니다. 10진수 숫자 $N$을 저장할 때 전구에 불이 켜지는(1인 비트) 개수를 세어 전기 소모량을 계산하려고 합니다.

---

## 💻 문제 설명
10진수 정수 $N$이 주어집니다. 이를 2진수로 변환했을 때 `1`의 총 개수를 구하여 출력하세요.

---

## 📥 입력 형식 (Input)
첫째 줄에 정수 $N$이 주어집니다. ($0 \le N \le 1,000,000$)

---

## 📤 출력 형식 (Output)
2진수 표현에서 `1`의 개수를 정수로 출력합니다.

---

## 💡 입출력 예시

### 예제 1
- **입력:**
```text
7
```
- **출력:**
```text
3
```

### 예제 2
- **입력:**
```text
0
```
- **출력:**
```text
0
```
