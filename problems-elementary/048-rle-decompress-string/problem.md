# 048. 비밀 압축문 해제하기! 런렝스 복원기

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열 파싱, 글자 반복 곱셈, 압축 해제
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

앞서 #026번 문제에서 화성 탐사선이 보낸 사진 데이터를 `A3B2C1` 처럼 줄여서 보냈던 것을 기억하나요?
지구의 지상 기지에 도착한 이 압축 전파 신호를 다시 원래 사진 문자열로 되돌려 놓아야 화면에 사진을 띄울 수 있습니다!

복원 규칙:
* 알파벳 대문자 뒤에 나오는 숫자만큼 그 글자를 연속으로 반복하여 이어붙입니다.
  * `A3` -> `AAA`
  * `B2` -> `BB`
  * `C1` -> `C`
  * 결과: `AAABBC`

압축된 문자열이 주어졌을 때, 원래 문자열로 감쪽같이 복원하는 프로그램을 작성해 주세요!
(단, 반복 숫자는 $1$ 이상 $99$ 이하의 정수입니다.)

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 런렝스로 압축된 문자열 $S$가 주어집니다. (알파벳 대문자와 숫자가 번갈아 등장하며, 압축 해제된 총 글자 수는 500자 이하입니다.)

---

## 📤 출력 형식

복원된 원래 문자열을 한 줄에 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
A3B2C1
```

**출력**
```text
AAABBC
```

### 예제 2

**입력**
```text
Z5
```

**출력**
```text
ZZZZZ
```

### 예제 3

**입력**
```text
X1Y1Z1
```

**출력**
```text
XYZ
```
