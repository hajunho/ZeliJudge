# 마법진의 두 대각선 에너지 대결! (주대각선 vs 부대각선 차이)

## 📖 문제 설명
새싹 마법학교의 호그와트 시험장! N x N 크기의 마법진에 마나 수치가 적혀 있습니다. 주대각선(왼쪽 위에서 오른쪽 아래)의 마나 합과 부대각선(오른쪽 위에서 왼쪽 아래)의 마나 합이 얼마나 균형을 이루는지, 두 합의 절댓값 차이(|D1 - D2|)를 측정해 마법진의 안정성을 평가하세요!

## 📥 입력 형식
첫 줄에 정사각형 행렬의 크기 N (1 <= N <= 100)이 주어집니다. 다음 N개의 줄에 걸쳐 각 행의 N개 정수가 공백으로 구분되어 주어집니다. (원소의 절댓값 <= 1,000)

## 📤 출력 형식
주대각선 합과 부대각선 합의 차이의 절댓값을 단일 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
3
1 2 3
4 5 6
7 8 9
```
**출력**
```text
0
```

## 힌트
N x N 정사각형 마법진에서 왼쪽 위-오른쪽 아래 주대각선 합과 오른쪽 위-왼쪽 아래 부대각선 합의 절댓값 차이를 구합니다.
