# 마법진의 두 대각선과 인덱스의 마법

정사각형 모양의 2차원 표(행렬, Matrix)에는 아주 특별한 두 개의 대각선이 존재합니다.

## 1. 주대각선 (Main Diagonal)
- 왼쪽 위 모서리 `(0, 0)`에서 오른쪽 아래 모서리 `(N-1, N-1)`로 이어지는 대각선입니다.
- 특징: **행 번호 `i`와 열 번호 `j`가 정확히 같습니다.** (`i == j`)
- 따라서 `grid[i][i]` 원소들만 더하면 $O(N)$의 시간에 빠르게 구할 수 있습니다.

## 2. 부대각선 (Anti-Diagonal)
- 오른쪽 위 모서리 `(0, N-1)`에서 왼쪽 아래 모서리 `(N-1, 0)`으로 이어지는 대각선입니다.
- 특징: **행 번호 `i`와 열 번호 `j`의 합이 항상 `N - 1`**입니다. (`i + j == N - 1`, 즉 `j = N - 1 - i`)
- 따라서 `grid[i][N - 1 - i]` 원소들을 더하면 됩니다.

## 3. 시간 복잡도 최적화
전체 $N \times N$ 개의 원소를 이중 반복문($O(N^2)$)으로 모두 순회할 필요 없이, 단일 반복문(`for i in range(N)`) 하나로 $O(N)$ 시간 안에 두 대각선의 합을 모두 계산할 수 있습니다!
