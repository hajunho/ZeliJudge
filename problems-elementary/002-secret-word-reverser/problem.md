# 002. 거꾸로 말해요! 마법 비밀 암호

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열(String), 인덱스(Index), 문자열 뒤집기
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

비밀 탐정 클럽의 하은이와 친구들은 다른 사람들에게 들키지 않고 비밀 쪽지를 주고받기 위해 마법 암호 규칙을 만들었습니다.
그 규칙은 바로 **단어의 글자 순서를 거꾸로 뒤집는 것**입니다!

예를 들어:
* `HELLO` 라는 단어를 거꾸로 뒤집으면 `OLLEH`가 됩니다.
* `MAGIC` 이라는 단어를 거꾸로 뒤집으면 `CIGAM`이 됩니다.

신기하게도 거꾸로 뒤집힌 암호 `OLLEH`를 다시 한 번 더 거꾸로 뒤집으면 원래 단어인 `HELLO`로 감쪽같이 돌아옵니다!
하은이가 보낸 영어 단어가 주어졌을 때, 단어를 거꾸로 뒤집어주는 비밀 암호 해독기 프로그램을 완성해 보세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 영어 알파벳 대소문자로 이루어진 단어 $S$가 공백 없이 주어집니다. ($1 \le \text{길이} \le 100$)

---

## 📤 출력 형식

단어 $S$를 맨 뒷글자부터 맨 앞글자까지 거꾸로 뒤집은 문자열을 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
HELLO
```

**출력**
```text
OLLEH
```

### 예제 2

**입력**
```text
MAGIC
```

**출력**
```text
CIGAM
```

### 예제 3

**입력**
```text
Python
```

**출력**
```text
nohtyP
```
