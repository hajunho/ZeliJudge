# 📘 [ZeliJudge Junior #002] 글자들의 기차: 문자열(String)과 번호표(Index)

---

## 1. 컴퓨터에게 글자는 '기차 칸'과 같아요!

우리가 글을 쓸 때 단어는 한 줄로 이어집니다. 파이썬 같은 컴퓨터 언어에서는 이런 글자들의 모임을 **문자열(String)**이라고 불러요.
컴퓨터는 문자열을 볼 때 마치 **번호가 붙은 기차 칸**처럼 생각합니다.

예를 들어 `"HELLO"`라는 단어가 있다면:
```
글자:    H   E   L   L   O
번호:   [0] [1] [2] [3] [4]
```
⚠️ **주의!** 컴퓨터는 숫자를 1이 아니라 **0부터** 셉니다! 이 번호표를 **인덱스(Index)**라고 불러요.

---

## 2. 문자열을 거꾸로 뒤집는 마법의 주문: `[::-1]`

파이썬에서는 문자열에서 원하는 부분만 싹둑 잘라오는 것을 **슬라이싱(Slicing)**이라고 해요.
슬라이싱에는 `[시작:끝:보폭(step)]`이라는 비밀 규칙이 있습니다:

* `word[0:3]` -> 0번부터 2번 칸까지 자르기
* `word[::2]` -> 처음부터 끝까지 2칸씩 폴짝폴짝 건너뛰며 읽기
* `word[::-1]` -> 보폭이 `-1`! 즉, **맨 뒤에서부터 앞으로 거꾸로 한 칸씩** 읽기!

```python
word = "HELLO"
print(word[::-1])  # 'OLLEH'
```

단 한 줄의 마법 주문 `[::-1]`만 기억하면 어떤 비밀 암호라도 순식간에 뒤집을 수 있답니다!
