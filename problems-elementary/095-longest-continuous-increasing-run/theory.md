# 컴퓨팅 사고력 교실: 계속해서 오르는 등산로! 최장 연속 증가 구간 길이

## 🌟 핵심 개념: 배열 순회, 연속 구간(Streak), 상태 유지, 최댓값 갱신

현재 증가 연속 길이를 `curr_len = 1`로 시작하여, $A[i] > A[i-1]$이면 `curr_len += 1`, 그렇지 않으면 `curr_len = 1`로 리셋하며 매 순간 `max_len = max(max_len, curr_len)`을 갱신합니다.

### 1. 실생활과 소프트웨어 속 이야기
- 컴퓨터 프로그램이나 게임, 스마트 기기는 이 원리를 어떻게 사용하고 있을까요?

### 2. 알고리즘 설계 팁
1. **입력 분석**: 문제에서 요구하는 입력 데이터의 형태와 범위를 파악합니다.
2. **핵심 규칙 구현**: 파이썬의 조건문, 반복문, 자료구조(리스트, 딕셔너리, 스택, 큐)를 활용하여 규칙을 코드로 옮깁니다.
3. **예외 케이스 확인**: 가장 작은 값, 경계선 값에서도 올바르게 동작하는지 점검합니다.
