# 다중 조건 정렬 (Multi-Criteria Sorting)

데이터를 한 가지 기준이 아니라 여러 가지 복합 기준으로 정렬해야 할 때가 많습니다.

## 1. 1차 기준과 2차 기준
- **1차 기준**: 가장 많이 등장한 순서 (**등장 횟수 내림차순**)
- **2차 기준**: 등장 횟수가 같다면 사전 순서 (**단어 오름차순**)

## 2. 파이썬의 튜플 정렬 키 마법
파이썬의 `sort()`나 `sorted()` 함수는 튜플을 비교할 때 첫 번째 원소를 먼저 비교하고, 첫 번째 원소가 같으면 두 번째 원소를 비교합니다.
```python
# 빈도수는 내림차순(-count), 단어는 오름차순(word)
sorted_words = sorted(counts.items(), key=lambda item: (-item[1], item[0]))
```
음수 부호 `-`를 붙이면 숫자의 대소 관계가 뒤집혀 **오름차순 정렬기를 내림차순 정렬기처럼** 동작하게 만들 수 있습니다!
