# 📘 [ZeliJudge Junior #026] 이미지 파일 용량을 줄이는 비결: 런렝스 압축(Run-Length Encoding)

---

## 1. 하얀 도화지에 검은 점 하나 찍기

만약 가로 1,000칸의 하얀 바탕에 검은 점이 1개 있다면:
* 원본: `WWWWWWWW...WWWB` (글자 1,000개!)
* 압축: `W999B1` (글자 단 6개!)

이렇게 **연속된 데이터(Run)**의 **길이(Length)**를 세어서 압축하는 방식을 **런렝스 압축(RLE)**이라고 부릅니다.

---

## 2. 현재 글자와 카운터 유지하기

알고리즘 구현의 핵심:
1. 지금 보고 있는 글자(`current_char`)와 연속 횟수(`count = 1`)를 기억합니다.
2. 다음 글자를 보면서:
   * 이전 글자와 같으면: `count += 1`
   * 다른 글자가 나타나면: 지금까지 센 결과를 기록(`result.append`)하고, 새 글자로 교체 후 `count = 1` 리셋!
3. 루프가 끝난 뒤 **마지막 남은 글자**도 잊지 않고 꼭 기록해 주는 것이 프로그래머의 꼼꼼함입니다!
