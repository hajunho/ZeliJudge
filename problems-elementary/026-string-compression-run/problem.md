# 026. 연속된 글자 줄이기! 런렝스 압축의 마법

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열 압축(Run-Length Encoding), 연속 구간 카운팅
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

우주 탐사선 '젤리호'는 화성에서 지구로 사진 데이터를 보낼 때 전파 신호가 약해서 용량을 줄여야 합니다.
우주 과학자들은 같은 글자가 연속해서 나올 때 **'글자 + 연속된 개수'**로 간단하게 줄여서 보내는 기발한 압축 방법을 발명했습니다!

예를 들어:
* `AAABBC` 는 A가 3번, B가 2번, C가 1번 연속 나오므로 -> `A3B2C1`
* `ZZZZZ` 는 Z가 5번 나오므로 -> `Z5`
* `XYZ` 는 X가 1번, Y가 1번, Z가 1번 나오므로 -> `X1Y1Z1`

이 압축 기술은 실제로 팩스(FAX)나 이미지 파일(BMP) 등에서 널리 쓰이는 **'런렝스 압축(Run-Length Encoding)'**입니다.
영어 대문자로 된 문자열이 주어졌을 때, 런렝스 압축 결과를 출력하는 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 영어 대문자로만 이루어진 문자열 $S$가 주어집니다. ($1 \le \text{길이} \le 100$)

---

## 📤 출력 형식

런렝스 방식으로 압축된 문자열을 한 줄에 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
AAABBC
```

**출력**
```text
A3B2C1
```

### 예제 2

**입력**
```text
ZZZZZ
```

**출력**
```text
Z5
```

### 예제 3

**입력**
```text
XYZ
```

**출력**
```text
X1Y1Z1
```
