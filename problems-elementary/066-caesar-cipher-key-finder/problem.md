# [초등] #066 비밀 암호 해독가! 잃어버린 시프트 열쇠(K) 찾기

## 📖 문제 줄거리 & 상황
탐정단이 악당의 암호문 $C$를 입수했습니다. 악당은 알파벳을 오른쪽으로 $K$칸 밀어내는 카이사르 암호를 사용했는데, 시프트 열쇠 $K$를 깜빡 잊어버렸습니다. 다행히 우리는 이 암호문 안에 원래 단어 $W$(예: `SECRET`, `HELP`)가 반드시 포함되어 있다는 정보를 알고 있습니다.

---

## 💻 문제 설명
암호문 $C$와 원래 원문에 들어있던 힌트 단어 $W$가 주어집니다. $0$부터 $25$까지의 시프트 값 중, 암호문을 왼쪽으로 $K$칸 복호화했을 때 힌트 단어 $W$가 부분 문자열로 나타나게 만드는 올바른 시프트 열쇠 $K$를 찾아 출력하세요. (만족하는 $K$는 유일합니다)

---

## 📥 입력 형식 (Input)
첫째 줄에 대문자 암호문 $C$가 주어집니다. ($1 \le |C| \le 100$)
둘째 줄에 대문자 힌트 단어 $W$가 주어집니다. ($1 \le |W| \le |C|$)

---

## 📤 출력 형식 (Output)
원래 힌트 단어 $W$가 복원되도록 하는 정수 시프트 열쇠 $K$ ($0 \le K \le 25$)를 출력합니다.

---

## 💡 입출력 예시

### 예제 1
- **입력:**
```text
KHOOR
HELLO
```
- **출력:**
```text
3
```

### 예제 2
- **입력:**
```text
PYTHON
PYTHON
```
- **출력:**
```text
0
```
