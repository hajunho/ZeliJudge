# 030. 급식실 식판 쌓기와 올바른 괄호 짝 맞추기

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 스택(Stack), 괄호 매칭, 유효성 검증
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

학교 급식실에는 깨끗하게 씻은 식판이 차곡차곡 위로 쌓여 있습니다.
학생들은 맨 위에 있는 식판부터 하나씩 꺼내어 밥을 먹습니다.
이렇게 **맨 나중에 들어간 것이 맨 먼저 나오는 구조**를 컴퓨터 과학에서는 **'스택(Stack)'**이라고 부릅니다.

컴퓨터 프로그래밍 언어에서 소괄호 `(` 와 `)`는 항상 식판처럼 올바르게 열리고 닫혀야 오류가 나지 않습니다:
* 올바른 괄호: `()`, `(())`, `()()`
  * 여는 괄호 `(`가 나오면 식판을 쌓고, 닫는 괄호 `)`가 나오면 식판을 꺼냅니다.
* 올바르지 않은 괄호:
  * `)(` : 열리지도 않았는데 닫는 괄호부터 나옴!
  * `((()` : 괄호를 열어놓고 닫지 않음!
  * `())` : 닫는 괄호가 너무 많음!

괄호 문장 $S$가 주어졌을 때, 괄호의 짝이 올바르면 `YES`, 아니면 `NO`를 출력하는 괄호 검사기를 완성해 보세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 괄호 문자 `(` 와 `)` 로만 이루어진 문자열 $S$가 공백 없이 주어집니다. ($1 \le \text{길이} \le 100$)

---

## 📤 출력 형식

올바른 괄호 문자열이면 `YES`, 아니면 `NO`를 대문자로 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
(())
```

**출력**
```text
YES
```

### 예제 2

**입력**
```text
()()
```

**출력**
```text
YES
```

### 예제 3

**입력**
```text
)(
```

**출력**
```text
NO
```

### 예제 4

**입력**
```text
((()
```

**출력**
```text
NO
```
