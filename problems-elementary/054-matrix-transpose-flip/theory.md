# 📘 [ZeliJudge Junior #054] 인공지능 딥러닝과 3D 그래픽스의 기본: 전치행렬(Transpose)

---

## 1. 가로를 세로로, 세로를 가로로!

원본 행렬에서 `grid[row][col]`에 있던 원소는 전치행렬에서 `new_grid[col][row]` 자리가 됩니다!
행 번호와 열 번호가 서로 완벽하게 맞바뀌는 것입니다.

---

## 2. 파이썬의 마법 지퍼: `zip(*grid)`

파이썬에서는 이 전치 작업을 단 한 줄로 끝낼 수도 있습니다:
```python
transposed = list(zip(*grid))
```
`zip` 함수는 여러 줄의 같은 열 원소들을 지퍼처럼 하나로 묶어줍니다!
인공지능 신경망에서 가중치 행렬을 계산하거나 사진을 90도 회전시킬 때 바로 이 전치행렬이 사용된답니다!
