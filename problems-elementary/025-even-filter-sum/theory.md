# 📘 [ZeliJudge Junior #025] 필터링과 한 줄 코딩의 예술: 리스트 컴프리헨션(List Comprehension)

---

## 1. 짝수 판별의 절대 공식: `x % 2 == 0`

어떤 숫자를 2로 나누었을 때 나머지가 0이면 짝수, 1이면 홀수입니다.
이 공식은 게임 프로그래밍, 짝홀 게임, 2차원 바둑판 무늬 그리기 등 어디에나 쓰입니다.

---

## 2. 파이썬의 꽃: 리스트 컴프리헨션

원하는 값만 골라 새 리스트를 만들 때 파이썬은 예술 같은 한 줄 문법을 선물합니다:
```python
evens = [x for x in nums if x % 2 == 0]
```
"nums 안의 x 중에서 2로 나눈 나머지가 0인 x만 쏙 뽑아라!"라는 뜻입니다.

그리고 `len(evens)`로 개수를 세고, `sum(evens)`로 합계를 내면 단 두 줄로 모든 문제를 시원하게 해결할 수 있답니다!
