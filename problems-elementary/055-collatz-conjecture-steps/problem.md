## 📖 재미있는 이야기 시나리오

구름 속에서 빗방울이 위로 솟구쳤다 아래로 떨어지기를 반복하다가 무거운 얼음 덩어리가 되어 땅으로 떨어지는 '우박'을 본 적이 있나요?
수학계에는 숫자가 커졌다 작아졌다 춤을 추다가 결국 1로 곤두박질치는 신비로운 **'우박수(Collatz Conjecture, 콜라츠 추측)'**가 있습니다!

변신 규칙:
* 어떤 자연수 $N$이 **짝수**라면: $2$로 나눕니다 ($N // 2$)
* 어떤 자연수 $N$이 **홀수**라면: $3$을 곱하고 $1$을 더합니다 ($3 \times N + 1$)
* 이 과정을 **$N$이 $1$이 될 때까지** 멈추지 않고 반복합니다!

예를 들어 $N = 6$이라면:
* $6$ (짝수) -> $3$
* $3$ (홀수) -> $10$
* $10$ (짝수) -> $5$
* $5$ (홀수) -> $16$
* $16$ (짝수) -> $8$
* $8$ (짝수) -> $4$
* $4$ (짝수) -> $2$
* $2$ (짝수) -> $1$ (도착!)
총 **8번**의 변신을 거쳐 1에 도달했습니다!

어떤 자연수 $N$이 주어졌을 때, 1이 될 때까지 거치는 총 변신 횟수를 구하는 프로그램을 작성해 주세요! (처음부터 $N=1$이면 횟수는 0입니다.)

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 자연수 $N$이 주어집니다. ($1 \le N \le 100,000$)

---

## 📤 출력 형식

1에 도달할 때까지 거친 변신 횟수를 정수로 출력합니다.

---

