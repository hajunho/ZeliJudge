# 📘 [ZeliJudge Junior #015] 100만 번 덧셈하기 vs 단 한 번의 곱셈: O(N)과 O(1)의 차이

---

## 1. 컴퓨터에게 100만 번 시키기 (for 루프)

컴퓨터에게 1부터 100만까지 더하라고 하면 반복문으로 풀 수 있습니다:
```python
total = 0
for i in range(1, n + 1):
    total += i
```
컴퓨터는 빠르기 때문에 100만 번 덧셈도 약 0.05초 만에 해냅니다.
하지만 $N$이 100억, 1조처럼 커진다면 컴퓨터도 10분, 1시간 동안 멈춰버릴 수 있습니다!

---

## 2. 가우스 공식: 0.00001초 만에 끝내는 지혜

가우스의 공식 $N \times (N + 1) // 2$를 쓰면 어떻게 될까요?
숫자가 아무리 커도 **곱셈 1번, 나눗셈 1번**이면 계산이 끝나버립니다!

* 100만 번 더하기 -> **$O(N)$ 시간**
* 공식으로 한 번에 풀기 -> **$O(1)$ 시간**

알고리즘을 잘 아는 프로그래머는 컴퓨터를 무식하게 혹사시키는 대신, 수학적 규칙을 찾아 빛의 속도로 문제를 해결한답니다!
