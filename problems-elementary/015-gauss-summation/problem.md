## 📖 재미있는 이야기 시나리오

옛날 독일의 한 초등학교 수학 시간, 선생님께서 아이들을 조용히 시키기 위해 엄청나게 어려운 문제를 내셨습니다:
> *"1부터 100까지 모든 숫자를 빠짐없이 다 더하거라!"*

다른 친구들이 공책에 $1 + 2 = 3$, $3 + 3 = 6$, $6 + 4 = 10$... 끙끙 앓으며 하나씩 더하고 있을 때,
열 살 소년 **카를 프리드리히 가우스(Gauss)**는 단 1분 만에 정답 `5050`을 외쳐 선생님을 깜짝 놀라게 했습니다!

가우스는 양 끝의 숫자를 짝지어 더하면 항상 똑같다는 엄청난 규칙을 발견했던 것입니다:
* $1 + 100 = 101$
* $2 + 99 = 101$
* $3 + 98 = 101$
* ...
이런 101이 총 50쌍 있으므로, $101 \times 50 = 5050$!
공식으로 나타내면:
$$\text{합} = \frac{N \times (N + 1)}{2}$$

어떤 자연수 $N$이 주어졌을 때, 1부터 $N$까지의 합을 구하는 프로그램을 만들어보세요!

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

## 📥 입력 형식

첫째 줄에 자연수 $N$이 주어집니다. ($1 \le N \le 1,000,000$)

---

## 📤 출력 형식

1부터 $N$까지 모든 정수를 더한 총합을 출력합니다.
