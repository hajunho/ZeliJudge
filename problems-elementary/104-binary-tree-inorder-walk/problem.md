# [초등] #104 동물원 족보 탐험 2! 이진 트리의 중위 순회(Inorder)

## 📖 문제 줄거리 & 상황
이번에는 동물원의 보물 방들을 '중위 순회(Inorder)' 규칙으로 탐험합니다. 중위 순회는 [1. 왼쪽 자식 서브트리 먼저 탐험 -> 2. 현재 방 방문 -> 3. 오른쪽 자식 서브트리 탐험] 순서로 진행됩니다. (이진 탐색 트리에서 중위 순회를 돌면 숫자가 오름차순으로 정렬되어 나오는 마법의 순회 방식입니다!)

---

## 💻 문제 설명
1번 노드가 루트인 $N$개 노드의 이진 트리 구조가 주어집니다. 중위 순회(Inorder: Left -> Root -> Right)로 방문한 노드들의 번호를 공백으로 구분하여 한 줄에 출력하세요.

---

## 📥 입력 형식 (Input)
첫째 줄에 노드의 개수 $N$이 주어집니다. ($1 \le N \le 100$)
둘째 줄부터 $N$개의 줄에 걸쳐 각 노드에 대해 `노드번호 왼쪽자식번호 오른쪽자식번호`가 공백으로 주어집니다. (자식이 없는 경우 `0`으로 표시)

---

## 📤 출력 형식 (Output)
중위 순회 방문 순서대로 노드 번호를 공백으로 구분하여 출력합니다.

---

## 💡 입출력 예시

### 예제 1
- **입력:**
```text
3
1 2 3
2 0 0
3 0 0
```
- **출력:**
```text
2 1 3
```

### 예제 2
- **입력:**
```text
1
1 0 0
```
- **출력:**
```text
1
```
