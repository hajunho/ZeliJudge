# 📘 [ZeliJudge Junior #018] 이름과 숫자를 짝지어 기억하는 마법 사전: 딕셔너리(Dictionary)

---

## 1. 후보마다 개표 바구니 만들기

리스트는 번호(0, 1, 2...)로만 찾아야 해서 "철수가 몇 표지?", "영희가 몇 표지?" 셀 때 복잡합니다.
이때 컴퓨터 프로그래밍에서는 단어와 뜻이 짝을 이루는 사전처럼, **이름(Key)**과 **표 수(Value)**를 짝지어 저장하는 **딕셔너리(Dictionary)**라는 초강력 자료구조를 씁니다:

```python
counts = {}
counts["minsoo"] = 3
counts["jiyoung"] = 2
```

---

## 2. 표가 들어올 때마다 1씩 올리기: `.get(name, 0) + 1`

새로운 투표용지가 나올 때마다:
* 아직 한 표도 못 받은 친구는 기본값 `0`에서 시작하고,
* 이미 표가 있는 친구는 기존 표에 `+ 1`을 더해줍니다!

파이썬의 `counts.get(name, 0) + 1`을 쓰면 이 모든 과정을 단 한 줄로 완벽하게 처리할 수 있습니다.
페이스북의 '좋아요' 수, 편의점 포스기의 재고 관리까지 모두 이 딕셔너리 원리로 돌아간답니다!
