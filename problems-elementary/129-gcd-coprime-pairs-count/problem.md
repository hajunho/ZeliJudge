# 마음이 통하는 서로소(Coprime) 친구 쌍 찾기

## 📖 문제 설명
수학 나라 파티에 N명의 친구들이 모였습니다. 각 친구는 저마다 좋아하는 자연수 카드를 들고 있습니다. 두 친구가 가진 수의 최대공약수가 '1'뿐일 때, 두 친구를 '마음이 통하는 서로소(Coprime) 짝꿍'이라고 부릅니다. 파티에 모인 친구들 중에서 서로소 짝꿍 쌍이 총 몇 개 만들어질 수 있는지 세어주세요!

## 📥 입력 형식
첫 줄에 수의 개수 N (2 <= N <= 100)이 주어집니다.\n둘째 줄에 N개의 자연수가 공백으로 주어집니다. (각 자연수 <= 1,000)

## 📤 출력 형식
서로소인 두 수의 쌍 (i < j)의 총 개수를 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
3
2 3 4
```
**출력**
```text
2
```

## 힌트
주어진 N개의 자연수 중 두 수의 최대공약수(GCD)가 1인 서로소(Coprime) 순서쌍 (i < j)의 총 개수를 구합니다.
