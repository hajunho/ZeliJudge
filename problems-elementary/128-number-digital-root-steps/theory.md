# 자릿수 덧셈 반복(Digital Root)과 연산 단계 카운팅

## 1. 연산의 반복 구조
자연수 $N$이 주어졌을 때:
- 만약 $N < 10$ 이라면 이미 한 자리 숫자이므로 연산 횟수는 **0**입니다.
- $N \ge 10$ 이라면 각 자릿수의 합을 구하고, 횟수 카운터를 1 증가시킵니다.
- 새롭게 얻은 숫자로 위의 과정을 $N < 10$이 될 때까지 계속 반복합니다.

## 2. 자릿수 분해하기
숫자를 문자열로 바꾸어 각 글자를 정수로 더하는 방법이 가장 직관적입니다:
```python
next_n = sum(int(digit) for digit in str(n))
```

## 3. 예시
- $N = 98$:
  - 1단계: $9 + 8 = 17$ (두 자리)
  - 2단계: $1 + 7 = 8$ (한 자리 도달!)
  - 총 연산 횟수: **2회**
