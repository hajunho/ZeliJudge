# 한 자리가 될 때까지! 마법 숫자 도달 횟수 카운터

## 📖 문제 설명
숫자 요정 젤리는 거대한 자연수를 받으면 자릿수를 모두 더해 작은 수로 줄이는 연금술을 부립니다. 줄어든 수가 여전히 두 자리 이상이면, 다시 자릿수를 더합니다. 이 과정을 반복하여 마침내 '한 자리 숫자(0~9)'가 될 때까지 총 몇 번의 덧셈 마법을 부려야 하는지 계산해주세요!

## 📥 입력 형식
한 줄에 자연수 N (0 <= N <= 1,000,000,000)이 주어집니다.

## 📤 출력 형식
한 자리 수가 될 때까지 수행한 자릿수 합산 연산의 횟수를 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
98
```
**출력**
```text
2
```

## 힌트
자연수 N의 각 자릿수를 더하는 연산을 반복하여 한 자리 수(< 10)가 될 때까지 거친 연산 횟수(Step)를 구합니다.
