## 1. 1조각만 부족해도 한 판을 더 시켜야 해!

10조각이 필요한데 $10 \div 8 = 1.25$판입니다.
피자 가게에서는 $0.25$판을 안 파니까 **2판**을 사야 합니다.
이렇게 소수점이 조금이라도 있으면 무조건 다음 정수로 올려주는 계산을 **올림(Ceiling)**이라고 합니다.

파이썬에서는 `math.ceil()` 함수를 쓸 수 있어요:
```python
import math
pizzas = math.ceil(total_slices / 8)
```

## 2. `math` 모듈 없이 정수 나눗셈으로 올림하는 비법

선배 프로그래머들은 모듈을 불러오지 않고도 정수 나눗셈으로 올림을 해냈습니다:
$$(A + B - 1) // B$$

* 총 10조각을 8로 나눌 때: `(10 + 7) // 8 = 17 // 8 = 2`!
* 딱 떨어지는 8조각일 때: `(8 + 7) // 8 = 15 // 8 = 1`!

이 놀라운 정수 연산 트릭은 컴퓨터 그래픽스나 게임 서버에서 엄청나게 자주 쓰인답니다!
