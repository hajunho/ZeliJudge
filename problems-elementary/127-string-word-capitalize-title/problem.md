# 멋진 동화책 제목 만들기! (단어 첫 글자 대문자 변환)

## 📖 문제 설명
출판사 에디터가 된 젤리는 뒤죽박죽 쓰여진 동화책 제목 원고를 검수하고 있습니다. 멋진 표지를 만들기 위해 문장에 있는 모든 영어 단어의 첫 글자는 대문자(Capital Letter)로 만들고, 나머지 글자들은 모두 단정한 소문자로 통일하려고 합니다. 자동 제목 변환기를 완성해주세요!

## 📥 입력 형식
한 줄에 알파벳과 공백으로 이루어진 문장이 주어집니다. (길이 1 <= 200)

## 📤 출력 형식
각 단어의 첫 글자가 대문자로 변환된 문자열을 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
the little prince
```
**출력**
```text
The Little Prince
```

## 힌트
공백으로 구분된 문자열의 각 단어 첫 글자를 대문자로, 나머지 글자는 소문자로 변환하여 Title Case로 출력합니다.
