# 038. 매일매일 연속 출석왕 챌린지

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 연속 구간 최대 길이(Max Streak), 상태 전이, 카운터
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

온라인 코딩 학습 사이트에서 한 달 동안 '매일매일 코딩 출석 챌린지'가 열렸습니다!
도윤이의 출석 도장 기록이 차례대로 주어집니다:
* `O` : 수업에 출석하여 문제를 푼 날
* `X` : 아쉽게 결석한 날

성실한 학생에게 주어지는 '출석왕 배지'를 받으려면 **가장 길게 연속으로 출석한 날수(최대 연속 스트릭)**를 알아야 합니다!

예를 들어 7일간의 기록이 `O O X O O O X`라면:
* 앞부분 연속 출석: 2일
* 뒷부분 연속 출석: 3일
최대 연속 출석 일수는 `3`일이 됩니다.

$N$일 동안의 출석 기록이 주어졌을 때, 도윤이의 최장 연속 출석 일수를 구하는 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 총 날수 자연수 $N$이 주어집니다. ($1 \le N \le 100$)
둘째 줄에 $N$개의 출석 기호(`O` 또는 `X`)가 공백으로 구분되어 주어집니다.

---

## 📤 출력 형식

가장 길게 연속으로 출석한 일수(정수)를 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
7
O O X O O O X
```

**출력**
```text
3
```

### 예제 2

**입력**
```text
4
X X X X
```

**출력**
```text
0
```

### 예제 3

**입력**
```text
5
O O O O O
```

**출력**
```text
5
```
