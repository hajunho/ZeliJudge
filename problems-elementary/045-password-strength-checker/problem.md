# 045. 해커를 막아라! 비밀번호 안전성 검사기

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열 검증, 불리언 플래그, 정보보안 기초
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

새싹초등학교 코딩 동아리에서는 학생들이 사용할 웹사이트를 만들고 있습니다.
해커들이 비밀번호를 쉽게 알아맞히지 못하도록 강력한 **비밀번호 보안 규칙**을 적용하기로 했습니다.

안전한 비밀번호(`STRONG`)가 되기 위한 4가지 조건:
1. 비밀번호의 전체 길이가 **8글자 이상**이어야 합니다.
2. 영어 **대문자**가 최소 1개 이상 포함되어야 합니다.
3. 영어 **소문자**가 최소 1개 이상 포함되어야 합니다.
4. **숫자(0~9)**가 최소 1개 이상 포함되어야 합니다.

이 4가지 조건을 **모두 만족하면 `STRONG`**, 단 하나라도 만족하지 못하면 `WEAK`를 출력하는 보안 검사 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 검사할 비밀번호 문자열 $P$가 공백 없이 주어집니다. (길이 $1 \le \text{길이} \le 50$, 알파벳과 숫자로만 구성)

---

## 📤 출력 형식

비밀번호가 4대 조건을 모두 만족하면 `STRONG`, 아니면 `WEAK`를 대문자로 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
Pass1234
```

**출력**
```text
STRONG
```

### 예제 2

**입력**
```text
password
```

**출력**
```text
WEAK
```

### 예제 3

**입력**
```text
PASS1234
```

**출력**
```text
WEAK
```

### 예제 4

**입력**
```text
Pass1
```

**출력**
```text
WEAK
```
