# 004. 3·6·9 박수 게임 심판관

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 반복문(for), 문자열 검색, 자릿수 분해, 카운팅
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

점심시간마다 교실에서 가장 인기 있는 놀이는 바로 '3·6·9 게임'입니다!
친구들이 둥글게 둘러앉아 1부터 시작해서 숫자를 차례대로 하나씩 외칩니다.

하지만 규칙이 있습니다:
* 말해야 하는 숫자에 `3`, `6`, `9`가 들어가 있으면 숫자를 말하지 않고 **박수를 짝!** 쳐야 합니다.
* 박수 치는 횟수는 숫자에 들어있는 **3, 6, 9의 총 개수**와 같습니다!
  * 예를 들어 `3`은 3이 1개 있으므로 박수 한 번: `CLAP`
  * `13`은 3이 1개 있으므로 박수 한 번: `CLAP`
  * `33`은 3이 2개 들어있으므로 박수 두 번: `CLAP-CLAP`
  * `36`은 3과 6이 1개씩 총 2개 있으므로: `CLAP-CLAP`
  * `369`는 3, 6, 9가 모두 들어있어 총 3개이므로: `CLAP-CLAP-CLAP`
* 만약 숫자에 3, 6, 9가 하나도 없다면 숫자를 그대로 말합니다. (예: `1`, `2`, `4`, `10` 등)

친구들이 틀리지 않고 게임을 할 수 있도록, 마지막 숫자 $N$이 주어졌을 때 1부터 $N$까지 차례대로 말해야 하는 내용을 한 줄에 하나씩 알려주는 자동 심판 프로그램을 만들어보세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 마지막 숫자 정수 $N$이 주어집니다. ($1 \le N \le 100$)

---

## 📤 출력 형식

1부터 $N$까지 각 줄마다 말해야 하는 숫자 또는 박수(`CLAP`, `CLAP-CLAP` 등)를 순서대로 출력합니다.

---
