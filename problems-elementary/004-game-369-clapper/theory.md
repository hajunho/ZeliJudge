---

## 1. 사람이 하면 지루한 일, 컴퓨터는 0.001초 만에!

1부터 100까지 3, 6, 9를 직접 세면서 박수 치려면 5분도 넘게 걸리고 중간에 실수로 틀리기 쉽습니다.
하지만 컴퓨터에게 **반복문(`for`)**을 시키면 100만 번의 숫자도 0.1초 만에 척척 검사해 줍니다!

```python
for i in range(1, 11):
    print(i) # 1부터 10까지 차례대로 출력!
```

## 2. 숫자를 글자(문자열)로 바꾸어 글자 세기

숫자 `36`에서 3과 6이 들어있는지 어떻게 알 수 있을까요?
숫자를 `str()` 마법 상자에 넣으면 **글자(문자열)**로 변신합니다:
* `str(36)` -> `"36"`

글자가 되면 파이썬의 편리한 도구인 `.count()`를 쓸 수 있어요:
```python
text = "36"
clap_count = text.count('3') + text.count('6') + text.count('9')
# clap_count는 2가 됩니다!
```

그리고 박수를 여러 번 칠 때는 `"-".join(["CLAP"] * clap_count)`를 쓰면 `"CLAP-CLAP"`처럼 깔끔하게 연결할 수 있답니다!
