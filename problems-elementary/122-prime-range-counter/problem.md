# 밤하늘의 별자리 소수 탐정단! (구간 소수 개수 세기)

## 📖 문제 설명
밤하늘에 번호가 매겨진 별들이 반짝입니다. 천문학자 젤리는 번호가 L부터 R까지인 별들 중, 쪼갤 수 없는 순수한 '소수(Prime)' 별들만 모아 새로운 별자리를 만들려고 합니다. L부터 R까지의 구간에 소수 별이 총 몇 개 있는지 세어주세요!

## 📥 입력 형식
한 줄에 두 자연수 L과 R이 공백으로 주어집니다. (1 <= L <= R <= 1,000)

## 📤 출력 형식
L 이상 R 이하에 존재하는 소수의 개수를 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
1 10
```
**출력**
```text
4
```

## 힌트
주어진 범위 [L, R] 내에 존재하는 소수(Prime Number)의 총 개수를 세어 출력합니다.
