# 📘 [ZeliJudge Junior #003] 컴퓨터가 똑똑한 결정을 내리는 법: 조건문(if)과 논리(and / or)

---

## 1. 만약에 ~라면? 컴퓨터의 두뇌 `if`

컴퓨터는 시키는 대로만 하는 기계지만, **조건문(`if`)**을 배우는 순간 스스로 상황을 판단하는 똑똑한 로봇으로 변신합니다.

일상생활에서도 우리는 늘 조건을 따집니다:
* *"만약 비가 오면(`if`), 우산을 챙긴다. 그렇지 않으면(`else`), 모자를 쓴다."*

파이썬 코드로는 이렇게 씁니다:
```python
if is_raining:
    print("우산을 챙겨요!")
else:
    print("모자를 써요!")
```

## 2. 여러 조건을 묶어주는 강력한 접착제: `and` 와 `or`

우리가 길을 건널 때는 여러 가지를 한꺼번에 살펴봐야 합니다:
1. **`and` (그리고)**: 연결된 조건이 **모두 다 참(True)**이어야 전체가 참이 됩니다!
   * `초록불이고 and 차가없다` -> 둘 다 맞아야 안심!
2. **`or` (또는)**: 연결된 조건 중 **단 하나라도 참(True)**이면 전체가 참이 됩니다!
   * `빨간불이거나 or 차가달린다` -> 둘 중 하나만 해당되어도 위험하니 STOP!

이처럼 `if`, `and`, `or`를 조립하면 자율주행 자동차나 스마트 로봇의 안전 뇌를 직접 코딩할 수 있답니다!
