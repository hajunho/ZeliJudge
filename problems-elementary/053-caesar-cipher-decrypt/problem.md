# 053. 적군의 암호를 해독하라! 카이사르 암호 복호화

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열, 아스키코드, 역방향 모듈러 연산, 복호화
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

앞서 #014번 문제에서 카이사르 장군이 알파벳을 오른쪽으로 $K$칸 밀어서 비밀 지령을 만들었던 것을 기억하나요?
아군 첩보원이 적군의 카이사르 암호문을 가로챘습니다!

암호를 해독(복호화)하려면 오른쪽으로 밀었던 암호문을 반대로 **왼쪽으로 $K$칸 다시 당겨와야** 합니다!
예를 들어 $K = 3$칸 밀어서 만든 암호문이 `DEF`라면:
* `D` -> `A`
* `E` -> `B`
* `F` -> `C`
원래 비밀 단어는 `ABC`였습니다!

만약 `A`에서 1칸을 왼쪽으로 당기면 다시 맨 뒤 알파벳인 `Z`로 빙글 돌아옵니다!
밀어낸 칸 수 $K$와 암호문이 주어졌을 때, 원래의 비밀 단어로 해독해 주는 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 밀어낸 칸 수 자연수 $K$가 주어집니다. ($1 \le K \le 25$)
둘째 줄에 영어 대문자로만 이루어진 암호문 단어가 주어집니다. ($1 \le \text{길이} \le 100$)

---

## 📤 출력 형식

해독된 원래 영어 대문자 단어를 한 줄에 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
3
DEF
```

**출력**
```text
ABC
```

### 예제 2

**입력**
```text
1
YZA
```

**출력**
```text
XYZ
```

### 예제 3

**입력**
```text
5
MJQQT
```

**출력**
```text
HELLO
```
