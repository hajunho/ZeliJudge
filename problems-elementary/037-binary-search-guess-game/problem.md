# 037. 1부터 100까지! 업다운 숫자 맞추기

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 이진 탐색(Binary Search), 업다운 게임, 탐색 횟수
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

소풍 버스 안에서 친구들과 '업-다운(UP-DOWN) 숫자 맞추기 게임'을 하고 있습니다!
친구가 1부터 $N$ 사이의 비밀 숫자 $T$를 마음속으로 정했습니다.

가장 똑똑하게 숫자를 맞추는 방법은 매번 **남은 범위의 딱 가운데 숫자**를 부르는 것입니다:
* 현재 탐색 범위가 $L$부터 $R$까지라면, 중간 숫자 $M = (L + R) // 2$를 부릅니다.
  * 만약 $M == T$라면: 정답! 게임이 즉시 끝납니다.
  * 만약 $M < T$라면: "UP!" (비밀 숫자가 더 크므로 다음 탐색 범위는 $M + 1$부터 $R$이 됩니다.)
  * 만약 $M > T$라면: "DOWN!" (비밀 숫자가 더 작으므로 다음 탐색 범위는 $L$부터 $M - 1$이 됩니다.)

범위의 끝 번호 $N$과 비밀 숫자 $T$가 주어졌을 때,
가운데 숫자를 부르는 똑똑한 전략으로 정답을 맞출 때까지 **총 몇 번의 숫자를 부르게 되는지** 계산해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 범위 끝 번호 $N$과 비밀 숫자 $T$가 공백으로 구분되어 주어집니다. ($1 \le T \le N \le 1,000$)

---

## 📤 출력 형식

정답을 맞출 때까지 질문한 총 횟수를 정수로 출력합니다.
