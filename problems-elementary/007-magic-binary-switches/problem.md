# 007. 보물 상자를 여는 4개의 전구 스위치

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 2진수(Binary), 10진수(Decimal), 자릿값(Place Value)
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

깊은 바닷속 해적선 보물창고를 탐험하던 민우는 번쩍이는 황금 보물 상자를 발견했습니다!
하지만 보물 상자 자물쇠에는 열쇠 구멍 대신 **4개의 전구 스위치**가 달려 있었습니다.

각 스위치는 켜지면 `1`, 꺼지면 `0` 상태가 됩니다.
보물 상자 뚜껑에는 다음과 같은 고대 해적의 암호문이 새겨져 있었습니다:

> *"네 개의 스위치는 왼쪽부터 차례대로 **8, 4, 2, 1**의 마법 힘을 품고 있느니라.*
> *불이 켜진(1) 스위치들의 마법 힘을 모두 더한 숫자가 바로 자물쇠를 푸는 비밀번호이니라!"*

예를 들어 스위치가 `1 0 1 1` 상태라면:
* 1번째 스위치 (8의 자리): 켜짐(`1`) -> **8**
* 2번째 스위치 (4의 자리): 꺼짐(`0`) -> **0**
* 3번째 스위치 (2의 자리): 켜짐(`1`) -> **2**
* 4번째 스위치 (1의 자리): 켜짐(`1`) -> **1**
비밀번호는 $8 + 0 + 2 + 1 = 11$이 됩니다!

4개의 스위치 불빛 상태가 주어졌을 때, 보물 상자를 열 수 있는 비밀번호(10진수 숫자)를 계산하는 프로그램을 만들어보세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 4개의 스위치 상태가 왼쪽부터 차례대로 공백으로 구분되어 주어집니다. 각 스위치는 켜짐(`1`) 또는 꺼짐(`0`) 중 하나입니다.

---

## 📤 출력 형식

보물 상자의 비밀번호에 해당하는 10진수 정수(0 이상 15 이하)를 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
1 0 1 1
```

**출력**
```text
11
```

### 예제 2

**입력**
```text
1 1 1 1
```

**출력**
```text
15
```

### 예제 3

**입력**
```text
0 0 0 0
```

**출력**
```text
0
```
