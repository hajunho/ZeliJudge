## 1. 몇 번 반복해야 할지 모를 때는 `while`문!

`for` 루프는 "10번 반복해!"처럼 횟수가 정해져 있을 때 좋습니다.
하지만 디지털 루트처럼 **"한 자리 숫자가 될 때까지"** 몇 번 반복해야 할지 미리 알 수 없을 때는 **`while` 조건 반복문**을 씁니다:

```python
while n >= 10:  # 두 자리 이상인 동안에는 계속 돌아라!
    # 자릿수 더하기
```

---

## 2. 숫자의 자릿수를 쪼개어 더하는 파이썬의 마법

숫자를 `str(n)`으로 글자로 바꾸면 각 자릿수를 하나씩 꺼낼 수 있습니다:
```python
total = sum(int(digit) for digit in str(n))
```

수학적으로 디지털 루트는 숫자를 9로 나눈 나머지와 아주 깊은 관련이 있는 신비로운 수론(Number Theory)의 한 분야랍니다!
