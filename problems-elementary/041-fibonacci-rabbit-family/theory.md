# 📘 [ZeliJudge Junior #041] 자연과 황금비율의 신비: 피보나치 수열과 변수 2개로 달리기

---

## 1. 솔방울과 해바라기 씨앗 속의 비밀

해바라기 꽃의 씨앗 나선 개수를 세어보면 21개, 34개, 55개, 89개처럼 항상 피보나치 숫자가 나옵니다.
자연이 가장 효율적으로 공간을 채우기 위해 피보나치 나선을 선택했기 때문입니다!

---

## 2. 변수 2개로 전진하는 마법: `a, b = b, a + b`

컴퓨터에서 피보나치를 구할 때 재귀함수를 무턱대고 쓰면 계산이 수백만 번 겹쳐 컴퓨터가 멈춰버립니다.
하지만 변수 2개(`a`는 지지난달, `b`는 지난달)만 들고 한 칸씩 앞으로 전진하면:
```python
a, b = b, a + b
```
단 $O(N)$의 빛의 속도로 답을 구할 수 있답니다!
