# 014. 한 글자씩 밀어내는 카이사르 비밀 암호

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열, 아스키코드(ASCII), 모듈러 순환
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

옛날 로마의 위대한 장군 율리우스 카이사르는 전쟁터에서 부하들에게 비밀 지령을 보낼 때 적군이 가로채도 읽을 수 없도록 특별한 암호를 사용했습니다.
그 암호는 바로 **모든 알파벳을 오른쪽으로 $K$칸씩 밀어서 바꾸는 방법**이었습니다!

예를 들어 $K = 3$칸씩 밀어낸다면:
* `A` -> `D`
* `B` -> `E`
* `C` -> `F`
* ...
* `X` -> `A`
* `Y` -> `B`
* `Z` -> `C` (Z 다음은 다시 맨 앞 알파벳인 A로 빙글 돌아옵니다!)

이 유명한 암호 방식을 **'카이사르 암호(시저 암호, Caesar Cipher)'**라고 부릅니다.
밀어낼 칸 수 $K$와 비밀 영어 단어가 주어졌을 때, 카이사르 암호문으로 변환해 주는 프로그램을 완성해 보세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 밀어낼 칸 수 정수 $K$가 주어집니다. ($1 \le K \le 25$)
둘째 줄에 영어 대문자로만 이루어진 단어 $W$가 주어집니다. ($1 \le \text{길이} \le 100$)

---

## 📤 출력 형식

암호화된 영어 대문자 단어를 한 줄에 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
3
ABC
```

**출력**
```text
DEF
```

### 예제 2

**입력**
```text
1
XYZ
```

**출력**
```text
YZA
```

### 예제 3

**입력**
```text
5
HELLO
```

**출력**
```text
MJQQT
```
