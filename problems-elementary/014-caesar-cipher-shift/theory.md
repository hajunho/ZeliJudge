# 📘 [ZeliJudge Junior #014] 글자를 숫자로 바꾸는 아스키코드와 % 26 순환 트릭

---

## 1. 컴퓨터에게 글자는 번호표다!

파이썬에는 글자를 숫자로 바꾸어 주는 마법의 함수 `ord()`와, 숫자를 다시 글자로 바꾸어 주는 `chr()` 함수가 있습니다:
* `ord('A')` -> 65
* `ord('B')` -> 66
* `chr(65)` -> `'A'`

---

## 2. 'Z' 다음을 다시 'A'로 되돌리는 `% 26`의 마법!

영어 알파벳은 총 26개입니다.
만약 `'Z'`에서 1칸을 밀면 어떻게 될까요? 그냥 1을 더하면 알파벳이 아닌 엉뚱한 기호가 나와 버립니다!

그래서 다음과 같은 3단계 변환을 거칩니다:
1. `'A'`를 0으로 맞추기: `idx = ord(ch) - ord('A')` (A는 0, Z는 25)
2. $K$칸을 더한 뒤 26으로 나눈 나머지 구하기: `(idx + k) % 26`
   * 만약 25(Z)에 1을 더하면 26이 되는데, `26 % 26 = 0`이 되어 다시 0(A)으로 완벽하게 돌아옵니다!
3. 다시 알파벳 문자로 복원: `chr(ord('A') + new_idx)`

이것이 현대 모든 정보 보안과 암호학의 가장 유서 깊은 출발점입니다!
