# 2x2 돋보기로 찾는 보물 상자! (부분 격자 합 최댓값)

## 📖 문제 설명
보물 탐험가 젤리가 비밀 동굴의 바닥 타일 지도를 발견했습니다. 바닥에는 R행 C열로 숫자가 새겨져 있습니다. 젤리는 가로 2칸 x 세로 2칸 크기의 정사각형 마법 돋보기를 지도 위에 올려놓고 마력 합을 측정하려 합니다. 돋보기 안 4칸의 숫자 합이 가장 큰 최댓값은 얼마일까요?

## 📥 입력 형식
첫 줄에 행의 수 R과 열의 수 C가 주어집니다. (2 <= R, C <= 100)\n다음 R개의 줄에 걸쳐 각 행의 C개 정수가 공백으로 주어집니다. (원소의 절댓값 <= 1,000)

## 📤 출력 형식
2x2 부분 격자 합의 최댓값을 단일 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
3 3
1 2 3
4 5 6
7 8 9
```
**출력**
```text
28
```

## 힌트
R x C 행렬에서 2x2 크기의 연속된 부분 격자 4칸의 합 중 최댓값을 구합니다.
