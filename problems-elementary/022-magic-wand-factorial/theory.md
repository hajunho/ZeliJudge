## 1. 덧셈의 기본값은 0, 곱셈의 기본값은 1!

합계를 구할 때는 처음에 빈 바구니 `total = 0`으로 시작했습니다.
하지만 곱셈을 할 때 `ans = 0`으로 시작하면 어떻게 될까요?
0에 무엇을 곱해도 영원히 0이 되어 버립니다!
그래서 **누적 곱셈을 할 때는 반드시 `ans = 1`**로 시작해야 합니다!

```python
ans = 1
for i in range(1, n + 1):
    ans = ans * i  # 또는 ans *= i
```

## 2. 눈덩이처럼 커지는 숫자: 팩토리얼의 위력

팩토리얼은 숫자가 커지는 속도가 세상에서 가장 빠른 연산 중 하나입니다:
* $1! = 1$
* $5! = 120$
* $10! = 362만$
* $15! = 1조 3000억!$

경우의 수(3명의 친구가 줄 서는 방법 $3! = 6$가지)를 계산할 때 팩토리얼이 핵심 공식으로 사용된답니다!
