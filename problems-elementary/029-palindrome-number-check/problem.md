# 029. 거꾸로 읽어도 똑같은 회문 숫자 찾기

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 수학, 숫자 뒤집기, 팰린드롬 판별
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

수학 마법사 머린은 특별한 대칭 에너지를 가진 숫자를 연구하고 있습니다.
`121`, `12321`, `7777`, `8` 처럼 **앞에서부터 읽으나 뒤에서부터 거꾸로 읽으나 완전히 똑같은 숫자**를 **'회문 숫자(Palindrome Number, 대칭수)'**라고 부릅니다.

반면에 `123`은 거꾸로 읽으면 `321`이 되어 원래 숫자와 다르므로 회문 숫자가 아닙니다.
`100`도 거꾸로 읽으면 `001` 즉 `1`이 되어 회문 숫자가 아닙니다.

어떤 자연수 $N$이 주어졌을 때,
이 숫자가 회문 숫자라면 `YES`, 아니라면 `NO`를 출력하는 마법 대칭수 판별기를 만들어보세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 자연수 $N$이 주어집니다. ($1 \le N \le 1,000,000,000$)

---

## 📤 출력 형식

회문 숫자이면 `YES`, 아니면 `NO`를 대문자로 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
121
```

**출력**
```text
YES
```

### 예제 2

**입력**
```text
12321
```

**출력**
```text
YES
```

### 예제 3

**입력**
```text
123
```

**출력**
```text
NO
```
