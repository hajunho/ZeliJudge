# 📘 [ZeliJudge Junior #029] 숫자를 문자열로 바라보는 발상의 전환

---

## 1. 숫자를 수학으로만 뒤집어야 할까?

수학적으로 숫자를 뒤집으려면 `10으로 나눈 나머지`를 구해 새 숫자에 10을 곱해 더하는 복잡한 연산을 해야 합니다.
하지만 프로그래밍에서는 발상을 조금만 바꾸면 기적 같은 일이 일어납니다:
> **"숫자를 글자(문자열)로 생각하면 글자 뒤집기 주문 `[::-1]`을 그대로 쓸 수 있잖아?!"**

```python
s = str(n)
if s == s[::-1]:
    print("YES")
```

---

## 2. 자료형 변환(Type Casting)의 힘

컴퓨터 프로그래밍에서는 데이터의 종류(숫자 int, 글자 str, 리스트 list 등)를 서로 자유롭게 바꾸는 것을 **형 변환(Type Casting)**이라고 부릅니다.
문제를 더 쉽게 풀 수 있는 형태로 자료형을 바꾸는 발상의 전환이 훌륭한 엔지니어의 핵심 능력이랍니다!
