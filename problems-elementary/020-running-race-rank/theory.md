# 📘 [ZeliJudge Junior #020] 기록으로 줄 세우기: 튜플(Tuple)과 기준 정렬(Key Sort)

---

## 1. 이름과 기록을 하나로 묶기: 튜플(Tuple)

달리기 순위를 정할 때 이름만 따로 정렬하거나 기록만 따로 정렬하면 누구 기록인지 엉망으로 섞여버립니다!
그래서 컴퓨터에서는 `(기록, 이름)`처럼 한 쌍으로 묶어주는 **튜플(Tuple)**이나 객체를 사용해요:

```python
runner = (13.80, "younghee")
```

---

## 2. 원하는 기준으로 정렬하기: `sort(key=...)`

파이썬에게 "기록 숫자 순서대로 정렬해줘!"라고 기준을 알려줄 때는 `key` 옵션을 씁니다:
```python
runners.sort(key=lambda x: x[0])
```
이렇게 하면 컴퓨터가 기록 숫자(첫 번째 값)를 기준으로 가장 빠른(작은) 순서대로 1등부터 꼴찌까지 완벽하게 줄을 세워줍니다!

그리고 `enumerate(runners, 1)`을 사용하면 1등부터 차례대로 등수 번호표를 손쉽게 붙일 수 있답니다!
