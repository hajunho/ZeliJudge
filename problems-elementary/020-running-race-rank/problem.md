# 020. 가을 운동회 100m 달리기 등수 매기기

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 리스트 정렬, 다중 속성 정렬(튜플), 순위 출력
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

만국기가 펄럭이는 가을 운동회의 하이라이트, 100m 달리기 결승전이 끝났습니다!
심판 선생님들의 스마트 워치에 각 학생들의 이름과 결승선을 통과한 시간(초)이 기록되었습니다.

달리기에서는 **시간이 작을수록(초가 적을수록) 더 빨리 달린 것**이므로 1등이 됩니다!
(예: 13.50초로 달린 친구가 14.20초로 달린 친구보다 빠릅니다.)

달리기에 참가한 $N$명의 학생 이름과 기록이 주어졌을 때,
가장 빠른 1등부터 꼴찌 $N$등까지 차례대로 등수와 이름, 기록을 출력하는 전광판 프로그램을 완성해 주세요!
(모든 학생의 달리기 기록은 서로 다르다고 가정합니다.)

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 참가 학생 수 자연수 $N$이 주어집니다. ($2 \le N \le 50$)
둘째 줄부터 $N$개의 줄에 걸쳐 학생 이름(공백 없는 단어)과 달리기 기록(초 단위 실수)이 공백으로 구분되어 주어집니다.

---

## 📤 출력 형식

1등부터 $N$등까지 각 줄마다 `등수 이름 기록` 형식으로 출력합니다. 등수는 `1`, `2`, ..., `N`으로 표시합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
3
minsoo 14.50
younghee 13.80
chulsoo 15.20
```

**출력**
```text
1 younghee 13.80
2 minsoo 14.50
3 chulsoo 15.20
```

### 예제 2

**입력**
```text
2
sora 12.30
mingo 11.90
```

**출력**
```text
1 mingo 11.90
2 sora 12.30
```
