# 📘 [ZeliJudge Junior #010] 두꺼운 국어사전에서 단어를 10초 만에 찾는 법: 사전식 순서(Lexicographical Order)

---

## 1. 사전식 순서(Lexicographical Order)란 무엇일까?

우리가 두꺼운 영어사전에서 `apple`을 찾을 때는 첫 글자 `a`가 있는 맨 앞 장을 펼칩니다.
반대로 `zebra`를 찾을 때는 맨 뒷장 `z`를 펼치지요!

컴퓨터도 글자를 비교할 때 똑같은 규칙을 씁니다:
1. 맨 첫 글자를 먼저 비교합니다: `'a' < 'b' < 'c' ... < 'z'`
2. 첫 글자가 똑같다면 두 번째 글자를 비교합니다: `'baby'` vs `'ball'` -> 둘 다 `'b'`로 시작하지만 두 번째 글자 `'a' < 'o'`이므로 `'baby'`가 먼저 옵니다!
3. 한 단어가 다른 단어의 앞부분과 완전히 똑같다면 더 짧은 단어가 먼저 옵니다: `'app'`이 `'apple'`보다 앞서요!

## 2. 컴퓨터가 글자의 크고 작음을 아는 비밀: 아스키(ASCII) 코드

컴퓨터는 원래 숫자만 아는 기계라고 했지요?
그렇다면 컴퓨터는 어떻게 `'a'`가 `'b'`보다 작다는 걸 알까요?

전 세계 모든 컴퓨터는 알파벳마다 고유한 약속 번호를 붙여두었습니다. 이것을 **아스키(ASCII) 코드**라고 해요:
* `'a'` = 97번
* `'b'` = 98번
* `'c'` = 99번

컴퓨터 눈에는 `'a' < 'b'`가 사실 `97 < 98`이라는 간단한 숫자 크기 비교였던 것입니다!

파이썬에서 `sorted(books)`를 쓰면 컴퓨터가 글자 번호를 바탕으로 순식간에 알파벳 사전 순서대로 완벽하게 정렬해 준답니다!
