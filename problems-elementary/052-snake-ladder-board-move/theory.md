# 📘 [ZeliJudge Junior #052] 게임 말판의 순간이동 포털: 딕셔너리(Dictionary) 맵핑

---

## 1. 사다리와 뱀을 기억하는 딕셔너리 포털

"4번 칸에 도착하면 15번으로 보내라!"는 규칙을 코드로 어떻게 표현할까요?
출발점(Key)과 도착점(Value)을 짝지어두는 **딕셔너리(`portals[u] = v`)**를 쓰면 완벽합니다:

```python
if pos in portals:
    pos = portals[pos] # 포털 점프!
```

---

## 2. 상태를 기억하며 주사위 굴리기

게임 시뮬레이션에서는 '현재 말의 위치(`pos = 1`)'를 변수에 담아두고,
주사위가 굴려질 때마다 하나씩 순서대로 규칙을 적용해 나가면 어떤 복잡한 룰의 보드게임도 척척 코딩할 수 있답니다!
