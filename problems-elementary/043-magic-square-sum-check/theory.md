# 📘 [ZeliJudge Junior #043] 모두 같은지 한 번에 확인하는 꿀팁: len(set(sums)) == 1

---

## 1. 8개의 합을 전부 집합에 넣어보기

8개의 숫자가 전부 똑같은지 비교하려면 `s1 == s2 and s2 == s3...` 길게 써야 할까요?
앞서 배운 **집합(`set`)**의 원리를 떠올려보세요!
> **"집합은 중복된 값을 하나로 합쳐버린다!"**

만약 8개의 합이 전부 15로 똑같다면, 집합에 넣었을 때 원소가 딱 1개(`{15}`)만 남습니다!
```python
if len(set(sums)) == 1:
    print("YES")
```
이 우아한 한 줄 검사법은 프로그래머들이 즐겨 쓰는 멋진 테크닉입니다!
