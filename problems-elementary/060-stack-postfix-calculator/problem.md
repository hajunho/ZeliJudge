# 060. 로봇이 계산하는 후위 표기법(Postfix) 한 자리 셈

* **카테고리**: 자료구조 스택(Stack), 후위 표기법(Postfix), 계산기 원리
* **시간 제한**: 1.0초

## 📖 재미있는 이야기 시나리오

우리가 일상에서 쓰는 계산식은 `3 + 4` 처럼 연산자(`+`)가 숫자 사이에 옵니다 (중위 표기법).
하지만 컴퓨터나 계산기 로봇의 두뇌는 괄호나 곱셈 우선순위 때문에 헷갈리는 것을 막기 위해 **연산자를 숫자 뒤에 쓰는 '후위 표기법(Postfix, 역폴란드 표기법)'**을 훨씬 좋아합니다!

후위 표기법 계산 규칙 (스택 활용):
1. 식을 왼쪽에서 오른쪽으로 차례대로 읽습니다.
2. **숫자를 만나면**: 스택에 차곡차곡 넣습니다 (Push).
3. **연산자(`+`, `-`, `*`)를 만나면**:
   * 스택에서 숫자 **2개를 꺼냅니다** (Pop).
   * 먼저 꺼낸 숫자가 $B$, 나중에 꺼낸 숫자가 $A$가 됩니다.
   * $A$ [연산자] $B$ 를 계산합니다!
   * 계산한 결과 숫자를 다시 스택에 넣습니다!
4. 식이 모두 끝나면 스택에 최종 정답 단 1개가 남게 됩니다!

예를 들어 `3 4 + 2 *` 라면:
* 3 넣고, 4 넣음 -> `[3, 4]`
* `+` 만남 -> 4와 3을 꺼내 $3 + 4 = 7$ 계산 후 다시 넣음 -> `[7]`
* 2 넣음 -> `[7, 2]`
* `*` 만남 -> 2와 7을 꺼내 $7 \times 2 = 14$ 계산 후 다시 넣음 -> `[14]`
최종 결과는 `14`입니다!

후위 표기식이 주어졌을 때, 최종 계산 결과를 출력하는 계산기 프로그램을 완성해 주세요!

## 🎯 문제 설명

## 📥 입력 형식

첫째 줄에 한 자리 자연수들과 연산자(`+`, `-`, `*`)가 공백으로 구분된 후위 표기식 문자열이 주어집니다. (식은 항상 올바르며, 계산 중간 및 결과는 정수 범위입니다.)

---

## 📤 출력 형식

식의 최종 계산 결과를 정수로 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
3 4 + 2 *
```

**출력**
```text
14
```

### 예제 2

**입력**
```text
5 1 2 + 4 * + 3 -
```

**출력**
```text
14
```

### 예제 3

**입력**
```text
10 20 +
```

**출력**
```text
30
```
