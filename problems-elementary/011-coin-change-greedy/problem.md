# 011. 문구점 거스름돈과 최소 동전 개수

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 그리디(탐욕법), 화폐 분할, 몫과 나머지
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

학교 앞 문구점 아저씨는 계산할 때마다 손님들에게 거스름돈을 줄 때 동전을 되도록 **가장 적은 개수**로 주려고 합니다.
동전이 너무 많으면 손님 주머니도 무겁고, 아저씨의 동전 서랍도 금방 바닥나기 때문입니다.

문구점에 준비된 동전은 4종류입니다:
* 500원짜리
* 100원짜리
* 50원짜리
* 10원짜리

손님에게 돌려주어야 할 거스름돈 $M$원이 주어졌을 때,
동전의 총 개수를 가장 적게 하면서 거슬러 주려면 각 동전이 몇 개씩 필요한지 계산하는 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 거슬러 주어야 할 금액 정수 $M$이 주어집니다. ($10 \le M \le 10,000$, $M$은 항상 10의 배수입니다.)

---

## 📤 출력 형식

500원, 100원, 50원, 10원짜리 동전의 개수를 차례대로 공백으로 구분하여 한 줄에 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
1260
```

**출력**
```text
2 2 1 1
```

### 예제 2

**입력**
```text
800
```

**출력**
```text
1 3 0 0
```

### 예제 3

**입력**
```text
70
```

**출력**
```text
0 0 1 2
```
