## 📖 재미있는 이야기 시나리오

수학 탐정단은 암호 자물쇠를 풀기 위해 특별한 숫자인 **'소수(Prime Number)'**를 찾고 있습니다.
소수란 **1보다 큰 자연수 중에서 1과 자기 자신만을 약수로 가지는 숫자**를 말합니다.
(즉, 더 이상 다른 자연수로 쪼갤 수 없는 가장 순수한 숫자들의 씨앗입니다!)

예를 들어:
* `2` : 1과 2로만 나누어떨어지므로 -> **소수 (PRIME)** (유일한 짝수 소수!)
* `7` : 1과 7로만 나누어떨어지므로 -> **소수 (PRIME)**
* `4` : 1, 2, 4로 나누어떨어지므로 (2의 배수) -> **합성수 (COMPOSITE)**
* `1` : 1보다 커야 한다는 규칙 때문에 -> **소수가 아님 (COMPOSITE)**

어떤 자연수 $N$이 주어졌을 때, 이 숫자가 소수이면 `PRIME`, 소수가 아니면 `COMPOSITE`를 출력하는 소수 탐정 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 자연수 $N$이 주어집니다. ($1 \le N \le 10,000$)

---

## 📤 출력 형식

소수이면 `PRIME`, 소수가 아니면 `COMPOSITE`를 대문자로 출력합니다.
