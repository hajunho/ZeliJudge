## 2. 유클리드 호제법(Euclidean Algorithm)의 비밀

기원전 300년 고대 그리스의 수학자 유클리드는 최대공약수를 초고속으로 구하는 알고리즘을 발견했습니다:
> **"$A$와 $B$의 최대공약수는 $B$와 $(A \% B)$의 최대공약수와 완벽하게 같다!"**

```python
def my_gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a
```

이 알고리즘은 인류 역사상 가장 오래된 알고리즘 중 하나이며, 오늘날 비트코인이나 최신 암호화 통신에서도 핵심 연산으로 쓰이고 있습니다!
