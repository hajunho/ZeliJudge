# [초등] #100 대망의 100번! 버블 정렬 vs 선택 정렬 스왑 대결

## 📖 문제 줄거리 & 상황
축하합니다! ZeliJudge Junior 트랙 대망의 100번째 문제입니다! 🎉
컴퓨터 과학 역사상 가장 친숙한 두 정렬 알고리즘인 '버블 정렬(Bubble Sort)'과 '선택 정렬(Selection Sort)'이 자리를 바꾸는 '스왑(Swap)' 횟수를 두고 세기의 대결을 펼칩니다!
주어진 배열을 오름차순으로 정렬할 때, 버블 정렬이 수행하는 총 스왑 횟수와 선택 정렬이 수행하는 총 스왑 횟수를 각각 계산해주세요!

---

## 💻 문제 설명
$N$개의 정수 배열이 주어집니다.
1. **버블 정렬**: 인접한 두 원소 $A[j] > A[j+1]$일 때마다 즉시 자리를 맞바꿉니다.
2. **선택 정렬**: $i$번째 자리($0 \le i < N-1$)에 대해, $i$부터 $N-1$까지의 원소 중 최솟값의 위치 `min_idx`를 찾은 후, `min_idx != i`이면 $A[i]$와 $A[min_idx]$를 1회 스왑합니다.
버블 정렬의 총 스왑 횟수와 선택 정렬의 총 스왑 횟수를 공백으로 구분하여 출력하세요.

---

## 📥 입력 형식 (Input)
첫째 줄에 배열의 크기 $N$이 주어집니다. ($1 \le N \le 100$)
둘째 줄에 $N$개의 정수가 공백으로 구분되어 주어집니다.

---

## 📤 출력 형식 (Output)
버블 정렬 스왑 횟수와 선택 정렬 스왑 횟수를 공백으로 구분하여 출력합니다.

---

## 💡 입출력 예시

### 예제 1
- **입력:**
```text
3
3 1 2
```
- **출력:**
```text
2 2
```

### 예제 2
- **입력:**
```text
3
1 2 3
```
- **출력:**
```text
0 0
```
