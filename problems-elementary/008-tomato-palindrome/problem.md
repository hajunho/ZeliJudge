# 008. 앞으로 읽어도 뒤로 읽어도 똑같은 거울 단어

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열(String), 회문(Palindrome), 대칭성 검사
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

국어 시간, 선생님께서 재미있는 수수께끼를 내셨습니다:
> *"토마토, 기러기, 스위스, 별똥별, 다시합창합시다!"*
> *"이 낱말들의 아주 특별하고 신기한 공통점은 무엇일까요?"*

손을 번쩍 든 지우가 외쳤습니다:
> *"앞에서부터 읽어도, 뒤에서부터 거꾸로 읽어도 똑같이 읽혀요!"*

선생님께서는 활짝 웃으시며 이런 낱말을 **'거울 단어'** 또는 컴퓨터 과학과 수학에서 **'회문(Palindrome, 팰린드롬)'**이라고 부른다고 알려주셨습니다.
영어 단어 중에도 `level`, `radar`, `noon`, `kayak` 같은 멋진 거울 단어들이 아주 많습니다.

친구들이 적어낸 영어 단어가 주어졌을 때,
이 단어가 거울 단어(회문)라면 `YES`를, 거울 단어가 아니라면 `NO`를 출력하는 마법 거울 판독기를 만들어보세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 영어 소문자로만 이루어진 단어 $W$가 주어집니다. ($1 \le \text{길이} \le 50$)

---

## 📤 출력 형식

단어가 거울 단어(회문)이면 `YES`, 아니면 `NO`를 대문자로 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
level
```

**출력**
```text
YES
```

### 예제 2

**입력**
```text
robot
```

**출력**
```text
NO
```

### 예제 3

**입력**
```text
kayak
```

**출력**
```text
YES
```
