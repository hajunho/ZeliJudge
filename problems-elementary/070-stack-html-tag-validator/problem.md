# [초등] #070 웹 브라우저의 마법! 열린 태그와 닫힌 태그 짝 검사

## 📖 문제 줄거리 & 상황
크롬이나 사파리 같은 웹 브라우저는 HTML 문서를 읽어 화면을 멋지게 꾸며줍니다. 굵은 글씨는 `<b>`와 `</b>`, 기울임꼴은 `<i>`와 `</i>`처럼 열린 태그와 닫힌 태그가 올바른 순서대로 감싸져 있어야 화면이 깨지지 않고 완벽하게 렌더링됩니다.

---

## 💻 문제 설명
공백으로 구분된 HTML 태그 목록이 주어집니다. 모든 태그가 올바르게 열리고 닫히며 중첩 규칙(나중에 열린 태그가 먼저 닫혀야 함)을 만족하면 `YES`, 그렇지 않으면 `NO`를 출력하세요.
태그의 종류는 `<b>`, `</b>`, `<i>`, `</i>`, `<u>`, `</u>`, `<p>`, `</p>` 총 4쌍입니다.

---

## 📥 입력 형식 (Input)
첫째 줄에 공백으로 구분된 태그 문자열들이 주어집니다. (태그 개수는 1개 이상 100개 이하)

---

## 📤 출력 형식 (Output)
올바른 태그 쌍이면 `YES`, 잘못된 태그 쌍이면 `NO`를 출력합니다.

---

## 💡 입출력 예시

### 예제 1
- **입력:**
```text
<b> <i> </i> </b>
```
- **출력:**
```text
YES
```

### 예제 2
- **입력:**
```text
<b> <i> </b> </i>
```
- **출력:**
```text
NO
```
