## 1. 주사위 2개로 만들 수 있는 세상: 36가지

첫 번째 주사위 눈금 6가지, 두 번째 주사위 눈금 6가지.
모두 합치면 $6 \times 6 = 36$가지 조합이 존재합니다.

컴퓨터에게 이 36가지를 하나도 빠뜨리지 않고 다 뒤져보라고 시킬 때 **이중 for 문**을 사용합니다:
```python
for a in range(1, 7):      # 첫 번째 주사위 (1~6)
    for b in range(1, 7):  # 두 번째 주사위 (1~6)
        if a + b == k:
            print(a, b)
```

## 2. 무식하지만 가장 강력한 '완전 탐색(Brute Force)'

가능한 모든 경우를 일일이 다 확인해보는 방법을 컴퓨터 과학에서는 **완전 탐색(Brute Force 브루트 포스)**이라고 불러요.
사람에게 36가지를 따지라면 머리가 아프지만, 컴퓨터는 36만 번, 3600만 번도 1초 만에 확인하므로 완전 탐색은 알고리즘의 든든한 기초 무기랍니다!
