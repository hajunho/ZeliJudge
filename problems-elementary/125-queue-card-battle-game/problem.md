# 번갈아 내는 카드 배틀! (선입선출 큐 시뮬레이션)

## 📖 문제 설명
카드 게임 대회에서 젤리와 친구가 각각 N장의 숫자가 적힌 카드를 덱에 들고 대결합니다. 매 라운드마다 두 사람은 덱의 맨 앞 카드를 동시에 꺼냅니다. 더 큰 숫자를 낸 사람이 두 카드를 모두 챙겨 자기 덱의 맨 뒤로 넣습니다(자기 카드를 먼저 넣고 상대 카드를 넣음). 무승부면 각자 카드를 자기 덱 맨 뒤에 도로 넣습니다. 카드가 0장이 되면 즉시 패배하여 게임이 끝납니다. M라운드 후 두 사람의 남은 카드 수를 구하세요!

## 📥 입력 형식
첫 줄에 초기 카드 수 N과 최대 진행 라운드 수 M (1 <= N <= 100, 1 <= M <= 1,000)이 주어집니다.\n둘째 줄에 젤리의 초기 카드 N개가 공백으로 주어집니다.\n셋째 줄에 친구의 초기 카드 N개가 공백으로 주어집니다.

## 📤 출력 형식
M라운드가 끝난 후 (또는 누군가의 카드가 다 떨어져 종료된 후) 젤리의 남은 카드 수와 친구의 남은 카드 수를 공백으로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
2 1
5 2
3 4
```
**출력**
```text
3 1
```

## 힌트
두 플레이어의 카드 덱을 큐로 모델링하여 매 라운드 카드를 비교하고 승자가 카드를 가져가는 배틀을 M라운드 시뮬레이션합니다.
