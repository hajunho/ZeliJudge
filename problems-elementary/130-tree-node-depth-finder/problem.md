# 동물원 족보 탐험 4! 특정 동물의 세대(깊이) 찾기

## 📖 문제 설명
새싹 동물원에는 1번 시조 사자 할아버지부터 시작되는 거대한 가계도 족보가 있습니다. 각 동물은 누구의 자식인지 부모-자식 번호가 기록되어 있습니다. 족보 관리자 젤리는 특정 동물 K번이 시조 할아버지(1번)로부터 몇 세대 자손인지(루트의 깊이는 0, 자식은 1, 손자는 2...) 그 세대 깊이(Depth)를 알고 싶습니다. K번 동물의 세대 깊이를 계산해주세요!

## 📥 입력 형식
첫 줄에 노드의 수 N (1 <= N <= 100)과 깊이를 알고 싶은 동물 번호 K (1 <= K <= N)가 공백으로 주어집니다.\n다음 N-1개의 줄에 걸쳐 부모 노드 P와 자식 노드 C가 공백으로 주어집니다. (항상 루트는 1번입니다. N=1일 때는 간선 줄이 없습니다.)

## 📤 출력 형식
동물 번호 K의 루트(1번)로부터의 깊이를 정수로 출력합니다.

## 💡 입출력 예시
### 예시 1
**입력**
```text
4 4
1 2
1 3
2 4
```
**출력**
```text
2
```

## 힌트
1번 루트 노드로부터 시작하는 트리에서 특정 노드 K의 깊이(루트로부터의 거리, 루트=0)를 구합니다.
