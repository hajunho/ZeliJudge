# 트리의 노드 깊이(Depth)와 부모 역추적

트리(Tree)는 사이클이 없는 계층형 연결 구조입니다.

## 1. 노드의 깊이(Depth)란?
- **루트 노드(Root, 1번)**의 깊이는 **0**입니다.
- 어떤 노드의 깊이는 **루트에서 그 노드까지 가기 위해 거치는 간선(Edge)의 개수**입니다.
- 즉, 부모의 깊이가 $D$라면, 자식의 깊이는 $D + 1$이 됩니다.

## 2. 부모 테이블을 이용한 역추적 ($O(N)$)
각 자식 노드 `C`의 부모 `P`를 딕셔너리나 배열 `parent[C] = P`로 기록해 둡니다.
특정 노드 $K$의 깊이를 구할 때는:
- 현재 노드를 $K$로 두고, 깊이 카운터를 0으로 초기화합니다.
- 현재 노드가 루트(1번)가 아닐 때까지 `curr = parent[curr]`로 거슬러 올라가며 깊이를 1씩 증가시킵니다.
- 루트에 도달했을 때의 카운터 값이 바로 정확한 깊이입니다!
