# [초등] #081 미로 탈출 로봇과 2차원 최단 거리 (2D BFS)

## 📖 문제 줄거리 & 상황
스마트 탐사 로봇이 $R \times C$ 크기의 고대 미로에 갇혔습니다. 미로의 빈칸(`0`)은 자유롭게 이동할 수 있지만, 돌벽(`1`)은 지나갈 수 없습니다. 로봇이 맨 왼쪽 위 입구 $(0, 0)$에서 출발하여 맨 오른쪽 아래 출구 $(R-1, C-1)$까지 상하좌우로만 이동할 때, 거쳐야 하는 최소 칸 수를 구하세요! (출발 칸과 도착 칸도 카운트에 포함합니다)

---

## 💻 문제 설명
$R$행 $C$열 미로 지도가 주어집니다. `0`은 이동할 수 있는 길, `1`은 벽입니다. $(0,0)$에서 $(R-1, C-1)$까지 이동하는 최단 경로의 칸 수를 출력하세요. 만약 도달할 수 없다면 `-1`을 출력합니다.

---

## 📥 입력 형식 (Input)
첫째 줄에 미로의 행 개수 $R$과 열 개수 $C$가 공백으로 주어집니다. ($2 \le R, C \le 20$)
둘째 줄부터 $R$개의 줄에 걸쳐 각 줄에 $C$개의 숫자(`0` 또는 `1`)가 공백으로 구분되어 주어집니다. (시작점과 도착점은 항상 `0`입니다)

---

## 📤 출력 형식 (Output)
시작 칸에서 도착 칸까지의 최소 이동 칸 수를 정수로 출력합니다. (도달 불가능 시 `-1`)

---

## 💡 입출력 예시

### 예제 1
- **입력:**
```text
4 4
0 0 1 0
1 0 1 0
1 0 0 0
1 1 1 0
```
- **출력:**
```text
7
```

### 예제 2
- **입력:**
```text
2 2
0 0
0 0
```
- **출력:**
```text
3
```
