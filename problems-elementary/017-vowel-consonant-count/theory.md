# 📘 [ZeliJudge Junior #017] 주머니 속에 쏙 들어있니?: in 연산자와 집합(Set)

---

## 1. 글자 하나하나 돋보기로 살펴보기

단어 속의 글자를 검사할 때 파이썬은 글자 하나씩 차례대로 꺼내 주는 멋진 반복문을 제공합니다:
```python
for ch in word:
    print(ch)
```

---

## 2. 모음인지 한 번에 물어보는 마법: `in` 연산자

어떤 글자가 `a, e, i, o, u` 중 하나인지 확인할 때 다섯 번씩 `if ch == 'a' or ch == 'e'...` 쓰면 코드가 너무 길어집니다.
이때 파이썬의 **`in` 연산자**를 쓰면 친구들에게 물어보듯 자연스럽게 쓸 수 있어요:
```python
if ch in "aeiou":
    # 모음 맞아요!
```

컴퓨터에게 찾고 싶은 목록을 주머니(집합, Set)에 담아두고 `in`으로 물어보면 단 0.000001초 만에 척척 찾아낸답니다!
