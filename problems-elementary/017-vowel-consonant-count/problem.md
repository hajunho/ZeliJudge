# 017. 비밀 단어 속 모음(a, e, i, o, u) 탐정

* **난이도**: 초급 (초등학생 / 코딩 입문)
* **카테고리**: 문자열 순회, 집합(Set) 포함 검사, 카운팅
* **시간 제한**: 1.0초
* **메모리 제한**: 256 MB
* **핵심 컴퓨터 원리**: [theory.md 읽으러 가기](theory.md)

---

## 📖 재미있는 이야기 시나리오

영어 마을의 탐정단은 암호 편지를 분석할 때 모음과 자음의 비율을 가장 먼저 조사합니다.
영어 알파벳 26개 중 입술이나 혀에 걸리지 않고 부드럽게 소리 나는 글자를 **모음(Vowel)**이라고 부릅니다.

영어 모음 5총사:
* `a`, `e`, `i`, `o`, `u`

모음을 뺀 나머지 모든 알파벳(예: b, c, d, f, g, ...)은 **자음(Consonant)**입니다.

영어 소문자로 이루어진 단어 $W$가 주어졌을 때,
1. 단어 속에 들어있는 모음의 총 개수와,
2. 자음의 총 개수를
차례대로 계산하는 단어 탐정 프로그램을 작성해 주세요!

---

## 🎯 문제 설명

주어진 입력을 바탕으로 올바른 정답을 계산하여 출력하세요.

---

## 📥 입력 형식

첫째 줄에 영어 소문자로만 이루어진 단어 $W$가 공백 없이 주어집니다. ($1 \le \text{길이} \le 100$)

---

## 📤 출력 형식

첫째 줄에 모음의 개수와 자음의 개수를 공백으로 구분하여 출력합니다.

---

## 💡 입출력 예시 (Sample Input & Output)

### 예제 1

**입력**
```text
apple
```

**출력**
```text
2 3
```

### 예제 2

**입력**
```text
banana
```

**출력**
```text
3 3
```

### 예제 3

**입력**
```text
sky
```

**출력**
```text
0 3
```
