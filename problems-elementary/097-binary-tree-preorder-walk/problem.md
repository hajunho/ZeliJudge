# [초등] #097 동물원 족보 탐험! 이진 트리의 전위 순회(Preorder)

## 📖 문제 줄거리 & 상황
동물원의 보물 안내도는 1번 방(루트)부터 시작하는 이진 트리 구조로 연결되어 있습니다. 탐험가는 '전위 순회(Preorder)' 규칙인 [1. 현재 방 방문 -> 2. 왼쪽 자식 방 탐험 -> 3. 오른쪽 자식 방 탐험] 순서로 모든 방을 차례대로 방문하려고 합니다.

---

## 💻 문제 설명
1번 노드가 루트인 $N$개 노드의 이진 트리 구조가 주어집니다. 전위 순회(Preorder: Root -> Left -> Right)로 방문한 노드들의 번호를 공백으로 구분하여 한 줄에 출력하세요.

---

## 📥 입력 형식 (Input)
첫째 줄에 노드의 개수 $N$이 주어집니다. ($1 \le N \le 100$)
둘째 줄부터 $N$개의 줄에 걸쳐 각 노드에 대해 `노드번호 왼쪽자식번호 오른쪽자식번호`가 공백으로 주어집니다. (자식이 없는 경우 `0`으로 표시됩니다)

---

## 📤 출력 형식 (Output)
전위 순회 방문 순서대로 노드 번호를 공백으로 구분하여 출력합니다.

---

## 💡 입출력 예시

### 예제 1
- **입력:**
```text
3
1 2 3
2 0 0
3 0 0
```
- **출력:**
```text
1 2 3
```

### 예제 2
- **입력:**
```text
1
1 0 0
```
- **출력:**
```text
1
```
