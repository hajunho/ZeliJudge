## 1. 두 컵의 물을 서로 바꾸는 방법 (Swap)

왼손에 주스 컵, 오른손에 우유 컵이 있을 때 둘의 내용물을 어떻게 바꿀까요?
**빈 컵(임시 변수 temp)**이 하나 필요합니다!
```python
temp = a
a = b
b = temp
```

하지만 파이썬에서는 임시 컵도 필요 없이 마법처럼 한 줄로 쓸 수 있습니다:
```python
a, b = b, a
```

## 2. 1회전마다 대장 1명이 자기 자리를 찾아간다!

버블 정렬 1회전을 마치면 가장 큰 대장 숫자가 반드시 맨 끝자리로 이동합니다.
