# 꽃봉오리를 오므려 홀수 주기를 수축하라! 에드몬즈의 블로섬 알고리즘 (Edmonds' Blossom Algorithm)

## 문제 설명
$V$개의 정점과 $E$개의 간선으로 이루어진 일반 무향 그래프가 주어집니다.
그래프는 이분 그래프가 아닐 수 있으며, 홀수 길이의 사이클이 포함될 수 있습니다.

서로 끝점을 공유하지 않는 간선들의 최대 부분집합인 **최대 매칭(Maximum Matching)**의 크기와 매칭된 간선들의 목록을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정점의 개수 $V$ ($1 \le V \le 100$)와 간선의 개수 $E$ ($0 \le E \le 500$)가 공백으로 구분되어 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 각 간선이 연결하는 두 정점 $u, v$ ($1 \le u < v \le V$)가 주어집니다.

## 출력 형식
- 첫째 줄에 최대 매칭의 크기 $M$을 출력합니다.
- 둘째 줄부터 $M$개 줄에 걸쳐 매칭된 두 정점 $u, v$ ($u < v$)를 한 줄에 하나씩 출력합니다. 매칭 쌍들은 $u$를 기준으로 오름차순 정렬하여 출력합니다.
- (해는 여러 개일 수 있으나, 알고리즘 구현 규칙에 따른 결정론적 매칭 결과를 출력합니다.)

## 예제 1
### 입력
```text
4 4
1 2
2 3
3 4
4 1
```
### 출력
```text
2
1 2
3 4
```

## 예제 2
### 입력
```text
5 5
1 2
2 3
3 4
4 5
5 1
```
### 출력
```text
2
1 2
3 4
```
**설명**: 5개의 정점으로 이루어진 홀수 사이클(5-cycle)입니다. 어떤 정점 하나는 남을 수밖에 없으므로 최대 매칭 크기는 2입니다.
