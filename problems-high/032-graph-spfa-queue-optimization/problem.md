# 큐로 필요한 노드만 갱신하라! SPFA 최단 경로 (Shortest Path Faster Algorithm)

## 문제 설명
벨만-포드 알고리즘은 매 라운드마다 모든 M개의 간선을 무조건 순회하므로 O(NM)의 시간이 걸립니다.
하지만 실제로는 직전 라운드에서 **최단 거리가 실제로 감소(갱신)한 정점에 연결된 간선들만** 다음 라운드에서 갱신될 가능성이 있습니다.

이 성질을 활용하여 거리가 갱신된 정점만 큐(Queue)에 넣어 처리하는 **SPFA(Shortest Path Faster Algorithm)**를 구현하세요.
어떤 정점이 큐에 N번 이상 들어가면 음수 사이클이 존재하는 것으로 판정합니다.

## 입력 형식
첫째 줄에 정점 수 N과 간선 수 M이 주어집니다. (1 <= N <= 1,000, 1 <= M <= 10,000)
둘째 줄부터 M개의 줄에 걸쳐 u, v, w가 주어집니다. (u에서 v로 가는 가중치 w 간선, 음수 가능)

## 출력 형식
1번 정점에서 도달 가능한 음수 사이클이 있다면 -1을 출력합니다.
없다면 2번부터 N번 정점까지 최단 거리를 한 줄에 하나씩 출력합니다 (도달 불가능 시 -1).

## 입출력 예제

### 예제 1
**입력:**
```text
3 4
1 2 4
1 3 3
2 3 -1
3 1 -2
```

**출력:**
```text
4
3
```

### 예제 2
**입력:**
```text
3 4
1 2 4
1 3 3
2 3 -4
3 1 -2
```

**출력:**
```text
-1
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
