# 비트마스크 외판원 순회 (TSP with Bitmask DP)

## 1. 순환성(Cycle)에 의한 시작점 고정
모든 도시를 방문하고 다시 출발지로 돌아오는 닫힌 사이클이므로, **어느 정점에서 출발하든 최적 순회 비용은 동일**합니다.
따라서 시작점을 0번(또는 1번) 도시로 고정하고 탐색할 수 있습니다.

## 2. 상태 정의 및 점화식
- `dp(cur, visited)`: 현재 `cur` 도시에 있고, 방문한 도시들의 비트마스크가 `visited`일 때, 나머지 모든 도시를 방문하고 0번 도시로 귀환하는 최소 비용
- 기저 사례: `visited == (1 << N) - 1`일 때, `W[cur][0]`이 0이 아니라면 `W[cur][0]` 반환, 갈 수 없다면 `INF` 반환
- 전이: 다음 미방문 도시 `nxt`에 대해 `W[cur][nxt] != 0`이면:
  $$\text{dp}(cur, visited) = \min_{nxt} (\text{dp}(nxt, visited \mid (1 \ll nxt)) + W[cur][nxt])$$
- 상태 수 $N \cdot 2^N$, 각 상태별 $N$개 분기이므로 시간 복잡도는 $O(N^2 2^N)$입니다.
