# 모든 도시를 한 번씩 방문하고 돌아오는 최소 비용! 비트마스크 외판원 순회 (Bitmask TSP DP)

## 문제 설명
1번부터 N번까지 번호가 매겨져 있는 N개의 도시가 있고, 도시들 사이에는 길이 있습니다.
외판원은 한 도시에서 출발해 N개의 도시를 모두 거쳐 다시 원래의 출발 도시로 돌아오는 순회 여행 경로를 계획하려고 합니다.
단, 한 번 갔던 도시로는 다시 갈 수 없습니다 (출발지로 돌아오는 마지막 귀환 제외).
각 도시 간의 이동 비용 행렬 W가 주어졌을 때, 가장 적은 비용을 들이는 외판원 순회 경로의 비용을 구하는 프로그램을 작성하세요.
방문한 도시 집합을 비트(Bit)로 표현하고 메모이제이션하는 $O(N^2 2^N)$ 비트마스크 DP를 적용하세요.

## 입력 형식
첫째 줄에 도시의 수 N이 주어집니다. (2 <= N <= 16)
다음 N개의 줄에는 각 도시 간 이동 비용 W[i][j]가 공백으로 구분되어 주어집니다. (0 <= W[i][j] <= 1,000,000)
W[i][i]는 항상 0이며, i에서 j로 갈 수 없는 경우 W[i][j]는 0으로 주어집니다. 순회가 불가능한 경우는 주어지지 않습니다.

## 출력 형식
외판원의 순회에 필요한 최소 비용을 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4
0 10 15 20
5 0 9 10
6 13 0 12
8 8 9 0
```

**출력:**
```text
35
```

### 예제 2
**입력:**
```text
2
0 5
7 0
```

**출력:**
```text
12
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
