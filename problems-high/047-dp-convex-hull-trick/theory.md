# 컨벡스 헐 트릭 (Convex Hull Trick)

## 1. 동적 계획법의 직선 변환
$$DP[i] = \min_{j < i} (B[j] \cdot A[i] + DP[j])$$
- 직선 $L_j: y = m_j x + k_j$ ($m_j = B[j], k_j = DP[j]$)
- $x = A[i]$에서의 최솟값 $\min_j (m_j x + k_j)$을 구하는 문제입니다.

## 2. 스택과 교점 판정
- 세 직선 $L_1, L_2, L_3$이 있을 때, $L_2$와 $L_3$의 교점이 $L_1$과 $L_2$의 교점보다 왼쪽에 있다면 $L_2$는 최솟값이 될 기회가 없으므로 스택에서 pop합니다.
- $A[i]$ 역시 단조 증가하므로 투 포인터를 이용해 최적 직선을 $O(1)$에 찾아 전체 $O(N)$에 해결됩니다.
