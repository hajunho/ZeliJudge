# 일차함수들의 최적화! 컨벡스 헐 트릭 (Convex Hull Trick CHT)

## 문제 설명
N개의 나무를 벌목하려고 합니다. i번째 나무를 자르면 비용이 발생합니다.
점화식이 다음과 같은 형태를 띨 때:
$$DP[i] = \min_{j < i} (DP[j] + A[i] \cdot B[j])$$

단순 2중 반복문은 O(N^2)이 걸려 N=100,000 이상에서 불가능합니다.
이 식은 기울기가 $B[j]$이고 y절편이 $DP[j]$인 직선들의 집합에서 $x = A[i]$일 때의 최솟값을 찾는 문제로 해석할 수 있습니다.
기울기 $B[j]$가 단조 감소(또는 증가)할 때 스택을 활용하여 볼록 껍질을 유지하는 **컨벡스 헐 트릭(Convex Hull Trick, CHT)**을 구현하여 O(N)에 해결하세요.

## 입력 형식
첫째 줄에 N이 주어집니다. (1 <= N <= 100,000)
둘째 줄에 N개의 정수 $A_1, A_2, \dots, A_N$이 공백으로 주어집니다. (A는 단조 증가, $A_1 = 0$)
셋째 줄에 N개의 정수 $B_1, B_2, \dots, B_N$이 공백으로 주어집니다. (B는 단조 감소, $B_N = 0$, 0 <= $A_i, B_i$ <= 100,000)

## 출력 형식
$DP[N]$의 최솟값을 정수 하나로 출력합니다. ($DP[1] = 0$)

## 입출력 예제

### 예제 1
**입력:**
```text
5
0 2 4 6 8
5 4 3 2 0
```

**출력:**
```text
40
```

### 예제 2
**입력:**
```text
1
0
0
```

**출력:**
```text
0
```

- 시간 제한: 5.0초, 메모리 제한: 512MB.
