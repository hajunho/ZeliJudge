# 최적의 길이를 결정하라! 매개변수 탐색과 랜선 자르기 (Parametric Search)

## 문제 설명
길이가 제각각인 K개의 랜선이 있습니다. 이 랜선들을 모두 동일한 길이 X로 잘라 적어도 N개 이상의 랜선을 만들려고 합니다.
자를 때 손실되는 길이는 없으며, 잘라낸 뒤 남은 자투리 랜선은 버립니다. 기존의 K개 랜선을 이어붙일 수는 없습니다.
적어도 N개 이상의 랜선을 만들 수 있는 **랜선의 최대 길이 X**를 구하는 프로그램을 작성하세요.

## 입력 형식
첫째 줄에 이미 가지고 있는 랜선의 개수 K와 필요한 랜선의 개수 N이 공백으로 주어집니다. (1 <= K <= 10,000, 1 <= N <= 1,000,000, K <= N)
둘째 줄부터 K개의 줄에 걸쳐 각 랜선의 길이가 자연수로 주어집니다. 랜선의 길이는 2^31 - 1 이하의 자연수입니다.

## 출력 형식
N개 이상의 랜선을 만들 수 있는 랜선의 최대 길이를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4 11
802
743
457
539
```

**출력:**
```text
200
```

### 예제 2
**입력:**
```text
1 1
100
```

**출력:**
```text
100
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
