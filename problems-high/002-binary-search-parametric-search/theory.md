# 매개변수 탐색(Parametric Search)

## 1. 개요 및 최적화 문제의 결정 문제화
매개변수 탐색은 **'조건을 만족하는 최댓값/최솟값을 구하라'는 최적화 문제**를 **'특정 값 X일 때 조건을 만족하는가? (Yes/No)'라는 결정 문제**로 바꾸어 이진 탐색으로 푸는 기법입니다.

## 2. 단조성(Monotonicity)
자르고자 하는 길이 X가 커질수록 만들 수 있는 랜선의 개수 C(X)는 단조 감소합니다:
- X가 작을수록 C(X) >= N (만족, True)
- X가 커질수록 C(X) < N (불만족, False)
따라서 참/거짓의 경계점을 이진 탐색(Binary Search)으로 O(K log(max_len)) 시간에 정확히 찾아낼 수 있습니다.
