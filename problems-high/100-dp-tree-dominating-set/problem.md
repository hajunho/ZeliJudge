# 모든 노드를 감시하는 최소의 파수꾼! 트리 지배 집합 DP

## 문제 설명
$1$번부터 $N$번까지의 정점으로 이루어진 트리가 주어집니다.
트리의 정점들 중 일부를 파수꾼(지배 집합)으로 배치하려고 합니다.
어떤 정점에 파수꾼을 배치하면, 그 정점 자신과 그 정점과 직접 간선으로 연결된 모든 이웃 정점들이 감시(지배)됩니다.

트리의 모든 정점을 감시하기 위해 배치해야 하는 **파수꾼의 최소 인원수**를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정점의 개수 $N$ ($1 \le N \le 100,000$)이 주어집니다.
- 다음 $N-1$개 줄에 걸쳐 각 줄마다 트리의 간선을 연결하는 두 정점 $u, v$ ($1 \le u, v \le N$)가 주어집니다.

## 출력 형식
- 모든 정점을 감시하기 위한 최소 파수꾼의 수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
6
1 2
1 3
2 4
2 5
3 6
```
### 출력
```text
2
```
**설명**: 정점 2와 3에 파수꾼을 배치하면:
- 2번 파수꾼: 1, 2, 4, 5 감시
- 3번 파수꾼: 1, 3, 6 감시
모든 정점 $\{1, 2, 3, 4, 5, 6\}$이 감시되며, 최소 2명입니다.

## 예제 2
### 입력
```text
3
1 2
2 3
```
### 출력
```text
1
```
**설명**: 2번 정점에 1명만 배치하면 1, 2, 3 모두 감시됩니다.
