# 이론 및 해설: 모든 노드를 감시하는 최소의 파수꾼! 트리 지배 집합 DP

### 트리 최소 지배 집합 (Tree Minimum Dominating Set)

그래프 $G$에서 정점 부분집합 $S$가 존재하여, $S$에 속하지 않는 모든 정점이 $S$의 최소 한 정점과 인접해 있을 때 $S$를 **지배 집합(Dominating Set)**이라고 합니다.
일반 그래프에서 최소 지배 집합은 NP-Hard이지만, 트리에서는 3가지 상태를 정의하여 상향식 DP로 $O(N)$에 해결할 수 있습니다.

1. **상태 정의**:
   - $DP[u][0]$: 노드 $u$가 **지배 집합에 선택된** 경우의 서브트리 최소 크기 ($+1$).
   - $DP[u][1]$: 노드 $u$는 **선택되지 않았지만, 최소 한 자식에 의해 지배된** 경우의 서브트리 최소 크기.
   - $DP[u][2]$: 노드 $u$는 **선택되지 않았고 아직 지배되지 않았지만(부모 노드가 지배해 주어야 함)**, $u$의 모든 자식들은 지배된 경우의 서브트리 최소 크기.
2. **전이식**:
   - $DP[u][0] = 1 + \sum_{v} \min(DP[v][0], DP[v][1], DP[v][2])$
   - $DP[u][2] = \sum_{v} DP[v][1]$
   - $DP[u][1] = DP[u][2] + \max\left(0, \min_v (DP[v][0] - DP[v][1])\right)$ (적어도 하나의 자식은 $0$ 상태여야 함).
