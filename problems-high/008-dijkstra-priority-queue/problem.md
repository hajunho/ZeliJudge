# 네트워크 최단 경로! 힙(Heap) 기반 다익스트라 (Dijkstra Shortest Path)

## 문제 설명
방향 그래프가 주어졌을 때, 주어진 시작 정점 K에서 다른 모든 정점으로 가는 최단 경로의 길이를 구하는 프로그램을 작성하세요.
모든 간선의 가중치는 10 이하의 음이 아닌 정수입니다.
우선순위 큐(Min-Heap, `heapq`)를 사용한 다익스트라 알고리즘을 구현하여 O((V + E) log V) 시간에 처리하세요.

## 입력 형식
첫째 줄에 정점의 개수 V와 간선의 개수 E가 주어집니다. (1 <= V <= 20,000, 1 <= E <= 300,000)
둘째 줄에 시작 정점의 번호 K가 주어집니다. (1 <= K <= V)
셋째 줄부터 E개의 줄에 걸쳐 각 간선을 나타내는 세 정수 u, v, w가 주어집니다. (u에서 v로 가는 가중치 w 간선, 1 <= w <= 10)

## 출력 형식
첫째 줄부터 V개의 줄에 걸쳐, i번째 줄에 i번 정점으로 가는 최단 경로의 값을 출력합니다.
시작점 자신은 0을 출력하고, 경로가 존재하지 않는 경우에는 INF를 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 6
1
5 1 1
1 2 2
1 3 3
2 3 4
2 4 5
3 4 6
```

**출력:**
```text
0
2
3
7
INF
```

### 예제 2
**입력:**
```text
3 2
1
1 2 5
2 3 3
```

**출력:**
```text
0
5
8
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
