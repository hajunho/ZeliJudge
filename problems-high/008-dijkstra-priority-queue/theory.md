# 다익스트라(Dijkstra) 최단 경로 알고리즘

## 1. 작동 원리
1. 시작 정점의 최단 거리를 0으로, 다른 모든 정점의 최단 거리를 무한대(INF)로 초기화합니다.
2. 최소 힙에 `(0, start)`를 삽입합니다.
3. 힙에서 가장 거리가 짧은 노드 `(dist, u)`를 꺼냅니다.
4. 이미 기록된 최단 거리 `distance[u]`보다 `dist`가 크다면 이미 방문한 것이므로 무시합니다.
5. u와 연결된 인접 노드 v에 대해 `dist + w < distance[v]`라면 거리를 갱신하고 힙에 삽입합니다.

## 2. 시간 복잡도
각 간선마다 최대 1번 힙에 원소가 삽입되므로 힙 연산 비용 $O(\log V)$를 곱해 $O((V + E) \log V)$가 보장됩니다.
