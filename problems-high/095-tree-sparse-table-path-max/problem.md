# 트리 경로의 최댓값을 로그 시간에! 희소 배열 LCA (Tree Path Max)

## 문제 설명
$N$개의 정점과 $N-1$개의 양방향 가중치 간선으로 이루어진 트리가 주어집니다.
다음과 같은 $Q$개의 질의를 처리하는 프로그램을 작성하세요:

- `u v`: 정점 $u$에서 정점 $v$까지의 단순 경로에 존재하는 모든 간선들의 가중치 중 최댓값을 출력합니다. (단, $u = v$인 경우 간선이 없으므로 $0$을 출력합니다.)

## 입력 형식
- 첫째 줄에 정점의 개수 $N$ ($1 \le N \le 100,000$)과 질의의 개수 $Q$ ($1 \le Q \le 100,000$)가 공백으로 구분되어 주어집니다.
- 다음 $N-1$개 줄에 걸쳐 각 줄마다 간선이 잇는 두 정점 $u, v$ ($1 \le u, v \le N$)와 가중치 $w$ ($1 \le w \le 10^9$)가 주어집니다.
- 다음 $Q$개 줄에 걸쳐 각 줄마다 질의할 두 정점 $u, v$ ($1 \le u, v \le N$)가 주어집니다.

## 출력 형식
- 각 질의마다 경로 상의 최대 간선 가중치를 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
5 3
1 2 10
1 3 30
2 4 20
2 5 40
4 5
3 4
1 1
```
### 출력
```text
40
30
0
```
**설명**: 
- $4 \to 5$ 경로는 $4 \to 2(20) \to 5(40)$이므로 최댓값은 40.
- $3 \to 4$ 경로는 $3 \to 1(30) \to 2(10) \to 4(20)$이므로 최댓값은 30.
- $1 \to 1$은 정점이 같으므로 0.

## 예제 2
### 입력
```text
3 2
1 2 5
2 3 7
1 3
2 3
```
### 출력
```text
7
7
```
