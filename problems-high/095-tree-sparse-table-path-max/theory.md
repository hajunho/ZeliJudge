# 이론 및 해설: 트리 경로의 최댓값을 로그 시간에! 희소 배열 LCA (Tree Path Max)

### 희소 배열과 트리 경로 최댓값 (Tree Path Maximum)

트리에서 임의의 두 정점 $u$와 $v$를 잇는 단순 경로에 존재하는 간선들의 가중치 최댓값을 빠르게 질의하는 문제입니다.

1. **이진 리프팅 (Binary Lifting)**:
   - $parent[k][u]$: 정점 $u$의 $2^k$번째 조상 정점 번호.
   - $max\_w[k][u]$: 정점 $u$에서 $2^k$번째 조상까지 올라가는 경로 상의 간선 가중치 최댓값.
   - 점화식:
     $$parent[k][u] = parent[k-1][parent[k-1][u]]$$
     $$max\_w[k][u] = \max(max\_w[k-1][u], max\_w[k-1][parent[k-1][u]])$$
2. **경로 쿼리 ($O(\log N)$)**:
   - 두 정점의 깊이(Depth)를 맞추며 $max\_w$를 갱신합니다.
   - 동시에 조상으로 점프하며 최소 공통 조상(LCA)에 도달할 때까지 가중치 최댓값을 누적합니다.
