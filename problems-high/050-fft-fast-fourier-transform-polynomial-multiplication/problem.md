# 다항식 곱셈을 번개처럼! 고속 푸리에 변환 (Fast Fourier Transform FFT)

## 문제 설명
최고차항의 차수가 N인 다항식 A(x)와 M인 다항식 B(x)가 주어집니다.
두 다항식을 곱한 결과 다항식 C(x) = A(x) * B(x)의 모든 계수를 구하는 프로그램을 작성하세요.

일반적인 다항식 곱셈은 계수끼리 일일이 곱하느라 O(NM)이 걸립니다.
복소수 단위원의 원시근(Primitive Root of Unity)을 이용하여 시간 도메인의 계수를 주파수 도메인(점 값 표현)으로 바꾼 뒤 점별 곱을 수행하고 역변환하는 **고속 푸리에 변환(FFT)**을 구현하여 O((N + M) log(N + M)) 시간에 해결하세요.

## 입력 형식
첫째 줄에 다항식 A의 차수 N과 다항식 B의 차수 M이 공백으로 주어집니다. (0 <= N, M <= 50,000)
둘째 줄에 A(x)의 0차항 계수부터 N차항 계수까지 N+1개의 정수가 공백으로 주어집니다.
셋째 줄에 B(x)의 0차항 계수부터 M차항 계수까지 M+1개의 정수가 공백으로 주어집니다. (계수는 -1,000 이상 1,000 이하의 정수)

## 출력 형식
C(x)의 0차항 계수부터 N+M차항 계수까지 N+M+1개의 정수를 공백으로 구분하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
1 1
1 2
3 4
```

**출력:**
```text
3 10 8
```

### 예제 2
**입력:**
```text
0 0
5
7
```

**출력:**
```text
35
```
