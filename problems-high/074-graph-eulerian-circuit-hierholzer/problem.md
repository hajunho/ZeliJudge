# 모든 길을 단 한 번씩만 지나라! 오일러 회로 (Hierholzer's Algorithm)

## 문제 설명
$N$개의 정점과 $M$개의 단방향 간선으로 이루어진 방향 그래프가 주어집니다.
모든 간선을 정확히 한 번씩만 지나서 출발점으로 되돌아오는 오일러 회로가 존재하는지 판정하고, 존재한다면 경로를 출력하는 프로그램을 작성하세요.

존재하지 않는다면 `-1`을 출력합니다.

## 입력 형식
- 첫째 줄에 정점의 개수 $N$ ($1 \le N \le 100,000$)과 간선의 개수 $M$ ($1 \le M \le 200,000$)이 주어집니다.
- 다음 $M$개 줄에 $u, v$ ($1 \le u, v \le N$)가 주어집니다 ($u \to v$).

## 출력 형식
- 오일러 회로가 존재하면 방문하는 $M+1$개의 정점 번호를 공백으로 구분하여 한 줄에 출력합니다.
- 존재하지 않으면 `-1`을 출력합니다.

## 예제 1
### 입력
```text
3 3
1 2
2 3
3 1
```
### 출력
```text
1 2 3 1
```

## 예제 2
### 입력
```text
3 2
1 2
2 3
```
### 출력
```text
-1
```
