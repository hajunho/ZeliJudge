# 2차원 평면의 직사각형 영역 합을 빠르게! 2D 세그먼트 트리

## 문제 설명
$R$개의 행과 $C$개의 열로 이루어진 2차원 격자판이 주어집니다.
다음 두 가지 쿼리를 처리하는 프로그램을 작성하세요:

- `1 r c x`: $(r, c)$ 위치의 값을 $x$로 변경합니다. (1-indexed)
- `2 r1 c1 r2 c2`: 좌상단 $(r_1, c_1)$부터 우하단 $(r_2, c_2)$까지의 직사각형 영역에 포함된 모든 칸의 값의 합을 출력합니다.

## 입력 형식
- 첫째 줄에 $R, C$ ($1 \le R, C \le 500$)와 쿼리의 수 $Q$ ($1 \le Q \le 50,000$)가 공백으로 구분되어 주어집니다.
- 다음 $R$개 줄에 걸쳐 각 줄마다 $C$개의 정수 $A_{r, c}$ ($0 \le A_{r, c} \le 10^4$)가 주어집니다.
- 다음 $Q$개 줄에 걸쳐 각 줄마다 쿼리가 주어집니다 (`1 r c x` 또는 `2 r1 c1 r2 c2`).

## 출력 형식
- 2번 쿼리가 주어질 때마다 영역 합을 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
3 3 4
1 2 3
4 5 6
7 8 9
2 1 1 3 3
2 2 2 3 3
1 2 2 10
2 2 2 3 3
```
### 출력
```text
45
28
33
```

## 예제 2
### 입력
```text
2 2 2
10 20
30 40
2 1 2 2 2
1 1 1 50
```
### 출력
```text
60
```
