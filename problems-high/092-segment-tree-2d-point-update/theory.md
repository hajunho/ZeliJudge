# 이론 및 해설: 2차원 평면의 직사각형 영역 합을 빠르게! 2D 세그먼트 트리

### 2차원 세그먼트 트리 (2D Segment Tree)

2차원 배열 $A[R][C]$에서 한 칸의 값을 갱신하고 직사각형 구간 $[r_1..r_2, c_1..c_2]$의 합을 빠르게 구하기 위해 세그먼트 트리의 각 노드에 내부 세그먼트 트리를 중첩하여 관리합니다.

1. **구조**:
   - 외부 세그먼트 트리는 행(Row) 구간 $[r_{start}, r_{end}]$를 관리합니다.
   - 외부 트리의 각 노드는 해당 행 구간에 대한 열(Column) 세그먼트 트리를 자식으로 가집니다.
2. **시간 복잡도**:
   - 점 갱신: 외부 트리 높이 $O(\log R)$ $\times$ 내부 트리 높이 $O(\log C) = O(\log R \log C)$.
   - 구간 질의: 외부 트리 $O(\log R)$개 노드 방문 $\times$ 각 내부 트리 $O(\log C) = O(\log R \log C)$.
