# 문자열의 모든 접미사를 사전순으로! 접미사 배열과 LCP 배열 (Suffix Array and LCP Array)

## 문제 설명
문자열 S가 주어졌을 때, S의 모든 접미사(Suffix)들을 사전순으로 정렬한 **접미사 배열(Suffix Array)**과, 정렬된 인접 접미사들 사이의 **최장 공통 접두사(LCP, Longest Common Prefix) 배열**을 구하는 프로그램을 작성하세요.

접미사들을 매번 비교하면 O(N^2 log N)이 걸리지만, 이전 길이의 랭크를 재활용하는 맨버-마이어스(Manber-Myers) 알고리즘으로 O(N log^2 N)에 SA를 구하고, 카사이(Kasai) 알고리즘으로 LCP 배열을 O(N)에 선형 시간으로 도출하세요.

## 입력 형식
첫째 줄에 알파벳 소문자로만 이루어진 문자열 S가 주어집니다. (1 <= len(S) <= 100,000)

## 출력 형식
첫째 줄에 접미사 배열의 각 원소(1-based 시작 인덱스)를 공백으로 구분하여 출력합니다.
둘째 줄에 LCP 배열을 공백으로 구분하여 출력합니다. (LCP의 첫 번째 원소는 항상 x로 출력)

## 입출력 예제

### 예제 1
**입력:**
```text
banana
```

**출력:**
```text
6 4 2 1 5 3
x 1 3 0 0 2
```

### 예제 2
**입력:**
```text
abracadabra
```

**출력:**
```text
11 8 1 4 6 9 2 5 7 10 3
x 1 4 1 1 0 3 0 0 0 2
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
