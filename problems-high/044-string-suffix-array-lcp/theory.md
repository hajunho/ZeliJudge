# 접미사 배열과 LCP 배열

## 1. 맨버-마이어스 (Manber-Myers) SA
- 길이 $2^k$인 접두사의 정렬 결과를 바탕으로, 앞 절반 랭크와 뒤 절반 랭크를 쌍`(rank[i], rank[i + 2^k])`으로 묶어 다음 길이 $2^{k+1}$을 정렬합니다.
- 총 $\lceil \log N \rceil$번의 정렬로 $O(N \log^2 N)$에 완성됩니다.

## 2. 카사이 (Kasai) LCP 알고리즘
- 원래 문자열 순서대로 접미사를 살펴보면, 이전 접미사의 LCP가 $h$였다면 다음 접미사의 LCP는 최소 $h-1$ 이상이라는 성질이 성립합니다.
- 따라서 $h$는 최대 $N$번 증가하고 $N$번 감소하므로 전체 $O(N)$에 LCP 배열을 계산할 수 있습니다.
