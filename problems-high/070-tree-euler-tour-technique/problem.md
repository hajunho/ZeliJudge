# 트리를 일직선으로 펴서 구간 쿼리로! 오일러 경로 테크닉 (Euler Tour Technique)

## 문제 설명
$1$번 정점을 루트로 하는 $N$개의 정점으로 이루어진 트리가 있습니다.
각 정점 $i$ ($1 \le i \le N$)는 초기 가중치 $W_i$를 가지고 있습니다.

다음 두 가지 쿼리를 처리하는 프로그램을 작성하세요:
- `1 u x`: 정점 $u$를 루트로 하는 서브트리에 속한 모든 정점의 가중치에 $x$를 더합니다.
- `2 u`: 정점 $u$를 루트로 하는 서브트리에 속한 모든 정점의 가중치 합을 구합니다.

합이 매우 클 수 있으므로 $10^9+7$로 나눈 나머지를 출력합니다.

## 입력 형식
- 첫째 줄에 정점의 수 $N$ ($1 \le N \le 100,000$)과 쿼리의 수 $Q$ ($1 \le Q \le 100,000$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 정수 $W_1, W_2, \dots, W_N$ ($0 \le W_i \le 10^9$)이 공백으로 구분되어 주어집니다.
- 다음 $N-1$개 줄에 걸쳐 각 줄마다 트리의 간선을 연결하는 두 정수 $u, v$ ($1 \le u, v \le N$)가 공백으로 구분되어 주어집니다.
- 다음 $Q$개 줄에 걸쳐 각 줄마다 쿼리가 주어집니다. (`1 u x` 또는 `2 u`) ($0 \le x \le 10^9$)

## 출력 형식
- 2번 쿼리가 주어질 때마다 서브트리 가중치 합을 $10^9+7$로 나눈 나머지를 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
5 5
1 2 3 4 5
1 2
1 3
2 4
2 5
2 1
1 2 10
2 1
2 2
2 3
```
### 출력
```text
15
45
41
3
```
**설명**: 
- 초기 전체 합은 $1+2+3+4+5 = 15$.
- `1 2 10`: $2$번의 서브트리는 $\{2, 4, 5\}$이므로 이 세 노드에 각각 10이 더해짐 ($+30$).
- 전체 합은 $15 + 30 = 45$.
- $2$번 서브트리 합은 $(2+10) + (4+10) + (5+10) = 41$.
- $3$번 서브트리 합은 $3$.

## 예제 2
### 입력
```text
3 3
10 20 30
1 2
2 3
2 2
1 1 5
2 3
```
### 출력

