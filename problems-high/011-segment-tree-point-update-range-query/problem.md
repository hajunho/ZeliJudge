# 구간의 합을 번개처럼 구하라! 세그먼트 트리 기초 (Segment Tree Point Update Range Sum)

## 문제 설명
N개의 수로 이루어진 수열이 주어집니다. 중간에 수의 변경이 빈번히 일어나며, 그 중간에 어떤 부분의 합을 구해야 합니다.
단순 배열로 처리하면 점 갱신은 O(1)이지만 구간 합은 O(N)이 걸리고, 누적합 배열은 구간 합이 O(1)이지만 갱신이 O(N)이 걸립니다.
이진 트리 구조를 활용하여 점 갱신과 구간 합 질의를 모두 O(log N)에 처리하는 세그먼트 트리(Segment Tree)를 구현하세요.

## 입력 형식
첫째 줄에 수의 개수 N, 변경이 일어나는 횟수 M, 구간의 합을 구하는 횟수 K가 주어집니다. (1 <= N <= 100,000, 1 <= M, K <= 10,000)
둘째 줄부터 N개의 줄에 걸쳐 초기 수가 주어집니다.
다음 M + K개의 줄에 쿼리가 주어집니다. `1 b c`는 b번째 수를 c로 바꾸는 연산이고, `2 b c`는 b번째부터 c번째 수까지의 합을 구하는 연산입니다. (1 <= b <= c <= N)

## 출력 형식
2번 쿼리가 주어질 때마다 구간 합을 한 줄에 하나씩 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 2 2
1
2
3
4
5
1 3 6
2 2 5
1 5 2
2 3 5
```

**출력:**
```text
17
12
```

### 예제 2
**입력:**
```text
3 1 1
10
20
30
2 1 3
1 2 50
```

**출력:**
```text
60
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
