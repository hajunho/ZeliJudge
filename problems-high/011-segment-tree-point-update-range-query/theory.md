# 세그먼트 트리 (Segment Tree)

## 1. 트리 구조와 크기
- 리프 노드들은 원래 배열의 원소들을 저장하고, 내부 노드들은 자식 노드들의 합(또는 최솟값/최댓값)을 저장합니다.
- N개의 원소에 대해 완전 이진 트리로 구성할 때 트리의 크기는 $4N$이면 충분합니다.

## 2. 시간 복잡도
- **초기 구축(Build)**: $O(N)$
- **점 갱신(Point Update)**: 리프에서 루트까지 트리 높이만큼 올라가며 갱신하므로 $O(\log N)$
- **구간 질의(Range Query)**: 겹치는 구간 노드들만 방문하므로 최대 $4 \log N$개 노드 탐색으로 $O(\log N)$
