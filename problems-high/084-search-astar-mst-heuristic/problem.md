# 휴리스틱으로 탐색의 빛을 밝혀라! A* 알고리즘과 MST (A* Search with MST)

## 문제 설명
$N$개의 도시가 있으며, 각 도시 쌍 사이를 이동하는 비용 행렬 $W_{i, j}$가 주어집니다.
어느 한 도시(1번 도시)에서 출발하여 모든 도시를 정확히 한 번씩만 방문한 뒤, 다시 출발 도시로 돌아오는 외판원 순회(TSP)의 최소 비용을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 도시의 수 $N$ ($2 \le N \le 16$)이 주어집니다.
- 다음 $N$개 줄에 걸쳐, 각 줄마다 $N$개의 양의 정수 $W_{i, j}$ ($1 \le W_{i, j} \le 10^5$, 단 $W_{i, i} = 0$)가 주어집니다.

## 출력 형식
- 모든 도시를 순회하고 출발점으로 돌아오는 최소 총비용을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
4
0 10 15 20
10 0 35 25
15 35 0 30
20 25 30 0
```
### 출력
```text
80
```

## 예제 2
### 입력
```text
3
0 5 9
5 0 4
9 4 0
```
### 출력
```text
18
```
