# 10^18번째 피보나치 수도 번개처럼! 분할 정복 행렬 거듭제곱 (Matrix Exponentiation Fibonacci)

## 문제 설명
피보나치 수는 $F_0 = 0, F_1 = 1$로 시작하며, $F_n = F_{n-1} + F_{n-2}$ ($n \ge 2$)의 점화식을 만족합니다.
자연수 N이 주어졌을 때, N번째 피보나치 수 $F_N$을 $1,000,000,007$로 나눈 나머지를 구하는 프로그램을 작성하세요.
단, N은 최대 $10^{18}$까지 주어지므로 $O(N)$ 반복문으로는 해결할 수 없습니다. $2 \times 2$ 행렬의 거듭제곱과 분할 정복(Divide and Conquer)을 이용하여 $O(\log N)$ 시간에 해결하세요.

## 입력 형식
첫째 줄에 자연수 N이 주어집니다. (1 <= N <= 1,000,000,000,000,000,000)

## 출력 형식
N번째 피보나치 수를 1,000,000,007로 나눈 나머지를 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
1
```

**출력:**
```text
1
```

### 예제 2
**입력:**
```text
2
```

**출력:**
```text
1
```
