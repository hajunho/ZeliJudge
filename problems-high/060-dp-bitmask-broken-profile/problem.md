# 윤곽선을 타고 흐르는 도미노! 깨진 프로파일 DP (Broken Profile Domino Tiling)

## 문제 설명
N x M 크기의 직사각형 격자판이 있습니다.
이 격자판을 2 x 1 크기의 도미노 블록들로 빈틈없이 완전히 덮는 경우의 수를 구하는 프로그램을 작성하세요.
도미노는 가로로 놓을 수도 있고 세로로 놓을 수도 있습니다.

일반적인 행 단위 비트마스크 DP는 $O(N 2^{2M})$이 걸리지만,
격자판의 칸을 한 칸씩(Cell by cell) 이동하며 경계선(윤곽선)의 덮인 상태 M개의 비트만 유지하는 **깨진 프로파일 DP(Broken Profile DP)**를 구현하여 $O(N M 2^M)$ 시간에 해결하세요.

## 입력 형식
첫째 줄에 N과 M이 공백으로 구분되어 주어집니다. (1 <= N <= 14, 1 <= M <= 14, N * M <= 100)

## 출력 형식
격자판을 도미노로 채우는 경우의 수를 1,000,000,007로 나눈 나머지를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
2 3
```

**출력:**
```text
3
```

### 예제 2
**입력:**
```text
1 2
```

**출력:**
```text
1
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
