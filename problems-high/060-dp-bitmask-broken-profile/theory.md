# 깨진 프로파일 DP (Broken Profile Domino Tiling)

## 1. 셀 단위 상태 전이
- 행 전체를 한 번에 채우지 않고, $(r, c)$ 칸을 하나씩 방문합니다.
- 프로파일은 현재 칸 직전 $M$개의 셀의 점유 상태를 비트마스크(길이 $M$)로 나타냅니다.

## 2. 전이 규칙
1. **현재 칸 $(r, c)$가 이미 덮여 있는 경우 (비트가 1)**: 추가 도미노를 놓지 않고 다음 칸으로 넘깁니다 (비트는 0으로 바뀜).
2. **현재 칸이 비어 있는 경우 (비트가 0)**:
   - 세로 도미노: 아래 칸 $(r+1, c)$와 함께 덮기 (새 프로파일의 비트를 1로 켬)
   - 가로 도미노: 오른쪽 칸 $(r, c+1)$와 함께 덮기 ($c < M - 1$이고 오른쪽 칸이 비어 있을 때)
- 각 셀당 상태 전이가 $O(1)$이므로 전체 $O(N M 2^M)$에 초고속 계산됩니다.
