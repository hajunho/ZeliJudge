# Mo's 알고리즘 (평방 분할법)

## 1. 쿼리 정렬 기준
- 블록 크기 $B = \lfloor \sqrt{N} \rfloor$로 설정합니다.
- 쿼리 $(l, r)$에 대해 $l / B$ (소속 블록 번호) 순으로 1차 정렬하고, 같은 블록 내에서는 $r$ 순으로 2차 정렬합니다.

## 2. 투 포인터 이동 비용
- $r$ 포인터는 각 블록마다 최대 $N$번 증가하므로 전체 $B \times N = O(N \sqrt{N})$번 이동합니다.
- $l$ 포인터는 쿼리마다 같은 블록 내에서 최대 $B$번 이동하므로 전체 $Q \times B = O(Q \sqrt{N})$번 이동합니다.
- 총 시간 복잡도는 $O((N + Q) \sqrt{N})$입니다.
