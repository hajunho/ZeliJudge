# 쿼리를 재배열하여 마법처럼 풀자! Mo's 알고리즘과 평방분할 (Mo's Algorithm Sqrt Decomposition)

## 문제 설명
길이 N의 수열 A가 주어지고, Q개의 구간 쿼리가 주어집니다:
- `l r`: 부분 수열 $A[l..r]$에서 **서로 다른 수의 개수**를 구합니다.

이 문제는 온라인으로 풀기 까다롭지만, 수열의 변경이 없는 정적 쿼리이므로 **오프라인 쿼리(Offline Queries)**로 해결할 수 있습니다.
구간의 왼쪽 끝점을 크기 $\sqrt{N}$인 블록 단위로 묶어 정렬하는 **Mo's 알고리즘**을 구현하여 O((N + Q) sqrt(N)) 시간에 해결하세요.

## 입력 형식
첫째 줄에 수열의 크기 N이 주어집니다. (1 <= N <= 100,000)
둘째 줄에 N개의 정수 $A_1, A_2, \dots, A_N$이 공백으로 주어집니다. (1 <= $A_i$ <= 1,000,000)
셋째 줄에 쿼리의 개수 Q가 주어집니다. (1 <= Q <= 100,000)
넷째 줄부터 Q개의 줄에 걸쳐 쿼리 l, r이 주어집니다. (1 <= l <= r <= N)

## 출력 형식
Q개의 줄에 걸쳐 각 쿼리의 답을 입력된 순서대로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5
1 1 2 1 3
3
1 5
2 4
3 5
```

**출력:**
```text
3
2
3
```

### 예제 2
**입력:**
```text
3
1 2 3
2
1 3
2 2
```

**출력:**
```text
3
1
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
