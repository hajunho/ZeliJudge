# 비트 연산으로 완성하는 기적의 트리! 펜윅 트리 (Fenwick Tree / BIT)

## 문제 설명
N개의 수로 이루어진 수열에서 특정 인덱스에 값을 더하는 점 덧셈 연산과, 구간 [L, R]의 합을 구하는 질의를 번갈아 수행해야 합니다.
세그먼트 트리에 비해 코드 길이가 절반 이하로 매우 짧고 메모리 오버헤드가 적은 **펜윅 트리(Fenwick Tree, Binary Indexed Tree)**를 구현하세요.
최하위 비트(LSB, `i & -i`)를 활용하여 누적합을 고속으로 관리하세요.

## 입력 형식
첫째 줄에 수열의 크기 N과 쿼리의 수 Q가 공백으로 주어집니다. (1 <= N, Q <= 100,000)
둘째 줄에 N개의 초기 정수가 공백으로 주어집니다.
셋째 줄부터 Q개의 줄에 걸쳐 쿼리가 주어집니다.
- `1 i x`: i번째 수에 정수 x를 더합니다. (1 <= i <= N)
- `2 l r`: l번째 수부터 r번째 수까지의 합을 출력합니다. (1 <= l <= r <= N)

## 출력 형식
2번 쿼리가 주어질 때마다 계산된 구간 합을 한 줄에 하나씩 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 4
1 2 3 4 5
2 1 5
1 3 5
2 2 4
2 1 5
```

**출력:**
```text
15
14
20
```

### 예제 2
**입력:**
```text
3 2
10 20 30
2 1 3
2 2 2
```

**출력:**
```text
60
20
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
