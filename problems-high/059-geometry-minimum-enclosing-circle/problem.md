# 모든 점을 품는 가장 작은 원! 웰즐(Welzl)의 최소 포괄원 (Minimum Enclosing Circle)

## 문제 설명
2차원 평면 위에 N개의 점이 주어졌을 때, 모든 점을 내부에 포함하거나 둘레 위에 놓이도록 하는 **가장 작은 원(최소 포괄원, Minimum Enclosing Circle, MEC)**의 중심 좌표 (x, y)와 반지름 r을 구하는 프로그램을 작성하세요.

점을 무작위로 섞은 뒤 점진적으로 원을 갱신하는 **웰즐(Welzl)** 알고리즘을 구현하여 기대 선형 시간 $O(N)$에 해결하세요.

## 입력 형식
첫째 줄에 점의 개수 N이 주어집니다. (1 <= N <= 100,000)
둘째 줄부터 N개의 줄에 걸쳐 각 점의 좌표 x, y가 공백으로 주어집니다. (-10,000 <= x, y <= 10,000)

## 출력 형식
첫째 줄에 원의 중심 x, y와 반지름 r을 공백으로 구분하여 소수점 둘째 자리까지 반올림하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
2
0 0
0 10
```

**출력:**
```text
0.00 5.00 5.00
```

### 예제 2
**입력:**
```text
1
5 5
```

**출력:**
```text
5.00 5.00 0.00
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
