# 이론 및 해설: 사각부등식으로 문단을 아름답게! 1D/1D DP 최적화 (1D/1D Optimization)

### 1D/1D 동적 계획법 최적화 (1D/1D Optimization)

다음 형태의 1차원 점화식
$$DP[i] = \min_{0 \le j < i} (DP[j] + W(j, i))$$
에서 비용 함수 $W(j, i)$가 사각부등식(Quadrangle Inequality / Monge Property)
$$W(a, d) + W(b, c) \ge W(a, c) + W(b, d) \quad (a \le b \le c \le d)$$
을 만족하면, 각 $i$에 대한 최적 전이점 $opt[i]$는 $i$에 대해 단조 증가합니다 ($opt[i] \le opt[i+1]$).

1. **덱과 이진 탐색을 이용한 최적화 ($O(N \log N)$)**:
   - 각 전이점 $j$가 어느 구간 $[l, r]$에서 최적인지를 관리합니다.
   - 덱(Deque)에 `(j, l, r)` 튜플들을 저장합니다.
   - 새로운 후보 $i$를 전이점으로 추가할 때:
     - 덱의 맨 뒤 원소 `(last_j, l, r)`에 대해, $l$에서도 $i$가 더 우세하다면 해당 원소를 덱에서 제거(pop)합니다.
     - 그렇지 않다면, $[l, r]$ 구간 내에서 $i$가 $last_j$보다 처음으로 더 유리해지는 지점을 이진 탐색으로 찾아 분할하고 삽입합니다.
   - 각 상태는 덱에 1번 들어가고 1번 나오며, 이진 탐색에 $O(\log N)$이 걸려 총 $O(N \log N)$에 해결됩니다.
