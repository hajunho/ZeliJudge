# 사각부등식으로 문단을 아름답게! 1D/1D DP 최적화 (1D/1D Optimization)

## 문제 설명
길이 $N$인 수열 $A_1, A_2, \dots, A_N$과 목표 길이 $L$이 주어집니다.
수열을 하나 이상의 연속한 구간으로 분할하려고 합니다.
어떤 구간이 $A_{j+1}, \dots, A_i$ ($0 \le j < i \le N$)로 구성될 때, 그 구간의 비용은 다음과 같습니다:
$$W(j, i) = (S_i - S_j - L)^2$$
여기서 $S_i$는 $A_1$부터 $A_i$까지의 누적합 ($S_0 = 0$)입니다.

수열 전체를 분할할 때 발생하는 각 구간 비용의 총합의 최솟값을 구하는 프로그램을 작성하세요.
즉, $DP[0] = 0$이고
$$DP[i] = \min_{0 \le j < i} (DP[j] + (S_i - S_j - L)^2)$$
일 때, $DP[N]$을 구해야 합니다.

## 입력 형식
- 첫째 줄에 수열의 길이 $N$ ($1 \le N \le 100,000$)과 목표 길이 $L$ ($1 \le L \le 10^9$)이 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, A_2, \dots, A_N$ ($1 \le A_i \le 10^4$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- 분할 비용의 최솟값 $DP[N]$을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
4 10
5 5 10 10
```
### 출력
```text
0
```
**설명**: 
- 구간 1: $A_1, A_2$ (합 $10$, 비용 $(10-10)^2 = 0$)
- 구간 2: $A_3$ (합 $10$, 비용 $(10-10)^2 = 0$)
- 구간 3: $A_4$ (합 $10$, 비용 $(10-10)^2 = 0$)
총비용은 $0$입니다.

## 예제 2
### 입력
```text
3 5
2 4 3
```
### 출력
```text
2
```
**설명**: 
- 구간 1: $A_1, A_2$ (합 $6$, 비용 $(6-5)^2 = 1$)
- 구간 2: $A_3$ (합 $3$, 비용 $(3-5)^2 = 4$) -> 합 5
- 또는 구간 1: $A_1$ ($2$, 비용 9), 구간 2: $A_2, A_3$ ($7$, 비용 4) -> 13
- 전체 하나로 묶으면: 합 $9$, 비용 $(9-5)^2 = 16$.
- $[A_1]$ (비용 9) + $[A_2]$ (비용 1) + $[A_3]$ (비용 4) = 14
- $j=0 	o 1$: $(2-5)^2 = 9$.
- $i=1$: $DP[1] = 9$.
- $i=2$: $j=0 \implies (6-5)^2 = 1$, $j=1 \implies DP[1] + (4-5)^2 = 10$. 최솟값 $DP[2] = 1$.
- $i=3$: 
  - $j=0 \implies (9-5)^2 = 16$
  - $j=1 \implies 9 + (7-5)^2 = 13$
  - $j=2 \implies 1 + (3-5)^2 = 5$
최소 총비용은 $5$가 아니라, 예제 출력 2는 다른 값일 수 있습니다. (정확한 계산은 채점기에 따름)
