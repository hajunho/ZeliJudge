# 뫼비우스 합을 아원형 속도로 정복하라! 메르텐스 함수 (Mertens Function Du Sieve)

## 문제 설명
뫼비우스 함수 $\mu(n)$은 다음과 같이 정의됩니다:
- $\mu(1) = 1$
- $n$이 서로 다른 $k$개의 소수의 곱으로 소인수분해되면 $\mu(n) = (-1)^k$
- $n$이 어떤 소수의 제곱 이상을 약수로 가지면(Square-full) $\mu(n) = 0$

양의 정수 $N$이 주어졌을 때, 뫼비우스 함수의 누적합인 **메르텐스 함수(Mertens Function)**
$$M(N) = \sum_{i=1}^N \mu(i)$$
의 값을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 양의 정수 $N$ ($1 \le N \le 10^9$)이 주어집니다.

## 출력 형식
- $M(N)$의 값을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
10
```
### 출력
```text
-1
```
**설명**: 
$\mu(1)=1, \mu(2)=-1, \mu(3)=-1, \mu(4)=0, \mu(5)=-1,$
$\mu(6)=1, \mu(7)=-1, \mu(8)=0, \mu(9)=0, \mu(10)=1$
총합 = $1 - 1 - 1 + 0 - 1 + 1 - 1 + 0 + 0 + 1 = -1$입니다.

## 예제 2
### 입력
```text
100
```
### 출력
