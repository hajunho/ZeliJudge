# 지속성 세그먼트 트리 (Persistent Segment Tree)

## 1. 노드 재사용 (Node Sharing)
- 기존의 완전한 트리를 복사하지 않고, 값이 변경되는 경로(루트에서 리프까지)의 $O(\log N)$개 노드만 새로 생성합니다.
- 변경되지 않는 서브트리는 이전 버전의 노드를 그대로 참조하므로 공간 복잡도는 $O((N + Q) \log N)$입니다.

## 2. 구간 k번째 수 질의
- 수열의 좌표 압축된 값들을 카운트하는 PST를 $1$부터 $N$까지 차례로 삽입해 `root[0..N]`을 생성합니다.
- $A[l..r]$ 구간의 빈도 트리는 `root[r]`과 `root[l-1]`의 좌측 자식 카운트 차이 `count = lc(root[r]) - lc(root[l-1])`로 확인합니다.
- $k \le count$면 왼쪽 자식으로, 아니면 $k - count$로 오른쪽 자식으로 $O(\log N)$에 내려갑니다.
