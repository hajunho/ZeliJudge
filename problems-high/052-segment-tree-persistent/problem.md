# 과거의 모든 트리를 기억하라! 지속성 세그먼트 트리 (Persistent Segment Tree)

## 문제 설명
길이 N의 수열 A[1..N]이 주어집니다. 다음과 같은 질의 Q개가 주어집니다:
- `l r k`: 부분 수열 $A[l..r]$을 오름차순 정렬했을 때, **k번째로 작은 수**를 구합니다.

매 쿼리마다 정렬하면 O(Q N log N)이 걸려 시간 초과가 발생합니다.
원소를 하나씩 삽입할 때마다 변경된 $O(\log N)$개의 노드만 새로 복제하여 버전별 트리를 유지하는 **지속성 세그먼트 트리(Persistent Segment Tree, PST)**를 구축하고, `root[r] - root[l-1]`의 차이로 구간 세그먼트 트리를 $O(\log N)$에 탐색하세요.

## 입력 형식
첫째 줄에 수열의 크기 N과 쿼리의 개수 Q가 공백으로 주어집니다. (1 <= N, Q <= 100,000)
둘째 줄에 N개의 정수 $A_1, A_2, \dots, A_N$이 공백으로 주어집니다. (-1,000,000,000 <= $A_i$ <= 1,000,000,000)
셋째 줄부터 Q개의 줄에 걸쳐 쿼리 l, r, k가 주어집니다. (1 <= l <= r <= N, 1 <= k <= r - l + 1)

## 출력 형식
Q개의 줄에 걸쳐 각 쿼리의 정답을 한 줄에 하나씩 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
7 3
1 5 2 6 3 7 4
2 5 3
4 4 1
1 7 3
```

**출력:**
```text
5
6
3
```

### 예제 2
**입력:**
```text
3 2
10 20 30
1 3 1
1 3 3
```

**출력:**
```text
10
30
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
