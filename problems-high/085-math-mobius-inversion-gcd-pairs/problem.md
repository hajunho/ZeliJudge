# 서로소인 쌍의 개수를 한눈에! 뫼비우스 반전 공식 (Mobius Inversion)

## 문제 설명
두 자연수 $N$과 $M$이 주어집니다.
다음 조건을 만족하는 순서쌍 $(i, j)$의 총 개수를 구하는 프로그램을 작성하세요:
- $1 \le i \le N$
- $1 \le j \le M$
- $\gcd(i, j) = 1$ (즉, $i$와 $j$는 서로소)

## 입력 형식
- 첫째 줄에 테스트 케이스의 수 $T$ ($1 \le T \le 10,000$)가 주어집니다.
- 다음 $T$개 줄에 걸쳐 각 줄마다 두 정수 $N, M$ ($1 \le N, M \le 1,000,000$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- 각 테스트 케이스마다 서로소 쌍의 개수를 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
2
3 3
4 5
```
### 출력
```text
7
13
```

## 예제 2
### 입력
```text
1
1 1
```
### 출력
```text
1
```
