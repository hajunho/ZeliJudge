# 자릿수를 따라 결정되는 상태! 자릿수 동적 계획법 (Digit DP)

## 문제 설명
두 자연수 A와 B, 그리고 한 자리 숫자 D (0 <= D <= 9)가 주어집니다.
A 이상 B 이하의 모든 정수를 십진법으로 표기했을 때, 숫자 D가 등장하는 총 횟수를 구하는 프로그램을 작성하세요.
단, A와 B는 최대 10^15까지 주어지므로 1부터 일일이 반복문을 돌릴 수 없습니다.
높은 자릿수부터 결정하며 메모이제이션하는 자릿수 동적 계획법(Digit DP)을 구현하세요.

## 입력 형식
첫째 줄에 세 정수 A, B, D가 공백으로 구분되어 주어집니다. (1 <= A <= B <= 10^15, 0 <= D <= 9)

## 출력 형식
A 이상 B 이하의 모든 정수에서 숫자 D가 등장한 총 횟수를 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
1 10 1
```

**출력:**
```text
2
```

### 예제 2
**입력:**
```text
1 100 0
```

**출력:**
```text
11
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
