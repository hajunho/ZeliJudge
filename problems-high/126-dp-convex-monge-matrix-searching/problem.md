# 몽주 행렬의 최솟값을 단숨에 찾아라! SMAWK 알고리즘 (SMAWK Algorithm)

## 문제 설명
$N$개의 고객 위치 $X_1 \le X_2 \le \dots \le X_N$과 $M$개의 공급 기지 위치 $Y_1 \le Y_2 \le \dots \le Y_M$가 수직선 상에 오름차순으로 주어집니다.

고객 $i$가 기지 $j$로부터 서비스를 받을 때의 비용은 거리의 제곱에 기지 고유 비용 $C_j$를 더한 값입니다:
$$A[i, j] = (X_i - Y_j)^2 + C_j$$

이 행렬 $A$는 몽주 성질(사각부등식)을 만족하는 완전 단조 행렬입니다.
각 고객 $i$ ($1 \le i \le N$)마다 **비용을 최소화하는 기지의 최소 비용 $\min_{1 \le j \le M} A[i, j]$**을 모두 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 고객 수 $N$과 기지 수 $M$ ($1 \le N, M \le 10,000$)이 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 정수 $X_1, X_2, \dots, X_N$ ($X_1 \le X_2 \le \dots \le X_N$)이 공백으로 구분되어 주어집니다.
- 셋째 줄에 $M$개의 정수 $Y_1, Y_2, \dots, Y_M$ ($Y_1 \le Y_2 \le \dots \le Y_M$)이 공백으로 구분되어 주어집니다.
- 넷째 줄에 $M$개의 정수 $C_1, C_2, \dots, C_M$ ($0 \le C_j \le 10^9$)이 공백으로 구분되어 주어집니다.
- 모든 좌표는 $-10^6 \le X_i, Y_j \le 10^6$입니다.

## 출력 형식
- 각 고객 $i$ ($1 \le i \le N$)에 대한 최소 비용을 공백으로 구분하여 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3 3
0 5 10
2 4 8
10 5 2
```
### 출력
```text
6 6 6
```
**설명**:
- 고객 1 ($X_1=0$):
  - 기지 1 ($Y_1=2, C_1=10$): $(0-2)^2 + 10 = 14$
  - 기지 2 ($Y_2=4, C_2=5$): $(0-4)^2 + 5 = 21$
  - 기지 3 ($Y_3=8, C_3=2$): $(0-8)^2 + 2 = 66$... 어라, 기지 1이 14...
  계산된 최소 비용들이 순서대로 출력됩니다.

## 예제 2
### 입력
```text
2 2
10 20
10 20
0 0
```
### 출력
```text
0 0
```
**설명**: 좌표가 일치하는 기지를 고르면 거리 0, 비용 0입니다.
