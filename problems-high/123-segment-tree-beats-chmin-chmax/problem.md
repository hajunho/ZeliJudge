# 상한을 두들겨 구간을 길들여라! 세그먼트 트리 비츠 (Segment Tree Beats)

## 문제 설명
길이 $N$인 수열 $A_1, A_2, \dots, A_N$이 주어집니다.

다음 두 가지 쿼리를 실시간으로 처리하는 프로그램을 작성하세요:
1. `1 l r x`: 구간 $[l, r]$의 모든 $i$ ($l \le i \le r$)에 대해 $A_i = \min(A_i, x)$로 갱신합니다.
2. `2 l r`: 구간 $[l, r]$의 원소들의 합 $\sum_{i=l}^r A_i$을 출력합니다.

## 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 100,000$)과 쿼리의 개수 $Q$ ($1 \le Q \le 100,000$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, A_2, \dots, A_N$ ($0 \le A_i \le 10^9$)이 공백으로 구분되어 주어집니다.
- 셋째 줄부터 $Q$개 줄에 걸쳐 각 쿼리가 한 줄에 하나씩 주어집니다.

## 출력 형식
- 2번 쿼리가 주어질 때마다 구간 합을 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
5 5
1 2 3 4 5
2 1 5
1 2 4 3
2 1 5
1 1 5 2
2 1 5
```
### 출력
```text
15
14
10
```
**설명**:
- 초기 1~5 합: $1+2+3+4+5 = 15$
- `1 2 4 3`: $[1, \min(2,3), \min(3,3), \min(4,3), 5] = [1, 2, 3, 3, 5]$
- 합: $1+2+3+3+5 = 14$
- `1 1 5 2`: 모든 원소가 $\min(A_i, 2)$ 적용 $\to [1, 2, 2, 2, 2]$
- 합: $1+2+2+2+2 = 10$
