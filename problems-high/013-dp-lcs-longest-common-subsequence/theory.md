# 최장 공통 부분 수열 (LCS)

## 1. 2차원 DP 점화식
`dp[i][j]`를 문자열 A의 앞 i개 문자와 문자열 B의 앞 j개 문자에 대한 LCS 길이라 하면:
- 만약 `A[i-1] == B[j-1]`이면: `dp[i][j] = dp[i-1][j-1] + 1`
- 만약 `A[i-1] != B[j-1]`이면: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

## 2. 실제 LCS 문자열 복원(Backtracking)
`dp[lenA][lenB]`에서 시작하여 역추적합니다:
- `A[i-1] == B[j-1]`이면 해당 문자를 결과 스택에 넣고 `(i-1, j-1)`로 이동합니다.
- 다르다면 `dp[i-1][j]`와 `dp[i][j-1]` 중 더 큰 값을 가진 방향으로 이동합니다.
