# 두 유전자 문자열의 공통 패턴! 최장 공통 부분 수열 (LCS Longest Common Subsequence)

## 문제 설명
두 개의 문자열 A와 B가 주어졌을 때, 두 문자열의 최장 공통 부분 수열(LCS, Longest Common Subsequence)의 길이와 해당 LCS 문자열을 구하는 프로그램을 작성하세요.

부분 수열(Subsequence)은 원래 문자열에서 몇 개의 문자를 건너뛰어 순서를 유지한 채 만든 수열입니다. 예를 들어 `ACAYKP`와 `CAPCAK`의 LCS는 `ACAK`로 길이는 4입니다.

## 입력 형식
첫째 줄과 둘째 줄에 각각 알파벳 대문자로만 이루어진 문자열이 주어집니다. 각 문자열의 길이는 최대 1,000자입니다.

## 출력 형식
첫째 줄에 LCS의 길이를 출력합니다.
LCS의 길이가 0보다 크다면, 둘째 줄에 LCS 문자열을 출력합니다. (답이 여러 개인 경우 아무거나 하나 출력)

## 입출력 예제

### 예제 1
**입력:**
```text
ACAYKP
CAPCAK
```

**출력:**
```text
4
ACAK
```

### 예제 2
**입력:**
```text
ABC
DEF
```

**출력:**
```text
0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
