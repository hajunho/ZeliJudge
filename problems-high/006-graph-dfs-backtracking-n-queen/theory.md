# N-Queen과 백트래킹 (Backtracking)

## 1. 탐색 공간의 축소
각 행(row)에는 정확히 1개의 퀸만 놓일 수 있습니다. 따라서 행 번호를 depth로 삼는 DFS를 진행합니다.

## 2. 충돌 검사 가지치기 (Pruning)
퀸을 `(r, c)`에 배치할 때 세 가지 조건을 검사해야 합니다:
1. 같은 열(column): `col[c]`
2. 우상향 대각선 (`/`): `r + c`가 일정함 (`diag1[r + c]`)
3. 좌하향 대각선 (`\`): `r - c`가 일정함 (`diag2[r - c + N - 1]`)
불리언 배열 또는 비트마스크를 사용해 O(1)에 충돌 여부를 검사하고, 충돌 시 즉시 탐색을 중단(Prune)함으로써 $O(N!)$ 연산량을 수천 배 이상 단축합니다.
