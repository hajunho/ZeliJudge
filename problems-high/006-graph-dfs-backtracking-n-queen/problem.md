# 체스판 위의 평화! N-Queen과 백트래킹 (N-Queen Backtracking)

## 문제 설명
N x N 체스판 위에 N개의 퀸을 서로 공격할 수 없게 배치하려고 합니다.
퀸은 상하, 좌우, 그리고 대각선 방향으로 칸 수 제한 없이 공격할 수 있습니다.
N이 주어졌을 때, 퀸 N개를 서로 공격할 수 없게 놓는 가능한 모든 방법의 수를 구하는 프로그램을 작성하세요.

## 입력 형식
첫째 줄에 정수 N이 주어집니다. (1 <= N <= 14)

## 출력 형식
퀸 N개를 서로 공격할 수 없게 놓는 경우의 수를 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
1
```

**출력:**
```text
1
```

### 예제 2
**입력:**
```text
2
```

**출력:**
```text
0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
