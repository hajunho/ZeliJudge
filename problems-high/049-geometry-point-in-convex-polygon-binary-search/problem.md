# 점이 볼록 다각형 안에 있을까? 이진 탐색 다각형 내부 판정 (Point in Convex Polygon Binary Search)

## 문제 설명
2차원 평면 위에 N개의 꼭짓점을 가진 볼록 다각형(Convex Polygon)이 반시계 방향 순서대로 주어집니다.
그 후 Q개의 질의 점 P가 주어졌을 때, 각 점이 볼록 다각형의 내부에 있는지, 둘레 위에 있는지, 아니면 외부에 있는지 판정하는 프로그램을 작성하세요.

매 쿼리마다 모든 변을 순회하면 O(NQ)가 걸립니다.
0번 꼭짓점을 기준으로 다각형을 N-2개의 삼각형 부채꼴로 분할하고, 점의 각도를 이진 탐색하여 **쿼리당 O(log N)**에 해결하세요.

## 입력 형식
첫째 줄에 볼록 다각형의 꼭짓점 수 N이 주어집니다. (3 <= N <= 100,000)
둘째 줄부터 N개의 줄에 걸쳐 반시계 방향 순서대로 꼭짓점 좌표 x, y가 주어집니다.
다음 줄에 쿼리의 개수 Q가 주어집니다. (1 <= Q <= 100,000)
다음 Q개의 줄에 걸쳐 질의 점 좌표 x, y가 주어집니다. (모든 좌표는 -1,000,000,000 이상 1,000,000,000 이하의 정수)

## 출력 형식
각 쿼리마다 점이 다각형 내부 또는 둘레에 있으면 1, 외부에 있으면 0을 한 줄에 하나씩 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4
0 0
10 0
10 10
0 10
3
5 5
0 0
15 5
```

**출력:**
```text
1
1
0
```

### 예제 2
**입력:**
```text
3
0 0
4 0
0 4
2
1 1
3 3
```

**출력:**
```text
1
0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
