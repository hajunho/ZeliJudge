# 두 개의 독립된 경로로 연결된 튼튼한 블록! 이중 결합 컴포넌트 (BCC)

## 문제 설명
무방향 연결 그래프가 주어집니다. 이 그래프에서 어떤 정점을 제거해도 연결성이 유지되는 극대 부분 그래프를 **이중 결합 컴포넌트(BCC, Biconnected Component / 2-Vertex-Connected Component)**라고 합니다.

단절점(Articulation Point)을 경계로 하여 간선들을 BCC 그룹으로 분리할 수 있습니다.
DFS 탐색 도중 간선들을 스택에 쌓고, 단절점 조건을 만족하는 순간 스택에서 간선들을 pop하여 BCC를 구성하는 알고리즘을 작성하세요.
그래프에 존재하는 총 BCC의 개수와, 각 BCC가 포함하는 간선의 개수들을 오름차순으로 정렬하여 출력하세요.

## 입력 형식
첫째 줄에 정점 수 V와 간선 수 E가 공백으로 주어집니다. (2 <= V <= 10,000, 1 <= E <= 100,000)
둘째 줄부터 E개의 줄에 걸쳐 무방향 간선의 두 정점 u, v가 주어집니다. (1 <= u, v <= V, u != v)

## 출력 형식
첫째 줄에 BCC의 총개수를 출력합니다.
둘째 줄에 각 BCC에 속한 간선의 개수를 오름차순으로 공백으로 구분하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
7 7
1 4
4 5
5 1
1 6
6 7
2 7
7 3
```

**출력:**
```text
5
1 1 1 1 3
```

### 예제 2
**입력:**
```text
3 3
1 2
2 3
3 1
```

**출력:**
```text
1
3
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
