# 이론 및 해설: 금지된 패턴을 피해 문자열을 세어라! KMP DFA 동적 계획법

### KMP DFA와 문자열 DP (KMP DFA String DP)

알파벳 소문자로 이루어진 길이 $L$인 문자열 중, 특정 패턴 $P$를 부분문자열로 **포함하지 않는** 문자열의 개수를 구하는 문제입니다.

1. **KMP 오토마톤 (DFA)**:
   - 상태 $s \in [0, |P|]$는 지금까지 매칭된 패턴 $P$의 접두사 길이를 나타냅니다.
   - 상태 $|P|$에 도달하면 패턴 전체가 발견된 것이므로 **금지된 종료 상태(Sink State)**입니다.
   - 상태 $s$에서 다음 문자 $c \in \Sigma$가 들어왔을 때의 전이 $nxt(s, c)$는 KMP의 실패 함수(Failure Function $\pi$)를 통해 $O(|P| \cdot |\Sigma|)$에 전처리할 수 있습니다.
2. **동적 계획법**:
   - $DP[i][s]$: 길이 $i$까지 구성했을 때 DFA의 상태가 $s$ ($0 \le s < |P|$)인 문자열의 개수.
   - $DP[i+1][nxt(s, c)] = (DP[i+1][nxt(s, c)] + DP[i][s]) \pmod{10^9+7}$
   - 최종 답은 $\sum_{s=0}^{|P|-1} DP[L][s] \pmod{10^9+7}$입니다.
