# 금지된 패턴을 피해 문자열을 세어라! KMP DFA 동적 계획법

## 문제 설명
길이 $L$인 문자열을 만들려고 합니다. 문자열은 알파벳 소문자 'a', 'b' 두 문자만으로 구성됩니다.
이때, 주어진 금지 패턴 $P$를 부분문자열로 **포함하지 않는** 서로 다른 문자열의 총 개수를 구하는 프로그램을 작성하세요.

답이 매우 클 수 있으므로 $10^9+7$로 나눈 나머지를 출력합니다.

## 입력 형식
- 첫째 줄에 만들고자 하는 문자열의 길이 $L$ ($1 \le L \le 10,000$)이 주어집니다.
- 둘째 줄에 'a'와 'b'로만 이루어진 금지 패턴 문자열 $P$ ($1 \le |P| \le 50$)가 주어집니다.

## 출력 형식
- 금지 패턴 $P$를 포함하지 않는 길이 $L$인 문자열의 개수를 $10^9+7$로 나눈 나머지를 출력합니다.

## 예제 1
### 입력
```text
3
ab
```
### 출력
```text
4
```
**설명**: 
길이 3인 'a', 'b' 문자열은 총 8개입니다: `aaa`, `aab`, `aba`, `abb`, `baa`, `bab`, `bba`, `bbb`.
이 중 `ab`를 포함하지 않는 문자열은 `aaa`, `baa`, `bba`, `bbb` 총 4개입니다.

## 예제 2
### 입력
```text
2
aa
```
### 출력
```text
3
```
**설명**: `ab`, `ba`, `bb` 3개입니다.
