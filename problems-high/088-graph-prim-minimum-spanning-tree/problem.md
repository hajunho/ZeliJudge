# 정점을 넓혀가며 숲을 이어라! 프림 알고리즘 (Prim's Algorithm MST)

## 문제 설명
$N$개의 정점과 $M$개의 양방향 가중치 간선으로 이루어진 연결 그래프가 주어집니다.
프림 알고리즘을 사용하여 모든 정점을 연결하는 최소 신장 트리(MST)의 총 가중치 합을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정점의 개수 $N$ ($1 \le N \le 100,000$)과 간선의 개수 $M$ ($1 \le M \le 200,000$)이 공백으로 구분되어 주어집니다.
- 다음 $M$개 줄에 걸쳐 각 줄마다 간선이 연결하는 두 정점 $u, v$ ($1 \le u, v \le N$)와 가중치 $w$ ($1 \le w \le 10^9$)가 주어집니다.

## 출력 형식
- 최소 신장 트리의 총 가중치 합을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
4 5
1 2 1
1 3 3
2 3 2
2 4 4
3 4 5
```
### 출력
```text
7
```

## 예제 2
### 입력
```text
3 3
1 2 10
2 3 20
3 1 30
```
### 출력
```text
30
```
