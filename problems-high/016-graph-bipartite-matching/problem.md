# 축제 파트너 매칭! 이분 매칭과 증가 경로 DFS (Bipartite Matching)

## 문제 설명
N명의 학생(A그룹, 1~N번)과 M개의 동아리 방(B그룹, 1~M번)이 있습니다.
각 학생은 자신이 들어가고 싶어 하는 몇 개의 동아리 방 목록을 가지고 있습니다.
한 동아리 방에는 최대 1명의 학생만 들어갈 수 있고, 각 학생도 최대 1개의 동아리 방만 선택할 수 있을 때, 동아리 방에 배정될 수 있는 **학생의 최대 수(최대 매칭 수)**를 구하는 프로그램을 작성하세요.
DFS 기반의 증가 경로(Augmenting Path) 알고리즘을 사용하여 구현하세요.

## 입력 형식
첫째 줄에 학생의 수 N과 동아리 방의 수 M이 공백으로 주어집니다. (1 <= N, M <= 1,000)
둘째 줄부터 N개의 줄에 걸쳐 각 학생이 들어가고 싶어 하는 동아리 방의 정보가 주어집니다.
i번째 줄에는 학생 i가 희망하는 방의 개수 C와, C개의 방 번호(1 이상 M 이하)가 주어집니다.

## 출력 형식
배정될 수 있는 최대 학생 수를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 5
2 1 2
1 1
2 2 3
3 3 4 5
1 1
```

**출력:**
```text
4
```

### 예제 2
**입력:**
```text
2 2
1 1
1 1
```

**출력:**
```text
1
```

## 채점 기준

- 시간 제한: 5.0초, 메모리 제한: 512MB.
