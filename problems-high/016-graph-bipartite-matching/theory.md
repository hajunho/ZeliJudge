# 이분 매칭 (Bipartite Matching)

## 1. 이분 그래프와 매칭
그래프의 정점들을 두 그룹 A와 B로 나누었을 때 모든 간선이 서로 다른 그룹 사이만을 잇는 그래프를 이분 그래프라고 합니다.
매칭이란 서로 간선을 공유하지 않는 간선들의 부분집합입니다.

## 2. 베르주(Berge) 정리와 증가 경로(Augmenting Path)
- 증가 경로는 매칭되지 않은 정점에서 출발하여 교대로 미매칭 간선과 매칭 간선을 지나 매칭되지 않은 정점으로 끝나는 경로입니다.
- DFS를 통해 각 A 그룹 정점에 대해 매칭을 시도합니다.
- 만약 상대 B 노드가 이미 매칭되어 있다면, 기존에 매칭된 A' 노드에게 다른 방을 양보할 수 있는지 재귀적으로 묻습니다.
- 양보가 가능하면 새로운 매칭이 성립하여 매칭 수가 1 늘어납니다.
