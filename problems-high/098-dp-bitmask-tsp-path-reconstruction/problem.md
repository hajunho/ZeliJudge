# 비트마스크 속 숨겨진 여정을 복원하라! TSP 경로 역추적

## 문제 설명
$N$개의 도시가 있으며, 각 도시 사이를 이동하는 비용 행렬 $W_{i, j}$가 주어집니다.
1번 도시에서 출발하여 모든 도시를 정확히 한 번씩만 방문한 후 다시 1번 도시로 돌아오는 최소 비용의 외판원 순회 경로를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 도시의 수 $N$ ($2 \le N \le 16$)이 주어집니다.
- 다음 $N$개 줄에 걸쳐 각 줄마다 $N$개의 양의 정수 $W_{i, j}$ ($1 \le W_{i, j} \le 10^5$, 단 $W_{i, i} = 0$)가 주어집니다.

## 출력 형식
- 첫째 줄에 최소 순회 비용을 출력합니다.
- 둘째 줄에 방문하는 도시 번호들을 1번 도시부터 시작하여 다시 1번 도시로 돌아오는 순서대로 공백으로 구분하여 출력합니다 ($N+1$개의 정수).
- 최적 경로가 여러 개라면 그중 아무것이나 하나만 출력합니다.

## 예제 1
### 입력
```text
4
0 10 15 20
10 0 35 25
15 35 0 30
20 25 30 0
```
### 출력
```text
80
1 2 4 3 1
```

## 예제 2
### 입력
```text
3
0 5 9
5 0 4
9 4 0
```
### 출력
```text
18
1 2 3 1
```
