# 연속된 수들의 합! 투 포인터 부분합 최적화 (Two Pointer Subarray Sum)

## 문제 설명
자연수 N개로 이루어진 수열이 주어집니다. 이 수열에서 연속된 몇 개의 수를 선택하여 그 합이 정확히 M이 되는 경우의 수를 구하는 프로그램을 작성하세요.

단순한 O(N^2) 2중 반복문은 N이 최대 100,000까지 주어지므로 시간 초과를 유발합니다. 왼쪽 포인터(left)와 오른쪽 포인터(right)를 선형적으로 전진시키는 O(N) 투 포인터(Two Pointer) 기법을 사용하여 해결하세요.

## 입력 형식
첫째 줄에 자연수 N과 M이 공백으로 구분되어 주어집니다. (1 <= N <= 100,000, 1 <= M <= 300,000,000)
둘째 줄에 N개의 자연수가 공백으로 구분되어 주어집니다. 각 자연수는 30,000 이하입니다.

## 출력 형식
연속 부분 수열의 합이 M이 되는 경우의 수를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4 2
1 1 1 1
```

**출력:**
```text
3
```

### 예제 2
**입력:**
```text
10 5
1 2 3 4 2 5 3 1 1 2
```

**출력:**
```text
3
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
