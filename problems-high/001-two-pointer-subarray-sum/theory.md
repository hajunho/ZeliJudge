# 투 포인터(Two Pointer) 알고리즘

## 1. 개요 및 배경
양의 정수로 이루어진 수열에서 특정 구간 합을 구할 때, 브루트포스로 모든 구간 [i, j]를 탐색하면 O(N^2)의 시간이 걸립니다. 수열의 모든 원소가 양수라면, 구간의 끝을 늘리면 합이 항상 증가하고, 시작을 줄이면 합이 항상 감소한다는 **단조성(Monotonicity)**이 성립합니다.

## 2. 알고리즘 동작 원리
1. 두 포인터 `left`와 `right`를 인덱스 0에서 시작하고, 현재 구간합 `current_sum`을 0으로 둡니다.
2. `current_sum < M`인 동안 `right`를 1씩 증가시키며 원소를 더합니다.
3. `current_sum == M`이면 경우의 수를 1 증가시킵니다.
4. `current_sum >= M`이면 `left`를 1씩 증가시키며 원소를 뺍니다.
5. 두 포인터가 각각 최대 N번만 전진하므로 총 시간 복잡도는 O(N)입니다.
