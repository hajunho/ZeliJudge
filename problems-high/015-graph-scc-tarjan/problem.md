# 서로 도달 가능한 강결합 묶음! 타잔(Tarjan) SCC 알고리즘 (Strongly Connected Components)

## 문제 설명
방향 그래프가 주어졌을 때, 강하게 연결된 컴포넌트(SCC, Strongly Connected Component)들을 모두 찾는 프로그램을 작성하세요.
방향 그래프의 SCC는 그래프 내부의 정점 u와 v 사이에 u에서 v로 가는 경로와 v에서 u로 가는 경로가 항상 존재하는 최대 부분 그래프입니다.
DFS 1회 순회와 스택을 활용하는 타잔(Tarjan) 알고리즘을 사용하여 O(V + E) 시간에 해결하세요.

## 입력 형식
첫째 줄에 정점의 개수 V와 간선의 개수 E가 공백으로 주어집니다. (1 <= V <= 10,000, 1 <= E <= 100,000)
둘째 줄부터 E개의 줄에 걸쳐 간선 정보 A, B가 주어집니다. (A에서 B로 가는 방향 간선)

## 출력 형식
첫째 줄에 SCC의 총 개수 K를 출력합니다.
둘째 줄부터 K개의 줄에 걸쳐 각 SCC에 속한 정점 번호들을 오름차순으로 출력하고 끝에 -1을 붙입니다.
각 SCC들을 출력할 때에는 각 컴포넌트의 가장 작은 정점 번호를 기준으로 오름차순 정렬하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
7 9
1 4
4 5
5 1
1 6
6 7
2 7
7 3
3 7
7 2
```

**출력:**
```text
3
1 4 5 -1
2 3 7 -1
6 -1
```

### 예제 2
**입력:**
```text
3 3
1 2
2 3
3 1
```

**출력:**
```text
1
1 2 3 -1
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
