# 제약 조건의 다포체 꼭짓점을 탐색하라! 심플렉스 알고리즘 (Simplex Algorithm)

## 문제 설명
공장에서 두 종류의 제품 $P_1$과 $P_2$를 생산하려고 합니다.
제품 1단위를 생산할 때 얻을 수 있는 이익은 각각 $c_1, c_2$원입니다.

생산에는 $M$종류의 자원이 필요하며, 각 제품 1단위를 만들 때 필요한 $i$번째 자원의 양은 각각 $a_{i1}, a_{i2}$이고 공장에 보유 중인 $i$번째 자원의 최대 한도는 $b_i$입니다.
$$a_{i1} x_1 + a_{i2} x_2 \le b_i \quad (1 \le i \le M)$$
$$x_1 \ge 0, \quad x_2 \ge 0$$

총 이익 $Z = c_1 x_1 + c_2 x_2$를 최대화할 때, 얻을 수 있는 **최대 이익**을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 자원 제약식의 개수 $M$ ($1 \le M \le 100$)이 주어집니다.
- 둘째 줄에 두 제품의 단위당 이익 $c_1, c_2$ ($1 \le c_1, c_2 \le 1,000$)가 공백으로 구분되어 주어집니다.
- 셋째 줄부터 $M$개 줄에 걸쳐 각 자원의 소모량 $a_{i1}, a_{i2}$ ($0 \le a_{i1}, a_{i2} \le 100$, 둘 다 0은 아님)와 보유 한도 $b_i$ ($1 \le b_i \le 100,000$)가 주어집니다.

## 출력 형식
- 얻을 수 있는 최대 이익을 소수점 둘째 자리까지 반올림하여 출력합니다.

## 예제 1
### 입력
```text
2
3 5
1 2 14
3 1 18
```
### 출력
```text
37.00
```
**설명**: 
- $x_1 + 2x_2 \le 14$
- $3x_1 + x_2 \le 18$
두 직선의 교점은 $x_1 = 22/5 = 4.4$, $x_2 = 24/5 = 4.8$.
이익 $Z = 3(4.4) + 5(4.8) = 13.2 + 24 = 37.2$... 
꼭짓점들:
- $(0, 0) \to 0$
- $(6, 0) \to 18$
- $(0, 7) \to 35$
- $(4.4, 4.8) \to 3(4.4) + 5(4.8) = 37.20$
최댓값은 $37.20$입니다.

## 예제 2
### 입력
```text
1
10 20
1 1 10
```
### 출력
```text
200.00
```
**설명**: $x_1=0, x_2=10$일 때 $10(0) + 20(10) = 200.00$입니다.
