# 제한된 범위 내의 정수해는 몇 개일까? 선형 디오판토스 방정식 (Diophantine Range)

## 문제 설명
방정식 $Ax + By = C$가 주어집니다.
다음 두 구간 조건을 동시에 만족하는 정수 순서쌍 $(x, y)$의 개수를 구하는 프로그램을 작성하세요:
$$x_1 \le x \le x_2$$
$$y_1 \le y \le y_2$$

단, $A, B$는 모두 $0$이 아닌 정수입니다.

## 입력 형식
- 첫째 줄에 정수 $A, B, C$ ($-10^9 \le A, B \le 10^9$, $A, B \ne 0$, $-10^{18} \le C \le 10^{18}$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 $x_1, x_2$ ($-10^9 \le x_1 \le x_2 \le 10^9$)가 공백으로 구분되어 주어집니다.
- 셋째 줄에 $y_1, y_2$ ($-10^9 \le y_1 \le y_2 \le 10^9$)가 공백으로 구분되어 주어집니다.

## 출력 형식
- 조건을 만족하는 정수해 $(x, y)$의 총 개수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
2 3 12
0 10
0 10
```
### 출력
```text
3
```

## 예제 2
### 입력
```text
2 4 5
-10 10
-10 10
```
### 출력
```text
0
```
