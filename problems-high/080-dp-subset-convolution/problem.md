# 서로소 부분집합들의 완벽한 결합! 부분집합 합성곱 (Subset Convolution)

## 문제 설명
정수 $N$이 주어지며, 원소의 개수가 $2^N$개인 두 수열 $A$와 $B$가 주어집니다 ($0$번 인덱스부터 $2^N - 1$번 인덱스까지).
두 수열의 부분집합 합성곱(Subset Convolution) 결과 수열 $C$를 구하는 프로그램을 작성하세요.

$$C[k] = \sum_{\substack{i \text{ OR } j = k \\ i \text{ AND } j = 0}} A[i] \cdot B[j] \pmod{10^9+7}$$

## 입력 형식
- 첫째 줄에 정수 $N$ ($1 \le N \le 16$)이 주어집니다.
- 둘째 줄에 $2^N$개의 정수 $A_0, A_1, \dots, A_{2^N - 1}$ ($0 \le A_i < 10^9+7$)이 주어집니다.
- 셋째 줄에 $2^N$개의 정수 $B_0, B_1, \dots, B_{2^N - 1}$ ($0 \le B_i < 10^9+7$)이 주어집니다.

## 출력 형식
- $C_0, C_1, \dots, C_{2^N - 1}$을 공백으로 구분하여 한 줄에 출력합니다.

## 예제 1
### 입력
```text
2
1 2 3 4
5 6 7 8
```
### 출력
```text
5 16 22 60
```

## 예제 2
### 입력
```text
1
3 7
2 5
```
### 출력
```text
6 29
```
