# 문자열의 모든 접미사를 선형 상태로 압축하라! 접미사 오토마톤 (Suffix Automaton)

## 문제 설명
길이 $N$의 알파벳 소문자로만 이루어진 문자열 $S$가 주어집니다.

이 문자열의 연속된 일부분으로 만들 수 있는 **서로 다른 부분 문자열(Distinct Substrings)**의 총 개수를 구하는 프로그램을 작성하세요.
단, 빈 문자열은 세지 않습니다.

## 입력 형식
- 첫째 줄에 알파벳 소문자로 구성된 문자열 $S$ ($1 \le |S| \le 100,000$)가 주어집니다.

## 출력 형식
- 문자열 $S$에 존재하는 서로 다른 부분 문자열의 총 개수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
abab
```
### 출력
```text
7
```
**설명**: 
길이 1: `a`, `b` (2개)
길이 2: `ab`, `ba` (2개)
길이 3: `aba`, `bab` (2개)
길이 4: `abab` (1개)
총합은 $2 + 2 + 2 + 1 = 7$개입니다.

## 예제 2
### 입력
```text
aaaa
```
### 출력
```text
4
```
**설명**: `a`, `aa`, `aaa`, `aaaa` 총 4개입니다.
