# 문자열의 모든 접미사를 선형 상태로 압축하라! 접미사 오토마톤 (Suffix Automaton)

## 핵심 개념 및 알고리즘 개요
- **태그**: 문자열, 접미사 오토마톤(Suffix Automaton, SAM), 서로 다른 부분문자열, 선형 시간, $O(N)$
- **핵심 요약**: 문자열의 모든 부분문자열을 $O(N)$ 상태와 전이로 나타내는 접미사 오토마톤으로 서로 다른 부분문자열 수를 구합니다.

---

### 접미사 오토마톤 (Suffix Automaton, SAM)

접미사 오토마톤(SAM)은 주어진 문자열 $S$의 **모든 부분 문자열(Substrings)**을 나타내는 가장 작고 강력한 유한 상태 기계(DFA)입니다.

1. **상태와 endpos 동치류**:
   - 어떤 부분문자열이 $S$에서 끝나는 위치들의 집합을 `endpos`라 합니다.
   - `endpos`가 정확히 같은 부분문자열들을 하나의 **상태(State)**로 묶습니다.
   - 각 상태 $u$는 어떤 최소 길이부터 최대 길이 `len[u]`까지의 연속된 길이의 부분문자열들을 표현합니다.
   - 상태의 총 개수는 최대 $2N-1$개, 전이 간선(Transition)의 개수는 최대 $3N-4$개로 **$O(N)$ 크기**에 불과합니다.

2. **접미사 링크 (Suffix Link)**:
   - 상태 $u$에서 표현하지 못하는 바로 직전의 더 짧은 접미사는 `link[u]`가 가리키는 상태로 연결됩니다.
   - 상태 $u$가 표현하는 서로 다른 부분문자열의 개수는 정확히 다음과 같습니다:
     $$\text{len}[u] - \text{len}[\text{link}[u]]$$

3. **서로 다른 부분 문자열의 총 개수**:
   - SAM의 루트 노드($0$번)를 제외한 모든 상태 $u$에 대해 위 값을 모두 합산하면 문자열 $S$에 존재하는 **서로 다른 부분 문자열의 총 개수**가 $O(N)$에 구해집니다:
     $$\text{Total} = \sum_{u \ne \text{root}} (\text{len}[u] - \text{len}[\text{link}[u]])$$

## 복잡도 분석
- **시간 복잡도**: 본문 이론 및 구현 참조
- **공간 복잡도**: $O(N)$ 또는 $O(V + E)$
