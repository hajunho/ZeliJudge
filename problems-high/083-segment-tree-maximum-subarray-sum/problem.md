# 구간의 최대 연속합을 실시간으로! 금광 세그먼트 트리 (Max Subarray Sum SegTree)

## 문제 설명
길이 $N$인 정수 수열 $A_1, A_2, \dots, A_N$이 주어집니다.
다음 두 가지 종류의 쿼리를 순서대로 처리하는 프로그램을 작성하세요:

- `1 i x`: $i$번째 원소를 $x$로 변경합니다 ($A_i \leftarrow x$).
- `2 l r`: 구간 $[l, r]$ ($l \le r$)에 속하는 연속된 하나 이상의 원소를 골랐을 때, 그 원소들의 합의 최댓값을 출력합니다.

## 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 100,000$)과 쿼리의 개수 $Q$ ($1 \le Q \le 100,000$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, A_2, \dots, A_N$ ($-10^9 \le A_i \le 10^9$)이 공백으로 구분되어 주어집니다.
- 다음 $Q$개 줄에 걸쳐 각 줄마다 쿼리가 주어집니다 (`1 i x` 또는 `2 l r`).
  - $1 \le i \le N$, $-10^9 \le x \le 10^9$
  - $1 \le l \le r \le N$

## 출력 형식
- 2번 쿼리가 주어질 때마다 구간 최대 연속합을 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
5 5
1 2 -4 5 3
2 1 5
2 1 2
1 3 10
2 1 5
2 3 3
```
### 출력
```text
8
3
17
10
```

## 예제 2
### 입력
```text
3 2
-10 -20 -30
2 1 3
1 2 50
```
### 출력
```text
-10
```
