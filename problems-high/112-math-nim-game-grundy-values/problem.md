# 승리의 필승 전략을 XOR로 밝혀라! 스프라그-그런디 정리 (Sprague-Grundy Theorem)

## 문제 설명
$K$개의 돌 무더기가 있습니다. 두 사람 A와 B가 번갈아 가며 돌을 가져가는 게임을 합니다.
A가 먼저 시작합니다.

자신의 차례가 된 플레이어는 임의의 한 돌 무더기를 선택한 후, 그 무더기에서 **1개, 2개, 또는 4개**의 돌을 가져갈 수 있습니다.
가져갈 돌이 없어 자신의 차례에 아무 행동도 할 수 없는 플레이어가 패배합니다.

두 플레이어 모두 최적의 전략으로 게임에 임할 때, 선공인 A가 이기면 `First`, 후공인 B가 이기면 `Second`를 출력하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 돌 무더기의 개수 $K$ ($1 \le K \le 100,000$)가 주어집니다.
- 둘째 줄에 각 무더기에 있는 돌의 개수 $S_1, S_2, \dots, S_K$ ($1 \le S_i \le 10^9$)가 공백으로 구분되어 주어집니다.

## 출력 형식
- 선공이 승리하면 `First`, 후공이 승리하면 `Second`를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3
1 2 3
```
### 출력
```text
First
```
**설명**:
각 돌 개수별 그런디 값 $G(n)$ 패턴:
- $G(0) = 0$
- $G(1) = \text{mex}(G(0)) = 1$
- $G(2) = \text{mex}(G(1), G(0)) = 2$
- $G(3) = \text{mex}(G(2), G(1)) = 0$
- $G(4) = \text{mex}(G(3), G(2), G(0)) = \text{mex}(0, 2, 0) = 1$
- $G(5) = \text{mex}(G(4), G(3), G(1)) = \text{mex}(1, 0, 1) = 2$
- $G(6) = \text{mex}(G(5), G(4), G(2)) = \text{mex}(2, 1, 2) = 0$
즉, $G(n) = n \bmod 3$입니다.
$G(1) \oplus G(2) \oplus G(3) = 1 \oplus 2 \oplus 0 = 3 \ne 0$이므로 선공(`First`) 승리입니다.

## 예제 2
### 입력
```text
2
3 6
```
### 출력
```text
Second
```
**설명**: $G(3) \oplus G(6) = 0 \oplus 0 = 0$이므로 후공(`Second`) 승리입니다.
