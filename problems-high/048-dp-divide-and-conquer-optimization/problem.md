# 분할하여 지배하는 동적 계획법! D&C 최적화 (Divide and Conquer Optimization DP)

## 문제 설명
N개의 수열을 K개의 연속된 부분 수열로 분할하려고 합니다.
각 그룹을 $[i, j]$로 묶을 때 발생하는 비용 함수 $C(i, j)$가 사각부등식(Quadrangle Inequality)을 만족합니다.
점화식: $DP[k][i] = \min_{j < i} (DP[k-1][j] + C(j+1, i))$

일반적인 DP는 상태 $K \times N$개에 각 전이 $O(N)$이 걸려 $O(K N^2)$이지만,
최적 분할점의 단조성 $opt[k][i] \le opt[k][i+1]$을 활용하는 **분할 정복 최적화(Divide and Conquer Optimization)**를 구현하여 $O(K N \log N)$ 시간에 해결하세요.

## 입력 형식
첫째 줄에 N과 K가 공백으로 주어집니다. (1 <= K <= N <= 3,000)
둘째 줄에 N개의 정수 $A_1, A_2, \dots, A_N$이 주어집니다. (비용 $C(l, r) = (\sum_{x=l}^r A_x)^2$)

## 출력 형식
N개의 수를 K개의 그룹으로 분할할 때 가능한 최소 비용 합을 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 3
1 2 3 4 5
```

**출력:**
```text
77
```

### 예제 2
**입력:**
```text
1 1
5
```

**출력:**
```text
25
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
