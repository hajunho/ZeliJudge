# 서로 다른 주기들이 만나는 날! 중국인의 나머지 정리 (Chinese Remainder Theorem)

## 문제 설명
k개의 연립 합동식(Congruence Equations)이 주어집니다:
$$x \equiv a_1 \pmod{m_1}$$
$$x \equiv a_2 \pmod{m_2}$$
$$\dots$$
$$x \equiv a_k \pmod{m_k}$$

모든 법(Modulus) $m_1, m_2, \dots, m_k$는 서로소(Pairwise Coprime)인 자연수입니다.
이 연립 합동식을 만족하는 **가장 작은 양의 정수 x (1 <= x <= m_1 m_2 ... m_k)**를 구하는 프로그램을 작성하세요.
중국인의 나머지 정리(Chinese Remainder Theorem, CRT)와 모듈로 역원을 구현하세요.

## 입력 형식
첫째 줄에 합동식의 개수 k가 주어집니다. (1 <= k <= 10)
둘째 줄부터 k개의 줄에 걸쳐 각 식의 나머지 a_i와 법 m_i가 공백으로 주어집니다. (0 <= a_i < m_i, 2 <= m_i <= 100, 모든 m_i는 서로소)

## 출력 형식
연립 합동식을 만족하는 최소의 양의 정수 x를 출력합니다. (만약 0이 나오면 $M = \prod m_i$를 출력)

## 입출력 예제

### 예제 1
**입력:**
```text
3
2 3
3 5
2 7
```

**출력:**
```text
23
```

### 예제 2
**입력:**
```text
2
1 2
2 3
```

**출력:**
```text
5
```
