# 에드몬즈-카프 (Edmonds-Karp) 최대 유량 알고리즘

## 1. 포드-풀커슨 방법과 증가 경로
- 잔여 용량 `residual = capacity[u][v] - flow[u][v]`가 남아있는 간선들로 소스에서 싱크까지 경로를 탐색합니다.
- 역방향 간선에 대해 가상의 유량 `flow[v][u] = -flow[u][v]`를 부여하여 기존에 흘려보낸 유량을 취소(양보)할 수 있게 합니다.

## 2. BFS와 최단 경로 보장 (에드몬즈-카프)
- DFS 대신 BFS를 사용하여 간선 수가 가장 적은 최단 증가 경로를 선택합니다.
- 최단 경로를 선택하면 증가 경로를 찾는 횟수가 최대 $O(VE)$번으로 제한되어, 전체 시간 복잡도가 $O(V E^2)$로 다항 시간(Polynomial Time) 내에 완료됨이 수학적으로 보장됩니다.
