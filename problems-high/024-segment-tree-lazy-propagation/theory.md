# 느리게 갱신되는 세그먼트 트리 (Lazy Propagation)

## 1. 핵심 아이디어: 지연 갱신
어떤 구간 노드가 질의 구간 `[b, c]`에 완전히 포함된다면, 굳이 그 자식들까지 내려가서 갱신하지 않고, `tree[node] += d * (구간 길이)`로 현재 노드만 갱신한 뒤 `lazy[node] += d`로 기록해 두고 즉시 리턴합니다.

## 2. 전파(Propagation) 원리
노드를 방문할 때 `lazy[node] != 0`이라면, 현재 노드의 값에 지연된 값을 반영하고 자식 노드가 있다면 자식 노드의 `lazy` 배열로 지연값을 물려준 뒤 `lazy[node] = 0`으로 초기화합니다.
