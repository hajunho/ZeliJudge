# 이분 매칭으로 모든 간선을 감시하라! 쾨닉의 정리 (König's Theorem)

## 문제 설명
왼쪽 정점 집합 $L$ ($1$번부터 $N$번까지)과 오른쪽 정점 집합 $R$ ($1$번부터 $M$번까지)로 이루어진 이분 그래프가 주어집니다.
모든 간선에 대해 최소 한쪽 끝 정점이 포함되도록 정점들을 선택할 때, 선택하는 정점의 개수를 최소화하는 **최소 정점 커버(Minimum Vertex Cover)**의 크기를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 왼쪽 정점의 수 $N$, 오른쪽 정점의 수 $M$ ($1 \le N, M \le 1,000$), 간선의 수 $E$ ($1 \le E \le 10,000$)가 공백으로 구분되어 주어집니다.
- 다음 $E$개 줄에 걸쳐 각 줄마다 간선이 잇는 왼쪽 정점 $u$ ($1 \le u \le N$)와 오른쪽 정점 $v$ ($1 \le v \le M$)가 주어집니다.

## 출력 형식
- 최소 정점 커버의 크기(선택해야 하는 최소 정점 수)를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3 3 4
1 1
1 2
2 2
3 3
```
### 출력
```text
3
```
**설명**: 최대 매칭이 3이므로 쾨닉의 정리에 의해 최소 정점 커버의 크기도 3입니다.

## 예제 2
### 입력
```text
4 4 4
1 1
2 1
3 1
4 1
```
### 출력
```text
1
```
**설명**: 오른쪽 1번 정점 하나만 선택하면 4개의 간선이 모두 커버됩니다.
