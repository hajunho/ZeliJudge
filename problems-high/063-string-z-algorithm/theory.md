# 이론 및 해설: 접두사와의 일치 길이를 선형 시간에! Z-알고리즘 (Z-Algorithm)

### Z-알고리즘 (Z-Algorithm)

길이 $N$인 문자열 $S$에 대해, $Z[i]$ ($0 \le i < N$)는 $S$와 $S[i:]$의 최장 공통 접두사(Longest Common Prefix, LCP)의 길이를 의미합니다. ($Z[0] = N$)

1. **원리 ($O(N)$)**:
   - 지금까지 확인한 일치 구간 중 가장 오른쪽 끝점 $R$을 갖는 구간 $[L, R]$ (즉, $S[L..R] == S[0..R-L]$)을 관리합니다.
   - 현재 인덱스 $i$에 대해:
     - $i > R$이면, 직접 문자를 하나씩 비교하여 $Z[i]$를 구하고 $[L, R]$을 갱신합니다.
     - $i \le R$이면, 대칭 위치 $k = i - L$에 대해 이미 계산된 $Z[k]$를 활용합니다:
       - 만약 $Z[k] < R - i + 1$이면, $Z[i] = Z[k]$가 확정됩니다.
       - 그렇지 않으면, 적어도 $R - i + 1$만큼은 일치하므로 $R+1$부터 추가 비교를 수행하고 새로운 $R$로 갱신합니다.
   - $R$은 단조 증가하므로 전체 시간 복잡도는 $O(N)$입니다.
