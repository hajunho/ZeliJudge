# 접두사와의 일치 길이를 선형 시간에! Z-알고리즘 (Z-Algorithm)

## 문제 설명
길이 $N$인 알파벳 소문자로 이루어진 문자열 $S$가 주어집니다.
각 인덱스 $i$ ($0 \le i < N$)에 대해, $S$의 접미사 $S[i \dots N-1]$과 $S$ 전체의 최장 공통 접두사(LCP) 길이 $Z[i]$를 구하는 프로그램을 작성하세요.

단, $i = 0$일 때 $S[0 \dots N-1]$은 $S$ 자신과 완전히 일치하므로 $Z[0] = N$입니다.

## 입력 형식
- 첫째 줄에 알파벳 소문자로만 이루어진 문자열 $S$ ($1 \le |S| \le 200,000$)가 주어집니다.

## 출력 형식
- $Z[0], Z[1], \dots, Z[N-1]$의 값을 공백으로 구분하여 한 줄에 출력합니다.

## 예제 1
### 입력
```text
aabzaa
```
### 출력
```text
6 1 0 0 2 1
```
**설명**: 
- $i=0$: `aabzaa`와 `aabzaa`의 LCP 길이는 $6$
- $i=1$: `abzaa`와 `aabzaa`의 LCP 길이는 $1$ (`a`)
- $i=2$: `bzaa`와 `aabzaa`의 LCP 길이는 $0$
- $i=3$: `zaa`와 `aabzaa`의 LCP 길이는 $0$
- $i=4$: `aa`와 `aabzaa`의 LCP 길이는 $2$ (`aa`)
- $i=5$: `a`와 `aabzaa`의 LCP 길이는 $1$ (`a`)

## 예제 2
### 입력
```text
aaaaa
```
### 출력
```text
5 4 3 2 1
```
