# 트리에서 가장 긴 경로를 찾아라! 트리 DP와 지름 (Tree DP Diameter)

## 문제 설명
$N$개의 정점과 $N-1$개의 양방향 가중치 간선으로 이루어진 트리가 주어집니다.
트리 상의 임의의 두 노드를 골랐을 때, 두 노드 사이의 단순 경로 상의 간선 가중치 합의 최댓값(트리의 지름)을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정점의 개수 $N$ ($1 \le N \le 100,000$)이 주어집니다.
- 다음 $N-1$개 줄에 걸쳐 각 줄마다 간선이 연결하는 두 정점 $u, v$ ($1 \le u, v \le N$)와 가중치 $w$ ($1 \le w \le 10^9$)가 주어집니다.

## 출력 형식
- 트리의 지름(가장 먼 두 정점 사이의 거리)을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
5
1 2 3
1 3 4
2 4 5
2 5 2
```
### 출력
```text
12
```

## 예제 2
### 입력
```text
3
1 2 10
2 3 20
```
### 출력
```text
30
```
