# 문자열 사전을 접두사 트리로! 트라이 자료구조 (Trie Prefix Tree)

## 문제 설명
전화번호 목록이 주어졌을 때, 이 목록이 일관성이 있는지 없는지 구하는 프로그램을 작성하세요.
어떤 번호가 다른 번호의 접두어(prefix)인 경우가 있으면 이 목록은 일관성이 없는 것입니다.
예를 들어, 긴급전화가 911이고, 영석이의 전화번호가 91125426이라면, 영석이에게 전화를 걸 수 없으므로 일관성이 없습니다.
트라이(Trie) 자료구조를 구축하며 문자열을 삽입하는 도중에 접두사 중복을 즉시 검출하는 알고리즘을 작성하세요.

## 입력 형식
첫째 줄에 테스트 케이스의 개수 T가 주어집니다. (1 <= T <= 20)
각 테스트 케이스의 첫째 줄에는 전화번호의 수 n이 주어집니다. (1 <= n <= 10,000)
다음 n개의 줄에는 각 전화번호가 한 줄에 하나씩 주어집니다. (전화번호 길이는 1 이상 10 이하의 숫자)

## 출력 형식
각 테스트 케이스마다 일관성이 있다면 YES, 일관성이 없다면 NO를 한 줄에 하나씩 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
2
3
911
97625999
91125426
5
113
12340
123440
12345
98346
```

**출력:**
```text
NO
YES
```

### 예제 2
**입력:**
```text
1
2
123
456
```

**출력:**
```text
YES
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
