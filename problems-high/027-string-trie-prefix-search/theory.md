# 트라이 (Trie) 자료구조

## 1. 트라이 노드 구조
- 각 노드는 다음 자식 문자들(0~9)을 가리키는 딕셔너리 또는 고정 크기 배열을 가집니다.
- `is_end`: 해당 노드에서 끝나는 전화번호가 있는지 여부를 나타내는 불리언 플래그입니다.

## 2. 접두어 충돌 판정
새로운 문자열을 삽입할 때 두 가지 경우를 검사합니다:
1. 문자를 타고 내려가는 도중 이미 `is_end == True`인 노드를 만난 경우 (기존 번호가 내 접두어)
2. 내 번호의 삽입이 끝났는데 이미 그 노드에 자식 노드가 존재하는 경우 (내가 기존 번호의 접두어)
- 각 문자열의 길이 L에 비례하여 $O(L)$ 시간에 검사할 수 있습니다.
