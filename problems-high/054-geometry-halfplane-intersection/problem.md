# 반평면들을 깎아 만든 볼록 다각형! 반평면 교집합 (Halfplane Intersection)

## 문제 설명
2차원 평면 위에 N개의 반평면(Halfplane)이 주어집니다. 각 반평면은 유향 직선 A -> B의 왼쪽 영역으로 주어집니다.
이 N개의 반평면들의 공통 교집합으로 만들어지는 유한한 볼록 다각형의 넓이를 구하는 프로그램을 작성하세요.

직선들을 편각(Angle) 순으로 정렬한 뒤, 데크(Deque)를 이용하여 불필요한 직선을 제거하는 **반평면 교집합(Halfplane Intersection)** 알고리즘을 구현하여 O(N log N) 시간에 해결하세요.
(공통 교집합이 없거나 넓이가 0이면 0.0을 출력합니다.)

## 입력 형식
첫째 줄에 반평면의 개수 N이 주어집니다. (3 <= N <= 100,000)
둘째 줄부터 N개의 줄에 걸쳐 각 반평면을 정의하는 유향 직선의 두 점 x1, y1, x2, y2가 공백으로 주어집니다. (점 1에서 점 2를 바라보았을 때 왼쪽 영역이 반평면입니다.)

## 출력 형식
반평면 교집합 영역의 넓이를 소수점 아래 둘째 자리에서 반올림하여 첫째 자리까지 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4
0 0 10 0
10 0 10 10
10 10 0 10
0 10 0 0
```

**출력:**
```text
100.0
```

### 예제 2
**입력:**
```text
3
0 0 4 0
4 0 0 3
0 3 0 0
```

**출력:**
```text
6.0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
