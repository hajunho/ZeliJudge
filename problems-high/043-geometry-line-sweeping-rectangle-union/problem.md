# 겹친 직사각형들의 총면적을 구하라! 라인 스위핑과 직사각형 합집합 (Rectangle Union Area Sweeping)

## 문제 설명
2차원 평면 위에 N개의 직사각형이 주어집니다. 각 직사각형은 변이 x축과 y축에 평행합니다.
이 직사각형들이 서로 겹치거나 맞닿을 수 있을 때, 직사각형들이 차지하는 **전체 영역의 넓이(합집합 면적)**를 구하는 프로그램을 작성하세요.

x좌표를 따라 수직선을 왼쪽에서 오른쪽으로 이동시키는 라인 스위핑(Line Sweeping)과, y구간의 덮인 길이를 관리하는 세그먼트 트리를 결합하여 O(N log N) 시간에 해결하세요.

## 입력 형식
첫째 줄에 직사각형의 개수 N이 주어집니다. (1 <= N <= 30,000)
둘째 줄부터 N개의 줄에 걸쳐 각 직사각형의 좌표 x1, y1, x2, y2가 공백으로 주어집니다. (x1, y1은 왼쪽 아래 꼭짓점, x2, y2는 오른쪽 위 꼭짓점, 0 <= x1 < x2 <= 1,000,000, 0 <= y1 < y2 <= 1,000,000)

## 출력 형식
직사각형들이 차지하는 총 넓이를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4
0 0 10 10
5 5 15 15
2 2 8 8
10 10 20 20
```

**출력:**
```text
220
```

### 예제 2
**입력:**
```text
1
0 0 10 10
```

**출력:**
```text
100
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
