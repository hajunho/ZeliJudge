# 트리를 무게중심으로 쪼개라! 센트로이드 분할 (Centroid Decomposition)

## 문제 설명
N개의 정점과 양의 정수 가중치를 가진 N-1개의 간선으로 이루어진 트리가 주어집니다.
트리 상의 두 정점 u와 v (u < v) 사이의 단순 경로 거리(간선 가중치 합)가 정확히 K 이하인 정점 쌍 (u, v)의 총개수를 구하세요.

트리의 모든 쌍을 검사하면 O(N^2)이지만,
서브트리를 제거했을 때 남은 컴포넌트들의 크기가 모두 원래 크기의 절반 이하가 되는 **무게중심(센트로이드, Centroid)**을 찾아 분할 정복(Divide & Conquer)을 수행하는 **센트로이드 분할**을 구현하여 O(N log^2 N) 또는 O(N log N)에 해결하세요.

## 입력 형식
첫째 줄에 정점 수 N과 거리 상한 K가 공백으로 주어집니다. (1 <= N <= 50,000, 1 <= K <= 1,000,000,000)
둘째 줄부터 N-1개의 줄에 걸쳐 각 간선의 정보 u, v, w가 주어집니다. (1 <= u, v <= N, 1 <= w <= 1,000)

## 출력 형식
경로 거리가 K 이하인 서로 다른 정점 쌍 (u, v) (u < v)의 총개수를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 4
1 2 3
1 3 1
1 4 2
3 5 1
```

**출력:**
```text
8
```

### 예제 2
**입력:**
```text
1 10
```

**출력:**
```text
0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
