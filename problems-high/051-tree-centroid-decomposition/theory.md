# 센트로이드 분할 (Centroid Decomposition)

## 1. 트리 센트로이드의 존재성
- 정점 $c$를 제거했을 때 나뉘는 모든 서브트리의 크기가 $\le \lfloor N/2 \rfloor$인 정점 $c$가 트리에는 항상 최소 1개 존재합니다.
- 센트로이드를 루트로 삼아 분할 정복을 진행하면 트리의 재귀 깊이가 최대 $O(\log N)$으로 엄격히 제한됩니다.

## 2. 경로 계산
- 현재 센트로이드 $c$를 지나는 경로의 거리는 각 서브트리 노드들의 $c$까지의 거리 $dist[x] + dist[y]$입니다.
- 투 포인터나 이진 탐색을 통해 거리가 $K$ 이하인 쌍을 $O(M \log M)$에 세고, 같은 서브트리에서 온 중복 쌍을 제외합니다.
