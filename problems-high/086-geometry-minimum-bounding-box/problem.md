# 다각형을 감싸는 가장 작은 직사각형! 회전하는 캘리퍼스 (Minimum Bounding Box)

## 문제 설명
2차원 평면 위에 $N$개의 점이 주어집니다.
이 점들을 모두 포함하는 직사각형 중 면적이 가장 작은 직사각형의 넓이를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 점의 개수 $N$ ($3 \le N \le 100,000$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 각 점의 좌표 $x, y$ ($-10^9 \le x, y \le 10^9$)가 공백으로 구분되어 주어집니다.

## 출력 형식
- 최소 외접 직사각형의 넓이를 소수점 둘째 자리까지 반올림하여 출력합니다.

## 예제 1
### 입력
```text
4
0 0
2 0
2 2
0 2
```
### 출력
```text
4.00
```

## 예제 2
### 입력
```text
3
0 0
4 0
0 3
```
### 출력
```text
12.00
```
