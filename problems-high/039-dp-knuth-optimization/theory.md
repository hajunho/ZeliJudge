# 크누스 최적화 (Knuth's Optimization)

## 1. 사각부등식과 단조성
비용 함수 $C(i, j)$가 단조성과 사각부등식($C(a, c) + C(b, d) \le C(a, d) + C(b, c)$)을 만족하면,
구간 $[i, j]$를 분할하는 최적의 지점 $opt[i][j]$는 다음 단조성을 만족합니다:
$$opt[i][j-1] \le opt[i][j] \le opt[i+1][j]$$

## 2. 시간 복잡도 증명
길이 $L$인 구간들에 대해 $k$의 탐색 범위는 $[opt[i][j-1], opt[i+1][j]]$로 제한됩니다.
이 범위들의 합은 $\sum_i (opt[i+1][j] - opt[i][j-1]) = O(N)$으로 망원급수처럼 상쇄되므로, 전체 시간 복잡도가 $O(N^3)$에서 $O(N^2)$로 대폭 감소합니다.
