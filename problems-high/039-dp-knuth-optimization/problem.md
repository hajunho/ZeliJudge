# 사각부등식의 마법! 크누스 최적화 구간 분할 DP (Knuth's Optimization DP)

## 문제 설명
N개의 수열 A[1..N]을 하나의 덩어리로 합치려고 합니다.
연속된 두 덩어리를 합칠 때 드는 비용은 두 덩어리의 원소 합입니다.
N개의 수를 모두 하나로 합치는 데 필요한 최소 총비용을 구하는 프로그램을 작성하세요.

일반적인 구간 DP $dp[i][j] = \min_{i \le k < j} (dp[i][k] + dp[k+1][j]) + \text{cost}$는 $O(N^3)$이 소요되어 $N=500$ 이상에서 시간 초과가 발생합니다.
사각부등식(Quadrangle Inequality)을 만족하여 최적 분할점 $opt[i][j-1] \le opt[i][j] \le opt[i+1][j]$ 단조성이 성립함을 활용하는 **크누스 최적화(Knuth's Optimization)**를 구현하여 $O(N^2)$ 시간에 해결하세요.

## 입력 형식
첫째 줄에 수의 개수 N이 주어집니다. (2 <= N <= 500)
둘째 줄에 N개의 자연수가 공백으로 주어집니다. (10,000 이하의 자연수)

## 출력 형식
N개의 수를 모두 하나로 합치는 데 필요한 최소 총비용을 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4
40 30 30 50
```

**출력:**
```text
300
```

### 예제 2
**입력:**
```text
2
10 20
```

**출력:**
```text
30
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
