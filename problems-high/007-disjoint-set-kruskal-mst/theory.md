# 크루스칼(Kruskal) MST 알고리즘

## 1. 탐욕적 선택 속성(Greedy Choice Property)
모든 간선을 가중치 오름차순으로 정렬한 뒤, 가장 가중치가 작은 간선부터 순서대로 선택합니다.
만약 선택한 간선이 이미 연결된 두 정점을 잇는다면(즉 사이클을 형성한다면) 그 간선은 건너뜁니다.

## 2. 분리 집합 (Union-Find)과 사이클 판정
- `find(x)`: 정점 x가 속한 트리의 루트를 찾습니다. 경로 압축(Path Compression)을 통해 거의 O(1)에 수행됩니다.
- `union(a, b)`: `find(a) == find(b)`이면 두 정점은 이미 같은 컴포넌트에 속해 있으므로 간선을 추가하면 사이클이 생깁니다.
- 두 루트가 다를 때만 두 집합을 합치고 가중치를 누적합니다.
- 총 시간 복잡도는 간선 정렬에 지배되어 $O(E \log E)$입니다.
