# 최소 비용으로 모든 도시 연결하기! 크루스칼 MST (Kruskal's Minimum Spanning Tree)

## 문제 설명
V개의 정점과 E개의 양방향 가중치 간선으로 이루어진 연결 그래프가 주어집니다.
모든 정점을 연결하면서 사이클이 생기지 않도록 하는 부분 그래프를 신장 트리(Spanning Tree)라고 합니다.
신장 트리를 구성하는 간선들의 가중치 합이 최소가 되는 **최소 신장 트리(Minimum Spanning Tree, MST)**를 구하고, 그 가중치 합을 출력하세요.
크루스칼(Kruskal) 알고리즘과 분리 집합(Union-Find with 경로 압축)을 사용하여 구현하세요.

## 입력 형식
첫째 줄에 정점의 개수 V와 간선의 개수 E가 공백으로 주어집니다. (1 <= V <= 10,000, 1 <= E <= 100,000)
둘째 줄부터 E개의 줄에 걸쳐 각 간선의 정보 u, v, w가 주어집니다. (1 <= u, v <= V, u != v, w는 정수 -1,000,000 <= w <= 1,000,000)

## 출력 형식
최소 신장 트리의 총 가중치를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
3 3
1 2 1
2 3 2
1 3 3
```

**출력:**
```text
3
```

### 예제 2
**입력:**
```text
4 5
1 2 1
1 3 4
2 3 2
2 4 5
3 4 3
```

**출력:**
```text
6
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
