# 문자열 속 모든 회문을 잎사귀로 피워내라! 팰린드롬 트리 (EERTREE)

## 핵심 개념 및 알고리즘 개요
- **태그**: 문자열, 팰린드롬 트리(Palindromic Tree / EERTREE), 회문 부분문자열, 선형 시간, $O(N)$
- **핵심 요약**: 문자열에 존재하는 모든 서로 다른 팰린드롬 부분문자열을 선형 시간 $O(N)$에 관리하는 팰린드롬 트리를 구축합니다.

---

### 팰린드롬 트리 (Palindromic Tree / EERTREE)

문자열 $S$에 존재하는 모든 서로 다른 팰린드롬(Palindrome) 부분문자열의 개수는 최대 $|S|$개에 불과합니다.
**팰린드롬 트리(EERTREE)**는 이 모든 팰린드롬을 두 개의 루트(길이 0인 짝수 루트, 길이 -1인 홀수 루트)를 기반으로 **$O(N)$ 선형 시간**에 구축하는 전용 오토마톤입니다.

1. **두 개의 루트 노드**:
   - `root_odd` (인덱스 1): 길이 $-1$. 어떤 문자 $c$를 양쪽에 붙이면 길이 1인 회문 $c$가 됩니다.
   - `root_even` (인덱스 0): 길이 $0$. 어떤 문자 $c$를 양쪽에 붙이면 길이 2인 회문 $cc$가 됩니다.

2. **전이 간선과 접미사 링크 (Suffix Link)**:
   - 노드 $u$ (회문 $P$)에서 간선 $c$를 타면 회문 $c P c$를 나타내는 노드로 이동합니다.
   - `link[u]`는 회문 $P$의 진부분문자열 중 **가장 긴 팰린드롬 접미사(Longest Proper Palindromic Suffix)**를 가리킵니다.

3. **온라인 증분 삽입**:
   - 문자를 하나씩 추가할 때마다 직전 팰린드롬 접미사 노드에서 링크를 타고 올라가며 $c P c$ 꼴을 만족하는 가장 긴 회문을 찾습니다.
   - 각 문자당 링크 이동의 상각 횟수는 $O(1)$이므로 전체 구축 시간 복잡도는 **$O(N)$**입니다.

---

## 복잡도 분석
- **시간 복잡도**: 본문 이론 및 구현 참조
- **공간 복잡도**: $O(N)$ 또는 $O(V + E)$

## 추천 연습 문제
- 관련 백준(BOJ) 및 Codeforces / ICPC 기출 고난도 문제
