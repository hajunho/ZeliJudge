# 문자열 속 모든 회문을 잎사귀로 피워내라! 팰린드롬 트리 (EERTREE)

## 문제 설명
알파벳 소문자로 이루어진 문자열 $S$가 주어집니다.

이 문자열의 연속된 부분 문자열 중에서 앞으로 읽으나 뒤로 읽으나 같은 **서로 다른 팰린드롬(Palindrome) 부분 문자열의 총 개수**를 구하는 프로그램을 작성하세요.
단, 빈 문자열은 세지 않습니다.

## 입력 형식
- 첫째 줄에 알파벳 소문자로 구성된 문자열 $S$ ($1 \le |S| \le 100,000$)가 주어집니다.

## 출력 형식
- 문자열 $S$에 존재하는 서로 다른 팰린드롬 부분 문자열의 총 개수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
abacaba
```
### 출력
```text
7
```
**설명**: 
서로 다른 팰린드롬 부분 문자열들:
- 길이 1: `a`, `b`, `c` (3개)
- 길이 3: `aba`, `aca` (2개)
- 길이 5: `bacab` (1개)
- 길이 7: `abacaba` (1개)
총합 7개입니다.

## 예제 2
### 입력
```text
aaaa
```
### 출력
```text
4
```
**설명**: `a`, `aa`, `aaa`, `aaaa` 총 4개입니다.
