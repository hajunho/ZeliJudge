# 음수 가중치도 끄떡없다! 벨만-포드 최단 경로와 음수 사이클 (Bellman-Ford Algorithm)

## 문제 설명
N개의 도시와 이들 사이를 잇는 M개의 버스 노선이 있습니다. 각 버스 노선은 가중치 C를 가지며, 이 가중치는 양수일 수도 있고 심지어 시간을 되돌리는 음수일 수도 있습니다.

1번 도시에서 출발하여 나머지 각 도시로 가는 가장 빠른 시간을 구하는 프로그램을 작성하세요.
단, 음수 사이클(어떤 경로를 무한히 돌면 시간이 계속 줄어드는 사이클)이 존재하는 경우에는 -1을 첫째 줄에 출력합니다.
다익스트라 알고리즘이 처리하지 못하는 음수 간선 그래프를 O(NM) 시간에 해결하는 벨만-포드(Bellman-Ford) 알고리즘을 구현하세요.

## 입력 형식
첫째 줄에 도시의 개수 N과 버스 노선의 개수 M이 주어집니다. (1 <= N <= 500, 1 <= M <= 6,000)
둘째 줄부터 M개의 줄에 걸쳐 버스 노선의 정보 A, B, C가 주어집니다. (A에서 B로 가는 가중치 C 버스, -10,000 <= C <= 10,000)

## 출력 형식
만약 1번 도시에서 출발해 음수 사이클이 발생한다면 첫째 줄에 -1을 출력합니다.
그렇지 않다면, 2번 도시부터 N번 도시까지 각 도시로 가는 최단 시간을 한 줄에 하나씩 출력합니다.
만약 해당 도시로 가는 경로가 없다면 -1을 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
3 4
1 2 4
1 3 3
2 3 -1
3 1 -2
```

**출력:**
```text
4
3
```

### 예제 2
**입력:**
```text
3 4
1 2 4
1 3 3
2 3 -4
3 1 -2
```

**출력:**
```text
-1
```
