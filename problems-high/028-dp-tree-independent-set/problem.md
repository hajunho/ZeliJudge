# 인접한 두 정점을 동시에 고르지 않기! 트리 다이나믹 프로그래밍 (Tree DP Maximum Independent Set)

## 문제 설명
트리의 각 정점에 우수 마을 주민 수(양의 정수 가중치)가 주어져 있습니다.
이 트리에서 몇 개의 정점을 선택하여 '우수 마을'로 지정하려고 합니다.
단, 두 우수 마을은 서로 직접 간선으로 연결될 수 없습니다 (독립 집합, Independent Set).
우수 마을로 선정된 마을 주민 수의 총합이 최대가 되도록 할 때, 그 최댓값을 구하는 프로그램을 작성하세요.
트리 상향식(Bottom-up) 동적 계획법을 적용하여 O(N) 시간에 해결하세요.

## 입력 형식
첫째 줄에 정점의 개수 N이 주어집니다. (1 <= N <= 10,000)
둘째 줄에 1번 마을부터 N번 마을까지의 주민 수가 공백으로 주어집니다. (10,000 이하의 자연수)
셋째 줄부터 N-1개의 줄에 걸쳐 트리 상에서 직접 연결된 두 정점 u, v가 주어집니다.

## 출력 형식
선택된 우수 마을 주민 수 총합의 최댓값을 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
7
1000 3000 4000 1000 2000 2000 7000
1 2
2 3
4 3
4 5
6 2
6 7
```

**출력:**
```text
14000
```

### 예제 2
**입력:**
```text
1
50
```

**출력:**
```text
50
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
