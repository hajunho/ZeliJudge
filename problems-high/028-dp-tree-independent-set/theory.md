# 트리 동적 계획법 (Tree DP)

## 1. 2가지 상태 정의
- `dp[u][0]`: u번 노드를 우수 마을로 선택하지 않았을 때, u의 서브트리에서 얻을 수 있는 최대 가중치
- `dp[u][1]`: u번 노드를 우수 마을로 선택했을 때, u의 서브트리에서 얻을 수 있는 최대 가중치

## 2. 자식 노드로부터의 전이
- u를 선택하지 않으면(`dp[u][0]`): 자식 v는 선택해도 되고 안 해도 됩니다.
  $$\text{dp}[u][0] = \sum_{v \in \text{child}(u)} \max(\text{dp}[v][0], \text{dp}[v][1])$$
- u를 선택하면(`dp[u][1]`): 인접한 자식 v는 절대로 선택할 수 없습니다.
  $$\text{dp}[u][1] = \text{weight}[u] + \sum_{v \in \text{child}(u)} \text{dp}[v][0]$$
