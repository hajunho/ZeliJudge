# 거대한 조합도 소수 진법으로 정복하라! 뤼카의 정리 (Lucas' Theorem)

## 문제 설명
두 개의 매우 큰 정수 $N, K$와 소수 $P$가 주어집니다.
이항계수 $\binom{N}{K}$를 $P$로 나눈 나머지를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정수 $N, K$ ($0 \le K \le N \le 10^{18}$)와 소수 $P$ ($2 \le P \le 100,000$)가 공백으로 구분되어 주어집니다.

## 출력 형식
- $\binom{N}{K} \pmod P$를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
5 2 3
```
### 출력
```text
1
```

## 예제 2
### 입력
```text
10 3 7
```
### 출력
```text
1
```
