# 거인의 보폭으로 지수를 맞춰라! 이산 로그와 아기걸음 거인걸음 (Baby-step Giant-step)

## 문제 설명
암호학 및 정수론에서 널리 쓰이는 이산 로그 문제입니다.
소수 $P$와 정수 $A, B$가 주어졌을 때,
$$A^x \equiv B \pmod P$$
를 만족하는 **가장 작은 음이 아닌 정수 $x$** ($0 \le x < P$)를 구하는 프로그램을 작성하세요. 만족하는 $x$가 존재하지 않는다면 `-1`을 출력합니다.

## 입력 형식
- 첫째 줄에 테스트케이스의 수 $T$ ($1 \le T \le 100$)가 주어집니다.
- 둘째 줄부터 $T$개 줄에 걸쳐 각 줄마다 세 정수 $A, B, P$ ($2 \le P \le 10^9$, $1 \le A, B < P$, $P$는 소수)가 공백으로 구분되어 주어집니다.

## 출력 형식
- 각 테스트케이스마다 조건을 만족하는 최소 음이 아닌 정수 $x$를 한 줄에 출력합니다. 해가 없다면 `-1`을 출력합니다.

## 예제 1
### 입력
```text
3
2 8 11
3 5 7
2 3 5
```
### 출력
```text
3
5
3
```
**설명**: 
- $2^3 = 8 \equiv 8 \pmod{11}$이므로 $x=3$.
- $3^5 = 243 = 34 \times 7 + 5 \equiv 5 \pmod 7$이므로 $x=5$.
- $2^3 = 8 \equiv 3 \pmod 5$이므로 $x=3$.

## 예제 2
### 입력
```text
2
5 2 11
2 1 1000000007
```
### 출력
```text
-1
0
```
**설명**: $A^0 = 1 \equiv 1 \pmod P$이므로 $B=1$일 때는 $x=0$입니다.
