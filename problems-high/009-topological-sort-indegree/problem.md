# 선수 과목 순서대로 수강하기! 진입 차수 기반 위상 정렬 (Topological Sort)

## 문제 설명
대학에는 1번부터 V번까지 V개의 과목이 있습니다. 과목들 사이에는 'A 과목을 들어야만 B 과목을 들을 수 있다'는 선수 조건이 총 E개 있습니다.
모든 선수 조건을 만족하면서 전체 과목을 수강할 수 있는 올바른 순서를 구하는 프로그램을 작성하세요.
진입 차수(Indegree)와 큐를 사용하는 카안(Kahn) 알고리즘을 구현하세요.
답이 여러 가지인 경우 아무거나 하나만 출력해도 되며, 사이클이 발생하여 모든 과목을 수강할 수 없는 경우는 주어지지 않습니다.

## 입력 형식
첫째 줄에 과목의 수 V와 선수 조건의 수 E가 공백으로 주어집니다. (1 <= V <= 32,000, 1 <= E <= 100,000)
둘째 줄부터 E개의 줄에 걸쳐 선수 조건 A, B가 주어집니다. (과목 A가 과목 B의 선수 과목)

## 출력 형식
수강해야 하는 과목의 번호를 순서대로 공백으로 구분하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
3 2
1 3
2 3
```

**출력:**
```text
1 2 3
```

### 예제 2
**입력:**
```text
4 2
4 2
3 1
```

**출력:**
```text
3 4 1 2
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
