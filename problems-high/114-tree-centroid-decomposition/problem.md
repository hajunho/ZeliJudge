# 트리의 중심을 잡아 분할 정복하라! 센트로이드 분할 (Centroid Decomposition)

## 문제 설명
$N$개의 정점으로 이루어진 트리가 주어집니다. 모든 간선의 가중치는 $1$입니다.

트리 상의 두 정점 $u, v$ ($u < v$) 사이의 단순 경로 상의 간선 수(거리)가 **$K$ 이하인 서로 다른 정점 쌍 $(u, v)$의 총 개수**를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 트리의 정점 수 $N$ ($1 \le N \le 50,000$)과 정수 $K$ ($1 \le K \le N$)가 공백으로 구분되어 주어집니다.
- 둘째 줄부터 $N-1$개 줄에 걸쳐 각 줄마다 트리의 간선이 잇는 두 정점 $u, v$ ($1 \le u, v \le N$)가 주어집니다.

## 출력 형식
- 거리가 $K$ 이하인 서로 다른 정점 쌍 $(u, v)$ ($u < v$)의 총 개수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
5 2
1 2
2 3
3 4
4 5
```
### 출력
```text
7
```
**설명**: 
일직선 경로 트리입니다. 
- 거리 1인 쌍: (1,2), (2,3), (3,4), (4,5) $\to$ 4개
- 거리 2인 쌍: (1,3), (2,4), (3,5) $\to$ 3개
총합은 $4 + 3 = 7$개입니다.

## 예제 2
### 입력
```text
4 1
1 2
1 3
1 4
```
### 출력
```text
3
```
**설명**: 거리가 1 이하인 쌍은 3개의 간선 (1,2), (1,3), (1,4)뿐입니다.
