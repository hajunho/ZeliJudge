# 복소 평면 위의 격자점을 헤아려라! 가우스 정수와 제곱수 합 (Gaussian Integers)

## 문제 설명
양의 정수 $N$이 주어질 때,
$$x^2 + y^2 = N$$
을 만족하는 **정수해 쌍 $(x, y) \in \mathbb{Z}^2$의 총 개수**를 구하는 프로그램을 작성하세요.

$x$와 $y$는 음수이거나 $0$일 수 있으며, 순서가 다른 쌍 $(x, y)$와 $(y, x)$는 서로 다른 해로 간주합니다.

## 입력 형식
- 첫째 줄에 양의 정수 $N$ ($1 \le N \le 10^{12}$)이 주어집니다.

## 출력 형식
- $x^2 + y^2 = N$을 만족하는 정수해 순서쌍 $(x, y)$의 총 개수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
5
```
### 출력
```text
8
```
**설명**: 
$5 = (\pm 1)^2 + (\pm 2)^2 = (\pm 2)^2 + (\pm 1)^2$
가능한 $(x, y)$ 쌍은 $(\pm 1, \pm 2)$ 4개와 $(\pm 2, \pm 1)$ 4개로 총 8개입니다.

## 예제 2
### 입력
```text
3
```
### 출력
```text
0
```
**설명**: 3은 $4k+3$ 형태의 소수이므로 두 제곱수의 합으로 나타낼 수 없습니다.
