# 모든 부분집합의 합을 초고속으로! SOS DP (Sum Over Subsets)

## 문제 설명
크기가 2^N인 정수 배열 A가 주어집니다. 인덱스는 0부터 2^N - 1까지입니다.
각 마스크 x (0 <= x < 2^N)에 대해, x의 모든 부분마스크 i (즉 `i & x == i`)들의 값 $A[i]$의 총합 $F[x]$를 구하려고 합니다:
$$F[x] = \sum_{i \subseteq x} A[i]$$

모든 x에 대해 부분집합을 단순 순회하면 $O(3^N)$이 걸려 $N=18$ 이상에서 시간 초과가 발생합니다.
비트 위치별로 하위 마스크를 점진적으로 결합하는 **SOS DP (Sum Over Subsets)**를 구현하여 $O(N 2^N)$ 시간에 해결하세요.

## 입력 형식
첫째 줄에 정수 N이 주어집니다. (1 <= N <= 18)
둘째 줄에 2^N개의 정수 $A[0], A[1], \dots, A[2^N - 1]$이 공백으로 주어집니다. (0 <= $A[i]$ <= 1,000)

## 출력 형식
2^N개의 정수 $F[0], F[1], \dots, F[2^N - 1]$을 공백으로 구분하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
2
1 2 3 4
```

**출력:**
```text
1 3 4 10
```

### 예제 2
**입력:**
```text
1
5 10
```

**출력:**
```text
5 15
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
