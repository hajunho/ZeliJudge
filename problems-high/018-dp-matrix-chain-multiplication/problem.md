# 괄호를 어디에 묶어야 곱셈이 적을까? 연쇄 행렬 곱셈 (Matrix Chain Multiplication)

## 문제 설명
N개의 행렬 $A_1, A_2, \dots, A_N$을 연속으로 곱하려고 합니다. 행렬의 크기는 순서대로 $r_1 \times c_1, r_2 \times c_2, \dots, r_N \times c_N$입니다.
행렬 곱셈은 결합 법칙이 성립하므로 괄호를 묶는 순서에 따라 필요한 원소 간 곱셈 연산의 총 횟수가 크게 달라집니다.
주어진 N개의 행렬을 모두 곱하는 데 필요한 최소 곱셈 연산 횟수를 구하는 프로그램을 작성하세요.
구간 동적 계획법(Range DP)을 적용하여 $O(N^3)$ 시간에 해결하세요.

## 입력 형식
첫째 줄에 행렬의 개수 N이 주어집니다. (1 <= N <= 500)
둘째 줄부터 N개의 줄에 걸쳐 각 행렬의 행의 개수 r과 열의 개수 c가 공백으로 주어집니다. (1 <= r, c <= 500)
항상 인접한 두 행렬의 곱셈이 가능한 크기만 주어집니다 ($c_i = r_{i+1}$).

## 출력 형식
모든 행렬을 곱하는 데 필요한 최소 곱셈 연산 횟수를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
3
5 3
3 2
2 6
```

**출력:**
```text
90
```

### 예제 2
**입력:**
```text
1
10 20
```

**출력:**
```text
0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
