# 역방향 그래프로 강결합을 분리하라! 코사라주 알고리즘 (Kosaraju's SCC)

## 문제 설명
$N$개의 정점과 $M$개의 단방향 간선으로 이루어진 방향 그래프가 주어집니다.
그래프의 모든 강결합 컴포넌트(SCC)의 개수를 구하고, 각 컴포넌트에 속한 정점 번호들을 출력하는 프로그램을 작성하세요.

각 SCC는 내부 정점 번호들을 오름차순으로 정렬하여 출력하며, 여러 개의 SCC는 각 SCC의 가장 작은 정점 번호를 기준으로 오름차순 정렬하여 출력합니다.

## 입력 형식
- 첫째 줄에 정점의 개수 $N$ ($1 \le N \le 100,000$)과 간선의 개수 $M$ ($1 \le M \le 200,000$)이 공백으로 구분되어 주어집니다.
- 다음 $M$개 줄에 걸쳐 각 줄마다 단방향 간선의 시작점 $u$와 도착점 $v$ ($1 \le u, v \le N$)가 공백으로 구분되어 주어집니다 ($u \to v$).

## 출력 형식
- 첫째 줄에 총 SCC의 개수 $K$를 출력합니다.
- 다음 $K$개 줄에 걸쳐, 각 SCC에 속한 정점 번호들을 오름차순으로 공백으로 구분하여 한 줄에 하나씩 출력합니다 (SCC들 또한 가장 작은 정점 번호 기준 오름차순).

## 예제 1
### 입력
```text
5 5
1 2
2 3
3 1
4 5
5 4
```
### 출력
```text
2
1 2 3
4 5
```

## 예제 2
### 입력
```text
4 3
1 2
2 3
3 4
```
### 출력
```text
4
1
2
3
4
```
