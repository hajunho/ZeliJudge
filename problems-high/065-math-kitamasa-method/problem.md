# 선형 점화식의 10^18번째 항을 빠르게! 키타마사법 (Kitamasa Method)

## 문제 설명
$K$차 선형 점화식
$$A_n = \sum_{i=1}^K c_i A_{n-i} \pmod{10^9+7} \quad (n \ge K)$$
과 초기 $K$개의 항 $A_0, A_1, \dots, A_{K-1}$이 주어집니다.

매우 큰 정수 $N$이 주어질 때, 수열의 $N$번째 항 $A_N \pmod{10^9+7}$을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 점화식의 차수 $K$ ($1 \le K \le 1000$)와 구하고자 하는 항의 인덱스 $N$ ($0 \le N \le 10^{18}$)이 공백으로 구분되어 주어집니다.
- 둘째 줄에 점화식의 계수 $c_1, c_2, \dots, c_K$ ($0 \le c_i < 10^9+7$)가 공백으로 구분되어 주어집니다.
- 셋째 줄에 초기 $K$개의 항 $A_0, A_1, \dots, A_{K-1}$ ($0 \le A_i < 10^9+7$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- $A_N \pmod{10^9+7}$을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
2 5
1 1
0 1
```
### 출력
```text
5
```
**설명**: 피보나치 수열 $A_0=0, A_1=1, A_2=1, A_3=2, A_4=3, A_5=5$이므로 $A_5 = 5$입니다.

## 예제 2
### 입력
```text
3 10
1 2 1
1 2 3
```
### 출력
```text
2779
```
