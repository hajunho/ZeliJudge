# 일차 부정방정식의 정수해를 구하라! 확장 유클리드 호제법 (Extended Euclidean Algorithm)

## 문제 설명
세 정수 A, B, C가 주어졌을 때, 일차 디오판토스 방정식(Linear Diophantine Equation) $Ax + By = C$를 만족하는 정수해 $(x, y)$가 존재하는지 판정하고, 존재한다면 **$x \ge 0$인 정수해 중 $x$가 가장 작은 해**를 구하는 프로그램을 작성하세요.

베주 항등식(Bézout's Identity)에 따라 $C$가 $\gcd(A, B)$의 배수일 때만 정수해가 존재합니다.
확장 유클리드 호제법(Extended Euclidean Algorithm)을 구현하여 해결하세요.

## 입력 형식
첫째 줄에 세 정수 A, B, C가 공백으로 구분되어 주어집니다. (1 <= A, B <= 1,000,000,000, 1 <= C <= 1,000,000,000)

## 출력 형식
정수해가 존재하지 않는다면 -1을 출력합니다.
존재한다면 x가 0 이상인 최소의 정수해 (x, y)를 공백으로 구분하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
3 5 11
```

**출력:**
```text
2 1
```

### 예제 2
**입력:**
```text
4 6 7
```

**출력:**
```text
-1
```
