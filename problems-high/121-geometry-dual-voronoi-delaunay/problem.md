# 공간을 세포로 분할하는 쌍대의 미학! 보로노이 다이어그램 (Voronoi Diagram)

## 문제 설명
2차원 평면 위에 $N$개의 물류 거점 좌표가 주어집니다. 어떤 세 점도 한 직선 위에 있지 않습니다.

각 거점 $p_i$에 가장 가까운 구역을 보로노이 다이어그램으로 나눌 때, **경계선을 공유하여 인접한 두 거점 쌍 $(u, v)$ (즉, 들로네 삼각분할의 간선)**들을 모두 찾으려고 합니다.
빈 외접원 판정(Empty Circumcircle Criterion)을 만족하는 서로 다른 들로네 간선의 총 개수를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 거점의 개수 $N$ ($3 \le N \le 100$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 각 거점의 정수 좌표 $x, y$ ($-1,000 \le x, y \le 1,000$)가 공백으로 구분되어 주어집니다. 모든 거점의 좌표는 서로 다릅니다.

## 출력 형식
- 들로네 삼각분할을 구성하는 서로 다른 간선(인접 보로노이 셀 쌍)의 총 개수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3
0 0
4 0
0 4
```
### 출력
```text
3
```
**설명**: 3개의 점은 하나의 삼각형을 형성하며, 세 변 모두가 들로네 간선입니다.

## 예제 2
### 입력
```text
4
0 0
2 0
2 2
0 2
```
### 출력
```text
5
```
**설명**: 정사각형의 네 변(4개)과 대각선 하나(1개)로 총 5개의 들로네 간선이 생성됩니다.
