# 길이 K의 경로를 거듭제곱으로 세다! 행렬 지수승 (Matrix Exponentiation)

## 문제 설명
$V$개의 정점과 $M$개의 단방향 간선으로 이루어진 방향 그래프가 주어집니다.
출발 정점 $S$에서 도착 정점 $E$로 가는 **정확히 $K$개의 간선을 거치는 서로 다른 경로의 수**를 구하는 프로그램을 작성하세요.

답이 매우 클 수 있으므로 $10^9+7$로 나눈 나머지를 출력합니다.

## 입력 형식
- 첫째 줄에 정점의 수 $V$ ($1 \le V \le 50$), 간선의 수 $M$ ($1 \le M \le 200$), 경로의 길이 $K$ ($1 \le K \le 10^{18}$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 출발 정점 $S$와 도착 정점 $E$ ($1 \le S, E \le V$)가 공백으로 구분되어 주어집니다.
- 다음 $M$개 줄에 걸쳐 각 줄마다 단방향 간선의 시작점 $u$와 도착점 $v$ ($1 \le u, v \le V$)가 주어집니다 ($u \to v$).

## 출력 형식
- 길이가 $K$인 경로의 수를 $10^9+7$로 나눈 나머지를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3 4 3
1 3
1 2
2 3
3 1
1 1
```
### 출력
```text
2
```

## 예제 2
### 입력
```text
2 2 10
1 1
1 2
2 1
```
### 출력
```text
1
```
