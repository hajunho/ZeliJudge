# 모든 회문을 선형 시간에! 매내처(Manacher) 알고리즘 (Longest Palindromic Substring)

## 문제 설명
문자열 S가 주어졌을 때, S의 부분 문자열 중 가장 긴 회문(Palindrome, 앞으로 읽으나 뒤로 읽으나 같은 문자열)의 길이를 구하세요.

각 중심에서 양쪽으로 확장하는 O(N^2) 알고리즘 대신, 이미 구한 회문의 대칭성을 재사용하여 본문 전체를 단 1번 훑는 **매내처(Manacher)** 알고리즘을 구현하여 O(N) 선형 시간에 해결하세요.
(짝수 길이 회문도 처리할 수 있도록 더미 문자 `#`을 문자 사이에 삽입하세요.)

## 입력 형식
첫째 줄에 알파벳 소문자로 이루어진 문자열 S가 주어집니다. (1 <= len(S) <= 500,000)

## 출력 형식
가장 긴 팰린드롬 부분 문자열의 길이를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
bananas
```

**출력:**
```text
5
```

### 예제 2
**입력:**
```text
racecar
```

**출력:**
```text
7
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
