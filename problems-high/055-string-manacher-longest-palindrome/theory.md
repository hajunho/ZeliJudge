# 매내처 (Manacher) 알고리즘

## 1. 더미 문자 삽입
`aba` -> `#a#b#a#`, `abba` -> `#a#b#b#a#` 처럼 문자 사이사이에 특수 문자를 넣으면 짝수 길이 회문도 홀수 길이로 통일됩니다.

## 2. 대칭 반지름 재사용 ($O(N)$)
- 현재까지 찾은 회문 중 가장 오른쪽 끝 $R$까지 닿는 회문의 중심을 $C$라 합니다.
- 탐색 중인 위치 $i < R$에 대해 대칭점 $i' = 2C - i$의 회문 반지름 $P[i']$를 가져옵니다:
  $$P[i] = \min(R - i, P[i'])$$
- $R$을 초과하는 부분에 대해서만 양방향 확장을 수행하므로, $R$은 오직 앞으로만 전진하여 총 시간 복잡도는 $O(N)$입니다.
