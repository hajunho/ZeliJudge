# 모든 정점 쌍의 최단 거리! 플로이드-워셜 알고리즘 (Floyd-Warshall All-Pairs Shortest Path)

## 문제 설명
n개의 도시와 한 도시에서 다른 도시로 이동하는 m개의 버스 노선이 있습니다. 각 버스는 이용할 때 비용이 듭니다.
모든 도시 쌍 (i, j)에 대해 도시 i에서 도시 j로 가는 데 필요한 최소 비용을 구하는 프로그램을 작성하세요.
동적 계획법 기반의 플로이드-워셜(Floyd-Warshall) 알고리즘을 구현하세요.

## 입력 형식
첫째 줄에 도시의 개수 n이 주어집니다. (1 <= n <= 100)
둘째 줄에 버스의 개수 m이 주어집니다. (1 <= m <= 100,000)
셋째 줄부터 m개의 줄에 걸쳐 버스의 정보 a, b, c가 주어집니다. (시작 도시 a, 도착 도시 b, 비용 c, 1 <= a, b <= n, 1 <= c <= 100,000)
시작 도시와 도착 도시를 연결하는 노선은 하나가 아닐 수 있습니다.

## 출력 형식
n개의 줄을 출력합니다. i번째 줄에는 i번 도시에서 j번 도시로 가는 최소 비용을 공백으로 구분하여 출력합니다.
자기 자신으로 가는 비용은 항상 0이며, 만약 i에서 j로 갈 수 없는 경우에는 0을 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 14
1 2 2
1 3 3
1 4 1
1 5 10
2 4 2
3 4 1
3 5 1
4 5 3
3 5 10
3 1 8
1 4 2
5 1 7
3 4 2
5 2 4
```

**출력:**
```text
0 2 3 1 4
12 0 15 2 5
8 5 0 1 1
10 7 13 0 3
7 4 10 6 0
```

### 예제 2
**입력:**
```text
2 1
1 2 3
```

**출력:**
```text
0 3
0 0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
