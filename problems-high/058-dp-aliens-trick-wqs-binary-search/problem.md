# 라그랑주 승수로 K개 제약을 날려라! 에일리언 트릭 (Aliens Trick / WQS Binary Search)

## 문제 설명
N개의 수열이 주어집니다. 이 수열에서 서로 겹치지 않는 구간을 **정확히 K개** 선택하여 선택된 구간 합의 최댓값을 구하려고 합니다.
구간 선택 개수가 정해져 있을 때 일반적인 DP는 $O(KN)$이 걸려 $K=100,000$일 때 시간 초과가 발생합니다.

목적 함수가 $K$에 대해 위로 볼록(Concave)하다는 성질을 이용하여, 구간을 1개 선택할 때마다 패널티 비용 $C$를 부과하고 패널티 $C$에 대한 이진 탐색으로 $K$개 제약을 제거하는 **에일리언 트릭(Aliens Trick / WQS 이진 탐색)**을 구현하세요.

## 입력 형식
첫째 줄에 N과 K가 공백으로 주어집니다. (1 <= K <= N <= 100,000)
둘째 줄에 N개의 정수 $A_1, A_2, \dots, A_N$이 공백으로 주어집니다. (-10,000 <= $A_i$ <= 10,000)

## 출력 형식
정확히 K개의 겹치지 않는 구간을 선택했을 때 구간 합의 최댓값을 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5 2
-1 2 3 -1 4
```

**출력:**
```text
9
```

### 예제 2
**입력:**
```text
1 1
5
```

**출력:**
```text
5
```

## 채점 기준

- 시간 제한: 5.0초, 메모리 제한: 512MB.
