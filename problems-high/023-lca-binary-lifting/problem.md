# 두 노드가 만나는 가장 가까운 조상! 이진 리프팅 LCA (Lowest Common Ancestor Binary Lifting)

## 문제 설명
N개의 정점으로 이루어진 트리가 주어집니다. 트리의 루트는 1번 정점입니다.
두 노드 쌍 (u, v)가 M개 주어졌을 때, 각 쌍에 대해 두 노드의 **가장 가까운 공통 조상(LCA, Lowest Common Ancestor)**을 구하는 프로그램을 작성하세요.

부모를 1칸씩 올라가는 단순 방식은 트리가 편향된 경우 질의당 O(N)이 걸려 총 O(MN)으로 시간 초과가 발생합니다.
희소 배열(Sparse Table)을 이용해 2^k 단위로 점프하는 이진 리프팅(Binary Lifting) 기법을 사용하여 각 질의를 O(log N)에 처리하세요.

## 입력 형식
첫째 줄에 노드의 개수 N이 주어집니다. (2 <= N <= 100,000)
다음 N-1개의 줄에 걸쳐 트리 상에서 연결된 두 정점이 주어집니다.
그 다음 줄에 질의의 개수 M이 주어집니다. (1 <= M <= 100,000)
다음 M개의 줄에 걸쳐 LCA를 구하고자 하는 두 정점 u, v가 주어집니다.

## 출력 형식
M개의 줄에 걸쳐 각 쿼리의 LCA 정점 번호를 한 줄에 하나씩 출력합니다.


```text

```

```text

```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
