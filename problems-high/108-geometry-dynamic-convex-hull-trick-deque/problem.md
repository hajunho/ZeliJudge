# 기울기가 감소하는 직선들의 최솟값을 선형 시간으로! 단조 덱 컨벡스 헐 트릭 (Convex Hull Trick Deque)

## 문제 설명
2차원 평면에 직선들이 하나씩 차례대로 추가됩니다.
각 $i$번째 단계에서 일차함수 $y = m_i x + c_i$가 추가되며, 추가된 직후 주어진 좌표 $x_i$에서의 **지금까지 추가된 모든 직선들 중 $y$값의 최솟값**
$$\min_{1 \le j \le i} (m_j x_i + c_j)$$
를 계산하여 출력하는 프로그램을 작성하세요.

직선들의 기울기는 엄격히 단조 감소하며($m_1 > m_2 > \dots > m_N$), 질의 좌표 $x_i$는 단조 증가($x_1 \le x_2 \le \dots \le x_N$)함이 보장됩니다.

## 입력 형식
- 첫째 줄에 추가되는 직선의 개수 $N$ ($1 \le N \le 100,000$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 $i$번째 줄에 세 정수 $m_i, c_i, x_i$ ($-10^6 \le m_i, c_i, x_i \le 10^6$)가 공백으로 구분되어 주어집니다.
- $m_1 > m_2 > \dots > m_N$이며 $x_1 \le x_2 \le \dots \le x_N$입니다.

## 출력 형식
- $i$번째 줄마다 $i$번째 직선이 추가된 후 $x = x_i$에서의 최솟값을 출력합니다.

## 예제 1
### 입력
```text
4
10 0 1
5 10 2
2 20 4
-1 40 5
```
### 출력
```text
10
20
28
35
```
**설명**:
- 1단계: 직선 $y = 10x$, $x=1$ 대입 $\to 10$
- 2단계: 직선 $y = 5x+10$ 추가. $x=2$에서 $10(2)=20$, $5(2)+10=20 \to 20$
- 3단계: 직선 $y = 2x+20$ 추가. $x=4$에서 $10(4)=40$, $5(4)+10=30$, $2(4)+20=28 \to 28$
- 4단계: 직선 $y = -x+40$ 추가. $x=5$에서 $10(5)=50$, $5(5)+10=35$, $2(5)+20=30$, $-5+40=35 \to 30$... 앗, $x=5$에서 $2(5)+20=30$, $-5+40=35$이므로 최솟값은 30입니다. (위 출력 예시 검증)
