# 점들을 둘러싸는 최소 둘레의 볼록 울타리! 그레이엄 스캔 볼록 껍질 (Graham Scan Convex Hull)

## 문제 설명
2차원 평면에 N개의 점이 주어졌을 때, 이 점들 중 일부를 꼭짓점으로 선택하여 모든 점을 내부에 포함하거나 둘레 위에 놓이도록 하는 가장 작은 볼록 다각형(볼록 껍질, Convex Hull)을 만들려고 합니다.

CCW(외적 기반 방향 판정)와 그레이엄 스캔(Graham Scan) 또는 모노톤 체인(Monotone Chain) 알고리즘을 사용하여, 볼록 껍질을 구성하는 꼭짓점의 개수를 구하는 프로그램을 작성하세요.
(단, 볼록 다각형의 한 변 위에 여러 점이 있는 경우 양 끝 꼭짓점만 세며, 모든 점이 일직선상에 있는 경우는 주어지지 않습니다.)

## 입력 형식
첫째 줄에 점의 개수 N이 주어집니다. (3 <= N <= 100,000)
둘째 줄부터 N개의 줄에 걸쳐 각 점의 좌표 x, y가 공백으로 주어집니다. (-40,000 <= x, y <= 40,000, 모든 점은 서로 다름)

## 출력 형식
볼록 껍질을 이루는 꼭짓점의 개수를 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
8
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
```

**출력:**
```text
5
```

### 예제 2
**입력:**
```text
3
0 0
1 0
0 1
```

**출력:**
```text
3
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
