# 두 개의 독립성을 동시에 만족하라! 매트로이드 교집합 (Matroid Intersection)

## 문제 설명
$V$개의 정점과 $E$개의 간선으로 이루어진 무향 그래프가 주어집니다.
각 간선은 $1$부터 $C$까지의 색상 중 하나로 칠해져 있습니다.

다음 두 가지 조건을 **동시에** 만족하도록 간선들을 선택하려고 합니다:
1. 선택한 간선들은 사이클을 형성하지 않아야 합니다 (포레스트 / 그래픽 매트로이드).
2. **어떤 색상도 2번 이상 선택될 수 없습니다** (각 색상당 최대 1개 / 분할 매트로이드).

선택할 수 있는 **간선의 최대 개수**를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정점의 수 $V$ ($1 \le V \le 50$), 간선의 수 $E$ ($1 \le E \le 200$), 색상의 수 $C$ ($1 \le C \le 200$)가 공백으로 구분되어 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 각 줄마다 간선이 잇는 두 정점 $u, v$ ($1 \le u < v \le V$)와 간선의 색상 $c$ ($1 \le c \le C$)가 주어집니다.

## 출력 형식
- 두 조건을 동시에 만족하는 선택 가능한 최대 간선의 개수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3 3 2
1 2 1
2 3 1
1 3 2
```
### 출력
```text
2
```
**설명**:
1번 색상 간선 2개와 2번 색상 간선 1개가 있습니다.
각 색상당 최대 1개만 선택 가능하므로 1번 색상 간선 중 하나와 2번 색상 간선 (1-3)을 선택하면 사이클 없이 크기 2를 얻습니다.

## 예제 2
### 입력
```text
3 3 3
1 2 1
2 3 2
1 3 3
```
### 출력
```text
2
```
**설명**: 3개의 간선이 모두 서로 다른 색상이지만, 3개를 모두 고르면 삼각형 사이클이 생기므로 최대 2개만 선택 가능합니다.
