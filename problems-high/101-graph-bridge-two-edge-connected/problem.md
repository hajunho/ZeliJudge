# 다리가 무너져도 고립되지 않는 섬들! 단절선과 2-간선 연결 요소 (Bridge & 2-Edge-Connected Components)

## 문제 설명
$N$개의 섬과 섬들을 양방향으로 잇는 $M$개의 다리가 있는 군도 국가가 있습니다.
모든 섬은 다리들을 통해 서로 오갈 수 있습니다(연결 그래프).

만약 태풍으로 인해 **단 하나의 다리**가 파괴되었을 때, 군도가 둘 이상의 구역으로 단절될 수 있는 위험한 다리를 **단절선(Bridge)**이라고 합니다.

단절선들을 모두 찾아 그 개수를 세고, 이 단절선들을 제거했을 때 남는 **2-간선 연결 요소(어떤 다리 하나가 끊겨도 상호 연결이 보장되는 안전한 구역들)**의 개수와 각 구역에 속한 섬의 개수들을 오름차순으로 정렬하여 출력하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 섬의 개수 $N$ ($1 \le N \le 10,000$)과 다리의 개수 $M$ ($1 \le M \le 50,000$)이 공백으로 구분되어 주어집니다.
- 둘째 줄부터 $M$개 줄에 걸쳐 각 다리가 잇는 두 섬의 번호 $u, v$ ($1 \le u, v \le N, u \ne v$)가 주어집니다. 다중 간선은 주어지지 않습니다.

## 출력 형식
- 첫째 줄에 단절선의 개수를 출력합니다.
- 둘째 줄에 2-간선 연결 요소의 개수를 출력합니다.
- 셋째 줄에 각 2-간선 연결 요소의 크기(속한 섬의 수)를 오름차순으로 정렬하여 공백으로 구분해 출력합니다.

## 예제 1
### 입력
```text
4 4
1 2
2 3
3 1
3 4
```
### 출력
```text
1
2
1 3
```
**설명**: 3번과 4번을 잇는 다리가 끊어지면 4번 섬이 고립되므로 단절선은 1개 (3-4)입니다. 이 다리를 제거하면 {4} (크기 1)와 {1, 2, 3} (크기 3)의 2개 컴포넌트로 나뉩니다.

## 예제 2
### 입력
```text
3 3
1 2
2 3
3 1
```
### 출력
```text
0
1
3
```
**설명**: 사이클을 이루므로 어떤 간선이 끊겨도 연결이 유지되어 단절선은 0개이며 전체가 하나의 2-간선 연결 요소입니다.
