# 서로소의 개수를 한 번에 체로 걸러라! 오일러 피 선형 체

## 문제 설명
자연수 $N$이 주어집니다.
$1$부터 $N$까지의 모든 자연수 $i$에 대해, 오일러 피 함수값 $\phi(i)$의 총합
$$\Phi(N) = \sum_{i=1}^N \phi(i)$$
을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 자연수 $N$ ($1 \le N \le 10,000,000$)이 주어집니다.

## 출력 형식
- $\sum_{i=1}^N \phi(i)$를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
5
```
### 출력
```text
10
```
**설명**: 
$\phi(1) = 1$, $\phi(2) = 1$, $\phi(3) = 2$, $\phi(4) = 2$, $\phi(5) = 4$.
합은 $1 + 1 + 2 + 2 + 4 = 10$입니다.

## 예제 2
### 입력
```text
10
```
### 출력
```text
32
```
