# 수많은 키워드를 한 번에 검출하라! 아호-코라식 다중 패턴 매칭 (Aho-Corasick Algorithm)

## 문제 설명
N개의 금칙어 단어 목록이 주어지고, 검사해야 할 긴 본문 텍스트 T가 주어집니다.
단어들을 하나씩 KMP로 찾으면 O(N x |T|)가 걸려 단어가 수만 개일 때 시스템이 마비됩니다.

단어들을 접두사 트리(Trie)로 구축한 뒤, BFS를 통해 KMP 실패 링크(Failure Link)를 연결하는 **아호-코라식(Aho-Corasick)** 알고리즘을 구현하여, 본문 T를 단 1번만 순회하며 본문에 포함된 금칙어들의 총 등장 횟수를 구하세요.

## 입력 형식
첫째 줄에 금칙어 단어의 개수 N이 주어집니다. (1 <= N <= 10,000)
다음 N개의 줄에 걸쳐 각 금칙어 단어가 주어집니다. (알파벳 소문자, 단어 길이 100 이하)
그 다음 줄에 본문 텍스트 T가 주어집니다. (알파벳 소문자, 1 <= len(T) <= 100,000)

## 출력 형식
본문 T 속에서 금칙어 단어들이 등장한 총 횟수를 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
4
he
she
his
hers
ushers
```

**출력:**
```text
3
```

### 예제 2
**입력:**
```text
2
a
b
abc
```

**출력:**
```text
2
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
