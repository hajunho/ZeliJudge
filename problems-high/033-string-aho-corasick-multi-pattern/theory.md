# 아호-코라식 (Aho-Corasick) 다중 패턴 매칭

## 1. 트라이(Trie) + BFS 실패 링크(Failure Link)
- 트라이의 각 노드에 대해, 매칭 실패 시 이동할 가장 긴 일치 접두사 노드를 BFS(너비 우선 탐색)로 찾아 연결합니다.
- 이는 KMP의 $\pi$ 실패 함수를 트리 구조로 확장한 것입니다.

## 2. 선형 탐색 보장
- 본문 $T$를 한 글자씩 읽으며 트라이의 상태 전이를 따릅니다.
- 실패 시 실패 링크를 타고 즉시 다음 후보 접두사로 이동하므로, 본문 길이 $|T|$에 비례하여 $O(|T| + \sum |P_i|)$에 전체 다중 매칭을 완료합니다.
