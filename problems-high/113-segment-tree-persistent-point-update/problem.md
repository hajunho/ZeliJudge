# 시간을 되돌려 과거의 배열을 질의하라! 영속 세그먼트 트리 (Persistent Segment Tree)

## 문제 설명
길이 $N$인 수열 $A_1, A_2, \dots, A_N$이 주어집니다. 초기 상태를 버전 $0$이라고 합니다.

다음 두 가지 쿼리를 처리하는 프로그램을 작성하세요:
1. `1 i v`: 가장 최근 버전의 수열에서 $i$번째 원소를 $v$로 변경하고, 이를 **새로운 버전**으로 저장합니다. (버전 번호가 1 증가)
2. `2 k l r`: 버전 $k$에서의 수열 구간 $[l, r]$의 원소들의 합 $\sum_{j=l}^r A_j$을 출력합니다. (버전이 생성되지 않음)

## 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 100,000$)과 쿼리의 개수 $Q$ ($1 \le Q \le 100,000$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, A_2, \dots, A_N$ ($0 \le A_i \le 10^9$)이 공백으로 구분되어 주어집니다.
- 셋째 줄부터 $Q$개 줄에 걸쳐 각 쿼리가 한 줄에 하나씩 주어집니다.

## 출력 형식
- 2번 쿼리가 주어질 때마다 구간 합을 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
5 5
1 2 3 4 5
2 0 1 5
1 3 10
2 0 1 5
2 1 1 5
2 1 3 3
```
### 출력
```text
15
15
22
10
```
**설명**:
- 버전 0의 1~5 합: $1+2+3+4+5 = 15$
- `1 3 10`으로 3번째 원소를 10으로 변경 $\to$ 버전 1 생성 ($[1, 2, 10, 4, 5]$)
- 버전 0의 1~5 합: 여전히 $15$ 유지!
- 버전 1의 1~5 합: $1+2+10+4+5 = 22$
- 버전 1의 3~3 합: $10$
