# 거대한 합성수의 숨겨진 약수 찾기! 폴라드-로 소인수분해 (Pollard's Rho Algorithm)

## 문제 설명
자연수 N이 주어졌을 때, N을 소인수분해하는 프로그램을 작성하세요.
단, N은 최대 10^18까지 주어집니다.

생일 역설(Birthday Paradox)과 $f(x) = (x^2 + c) \bmod N$ 수열, 그리고 플로이드 순환 탐지 알고리즘을 결합하여 합성수의 비자명한 약수를 O(N^{1/4}) 시간에 찾아내는 **폴라드-로(Pollard's Rho)** 알고리즘을 구현하세요.
밀러-라빈 소수 판별법과 재귀적으로 결합하여 모든 소인수를 오름차순으로 출력하세요.

## 입력 형식
첫째 줄에 자연수 N이 주어집니다. (2 <= N <= 1,000,000,000,000,000,000)

## 출력 형식
N의 모든 소인수를 크기 순서대로(오름차순) 한 줄에 하나씩 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
18991325453139
```

**출력:**
```text
3
3
13
179
271
1381
2423
```

### 예제 2
**입력:**
```text
2
```

**출력:**
```text
2
```
