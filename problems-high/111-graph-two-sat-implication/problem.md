# 참과 거짓의 그물망을 풀어라! 2-SAT 문제와 강결합 컴포넌트 (2-SAT SCC)

## 문제 설명
$N$개의 불리언 변수 $x_1, x_2, \dots, x_N$과 $M$개의 2-CNF 절이 주어집니다.
각 절은 $(l_1 \lor l_2)$ 형태이며, $l$이 양수 $i$이면 $x_i$, 음수 $-i$이면 $\neg x_i$를 의미합니다.

모든 절을 동시에 만족시키는 참(1) / 거짓(0) 할당이 존재하는지 판별하고, 존재한다면 각 변수의 참/거짓 값을 출력하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 변수의 개수 $N$ ($1 \le N \le 10,000$)과 절의 개수 $M$ ($1 \le M \le 100,000$)이 공백으로 구분되어 주어집니다.
- 둘째 줄부터 $M$개 줄에 걸쳐 각 줄마다 절을 구성하는 두 정수 $l_1, l_2$ ($-N \le l_1, l_2 \le N, l_1, l_2 \ne 0$)가 주어집니다.

## 출력 형식
- 만족시키는 할당이 존재한다면 첫째 줄에 `1`을 출력하고, 둘째 줄에 $x_1$부터 $x_N$까지의 진리값(참이면 `1`, 거짓이면 `0`)을 공백으로 구분하여 출력합니다. (가능한 해가 여러 개이면 그중 아무거나 하나 출력)
- 만족시키는 할당이 존재하지 않는다면 첫째 줄에 `0`만 출력합니다.

## 예제 1
### 입력
```text
3 4
1 2
-1 3
-2 -3
1 3
```
### 출력
```text
1
1 0 1
```
**설명**: $x_1=1, x_2=0, x_3=1$로 설정하면 모든 절 $(1 \lor 0), (0 \lor 1), (1 \lor 0), (1 \lor 1)$이 참이 됩니다.

## 예제 2
### 입력
```text
1 2
1 1
-1 -1
```
### 출력
```text
0
```
**설명**: $x_1$이 참이면서 동시에 거짓이어야 하므로 만족 불가능합니다.
