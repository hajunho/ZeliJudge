# 구간 안에서 k보다 큰 수는 몇 개? 머지 소트 트리 (Merge Sort Tree)

## 문제 설명
수열 A[1..N]이 주어집니다. 다음과 같은 형태의 질의 M개가 주어집니다:
- `l r k`: 부분 수열 $A[l..r]$에서 $k$보다 엄격히 큰 원소의 개수를 출력합니다.

단순 순회는 쿼리당 O(N)이 걸려 총 O(NM)으로 시간 초과가 발생합니다.
세그먼트 트리의 각 노드에 해당 구간의 원소들을 정렬된 리스트로 보관하는 **머지 소트 트리(Merge Sort Tree)**를 구축하고, 이진 탐색(`bisect_right`)을 활용하여 각 쿼리를 $O(\log^2 N)$ 시간에 처리하세요.

## 입력 형식
첫째 줄에 수열의 크기 N이 주어집니다. (1 <= N <= 100,000)
둘째 줄에 N개의 정수 $A_i$가 공백으로 주어집니다. (-1,000,000,000 <= $A_i$ <= 1,000,000,000)
셋째 줄에 쿼리의 개수 M이 주어집니다. (1 <= M <= 100,000)
다음 M개의 줄에 걸쳐 쿼리 l, r, k가 주어집니다. (1 <= l <= r <= N)

## 출력 형식
M개의 줄에 걸쳐 각 쿼리의 정답을 한 줄에 하나씩 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5
5 1 2 3 4
3
2 4 1
4 4 4
1 5 2
```

**출력:**
```text
2
0
3
```

### 예제 2
**입력:**
```text
3
10 20 30
2
1 3 15
1 2 25
```

**출력:**
```text
2
0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
