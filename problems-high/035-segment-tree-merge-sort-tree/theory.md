# 머지 소트 트리 (Merge Sort Tree)

## 1. 노드별 정렬 배열 유지
- 세그먼트 트리의 각 노드가 단일 스칼라 값이 아니라 **정렬된 서브배열(Sorted List)**을 가집니다.
- 두 자식 노드의 정렬된 리스트를 병합(Merge)하여 부모 노드를 생성하므로 트리 전체 구축에 $O(N \log N)$ 시간과 공간이 소요됩니다.

## 2. 쿼리 질의 ($O(\log^2 N)$)
- 질의 구간 `[l, r]`을 커버하는 $O(\log N)$개의 세그먼트 트리 노드를 찾습니다.
- 각 노드의 정렬된 리스트에서 $k$의 위치를 이진 탐색(`bisect_right`)으로 찾아 $k$보다 큰 원소 수를 $O(\log N)$에 카운트합니다.
- 따라서 쿼리당 $O(\log^2 N)$에 해결됩니다.
