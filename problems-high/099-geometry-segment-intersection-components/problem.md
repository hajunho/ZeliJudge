# 얽히고설킨 선분들을 그룹 짓다! 선분 교차와 분리 집합

## 문제 설명
2차원 평면 위에 $N$개의 선분이 주어집니다.
두 선분이 서로 만나거나 교차하면(끝점에서 만나는 경우 포함) 두 선분은 같은 그룹에 속합니다.
또한, 선분 $A$와 $B$가 같은 그룹이고 $B$와 $C$가 같은 그룹이면 $A$와 $C$도 같은 그룹에 속합니다.

주어진 선분들이 총 몇 개의 그룹으로 나뉘는지, 그리고 가장 큰 그룹에 속한 선분의 개수는 몇 개인지 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 선분의 개수 $N$ ($1 \le N \le 3,000$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐, 각 줄마다 선분의 양 끝점 좌표 $x_1, y_1, x_2, y_2$ ($-10^9 \le x_1, y_1, x_2, y_2 \le 10^9$)가 정수로 주어집니다.

## 출력 형식
- 첫째 줄에 총 그룹의 개수를 출력합니다.
- 둘째 줄에 가장 큰 그룹에 속한 선분의 개수를 출력합니다.

## 예제 1
### 입력
```text
3
1 1 2 3
2 1 0 0
1 0 1 1
```
### 출력
```text
2
2
```
**설명**: 1번 선분과 3번 선분이 점 $(1, 1)$에서 만나 같은 그룹(크기 2)을 형성하고, 2번 선분은 독립된 그룹(크기 1)을 이룹니다.

## 예제 2
### 입력
```text
3
-1 -1 1 1
-1 1 1 -1
0 2 2 0
```
### 출력
```text
2
2
```
