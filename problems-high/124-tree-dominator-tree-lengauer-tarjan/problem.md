# 모든 길목을 지배하는 절대자를 찾아라! 지배자 트리 (Dominator Tree)

## 문제 설명
$V$개의 정점과 $E$개의 방향성 단방향 도로로 이루어진 도시가 있습니다.
1번 정점이 도시의 중심 기지(루트 $r=1$)입니다.

도시의 어떤 정점 $v$ ($v \ne 1$)에 대해, 1번 기지에서 $v$로 이동할 때 **반드시 거쳐야만 하는 마지막 직전의 필수 검문소**를 $v$의 **즉각 지배자($idom(v)$)**라고 합니다.
모든 도달 가능한 정점 $v$ ($2 \le v \le V$)의 즉각 지배자 $idom(v)$를 구하는 프로그램을 작성하세요. (1번에서 도달할 수 없는 정점의 $idom$은 0으로 처리합니다.)

## 입력 형식
- 첫째 줄에 정점의 개수 $V$ ($1 \le V \le 10,000$)와 간선의 개수 $E$ ($1 \le E \le 50,000$), 그리고 시작 정점 $r=1$이 공백으로 구분되어 주어집니다.
- 둘째 줄부터 $E$개 줄에 걸쳐 각 단방향 간선 $u \to v$ ($1 \le u, v \le V$)가 주어집니다.

## 출력 형식
- 2번 정점부터 $V$번 정점까지, 각 정점의 즉각 지배자 $idom(v)$ 번호를 공백으로 구분하여 한 줄에 출력합니다.

## 예제 1
### 입력
```text
4 4 1
1 2
2 3
3 4
1 4
```
### 출력
```text
1 2 1
```
**설명**:
- 1에서 2로 가는 유일한 길목은 1 $\to idom(2) = 1$
- 1에서 3으로 가려면 반드시 2를 통과해야 함 $\to idom(3) = 2$
- 1에서 4로 가는 길은 1->4와 1->2->3->4 두 갈래가 있으므로 공통 길목은 1뿐임 $\to idom(4) = 1$

## 예제 2
### 입력
```text
3 3 1
1 2
2 3
1 3
```
### 출력
```text
1 1
```
