# 끝없는 평면들을 잘라 핵을 도출하라! 반평면 교집합 (Half-plane Intersection)

## 문제 설명
2차원 평면 위에 $N$개의 유향 선분(직선)이 주어집니다.
각 직선은 점 $A(x_1, y_1)$에서 점 $B(x_2, y_2)$로 향하며, 진행 방향의 **왼쪽 영역**(CCW $> 0$ 또는 온전한 왼쪽 반평면)이 유효한 영역입니다.

모든 반평면들의 공통 교집합으로 생기는 볼록 다각형 영역의 **넓이**를 구하는 프로그램을 작성하세요.
단, 교집합 영역은 항상 유계(Bounded, 닫힌 유한 다각형)이거나 공집합임이 보장됩니다.

## 입력 형식
- 첫째 줄에 반평면을 정의하는 직선의 개수 $N$ ($3 \le N \le 1,000$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 각 줄마다 네 정수 $x_1, y_1, x_2, y_2$ ($-1,000 \le x_1, y_1, x_2, y_2 \le 1,000$)가 공백으로 구분되어 주어집니다. ($A \to B$ 벡터의 왼쪽이 유효 영역)

## 출력 형식
- 공통 교집합 볼록 다각형의 넓이를 소수점 둘째 자리까지 반올림하여 출력합니다. 교집합 영역이 없거나 넓이가 0이면 `0.00`을 출력합니다.

## 예제 1
### 입력
```text
4
0 0 10 0
10 0 10 10
10 10 0 10
0 10 0 0
```
### 출력
```text
100.00
```
**설명**: 
원점 $(0,0)$에서 $(10,0)$, $(10,10)$, $(0,10)$을 반시계 방향으로 도는 4개의 직선입니다.
진행 방향의 왼쪽 영역의 교집합은 가로 10, 세로 10의 정사각형이 되므로 넓이는 $100.00$입니다.

## 예제 2
### 입력
```text
3
0 0 5 0
5 0 0 5
0 5 0 0
```
### 출력
```text
12.50
```
**설명**: 밑변 5, 높이 5인 직각이등변삼각형 영역으로 넓이는 $5 \times 5 / 2 = 12.50$입니다.
