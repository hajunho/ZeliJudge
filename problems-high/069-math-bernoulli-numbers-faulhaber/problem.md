# 자연수 거듭제곱의 합을 단숨에! 베르누이 수와 파울하버 공식

## 문제 설명
자연수 $N$과 거듭제곱 지수 $k$가 주어집니다.
$1$부터 $N$까지의 자연수의 $k$제곱의 합
$$S_k(N) = \sum_{i=1}^N i^k = 1^k + 2^k + 3^k + \dots + N^k$$
을 구하는 프로그램을 작성하세요.

답이 매우 클 수 있으므로 $10^9+7$로 나눈 나머지를 출력합니다.

## 입력 형식
- 첫째 줄에 정수 $N$ ($1 \le N \le 10^{18}$)과 지수 $k$ ($1 \le k \le 1000$)가 공백으로 구분되어 주어집니다.

## 출력 형식
- $S_k(N) \pmod{10^9+7}$을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
10 1
```
### 출력
```text
55
```
**설명**: $1 + 2 + \dots + 10 = 55$입니다.

## 예제 2
### 입력
```text
5 2
```
### 출력
```text
55
```
**설명**: $1^2 + 2^2 + 3^2 + 4^2 + 5^2 = 1 + 4 + 9 + 16 + 25 = 55$입니다.

## 예제 3
### 입력
```text
1000000000 3
```
### 출력
```text
250000007
```
