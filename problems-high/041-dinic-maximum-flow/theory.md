# 디닉 (Dinic) 알고리즘

## 1. 레벨 그래프 (Level Graph)
- 소스로부터 BFS를 수행하여 각 노드의 최단 거리(레벨, `level[u]`)를 매깁니다.
- 싱크에 도달하지 못하면(`level[sink] == -1`) 더 이상 증가 경로가 없으므로 종료합니다.

## 2. 블로킹 유량 (Blocking Flow)과 Work 포인터
- DFS 탐색 시 오직 레벨이 1 증가하는 간선(`level[v] == level[u] + 1`)만을 따라 유량을 밀어냅니다.
- `work[u]` 포인터를 두어 이미 포화되었거나 막힌 간선을 다음 DFS에서 재방문하지 않도록 건너뜁니다.
- 일반 그래프에서 $O(V^2 E)$, 특히 이분 매칭 유량 네트워크에서는 $O(E \sqrt{V})$로 동작합니다.
