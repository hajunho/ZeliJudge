# 이론 및 해설: 슬라이딩 윈도우 속 최댓값을 잡다! 단조 큐 최적화 DP (Monotonic Queue DP)

### 단조 큐 최적화 DP (Monotonic Queue DP)

다음과 같이 최근 $K$개 범위 내의 이전 상태에 의존하는 DP 점화식
$$DP[i] = \max_{i-K \le j < i} (DP[j]) + A[i]$$
은 일반적인 탐색 시 $O(NK)$가 소요됩니다.

1. **단조 큐의 원리**:
   - 덱(Deque)에 `(인덱스, DP값)`을 저장하되, DP값이 단조 감소(Monotonically Decreasing)하도록 유지합니다.
   - 새로운 원소 $DP[i-1]$을 덱의 뒤(back)에 넣을 때, 이보다 작거나 같은 기존 원소들은 앞으로 영원히 최적값이 될 수 없으므로 모두 `pop_back()`합니다.
   - 덱의 앞(front)에 위치한 원소 중 인덱스가 $i - K$ 미만인 원소는 슬라이딩 윈도우 범위를 벗어났으므로 `pop_front()`합니다.
   - 덱의 맨 앞 원소가 항상 구간 $[i-K, i-1]$ 내의 최댓값을 유지하므로, $O(1)$에 최적값을 참조할 수 있습니다.
2. **시간 복잡도**:
   - 모든 인덱스는 덱에 정확히 한 번 삽입되고 최대 한 번 제거되므로 전체 시간 복잡도는 $O(N)$입니다.
