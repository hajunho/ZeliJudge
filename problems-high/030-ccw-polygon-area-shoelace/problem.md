# 신발끈 공식으로 다각형 넓이 구하기! 신발끈 정리 (Shoelace Formula)

## 문제 설명
2차원 평면 위에 N개의 꼭짓점으로 이루어진 단순 다각형(Simple Polygon)이 주어집니다.
꼭짓점들은 다각형의 둘레를 따라 시계 방향 또는 반시계 방향 순서대로 주어집니다.
이 다각형의 면적(넓이)을 구하는 프로그램을 작성하세요.
오목 다각형이든 볼록 다각형이든 상관없이 항상 정확한 넓이를 계산해 주는 **신발끈 공식(Shoelace Formula, Gauss's Area Formula)**을 구현하세요.

## 입력 형식
첫째 줄에 다각형 꼭짓점의 개수 N이 주어집니다. (3 <= N <= 10,000)
둘째 줄부터 N개의 줄에 걸쳐 각 꼭짓점의 좌표 x, y가 공백으로 주어집니다. (-100,000 <= x, y <= 100,000)

## 출력 형식
다각형의 면적을 소수점 아래 둘째 자리에서 반올림하여 첫째 자리까지 출력합니다. (예: 12.0, 7.5)

## 입출력 예제

### 예제 1
**입력:**
```text
4
0 0
0 10
10 10
10 0
```

**출력:**
```text
100.0
```

### 예제 2
**입력:**
```text
3
0 0
4 0
0 3
```

**출력:**
```text
6.0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
