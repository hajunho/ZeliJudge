# 불일치 시 접두사로 점프! KMP 문자열 패턴 매칭 (Knuth-Morris-Pratt KMP)

## 문제 설명
긴 본문 문자열 T에서 특정 패턴 문자열 P가 등장하는 모든 위치를 찾으려고 합니다.
단순한 브루트포스 매칭은 최악의 경우 O(N x M)이 걸려 시간 초과가 발생합니다.

일치했던 정보(접두사와 접미사가 일치하는 최대 길이)를 담은 실패 함수(Failure Function, pi 배열)를 전처리하여, 불일치가 발생했을 때 본문 포인터를 뒤로 되돌리지 않고 O(N + M)에 탐색을 완료하는 KMP 알고리즘을 구현하세요.

## 입력 형식
첫째 줄에 본문 문자열 T가 주어집니다. (1 <= len(T) <= 1,000,000)
둘째 줄에 찾고자 하는 패턴 문자열 P가 주어집니다. (1 <= len(P) <= 1,000,000)

## 출력 형식
첫째 줄에 T에서 P가 매칭된 총 횟수를 출력합니다.
둘째 줄에 P가 나타나는 시작 인덱스(1-based)를 오름차순으로 공백으로 구분하여 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
ABC ABCDAB ABCDABCDABDE
ABCDABD
```

**출력:**
```text
1
16
```

### 예제 2
**입력:**
```text
AAAAA
AA
```

**출력:**
```text
4
1 2 3 4
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
