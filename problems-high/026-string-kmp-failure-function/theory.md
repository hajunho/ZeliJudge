# KMP (Knuth-Morris-Pratt) 알고리즘

## 1. 실패 함수 $\pi[i]$
- $\pi[i]$: 패턴 $P[0..i]$의 부분 문자열 중 접두사(Prefix)이면서 접미사(Suffix)인 가장 긴 문자열의 길이
- 패턴 자체에 대해 KMP 투 포인터를 적용하여 $O(M)$ 시간에 생성합니다.

## 2. 점프 매칭 원리
- 본문 $T[i]$와 패턴 $P[j]$를 비교하다가 불일치가 발생하면, 패턴 포인터 $j$를 $\pi[j-1]$로 점프시킵니다.
- 이미 일치했던 접두사 부분을 다시 비교하지 않고 건너뛰므로, 본문 포인터 $i$는 오직 앞으로만 전진합니다.
