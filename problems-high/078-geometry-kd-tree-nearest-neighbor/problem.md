# 공간을 절반씩 쪼개어 가장 가까운 점을 찾아라! 2D k-d 트리

## 문제 설명
2차원 평면 위에 $N$개의 점이 주어집니다.
이후 주어지는 $Q$개의 질의점 $(qx, qy)$에 대해, 평면 위의 $N$개 점들 중 질의점과 가장 가까운 점까지의 **거리의 제곱**을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 평면 위 점의 개수 $N$ ($1 \le N \le 100,000$)과 질의의 개수 $Q$ ($1 \le Q \le 10,000$)가 공백으로 구분되어 주어집니다.
- 다음 $N$개 줄에 각 줄마다 점의 좌표 $x, y$ ($-10^9 \le x, y \le 10^9$)가 주어집니다.
- 다음 $Q$개 줄에 각 줄마다 질의점의 좌표 $qx, qy$ ($-10^9 \le qx, qy \le 10^9$)가 주어집니다.

## 출력 형식
- 각 질의마다 가장 가까운 점까지의 거리의 제곱을 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
5 3
2 3
5 4
9 6
4 7
8 1
2 3
7 2
0 0
```
### 출력
```text
0
2
13
```

## 예제 2
### 입력
```text
3 2
0 10
0 20
0 30
0 15
0 50
```
### 출력
```text
25
400
```
