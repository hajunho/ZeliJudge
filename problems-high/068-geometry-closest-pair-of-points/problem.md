# 평면 위 가장 가까운 두 별! 최근접 점의 쌍 (Closest Pair of Points)

## 문제 설명
2차원 평면 위에 $N$개의 점이 주어집니다.
이 점들 중에서 가장 가까운 두 점 사이의 거리의 제곱을 구하는 프로그램을 작성하세요.

두 점 $(x_1, y_1)$과 $(x_2, y_2)$ 사이의 거리의 제곱은 $(x_1 - x_2)^2 + (y_1 - y_2)^2$입니다.

## 입력 형식
- 첫째 줄에 점의 개수 $N$ ($2 \le N \le 100,000$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐, 각 줄마다 점의 좌표를 나타내는 두 정수 $x, y$ ($-10^9 \le x, y \le 10^9$)가 공백으로 구분되어 주어집니다.
- 같은 위치에 여러 점이 주어질 수도 있습니다.

## 출력 형식
- 가장 가까운 두 점 사이의 거리의 제곱을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
4
0 0
10 10
0 10
10 0
```
### 출력
```text
100
```
**설명**: $(0, 0)$과 $(0, 10)$ 사이의 거리의 제곱은 $0^2 + 10^2 = 100$이며, 이것이 최소입니다.

## 예제 2
### 입력
```text
5
0 0
1 1
2 4
3 9
4 16
```
### 출력
```text
2
```
**설명**: $(0, 0)$과 $(1, 1)$ 사이의 거리의 제곱은 $(1-0)^2 + (1-0)^2 = 2$입니다.
