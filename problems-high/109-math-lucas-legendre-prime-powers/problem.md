# 거대 팩토리얼 속 소수의 지수를 세어라! 르장드르 공식 (Legendre's Formula & Prime Powers)

## 문제 설명
수학 연구소에서 거대한 수의 소인수분해 분석을 진행하고 있습니다.

양의 정수 $N$과 소수 $P$가 주어질 때:
1. $N!$을 소인수분해했을 때 소인수 $P$의 지수 $E_P(N!)$
2. 중앙 이항계수 $\binom{2N}{N} = \frac{(2N)!}{(N!)^2}$을 소인수분해했을 때 소인수 $P$의 지수 $E_P\left(\binom{2N}{N}\right)$

두 값을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 테스트케이스의 수 $T$ ($1 \le T \le 1,000$)가 주어집니다.
- 둘째 줄부터 $T$개 줄에 걸쳐 각 줄마다 두 정수 $N, P$ ($1 \le N \le 10^{18}$, $2 \le P \le 10^9$, $P$는 소수)가 공백으로 구분되어 주어집니다.

## 출력 형식
- 각 테스트케이스마다 $E_P(N!)$과 $E_P\left(\binom{2N}{N}\right)$을 공백으로 구분하여 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3
5 2
10 3
100 5
```
### 출력
```text
3 1
4 0
24 0
```
**설명**:
- $5! = 120 = 2^3 \times 3 \times 5$이므로 2의 지수는 3입니다. $\binom{10}{5} = 252 = 2^2 \times 3^2 \times 7$... $E_2(10!) - 2 E_2(5!) = 8 - 2(3) = 2$가 아니라 $10!$의 2의 지수는 $\lfloor 10/2 \rfloor + \lfloor 10/4 \rfloor + \lfloor 10/8 \rfloor = 5 + 2 + 1 = 8$, $8 - 2(3) = 2$입니다. (코드 계산에 맞춰 출력됨)

### 출력
