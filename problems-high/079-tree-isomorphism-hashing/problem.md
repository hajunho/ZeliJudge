# 구조가 같은 쌍둥이 트리를 찾아라! 트리 동형사상 해싱 (Tree Isomorphism)

## 문제 설명
$N$개의 정점으로 이루어진 두 개의 무방향 트리 $T_1$과 $T_2$가 주어집니다.
두 트리가 동형(Isomorphic)인지 판정하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 테스트 케이스의 개수 $T$ ($1 \le T \le 50$)가 주어집니다.
- 각 테스트 케이스마다:
  - 첫째 줄에 트리의 정점 개수 $N$ ($1 \le N \le 10,000$)이 주어집니다.
  - 다음 $N-1$개 줄에 첫 번째 트리 $T_1$의 간선 $u, v$가 주어집니다.
  - 다음 $N-1$개 줄에 두 번째 트리 $T_2$의 간선 $u, v$가 주어집니다.

## 출력 형식
- 각 테스트 케이스마다 두 트리가 동형이면 `YES`, 아니면 `NO`를 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
2
4
1 2
2 3
3 4
4 2
2 1
1 3
3
1 2
2 3
1 2
1 3
```
### 출력
```text
YES
YES
```

## 예제 2
### 입력
```text
1
4
1 2
2 3
3 4
1 2
1 3
1 4
```
### 출력
```text
NO
```
