# 비트를 반대로 뒤집어 최대를 만들어라! 0-1 트라이 (0-1 Trie)

## 문제 설명
$N$개의 음이 아닌 정수로 이루어진 수열 $A_1, A_2, \dots, A_N$이 주어집니다.
서로 다른 두 수 $A_i, A_j$ ($1 \le i < j \le N$)를 골랐을 때, 배타적 논리합(XOR) 값 $A_i \oplus A_j$의 최댓값을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정수의 개수 $N$ ($2 \le N \le 100,000$)이 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, A_2, \dots, A_N$ ($0 \le A_i \le 10^9$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- 서로 다른 두 원소의 XOR 최댓값을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
4
3 10 5 25
```
### 출력
```text
28
```
**설명**: $5 \oplus 25 = 28$ ($00101_{(2)} \oplus 11001_{(2)} = 11100_{(2)} = 28$)이 최대입니다.

## 예제 2
### 입력
```text
3
1 2 3
```
### 출력
```text
3
```
**설명**: $1 \oplus 2 = 3$이 최대입니다.
