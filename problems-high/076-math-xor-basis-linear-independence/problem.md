# 비트 공간의 기저를 찾아라! XOR 기저 집합 (XOR Basis)

## 문제 설명
$N$개의 음이 아닌 정수 $A_1, A_2, \dots, A_N$이 주어집니다.
이 수들 중 0개 이상의 원소를 임의로 골라 만들 수 있는 부분집합 XOR 합의 최댓값을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 정수의 개수 $N$ ($1 \le N \le 100,000$)이 주어집니다.
- 둘째 줄에 $N$개의 정수 $A_1, A_2, \dots, A_N$ ($0 \le A_i \le 10^{18}$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- 가능한 부분집합 XOR 합의 최댓값을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3
12 4 8
```
### 출력
```text
12
```

## 예제 2
### 입력
```text
3
1 2 4
```
### 출력
```text
7
```
