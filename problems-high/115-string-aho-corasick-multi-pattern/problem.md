# 본문 한 번 스캔으로 수많은 단어를 사냥하라! 아호-코라식 (Aho-Corasick)

## 문제 설명
인터넷 필터링 시스템에서 $K$개의 금지어 단어 목록이 주어집니다.
긴 게시글 본문 텍스트 $T$가 주어질 때, 본문 안에 **금지어들이 등장하는 총 횟수**를 구하는 프로그램을 작성하세요.

서로 다른 금지어가 겹치는 위치에서 등장하거나, 동일한 금지어가 여러 번 등장하는 경우 모두 각각 개별 횟수로 합산합니다.

## 입력 형식
- 첫째 줄에 금지어의 개수 $K$ ($1 \le K \le 1,000$)가 주어집니다.
- 둘째 줄부터 $K$개 줄에 걸쳐 각 금지어 문자열 $P_i$ ($1 \le |P_i| \le 100$)가 주어집니다.
- 다음 줄에 본문 텍스트 $T$ ($1 \le |T| \le 100,000$)가 주어집니다.
- 모든 문자열은 알파벳 소문자로만 구성됩니다.

## 출력 형식
- 본문 $T$ 안에서 금지어들이 등장한 총 횟수를 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3
he
she
hers
ushers
```
### 출력
```text
3
```
**설명**: 
본문 `ushers`:
- `she`: 인덱스 1~3 (`ushe`...) $\to$ 1회
- `he`: 인덱스 2~3 (`ushe`...) $\to$ 1회
- `hers`: 인덱스 2~5 (`ushers`) $\to$ 1회
총 3회 등장합니다.

## 예제 2
### 입력
```text
2
a
aa
aaa
```
### 출력
```text
5
```
**설명**:
- `a`: 0, 1, 2 위치에서 3회
- `aa`: 0~1, 1~2 위치에서 2회
총합 5회 등장합니다.
