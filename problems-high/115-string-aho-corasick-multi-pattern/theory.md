# 본문 한 번 스캔으로 수많은 단어를 사냥하라! 아호-코라식 (Aho-Corasick)

## 핵심 개념 및 알고리즘 개요
- **태그**: 문자열, 아호-코라식(Aho-Corasick), 트라이(Trie), KMP 실패 함수, 다중 패턴 매칭, $O(|T| + \sum |P|)$
- **핵심 요약**: 여러 패턴 문자열들로 구축한 트라이에 KMP 실패 링크를 연결하여 본문 전체에서 패턴 매칭 총 횟수를 선형 시간에 구합니다.

---

### 아호-코라식 (Aho-Corasick) 다중 패턴 매칭

하나의 긴 본문 텍스트 $T$에서 $K$개의 서로 다른 패턴 $P_1, P_2, \dots, P_K$의 출현을 동시에 찾는 알고리즘입니다.
단순 KMP를 $K$번 돌리면 $O(K |T|)$가 걸리지만, 아호-코라식은 **$O(|T| + \sum |P_i|)$**의 선형 시간에 해결합니다.

1. **트라이(Trie) 구축**:
   - $K$개의 모든 패턴을 트라이에 삽입합니다.
   - 각 노드는 어떤 패턴 접두사를 나타냅니다.

2. **실패 링크 (Failure Link) 구축 (BFS)**:
   - 루트의 직속 자식들의 실패 링크는 루트($0$)로 설정합니다.
   - BFS 순서로 노드 $u$의 자식 $v$ (간선 문자 $c$)에 대해:
     - 부모 $u$의 실패 링크를 타고 올라가며 문자 $c$로 갈 수 있는 가장 긴 일치 접미사 노드를 찾아 $v$의 실패 링크로 연결합니다.
   - 패턴의 끝 노드라면 매칭 카운트(`cnt[v]`)를 기록하고, 실패 링크를 통해 누적 매칭 정보도 전파합니다.

3. **본문 탐색 (Text Scan)**:
   - 본문 문자열을 한 글자씩 읽으며 트라이 전이를 따릅니다.
   - 매칭되지 않으면 실패 링크를 타고 이동하며, 각 상태에 도달할 때마다 매칭된 패턴들의 개수를 누적 합산합니다.

---

## 복잡도 분석
- **시간 복잡도**: 본문 이론 및 구현 참조
- **공간 복잡도**: $O(N)$ 또는 $O(V + E)$

## 추천 연습 문제
- 관련 백준(BOJ) 및 Codeforces / ICPC 기출 고난도 문제
