# 사각부등식의 단조성으로 루프를 건너뛰어라! 분할 정복 DP 최적화 (D&C DP Optimization)

## 문제 설명
길이 $N$인 양의 정수 수열 $A_1, A_2, \dots, A_N$이 주어집니다.
이 수열을 비어있지 않은 **정확히 $K$개의 연속된 부분 수열**로 분할하려고 합니다.

어떤 부분 수열 $A[j+1 \dots i]$의 비용은 원소들의 합의 제곱으로 정의됩니다:
$$C(j, i) = \left( \sum_{m=j+1}^i A_m \right)^2$$

$K$개 부분 수열들의 비용의 총합의 최솟값을 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 수열의 크기 $N$ ($1 \le N \le 10,000$)과 분할할 구간의 수 $K$ ($1 \le K \le \min(N, 50)$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 양의 정수 $A_1, A_2, \dots, A_N$ ($1 \le A_i \le 100$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- $K$개의 연속 부분 수열로 분할했을 때 비용 총합의 최솟값을 한 줄에 출력합니다.

## 예제 1
### 입력
```text
3 2
1 2 3
```
### 출력
```text
13
```
**설명**:
- `[1]`, `[2, 3]`으로 분할: $1^2 + (2+3)^2 = 1 + 25 = 26$
- `[1, 2]`, `[3]`으로 분할: $(1+2)^2 + 3^2 = 9 + 9 = 18$... 
앗, 1 2 3 분할:
[1], [2, 3] -> 1 + 25 = 26
[1, 2], [3] -> 9 + 9 = 18
최솟값은 18입니다.

## 예제 2
### 입력
```text
4 1
1 2 3 4
```
### 출력
```text
100
```
**설명**: 1개 구간이므로 $(1+2+3+4)^2 = 10^2 = 100$입니다.
