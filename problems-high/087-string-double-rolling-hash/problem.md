# 두 개의 소수로 충돌을 완벽 방어하라! 더블 롤링 해시 (Double Rolling Hash)

## 문제 설명
길이 $N$인 문자열 $S$가 주어집니다.
다음과 같은 $Q$개의 질의를 처리하는 프로그램을 작성하세요:

- `l1 r1 l2 r2`: $S$의 부분문자열 $S[l1 \dots r1]$과 $S[l2 \dots r2]$가 완전히 동일한 문자열인지 판정합니다. (1-indexed)

## 입력 형식
- 첫째 줄에 문자열 $S$ ($1 \le |S| \le 200,000$)가 주어집니다.
- 둘째 줄에 질의의 개수 $Q$ ($1 \le Q \le 100,000$)가 주어집니다.
- 다음 $Q$개 줄에 걸쳐 각 줄마다 네 정수 $l1, r1, l2, r2$ ($1 \le l1 \le r1 \le |S|$, $1 \le l2 \le r2 \le |S|$)가 주어집니다.

## 출력 형식
- 각 질의마다 두 부분문자열이 같으면 `YES`, 다르면 `NO`를 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
abacaba
4
1 3 5 7
1 4 4 7
2 2 6 6
1 7 1 7
```
### 출력
```text
YES
NO
YES
YES
```

## 예제 2
### 입력
```text
aaaaa
2
1 2 3 4
1 3 2 5
```
### 출력
```text
YES
NO
```
