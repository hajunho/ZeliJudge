# 명제들의 참/거짓을 만족시켜라! 2-SAT과 강결합 컴포넌트 (2-SAT with SCC)

## 문제 설명
2-CNF(2-Conjunctive Normal Form) 형태의 논리 명제식이 주어집니다.
이 식은 $M$개의 절(Clause)로 이루어져 있으며, 각 절은 $(x_i \lor x_j)$ 형태로 두 변수의 논리합으로 구성됩니다.
각 변수는 $1$부터 $N$까지의 번호를 가지며, 음수 $-k$는 $\neg x_k$ (NOT $x_k$)를 의미합니다.

이 전체 논리식을 참(True)으로 만들 수 있는 각 변수의 참/거짓 할당이 존재하는지 판별하는 프로그램을 작성하세요.
논리 함의 관계($\neg A \implies B$, $\neg B \implies A$)를 방향 그래프로 변환하고 타잔(Tarjan) SCC 알고리즘으로 모순 여부를 $O(N + M)$에 판별하세요.

## 입력 형식
첫째 줄에 변수의 개수 N과 절의 개수 M이 공백으로 주어집니다. (1 <= N, M <= 10,000)
둘째 줄부터 M개의 줄에 걸쳐 각 절을 나타내는 두 정수 i, j가 주어집니다. (-N <= i, j <= N, i, j != 0)

## 출력 형식
식을 만족시키는 변수 할당이 가능하면 1을, 불가능하면 0을 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
3 4
1 2
-1 3
2 -3
-2 -3
```

**출력:**
```text
1
```

### 예제 2
**입력:**
```text
1 2
1 1
-1 -1
```

**출력:**
```text
0
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
