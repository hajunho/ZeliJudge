# 수열의 비밀을 푸는 최소 다항식! 베릴레캄프-매시 (Berlekamp-Massey)

## 문제 설명
정수 수열 $s_0, s_1, \dots, s_{N-1}$이 주어집니다.
이 수열을 생성하는 최소 차수 $L$의 선형 점화식
$$s_i = \sum_{j=1}^L c_j s_{i-j} \pmod{10^9+7}$$
을 구하는 프로그램을 작성하세요.

단, 모든 $s_i$가 $0$인 경우 차수 $L = 0$입니다.

## 입력 형식
- 첫째 줄에 수열의 길이 $N$ ($1 \le N \le 500$)이 주어집니다.
- 둘째 줄에 수열의 원소 $s_0, s_1, \dots, s_{N-1}$ ($0 \le s_i < 10^9+7$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- 첫째 줄에 최소 차수 $L$을 출력합니다.
- 둘째 줄에 점화식의 계수 $c_1, c_2, \dots, c_L$을 공백으로 구분하여 출력합니다. 만약 $L = 0$인 경우 둘째 줄은 출력하지 않거나 빈 줄을 출력합니다.

## 예제 1
### 입력
```text
6
1 1 2 3 5 8
```
### 출력
```text
2
1 1
```
**설명**: 피보나치 수열이므로 $s_i = 1 \cdot s_{i-1} + 1 \cdot s_{i-2}$가 성립하며 차수는 $2$, 계수는 `1 1`입니다.

## 예제 2
### 입력
```text
5
1 2 4 8 16
```
### 출력
```text
1
2
```
**설명**: 등비수열이므로 $s_i = 2 \cdot s_{i-1}$ ($L=1$, 계수 `2`)입니다.
