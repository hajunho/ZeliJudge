# 다각형을 삼각형으로 쪼개는 최소 비용! 볼록 다각형 삼각분할 DP (Convex Polygon Triangulation)

## 문제 설명
2차원 평면 위에 $N$개의 점으로 이루어진 **볼록 다각형**이 주어집니다. 꼭짓점들은 시계 방향 순서대로 $1$번부터 $N$번까지 번호가 매겨져 있습니다.

이 볼록 다각형의 내부에서 서로 교차하지 않는 대각선들을 그어 정확히 $N-2$개의 삼각형으로 분할하려고 합니다.
분할된 모든 삼각형들의 둘레(세 변의 유클리드 길이의 합)의 총합을 최소화하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 볼록 다각형 꼭짓점의 수 $N$ ($3 \le N \le 100$)이 주어집니다.
- 둘째 줄부터 $N$개 줄에 걸쳐 각 줄마다 꼭짓점의 정수 좌표 $x, y$ ($-1,000 \le x, y \le 1,000$)가 시계 방향 순서로 주어집니다.

## 출력 형식
- 분할된 삼각형들의 둘레 총합의 최솟값을 소수점 넷째 자리까지 반올림하여 출력합니다.

## 예제 1
### 입력
```text
4
0 0
0 1
1 1
1 0
```
### 출력
```text
6.8284
```
**설명**: 
한 변의 길이가 1인 정사각형입니다. 
대각선 하나의 길이는 $\sqrt{2} \approx 1.4142$입니다.
어느 대각선으로 분할하든 두 직각이등변삼각형이 생기며, 각 둘레는 $1 + 1 + \sqrt{2} \approx 3.4142$입니다.
둘레의 합은 $2 \times 3.414213... \approx 6.8284$입니다.

## 예제 2
### 입력
```text
3
0 0
3 0
0 4
```
### 출력
```text
12.0000
```
**설명**: 이미 삼각형이므로 세 변의 길이 $3 + 4 + 5 = 12.0000$입니다.
