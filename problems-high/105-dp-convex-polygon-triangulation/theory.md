# 다각형을 삼각형으로 쪼개는 최소 비용! 볼록 다각형 삼각분할 DP (Convex Polygon Triangulation)

## 핵심 개념 및 알고리즘 개요
- **태그**: 동적 계획법(DP), 기하학, 다각형 삼각분할(Polygon Triangulation), 구간 DP, $O(N^3)$
- **핵심 요약**: 볼록 다각형을 서로 교차하지 않는 대각선으로 $N-2$개의 삼각형으로 분할할 때 둘레 합의 최솟값을 구간 DP로 구합니다.

---

### 볼록 다각형의 최소 가중 삼각분할 (Minimum Weight Triangulation)

볼록 다각형의 꼭짓점이 시계 방향으로 $0, 1, \dots, N-1$로 정렬되어 있을 때, 서로 교차하지 않는 대각선을 그어 다각형을 $N-2$개의 삼각형으로 분할합니다.

1. **부분 문제 정의**:
   - $DP(i, j)$: 꼭짓점 $i, i+1, \dots, j$로 이루어진 다각형을 삼각분할할 때 필요한 삼각형들의 둘레의 최소 합.
   - $j - i < 2$: 꼭짓점이 2개 이하이므로 삼각형을 만들 수 없음 ($DP(i, j) = 0$).
   - $j - i = 2$: 세 꼭짓점 $i, i+1, j$로 이루어진 단 하나의 삼각형 $(\text{perimeter}(i, i+1, j))$.

2. **점화식**:
   - 간선 $(i, j)$를 한 변으로 공유하는 세 번째 꼭짓점 $k$ ($i < k < j$)를 선택합니다.
   - 삼각형 $(i, k, j)$가 형성되면, 남은 영역은 두 개의 독립적인 부분 다각형 $(i, \dots, k)$와 $(k, \dots, j)$로 분할됩니다:
   $$DP(i, j) = \min_{i < k < j} \Big( DP(i, k) + DP(k, j) + \text{cost}(i, k, j) \Big)$$
   - 여기서 $\text{cost}(i, k, j) = \text{dist}(i, k) + \text{dist}(k, j) + \text{dist}(j, i)$입니다.

3. **시간 복잡도**:
   - 구간 길이 $len = j - i + 1$을 $3$부터 $N$까지 증가시키며 계산합니다.
   - 상태 수 $O(N^2)$, 각 상태 전이 $O(N)$이므로 총 시간 복잡도는 **$O(N^3)$**입니다.

---

## 복잡도 분석
- **시간 복잡도**: 본문 이론 및 구현 참조
- **공간 복잡도**: $O(N)$ 또는 $O(V + E)$

## 추천 연습 문제
- 관련 백준(BOJ) 및 Codeforces / ICPC 기출 고난도 문제
