# 트리를 자르고 붙이며 경로를 질의하라! 링크-컷 트리 (Link-Cut Tree)

## 문제 설명
$1$번부터 $N$번까지의 정점이 있으며, 처음에는 간선이 전혀 없는 상태입니다. 각 정점 $i$는 고유한 가중치 $W_i$를 가집니다.
다음 세 가지 유형의 쿼리를 순서대로 처리하는 프로그램을 작성하세요.

1. `1 u v`: 정점 $u$와 정점 $v$ 사이에 간선을 연결합니다 (`link`). (단, $u$와 $v$는 서로 다른 트리 컴포넌트에 속해 있음이 보장됩니다.)
2. `2 u v`: 정점 $u$와 정점 $v$ 사이의 간선을 제거합니다 (`cut`). (단, $u$와 $v$ 사이에 직접 간선이 존재함이 보장됩니다.)
3. `3 u v`: 정점 $u$에서 정점 $v$까지의 단순 경로 상에 존재하는 모든 정점들의 가중치 최댓값을 출력합니다 (`query`). (단, $u$와 $v$는 같은 트리 컴포넌트에 속해 있음이 보장됩니다.)

## 입력 형식
- 첫째 줄에 정점의 개수 $N$ ($1 \le N \le 10,000$)과 쿼리의 개수 $Q$ ($1 \le Q \le 30,000$)가 공백으로 구분되어 주어집니다.
- 둘째 줄에 $N$개의 정수 $W_1, W_2, \dots, W_N$ ($0 \le W_i \le 10^9$)이 주어집니다.
- 다음 $Q$개 줄에 걸쳐 각 줄마다 쿼리가 세 정수 `type u v` 형태로 주어집니다.

## 출력 형식
- 3번 쿼리가 주어질 때마다 단순 경로 상의 가중치 최댓값을 한 줄에 하나씩 출력합니다.

## 예제 1
### 입력
```text
5 7
10 20 30 40 50
1 1 2
1 2 3
3 1 3
1 3 4
3 1 4
2 2 3
1 2 5
```
### 출력
```text
30
40
```
**설명**: 
- $1-2-3$이 연결되어 있을 때, $1$에서 $3$까지 경로는 정점 $1(10), 2(20), 3(30)$이므로 최댓값은 $30$입니다.
- $3-4(40)$가 추가 연결된 후 $1$에서 $4$까지 경로는 $1, 2, 3, 4$이므로 최댓값은 $40$입니다.

## 예제 2
### 입력
```text
3 4
5 15 25
1 1 2
1 2 3
2 1 2
3 2 3
```
### 출력
```text
25
```
