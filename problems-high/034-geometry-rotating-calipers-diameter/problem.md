# 평면 위 가장 먼 두 점! 회전하는 캘리퍼스 (Rotating Calipers Diameter)

## 문제 설명
2차원 평면 위에 N개의 점이 주어졌을 때, **가장 먼 두 점 사이의 거리의 제곱**을 구하는 프로그램을 작성하세요.

모든 점 쌍을 검사하는 O(N^2) 완전 탐색은 N이 최대 100,000까지 주어지므로 불가능합니다.
1. 그레이엄 스캔 또는 모노톤 체인으로 점들의 볼록 껍질(Convex Hull)을 먼저 구합니다.
2. 평행한 두 접선을 회전시키며 대척점(Antipodal Pair)을 선형 시간에 찾는 **회전하는 캘리퍼스(Rotating Calipers)**를 구현하세요.

## 입력 형식
첫째 줄에 점의 개수 N이 주어집니다. (2 <= N <= 100,000)
둘째 줄부터 N개의 줄에 걸쳐 각 점의 좌표 x, y가 주어집니다. (-10,000 <= x, y <= 10,000)

## 출력 형식
가장 먼 두 점 사이의 거리의 제곱을 정수 하나로 출력합니다.

## 입출력 예제

### 예제 1
**입력:**
```text
5
-4 1
-1 3
2 3
3 0
0 -2
```

**출력:**
```text
50
```

### 예제 2
**입력:**
```text
2
0 0
3 4
```

**출력:**
```text
25
```

## 채점 기준
- 전체 10개 테스트 케이스를 모두 통과해야 100점 정답 처리됩니다.
- 시간 제한: 5.0초, 메모리 제한: 512MB.
