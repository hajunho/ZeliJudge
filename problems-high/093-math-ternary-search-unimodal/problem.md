# 단봉 함수의 극값을 정밀 탐색하라! 삼분 탐색 (Ternary Search)

## 문제 설명
수직선 위에 $N$개의 집이 위치해 있습니다. $i$번째 집의 위치는 $X_i$입니다.
새로운 물류 창고를 수직선 상의 어떤 좌표 $x$에 건설하려고 합니다.
창고를 좌표 $x$에 지을 때, 모든 집까지의 거리의 거듭제곱 가중합
$$f(x) = \sum_{i=1}^N |x - X_i|^3$$
의 값을 최소화하려고 합니다.

$f(x)$를 최소로 만드는 창고의 위치 $x$에서의 최솟값 $f(x)$를 구하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 집의 개수 $N$ ($1 \le N \le 10,000$)이 주어집니다.
- 둘째 줄에 $N$개의 정수 $X_1, X_2, \dots, X_N$ ($-10,000 \le X_i \le 10,000$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- $f(x)$의 최솟값을 소수점 둘째 자리까지 반올림하여 출력합니다.

## 예제 1
### 입력
```text
3
0 2 4
```
### 출력
```text
16.00
```
**설명**: $x=2$에 지으면 $|2-0|^3 + |2-2|^3 + |2-4|^3 = 8 + 0 + 8 = 16.00$으로 최소입니다.

## 예제 2
### 입력
```text
2
-10 10
```
### 출력
```text
2000.00
```
**설명**: $x=0$에 지으면 $|0 - (-10)|^3 + |0 - 10|^3 = 1000 + 1000 = 2000.00$입니다.
