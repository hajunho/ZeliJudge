# 무한 급수를 미분하고 적분하라! 형식적 멱급수의 미적분 (Formal Power Series Calculus)

## 문제 설명
알고리즘 대회 및 현대 대수학에서 형식적 멱급수(Formal Power Series, FPS)는 수열의 생성함수를 조작하는 핵심 도구입니다.

모듈러 소수 $M = 998,244,353$ 상에서 정의된 $N$차 다항식
$$P(x) = \sum_{i=0}^N a_i x^i = a_0 + a_1 x + a_2 x^2 + \dots + a_N x^N$$
이 주어집니다.

다항식 $P(x)$의 **도함수 $P'(x)$**와, 적분상수가 $0$인 **부정적분 $\int P(x) dx$**의 계수들을 $M$으로 나눈 나머지로 계산하는 프로그램을 작성하세요.

## 입력 형식
- 첫째 줄에 다항식의 최고차수 $N$ ($1 \le N \le 100,000$)이 주어집니다.
- 둘째 줄에 $N+1$개의 정수 $a_0, a_1, \dots, a_N$ ($0 \le a_i < 998,244,353$)이 공백으로 구분되어 주어집니다.

## 출력 형식
- 첫째 줄에 $P'(x)$의 계수 $N$개를 $x^0$ 항부터 $x^{N-1}$ 항까지 순서대로 공백으로 구분하여 출력합니다.
- 둘째 줄에 $\int P(x) dx$의 계수 $N+2$개를 $x^0$ 항($=0$)부터 $x^{N+1}$ 항까지 순서대로 공백으로 구분하여 출력합니다. 모든 계수는 $998,244,353$으로 나눈 나머지여야 합니다.

## 예제 1
### 입력
```text
3
1 2 3 4
```
### 출력
```text
2 6 12
0 1 1 1 1
```
**설명**: 
- $P(x) = 1 + 2x + 3x^2 + 4x^3$
- $P'(x) = 2 + 6x + 12x^2$
- $\int P(x) dx = 0 + x + x^2 + x^3 + x^4$

## 예제 2
### 입력
```text
2
5 0 3
```
### 출력
```text
0 6
0 5 0 1
```
**설명**:
- $P(x) = 5 + 3x^2$
- $P'(x) = 0 + 6x$
- $\int P(x) dx = 0 + 5x + 0x^2 + x^3$
