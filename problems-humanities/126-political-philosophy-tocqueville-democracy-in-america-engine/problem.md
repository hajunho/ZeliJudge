# #126 - 알렉시 드 토크빌의 미국의 민주주의: 조건의 평등, 개인주의, 결사체, 다수의 폭정과 연성 전제정 극복 엔진

## 📖 문제 배경과 역사적 맥락

> *"민주주의 사회에서 인간들이 고립되어 서로 무관심해질 때, 국가 권력은 거대하고 온정적인 후견인처럼 그들 위에 군림한다. 이 권력은 절대적이고 세밀하며 규칙적이고 선견지명이 있으며 자애롭다. 그것은 시민들의 쾌락을 보장하고 안위를 돌보며 모든 활동을 지도한다. 그러나 이러한 연성 전제정(Soft Despotism)은 인간의 의지를 꺾지 않고 다만 부드럽게 굴절시키며, 마침내 국가 전체를 소심하고 근면한 동물 떼로 전락시키고 정부를 그 목자로 삼는다."*  
> — **알렉시 드 토크빌 (Alexis de Tocqueville, 1805–1859), 『미국의 민주주의』(De la démocratie en Amérique, 1840)**

19세기 프랑스의 사상가이자 정치가인 **알렉시 드 토크빌(Alexis de Tocqueville)**은 1831년 미국의 교도소 제도를 시찰한다는 명목으로 신대륙을 여행한 뒤, 불멸의 고전 **『미국의 민주주의(Democracy in America)』**를 저술했습니다.

토크빌은 인류 역사가 귀족제에서 **"조건의 평등(Égalité des conditions)"**으로 나아가는 섭리적이고 거스를 수 없는 대세(Providential Fact)에 놓여 있음을 간파했습니다. 그러나 그는 민주주의가 자동적으로 자유(Liberté)를 보장하지 않는다는 사실을 냉철하게 경고했습니다. 평등이 심화될수록 시민들은 공공 영역에서 물러나 사적 쾌락에 안주하는 **개인주의(Individualisme)**와 **원자화(Atomization)**에 빠지며, 이는 필연적으로 행정적 중앙집권화와 거대한 **온정주의적 후견 국가(Tutelary State)**를 불러와 인류 역사상 유례없는 **"연성 전제정(Democratic/Soft Despotism)"**을 낳는다는 것입니다.

### 토크빌 정치철학의 4대 핵심 원리
1. **조건의 평등과 개인주의의 함정**:
   - 이기심(Égoïsme)이 본능적 맹목성이라면, 개인주의(Individualisme)는 숙고된 격리입니다. 평등한 민주 시민은 국가나 공동체에 빚진 것이 없다고 느끼며, 가족과 친구라는 좁은 울타리로 물러나 공적 책무를 방기합니다.
2. **다수의 폭정(Tyranny of the Majority)**:
   - 다수의 지배는 물리적 폭력에 그치지 않고, 다수의 여론과 도덕적 절대성을 통해 개인의 영혼과 사상을 굴복시키는 지적 폭정으로 진화합니다.
3. **온정적 전제정치(Tutelary State / Soft Despotism)**:
   - 고립된 개인들은 거대한 국가 권력 앞에 한없이 무력해지며, 국가는 이들의 모든 일상을 관리·보호해 주는 대가로 시민의 자유로운 주도권을 박탈합니다.
4. **결사체와 타운십 지방자치(The Art of Association)**:
   - 토크빌이 미국에서 발견한 가장 위대한 발명은 **자발적 시민 결사체(Civic & Political Associations)**와 **뉴잉글랜드 타운십(Township self-governance)**이었습니다. 결사체는 고립된 개인들을 묶어 귀족제의 독립적 중간 세력을 대체하며, 시민들에게 스스로를 다스리는 공공의 덕성을 훈련시킵니다.

본 과제에서는 토크빌의 정치사회학적 변수들을 기반으로 민주 사회의 상태 전이를 추적하고, 최종 체제(`final_regime`)와 자유 지수(`liberty_index`)를 계산하는 시뮬레이션 엔진을 구현합니다.

## 📥 입력 형식 (Input Specification)

입력은 표준 입력(Standard Input)으로 단일 JSON 객체가 주어집니다:

```json
{
  "initial_state": {
    "equality_level": 65.0,
    "centralization": 25.0,
    "individualism": 30.0,
    "civic_associations": 55.0,
    "majority_conformism": 25.0
  },
  "events": [
    {
      "type": "EGALITARIAN_EXPANSION",
      "params": {
        "intensity": 20.0
      }
    },
    {
      "type": "INDIVIDUALISTIC_WITHDRAWAL",
      "params": {
        "apathy": 30.0
      }
    },
    {
      "type": "TUTELARY_STATE_EXPANSION",
      "params": {
        "bureaucracy": 35.0
      }
    },
    {
      "type": "FORM_CIVIC_ASSOCIATION",
      "params": {
        "vitality": 40.0
      }
    },
    {
      "type": "FREE_PRESS_DEBATE",
      "params": {
        "pluralism": 25.0
      }
    }
  ]
}
```

### 제약조건 및 파라미터 규칙:
1. `initial_state`:
   - `equality_level`: 사회적 조건의 평등 수준 ($[0, 100]$, 기본값 `60.0`).
   - `centralization`: 국가 행정 및 권력의 중앙집권도 ($[0, 100]$, 기본값 `30.0`).
   - `individualism`: 공공 영역에서 사적 울타리로 후퇴하는 개인주의화 정도 ($[0, 100]$, 기본값 `35.0`).
   - `civic_associations`: 자발적 시민 결사체 및 타운십 자치 활력도 ($[0, 100]$, 기본값 `50.0`).
   - `majority_conformism`: 다수의 여론 압력과 획일적 순응도 ($[0, 100]$, 기본값 `30.0`).
2. `events`: 다음 7가지 사회적 사건이 순서대로 발생합니다:
   - `EGALITARIAN_EXPANSION`:
     - 파라미터: `intensity` ($I$, 기본값 `20.0`).
     - 효과:
       - $\text{equality} = \min(100.0, \text{equality} + I)$
       - $\text{individualism} = \min(100.0, \text{individualism} + I \times 0.4)$
       - $\text{conformism} = \min(100.0, \text{conformism} + I \times 0.3)$
   - `INDIVIDUALISTIC_WITHDRAWAL`:
     - 파라미터: `apathy` ($A$, 기본값 `25.0`).
     - 효과:
       - $\text{individualism} = \min(100.0, \text{individualism} + A)$
       - $\text{associations} = \max(0.0, \text{associations} - A \times 0.8)$
       - $\text{centralization} = \min(100.0, \text{centralization} + A \times 0.3)$
   - `MAJORITY_OPINION_PRESSURE`:
     - 파라미터: `pressure` ($P$, 기본값 `30.0`).
     - 효과:
       - $\text{conformism} = \min(100.0, \text{conformism} + P)$
       - $\text{associations} = \max(0.0, \text{associations} - P \times 0.4)$
   - `TUTELARY_STATE_EXPANSION`:
     - 파라미터: `bureaucracy` ($B$, 기본값 `30.0`).
     - 효과:
       - $\text{centralization} = \min(100.0, \text{centralization} + B)$
       - $\text{individualism} = \min(100.0, \text{individualism} + B \times 0.4)$
       - $\text{associations} = \max(0.0, \text{associations} - B \times 0.6)$
   - `FORM_CIVIC_ASSOCIATION`:
     - 파라미터: `vitality` ($V$, 기본값 `30.0`).
     - 효과:
       - $\text{associations} = \min(100.0, \text{associations} + V)$
       - $\text{individualism} = \max(0.0, \text{individualism} - V \times 0.7)$
       - $\text{conformism} = \max(0.0, \text{conformism} - V \times 0.3)$
       - $\text{centralization} = \max(0.0, \text{centralization} - V \times 0.3)$
   - `FREE_PRESS_DEBATE`:
     - 파라미터: `pluralism` ($D$, 기본값 `25.0`).
     - 효과:
       - $\text{conformism} = \max(0.0, \text{conformism} - D)$
       - $\text{associations} = \min(100.0, \text{associations} + D \times 0.5)$
       - $\text{individualism} = \max(0.0, \text{individualism} - D \times 0.3)$
   - `CIVIC_EDUCATION_RENEWAL`:
     - 파라미터: `enlightenment` ($E$, 기본값 `20.0`).
     - 효과:
       - $\text{individualism} = \max(0.0, \text{individualism} - E \times 0.6)$
       - $\text{associations} = \min(100.0, \text{associations} + E \times 0.5)$

## 🧮 자유 지수 및 체제 판정 공식

매 사건 처리 후 다음 수식에 따라 **자유 지수(Liberty Index)**와 **사회 체제(Regime)**를 판정합니다:

### 1. 자유 지수 ($L$)
$$
L_{\text{raw}} = (0.40 \times \text{associations}) + (0.20 \times \text{equality}) - (0.25 \times \text{centralization}) - (0.20 \times \text{individualism}) - (0.15 \times \text{conformism}) + 50.0
$$
$$
L = \text{round}(\min(100.0, \max(0.0, L_{\text{raw}})), 2)
$$

### 2. 사회 체제 (`regime`) 판정 우선순위 (If-Elif 순서 엄수):
1. $\text{centralization} \ge 70.0 \land \text{individualism} \ge 60.0 \land \text{associations} < 40.0 \implies$ `"DEMOCRATIC_DESPOTISM"` (연성/온정적 전제정치)
2. $\text{conformism} \ge 70.0 \land L < 50.0 \implies$ `"TYRANNY_OF_MAJORITY"` (다수의 폭정)
3. $\text{associations} \ge 75.0 \land \text{centralization} < 40.0 \implies$ `"TOWNSHIP_SELF_GOVERNANCE"` (타운십 풀뿌리 자치체)
4. $L \ge 65.0 \land \text{associations} \ge 50.0 \implies$ `"FREE_DEMOCRATIC_REPUBLIC"` (자유민주공화국)
5. $\text{individualism} \ge 75.0 \land L < 40.0 \implies$ `"ATOMIZED_MASS_SOCIETY"` (원자화된 대중사회)
6. 기타 $\implies$ `"MODERATE_DEMOCRACY"` (온건한 민주주의)

### 3. 최종 메타 평가:
- `is_free_society`: $L \ge 60.0 \land \text{final\_regime} \in \{\text{"FREE\_DEMOCRATIC\_REPUBLIC"}, \text{"TOWNSHIP\_SELF\_GOVERNANCE"}\}$
- `is_despotic_or_tyrannical`: $\text{final\_regime} \in \{\text{"DEMOCRATIC\_DESPOTISM"}, \text{"TYRANNY\_OF\_MAJORITY"}\}$

```json
    {
      "epoch": 1,

      "equality": 85.0,
      "centralization": 25.0,
      "individualism": 38.0,
      "associations": 55.0,
      "conformism": 31.0,
      "liberty_index": 67.45,
      "regime": "FREE_DEMOCRATIC_REPUBLIC"
    }
  ]

```

*참고*: 모든 부동소수점 수치는 소수점 둘째 자리까지 반올림(`round(val, 2)`)합니다.
