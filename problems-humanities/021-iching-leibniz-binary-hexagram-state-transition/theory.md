# 라이프니츠의 이진법과 주역 64괘의 정보 이론 (Leibniz's Binary Arithmetic and I Ching Information Theory)

## 1. 역사적 배경: 라이프니츠와 부베 신부의 서신 (1697~1703)

17세기 말, 미적분학의 창시자 고트프리트 빌헬름 라이프니츠(Gottfried Wilhelm Leibniz)는 기호 논리학의 보편적 언어(Characteristica Universalis)와 사유의 계산화(Calculus Ratiocinator)를 모색하고 있었습니다. 그는 0(무, 無)과 1(유, 有 또는 신, 神)이라는 두 가지 원소만으로 우주 만물의 수리적 질서를 창조할 수 있다는 확신을 가지고 이진법(Binary System)을 완성했습니다.

1701년, 북경의 예수회 선교사 조아킴 부베(Joachim Bouvet, 백진 白晉) 신부는 라이프니츠에게 북송 대의 학자 소옹(邵雍, 1011~1077)이 도식화한 《복희육十四괘방위도(伏羲六十四卦方位圖)》와 《차서도(次序圖)》를 담은 서신을 보냈습니다. 라이프니츠는 이 괘도에서 끊어진 효(陰爻, --)를 0으로, 이어진 효(陽爻, —)를 1로 치환했을 때, 64괘가 정확하게 $0(000000_2)$부터 $63(111111_2)$까지 순차적으로 증가하는 이진법 계수 체계임을 발견했습니다.

라이프니츠는 1703년 파리 왕립학술원에 《이진법 산술에 관한 해설(Explication de l'arithmétique binaire)》을 발표하며, 3천 년 전 고대 중국의 성왕 복희가 이미 이진법 체계를 통찰하고 기호화했음을 유럽 학계에 선언했습니다.

## 2. 시초점(蓍草占)의 불균등 확률 분포와 사상(四象)

주역 계사상전(繫辭上傳) 제9장에 기록된 대연지수(大衍之數) 50본을 활용한 시초점법(삼변일효 三變一爻, 총 18변을 거쳐 6효 도출)은 동전을 던지는 균등 확률($p=0.5$)과 달리 **본질적인 불균등 확률 구조**를 갖습니다:

1. **사상의 형성과 출현 확률**:
   - **노음(老陰, 6)**: $\\frac{4}{64} = \\frac{1}{16} = 0.0625$ ($6.25\\%$)
   - **소양(少陽, 7)**: $\\frac{20}{64} = \\frac{5}{16} = 0.3125$ ($31.25\\%$)
   - **소음(少陰, 8)**: $\\frac{28}{64} = \\frac{7}{16} = 0.4375$ ($43.75\\%$)
   - **노양(老陽, 9)**: $\\frac{12}{64} = \\frac{3}{16} = 0.1875$ ($18.75\\%$)

2. **확률론적 통찰**:
   - 기저 음효(0)가 나올 확률: $P(6) + P(8) = \\frac{1}{16} + \\frac{7}{16} = \\frac{8}{16} = 0.5$.
   - 기저 양효(1)가 나올 확률: $P(7) + P(9) = \\frac{5}{16} + \\frac{3}{16} = \\frac{8}{16} = 0.5$.
   - 즉, **기저 상태(본괘)의 음양 기대치는 완벽한 대칭(50:50)**을 이룹니다.
   - 그러나 **변효가 발생할 확률(Dynamic Instability)**은 음이 양으로 변할 확률($P(6)=6.25\\%$)보다 양이 음으로 변할 확률($P(9)=18.75\\%$)이 정확히 3배 높습니다. 이는 "극에 달한 양(陽)은 음(陰)보다 더 쉽게 붕괴하고 변전한다"는 동양 철학의 순환론적 시간관을 수학적으로 반영합니다.

## 3. 괘의 사상적 변형 군(Symmetry & Transformation Groups)

하나의 대성괘는 단순한 정적 코드가 아니라, 상태 공간(State Space) 상에서 대칭군(Symmetry Group)을 이루는 동적 객체입니다:

1. **지괘(之卦 / 변괘 變卦, State Transition)**:
   - 각 효 $i$의 변효 플래그 $c_i \\in \\{0, 1\\}$에 의한 마스크 전이:
     $$s_{\\text{resulting}} = s_{\\text{base}} \\oplus (\\sum_{i=1}^6 c_i 2^{k_i})$$
2. **호괘(互卦, Nuclear / Latent Structure)**:
   - 외면적 상괘/하괘 사이에 중첩된 2, 3, 4, 5효를 추출하여 사태의 은밀한 인과적 잠재력을 드러냄.
3. **착괘(錯卦, Bitwise Inversion / Polar Duality)**:
   - 사물을 정반대 관점에서 관조: $s_{\\text{inverse}} = \\sim s_{\\text{base}} \\land 0x3F$.
4. **종괘(綜卦, 180° Spatial Inversion / Reciprocal Perspective)**:
   - 상대방의 입장에서 바라본 사태의 형세: 효의 시계열 순서를 완전히 반전.

이러한 상태 공간의 회전과 반전 대칭성은 현대 컴퓨터 과학의 부울 대수(Boolean Algebra), 군론(Group Theory), 그리고 오류 정정 부호(Error-Correcting Codes)의 기초 개념과 정밀하게 일치합니다.
