# 주역과 라이프니츠의 이진법: 64괘 상태 전이 및 확률 시뮬레이터 (I Ching & Leibniz's Binary Arithmetic)

## 문제 설명

1703년, 독일의 수학자이자 철학자인 고트프리트 빌헬름 라이프니츠(Gottfried Wilhelm Leibniz)는 프랑스 왕립학술원에 역사적인 논문 《이진법 산술에 관한 해설(Explication de l'arithmétique binaire)》을 발표했습니다. 이 논문에서 라이프니츠는 0과 1만을 사용하는 이진법 산술 체계를 제안하며, 3천 년 전 동아시아의 복희(伏羲)와 북송의 소옹(邵雍)이 정립한 주역(周易, I Ching) 64괘의 질서가 완벽한 6비트 이진법 수열과 일치한다는 사실을 밝히고 경탄을 금치 못했습니다.

주역에서 괘(卦, Hexagram)는 아래(초효, 初爻)부터 위(상효, 上爻)까지 6개의 효(爻, Line)로 구성됩니다. 각 효는 음(陰, --, 0)과 양(陽, —, 1)의 이원적 상태를 취합니다. 6개의 효는 아래 3효로 구성된 **하괘(下卦 / 내괘 內卦)**와 위 3효로 구성된 **상괘(上卦 / 외괘 外卦)**로 나뉘어 총 $2^6 = 64$개의 대성괘(大成卦)를 형성합니다.

전통적인 시초점(蓍草占, Yarrow Stalk Divination) 방식에서는 50본의 시초를 음양의 질서에 따라 나누어 4개의 숫자 $\{6, 7, 8, 9\}$ 중 하나를 각 효마다 얻습니다. 이 숫자들은 사상(四象)과 상태 전이의 동역학을 내포합니다:
- **6 (노음, 老陰)**: 기저 상태는 음(0)이지만, 극에 달하여 양(1)으로 변화하는 **변효(變爻, Changing Line)**입니다.
- **7 (소양, 少陽)**: 기저 상태 양(1)이며 변화하지 않는 불변효입니다.
- **8 (소음, 少陰)**: 기저 상태 음(0)이며 변화하지 않는 불변효입니다.
- **9 (노양, 老陽)**: 기저 상태는 양(1)이지만, 극에 달하여 음(0)으로 변화하는 **변효(變爻, Changing Line)**입니다.

본 문제에서는 시초점 효 추출 결과가 주어졌을 때, 라이프니츠의 이진법 수리 체계와 역학의 괘상 변형 원리에 따라 다음 상태들을 해석하고 계산하는 **주역 상태 전이 및 확률 시뮬레이터**를 구현해야 합니다:

1. **효별 상태 분석 및 점괘 확률 계산**:
   - 시초점 각 숫자의 출현 확률: $P(6) = \\frac{1}{16}$, $P(7) = \\frac{5}{16}$, $P(8) = \\frac{7}{16}$, $P(9) = \\frac{3}{16}$.
   - 6개 효의 결합 확률 $P(\\text{lines}) = \\prod_{i=1}^6 P(\\text{line}_i)$을 계산하여 소수점 이하 8자리로 반올림합니다.
2. **본괘(本卦, Base Hexagram)**:
   - 시초점 초기 상태로 결정되는 6비트 괘.
3. **지괘(之卦 / 변괘 變卦, Resulting Hexagram)**:
   - 변효(6은 1로, 9는 0으로)가 전이된 후 최종적으로 도달하는 괘. 변효가 없으면 본괘와 동일합니다.
4. **호괘(互卦, Nuclear Hexagram)**:
   - 본괘 내부의 잠재적 인과를 나타내는 괘로, 2, 3, 4효로 하괘를 이루고, 3, 4, 5효로 상괘를 이룹니다.
5. **착괘(錯卦 / 대괘 對卦, Inverse Hexagram)**:
   - 본괘의 모든 효(6비트)를 음양 반전(Bitwise NOT, $0 \\leftrightarrow 1$)한 괘.
6. **종괘(綜卦 / 반괘 反卦, Reverse Hexagram)**:
   - 본괘를 상하 180도 뒤집은(효의 순서를 1~6에서 6~1로 역전한) 괘.
7. **문왕 64괘 및 팔괘 명칭 매핑**:
   - 도출된 각 괘의 상괘/하괘 삼효(Trigram) 번호와 명칭, 문왕 64괘 순번(1~64), 국문 괘명(예: "수뢰둔"), 한자 괘명(예: "水雷屯"), 그리고 유니코드 괘 기호(`chr(0x4DC0 + kw_num - 1)`)를 결합하여 반환합니다.

## 입력 형식

표준 입력(`sys.stdin`)을 통해 JSON 형식의 단일 객체가 전달됩니다:

```json
{
  "divinations": [
    {
      "id": "query_1",
      "lines": [7, 8, 9, 6, 7, 8]
    }
  ]
}
```

- `divinations`: 시초점 점괘 질의 목록.
  - `id`: 질의 고유 식별자 문자열.
  - `lines`: 초효(Line 1, 맨 아래)부터 상효(Line 6, 맨 위)까지 순서대로 나열된 6개의 정수 리스트. 각 원소는 $6, 7, 8, 9$ 중 하나입니다.

## 삼괘(Trigram) 이진 인코딩 규칙

팔괘(8 Trigrams)는 3개의 효로 구성되며, 삼괘 값 $v$는 삼괘의 아래 효(bottom), 중간 효(mid), 윗 효(top)에 대해 다음과 같이 정의됩니다:
$$v = (\\text{bottom} \\ll 2) \\mid (\\text{mid} \\ll 1) \\mid \\text{top}$$

| 값 ($v$) | 이진 표기 | 괘명(한글) | 괘명(한자) | 오행/자연 | 기호 | 효 구성 (아래 $\\to$ 위) |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | `000` | 곤 | 坤 | 지(地) | ☷ | 음, 음, 음 |
| 1 | `001` | 간 | 艮 | 산(山) | ☶ | 음, 음, 양 |
| 2 | `010` | 감 | 坎 | 수(水) | ☵ | 음, 양, 음 |
| 3 | `011` | 손 | 巽 | 풍(風) | ☴ | 음, 양, 양 |
| 4 | `100` | 진 | 震 | 뢰(雷) | ☳ | 양, 음, 음 |
| 5 | `101` | 리 | 離 | 화(火) | ☲ | 양, 음, 양 |
| 6 | `110` | 태 | 兌 | 택(澤) | ☱ | 양, 양, 음 |
| 7 | `111` | 건 | 乾 | 천(天) | ☰ | 양, 양, 양 |

대성괘 6비트 정수값은 다음과 같이 결합됩니다:
$$\\text{hex\\_val} = (v_{\\text{upper}} \\ll 3) \\mid v_{\\text{lower}}$$
