# #003 [칼퇴를 사수하라!: 근로기준법 주 52시간 상한제 위반 판정과 연장·야간·휴일 근로수당 계산 룰 엔진 (Labor Standards Act 52-Hour Workweek Compliance & Overtime/Night/Holiday Wage Engine)]

## 1. 장애 및 실무 시나리오

IT 스타트업 및 유니콘 기업들이 급격히 성장하면서, 인사팀(HR)과 노무관리 부서는 수천 명에 달하는 임직원의 출퇴근 기록 및 급여 정산 문제로 고용노동부 근로감독(Labor Audit)의 타깃이 되었습니다.

근로기준법 개정에 따라 **1주 최대 근로시간은 법정근로 40시간 + 연장근로 한도 12시간을 합쳐 총 52시간**을 절대 초과할 수 없습니다. 주 52시간을 초과하면 대표이사가 **2년 이하의 징역 또는 2천만 원 이하의 벌금형(형사처벌)**에 처해집니다.

그러나 기존 사내 ERP 시스템은 엑셀 수식 기반의 주먹구구식 계산기를 사용하여 다음과 같은 심각한 법률 위반 및 노무 갈등을 일으켰습니다:
1. **철야 야간 근무(익일 퇴근) 분할 실패**: 밤 20:00에 출근해 다음 날 새벽 05:00에 퇴근한 경우, 날짜가 바뀌면서 24시간 타임라인이 왜곡되어 야간근로수당(22:00~06:00, 50% 가산)이 누락됨.
2. **휴일근로의 8시간 초과 누진 할증(100%) 미적용**: 토요일 특근 시 8시간 이내는 50% 가산이지만 8시간을 초과한 분은 100% 가산되어야 함에도 단순 50% 일괄 지급하여 임금체불 발생.
3. **법정 휴게시간(근로기준법 제54조) 미부여**: 4시간 이상 근무 시 30분, 8시간 이상 근무 시 1시간 이상의 무급 휴게시간을 근무 도중 부여해야 함에도, 휴게 없이 10시간 연속 근무시킨 기록이 고용노동부에 적발됨.
4. **휴일근로의 주 52시간 산입 누락**: 2018년 개정 전 구법(주 68시간제)을 답습하여 주말 휴일근로 시간을 주 52시간 한도 집계에서 제외하는 바람에 주 52시간 위반 사실을 사전에 경고하지 못함.

HR 테크 솔루션 팀은 근로기준법 및 대법원 판례(대법원 2018다226732 전원합의체 등)에 완벽히 부합하는 **출퇴근 분 단위 타임라인 파서 및 법정 가산수당·컴플라이언스 판정 룰 엔진**을 구축하기로 결정했습니다.

## 2. 노동법 및 컴퓨터 과학 원리: 1차원 구간 교집합과 다차원 누적 룰 엔진

### 2.1 근로기준법상 법정 근로시간 및 가산수당 체계 (제50조, 제53조, 제54조, 제56조)
- **기본 법정근로시간**: 1일 8시간, 1주 40시간 (제50조)
- **연장근로 한도**: 당사자 합의 시 1주 12시간 한도 (제53조) $\rightarrow$ **주 52시간 상한제**
- **법정 휴게시간 (제54조)**:
  - 실근로시간 4시간 이상: 30분 이상
  - 실근로시간 8시간 이상: 1시간 이상 (무급, 근로시간에서 완전 제외)
- **법정 가산수당 할증률 (제56조)**:
  - **연장근로**: 1일 8시간 초과분 또는 1주 40시간 초과분 $\rightarrow$ 통상임금의 **50% 가산** ($1.5 \times W_{base}$)
  - **야간근로**: 오후 10시(22:00) ~ 다음 날 오전 6시(06:00) 사이의 근로 $\rightarrow$ 통상임금의 **50% 가산** ($+0.5 \times W_{base}$)
  - **휴일근로 (대법원 2018다226732 전원합의체)**:
    - 8시간 이내: 통상임금의 **50% 가산** ($1.5 \times W_{base}$)
    - 8시간 초과: 통상임금의 **100% 가산** ($2.0 \times W_{base}$)
  - **중복 할증 (Stacking)**: 연장이면서 야간이거나, 휴일이면서 야간인 경우 각각의 할증률을 중복 합산 (예: 휴일 8시간 초과 + 야간 = $1.0 + 1.0 + 0.5 = 2.5 \times W_{base}$)

```
+-------------------------------------------------------------------------+
|                  24시간 타임라인 & 야간 시간대 구간 교집합                |
|                                                                         |
| 00:00          06:00                      22:00                 24:00   |
| ┌───────────────┬───────────────────────────┬─────────────────────┐   |
| │  야간 근로     │        주간 통상 근로        │      야간 근로       │   |
| │  (00:00~06:00)│        (06:00~22:00)      │    (22:00~24:00)    │   |
| └───────────────┴───────────────────────────┴─────────────────────┘   |
|                                                                         |
|  * 출근(start_time) ~ 퇴근(end_time) 구간에서 휴게시간(breaks) 차감     |
|  * 분(minute) 단위로 야간 구간과의 교집합 여부를 판별하여 누적            |
+-------------------------------------------------------------------------+
```

## 3. 입력 사양 (Input Specification)

표준 입력(stdin)으로 한 직원의 1주일 출퇴근 기록 JSON 객체가 주어집니다:

```json
{
  "employee_id": "EMP-2026-001",
  "employee_name": "김표준",
  "hourly_rate": 15000,
  "records": [
    {
      "date": "2026-10-12",
      "day_of_week": "MON",
      "is_holiday": false,
      "start_time": "09:00",
      "end_time": "18:00",
      "breaks": [
        { "start": "12:00", "end": "13:00" }
      ]
    }
  ]
}
```

### 처리 조건:
1. **익일 퇴근 처리**: `end_time <= start_time`인 경우 자정을 넘겨 다음 날 퇴근한 것으로 간주합니다 (예: `20:00` ~ `05:00` $\rightarrow$ 총 9시간 경과).
2. **휴게시간 차감**: 근무 구간 내의 휴게시간(`breaks`)을 차감하여 실근로시간(`actual_mins`)을 도출합니다.
3. **평일 vs 휴일**:
   - `is_holiday: false` (평일):
     - 1일 8시간 초과분은 일 연장근로.
     - 1일 8시간 이내의 근로시간을 월요일부터 누적하여 주 40시간 초과 시점부터는 주 연장근로로 전환.
   - `is_holiday: true` (주말/휴일):
     - 8시간 이내는 휴일 기본(50% 가산), 8시간 초과분은 휴일 연장(100% 가산).
4. **시간 단위 표기**: 모든 시간 집계는 시간 단위(hours)로 환산하며 소수점 둘째 자리(`round(h, 2)`)로 표기합니다.

## 4. 출력 사양 (Output Specification)

표준 출력(stdout)으로 다음 스키마의 JSON을 한 줄로 출력합니다:

```json
{
  "status": "COMPLIANT_NORMAL",
  "employee_id": "EMP-2026-001",
  "employee_name": "김표준",
  "hourly_rate": 15000,
  "work_summary": {
    "total_work_hours": 40.0,
    "regular_work_hours": 40.0,
    "overtime_hours": 0.0,
    "night_hours": 0.0,
    "holiday_hours": 0.0
  },
  "wage_breakdown": {
    "base_wage": 600000,
    "overtime_premium": 0,
    "night_premium": 0,
    "holiday_premium": 0,
    "gross_pay": 600000
  },
  "daily_reports": [
    {
      "date": "2026-10-12",
      "day_of_week": "MON",
      "is_holiday": false,
      "actual_work_hours": 8.0,
      "break_hours": 1.0,
      "night_hours": 0.0,
      "overtime_hours": 0.0,
      "holiday_hours": 0.0
    }
  ],
  "diagnostics": [
    "주 40시간 이내(총 40.0시간) 표준 법정근로시간을 준수했습니다."
  ],
  "recommendation": "표준 급여 정상 지급."
}
```

### 판정 상태 (`status`):
1. `"VIOLATION_52_HOURS_EXCEEDED"`:
   - 주간 총 실근로시간 `total_work_hours > 52.0`인 경우. (근로기준법 형사처벌 대상 최우선 경고).
2. `"VIOLATION_REST_PERIOD_MISSING"`:
   - 실근로 4시간 이상인데 휴게 30분 미만이거나, 실근로 8시간 이상인데 휴게 1시간 미만인 날이 존재하는 경우.
3. `"COMPLIANT_OVERTIME"`:
   - 주 52시간 이하이면서 연장근로 또는 휴일근로가 발생한 적법한 근무.
4. `"COMPLIANT_NORMAL"`:
   - 주 40시간 이내 표준 준수 근무.
