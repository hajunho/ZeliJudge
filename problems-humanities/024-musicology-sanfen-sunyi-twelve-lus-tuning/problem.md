# 동양 음악학과 음향학: 삼분손익법(三分損益法) 12율관(十二律管) 음률 산출, 피타고라스 콤마 오차 및 세종대왕 황종척(黃鍾尺) 복원 시뮬레이터

## 문제 설명

기원전 7세기 전국시대 《관자(管子)》 〈지원편(地員篇)〉과 한나라 사마천의 《사기(史記)》 〈율서(律書)〉에는 인류 역사상 가장 오래된 음향학적 수리 이론인 **삼분손익법(三分損益法)**이 기록되어 있습니다. 고대 서양에서 피타고라스(Pythagoras)가 현(String)의 길이 분할을 통해 순정 5도 음률을 발견했던 것과 마찬가지로, 동양에서는 대나무 관(律管)의 길이와 공명 주파수를 기준으로 완벽한 12개의 음률(十二律)을 창성했습니다.

조선 초, 세종대왕은 박연(朴堧)과 함께 명나라에서 전래되어 조율이 어긋나 있던 불완전한 편경(編磬)과 아악(雅樂)을 바로잡기 위해 거국적인 음률 개혁을 단행했습니다. 세종은 경기도 남양산 경석(磬石)을 채취하여 12율 편경을 직접 조율하고, 황해도산 검은 기장 곡식(黍) 100알을 늘어세운 길이를 **황종척(黃鍾尺, 1척=약 31.1cm)**으로 공포하여 동아시아 도량형과 음악의 표준 척도로 삼았습니다.

### 1. 삼분손익법의 수학적 생성 원리

기준음인 **황종(黃鍾, C)** 율관의 길이를 $L_0 = 81$ ($3^4$)분으로 설정하고, 다음 두 가지 연산을 번갈아 수행하여 12개의 음을 순차적으로 유도합니다:

1. **삼분손일(三分損一, Remove 1/3, $\times \frac{2}{3}$)**:
   - 율관의 길이를 $1/3$ 잘라내어 $2/3$로 줄입니다.
   - 관의 길이가 줄어들면 음향학적으로 주파수는 $\frac{3}{2}$배로 높아져 **완전 5도(Perfect 5th, 약 702 Cent) 상행**합니다.
   - 예: 황종(81) $\times \frac{2}{3} = 54 \implies$ **임종(林鍾, G)**
2. **삼분익일(三分益一, Add 1/3, $\times \frac{4}{3}$)**:
   - 율관의 길이에 $1/3$을 더하여 $4/3$로 늘립니다.
   - 주파수는 $\frac{3}{4}$배로 낮아져 **완전 4도(Perfect 4th, 약 498 Cent) 하행**하며, 이는 1옥타브 내에서 음정을 재배치하는 효과를 갖습니다.
   - 예: 임종(54) $\times \frac{4}{3} = 72 \implies$ **태주(太簇, D)**

12율은 5도권(Circle of Fifths) 순환 순서에 따라 다음과 같이 생성됩니다:
- 황종(C, 81) $\to$ 임종(G, 54, 손) $\to$ 태주(D, 72, 익) $\to$ 남려(A, 48, 손) $\to$ 고선(E, 64, 익) $\to$ 응종(B, 42.6667, 손) $\to$ 유빈(F#, 56.8889, 익) $\to$ 대려(C#, 75.8519, 익) $\to$ 이칙(G#, 50.5679, 손) $\to$ 협종(D#, 67.4239, 익) $\to$ 무역(A#, 44.9492, 손) $\to$ 중려(F, 59.9323, 익).

### 2. 피타고라스 콤마(Pythagorean Comma) 오차

12번째 음인 중려(仲呂)에서 다시 삼분익일($\times \frac{4}{3}$)을 적용하여 13번째 청황종(1옥타브 위의 황종)을 생성하면, 그 길이는 $59.9323 \times \frac{4}{3} \approx 79.9098$이 되어 원래의 황종(81)으로 완전히 닫히지 않습니다.
- 율관 길이 비율: $\left(\frac{3}{2}\right)^{12} \div 2^7 = \frac{3^{12}}{2^{19}} \approx 1.013643$
- 센트(Cent) 오차: $1200 \times \log_2\left(\frac{3^{12}}{2^{19}}\right) \approx \mathbf{23.46 \text{ Cent}}$
이 오차는 12평균율이 발명되기 전까지 동서양 음악 이론가들이 순환 완결을 위해 고뇌했던 음악학의 핵심 난제입니다.

### 3. 오성(五聲, Pentatonic Scale)과 선법 도출

12율 중 임의의 음을 으뜸음인 **궁(宮)**으로 설정하면, 동양의 전통 5음계인 **궁(宮, 0)·상(商, +2반음)·각(角, +4반음)·치(徵, +7반음)·우(羽, +9반음)**의 율관과 주파수가 즉시 도출됩니다.

본 문제에서는 기준 율관 길이와 기준 주파수, 그리고 으뜸음 질의가 주어졌을 때, 삼분손익법 12율관의 계통도, 주파수(Hz), 센트(Cent), 피타고라스 콤마, 반음계 순서 정렬 및 5음계 선법을 계산하는 **동양 음악학 음향 복원 엔진**을 구현해야 합니다.

## 입력 형식

표준 입력(`sys.stdin`)을 통해 단일 JSON 객체가 전달됩니다:

```json
{
  "base_length": 81.0,
  "base_frequency_hz": 261.625565,
  "queries": [
    {
      "id": "q1",
      "tonic": "황종"
    }
  ]
}
```
