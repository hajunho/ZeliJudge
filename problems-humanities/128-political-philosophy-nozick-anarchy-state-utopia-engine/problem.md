# #128 - 로버트 노직의 아나키에서 유토피아로: 소유 권리론, 취득·이전·교정의 원칙, 윌트 체임벌린 논변 및 최소국가론 엔진

## 📖 문제 배경과 역사적 맥락

> *"개인은 권리를 지니고 있으며, 어느 누구도 침해할 수 없는 권리의 영역이 존재한다. 국가는 강제력, 절도, 사기로부터의 보호와 계약 집행에 국한된 최소국가(Minimal State)일 때에만 도덕적으로 정당화될 수 있다. 그보다 더 확장된 국가는 시민들에게 특정 행동을 강제하거나 재분배를 위해 개인의 자유를 침해하게 되며, 이는 정당화될 수 없다. 과세를 통한 재분배는 본질적으로 '강제 노동(Forced Labor)'과 다름없다."*  
> — **로버트 노직 (Robert Nozick, 1938–2002), 『아나키에서 유토피아로』(Anarchy, State, and Utopia, 1974)**

20세기 후반, 존 롤스(John Rawls)의 『정의론』(1971)이 복지국가와 조세 재분배의 철학적 정당성을 확립하자, 이에 맞서 자유지상주의(Libertarianism)의 절대적 기치를 든 하버드 대학교 철학과 교수 **로버트 노직(Robert Nozick)**은 1974년 세기의 명저 **『아나키에서 유토피아로(Anarchy, State, and Utopia)』**를 발표했습니다.

노직은 롤스식의 분배 정의가 "어떤 최종 결과 패턴(End-State / Patterned Distribution)을 정의롭다고 정해두고 국가가 폭력적인 세금을 통해 그 패턴을 강제하는 정형적 정의관"에 불과하다고 맹렬히 비판했습니다. 노직에 따르면, 정의는 결과의 모양(Pattern)이 아니라 **"그 소유가 역사적으로 정당한 절차를 거쳐 발생했는가(Historical Entitlement Theory)"**에 달려 있습니다.

### 노직 소유 권리론의 3대 핵심 기둥
1. **정당한 취득의 원칙 (Justice in Acquisition)**:
   - 자연 상태의 무주물에 노동을 섞어 정당하게 취득하되, 타인의 처지를 악화시키지 않도록 "충분하고도 질 좋은 것을 남겨두어야 한다"는 **로크의 단서(Lockean Proviso)**를 준수해야 합니다.
2. **정당한 이전의 원칙 (Justice in Transfer)**:
   - 사기(Fraud)나 강제력(Coercion/Theft) 없이 자발적인 계약, 매매, 증여를 통해 이전된 재산은 전적으로 정당합니다.
3. **부정의의 교정 원칙 (Rectification of Injustice)**:
   - 과거에 취득이나 이전의 원칙이 위반된 경우(약탈, 사기), 국가는 이를 피해자에게 원상 복구시켜 정당한 소유권을 회복시켜야 합니다.
4. **윌트 체임벌린 논변 (Wilt Chamberlain Argument)**:
   - 사회가 롤스주의든 평등주의든 이상적인 분배 상태 $D_1$에서 시작하더라도, 100만 명의 관중이 농구 스타 윌트 체임벌린의 경기를 보기 위해 자발적으로 25센트씩 지불한다면 체임벌린은 거대한 부를 얻고 새로운 분배 $D_2$는 불평등해집니다.
   - 이 과정에서 누구도 강요받지 않았고 모든 거래가 자유로웠다면 $D_2$는 정의롭습니다. 만약 국가가 $D_1$ 패턴을 유지하려 한다면, 시민들의 일거수일투족과 자유로운 계약에 지속적으로 폭력적으로 개입해야 합니다.

본 과제에서는 노직의 소유 권리론 상태 머신을 구축하여 거래의 정당성과 국가의 개입 여부를 시뮬레이션하는 계산 자유지상주의 엔진을 구현합니다.

## 📥 입력 형식 (Input Specification)

입력은 표준 입력(Standard Input)으로 단일 JSON 객체가 주어집니다:

```json
{
  "initial_state": {
    "agents": {
      "Wilt": {"holdings": 10.0, "legitimate_title": true},
      "Fan1": {"holdings": 10.0, "legitimate_title": true},
      "Fan2": {"holdings": 10.0, "legitimate_title": true},
      "Fan3": {"holdings": 10.0, "legitimate_title": true},
      "Fan4": {"holdings": 10.0, "legitimate_title": true}
    }
  },
  "events": [
    {
      "type": "WILT_CHAMBERLAIN_TRANSACTION",
      "params": {
        "star_agent": "Wilt",
        "ticket_price": 5.0,
        "spectator_agents": ["Fan1", "Fan2", "Fan3", "Fan4"]
      }
    },
    {
      "type": "STATE_PATTERNED_REDISTRIBUTION",
      "params": {
        "tax_rate": 0.5,
        "target_agents": ["Wilt"],
        "beneficiary_agents": ["Fan1", "Fan2", "Fan3", "Fan4"]
      }
    }
  ]
}
```

### 제약조건 및 파라미터 규칙:
1. `initial_state`:
   - `agents`: 행위자 사전. 각 행위자는 `holdings`(보유 자산), `legitimate_title`(정당한 권리 여부, 기본값 `true`), `proviso_violated`(로크의 단서 위반 여부, 기본값 `false`)를 가집니다.
2. `events`: 다음 6가지 사건이 순서대로 발생합니다:
   - `ORIGINAL_ACQUISITION`:
     - 파라미터: `agent_id`, `amount`, `violates_lockean_proviso` (불리언).
     - 동작: `holdings += amount`. 만약 `violates_lockean_proviso == true`이면 `proviso_violated = true`, `legitimate_title = false`.
     - 상태: 위반 시 `ACQUISITION_PROVISO_VIOLATED`, 미위반 시 `LEGITIMATE_ACQUISITION`.
   - `VOLUNTARY_TRANSFER`:
     - 파라미터: `from_agent`, `to_agent`, `amount`, `coercion_or_fraud` (불리언).
     - 동작: 자산 이전 `min(amount, from.holdings)`. 만약 `coercion_or_fraud == true`이면 `to_agent`의 `legitimate_title = false`, 상태: `COERCED_OR_FRAUD_TRANSFER`. 미발생 시 상태: `VOLUNTARY_TRANSFER_SUCCESS`.
   - `WILT_CHAMBERLAIN_TRANSACTION`:
     - 파라미터: `star_agent`, `ticket_price`, `spectator_agents`.
     - 동작: 각 관중이 `ticket_price`를 스타에게 자발적으로 이전. 상태: `CHAMBERLAIN_TRANSACTION_SUCCESS`.
   - `RECTIFY_INJUSTICE`:
     - 파라미터: `victim_agent`, `perpetrator_agent`, `restitution_amount`.
     - 동작: 가해자에게서 피해자로 자산 반환, 가해자의 `legitimate_title = true`, `total_rectifications += 1`. 상태: `INJUSTICE_RECTIFIED`.
   - `STATE_PATTERNED_REDISTRIBUTION`:
     - 파라미터: `tax_rate`, `target_agents`, `beneficiary_agents`.
     - 동작: 국가가 특정 대상자에게 강제 과세하여 수혜자들에게 균등 분배. `total_coercive_interventions += 1`. 상태: `PATTERNED_TAX_IMPOSED`.
   - `MINIMAL_STATE_PROTECTION`:
     - 동작: 최소국가가 재분배 없이 소유권 경계와 계약 집행만 수호. 상태: `MINIMAL_STATE_ENFORCED`.

### 3. 정의 판정 로직:
- `is_just_entitlement`: 모든 행위자가 `legitimate_title == true`이고 `proviso_violated == false`인 경우에만 `true`.
- `is_patterned_equal`: $\min(\text{holdings}) > 0 \land \frac{\max(\text{holdings})}{\min(\text{holdings})} \le 1.2$ 인 경우에만 `true`.

## 📤 출력 형식 (Output Specification)

시뮬레이션 완료 후 최종 소유권 상태를 압축 JSON 문자열(`separators=(',', ':')`, `ensure_ascii=False`)로 표준 출력에 인쇄합니다:

```json
{
  "final_is_just_entitlement": true,
  "final_is_patterned_equal": false,
  "total_coercive_interventions": 1,
  "total_rectifications": 0,
  "agents": {
    "Fan1": {
      "holdings": 8.75,
      "legitimate_title": true,
      "proviso_violated": false
    },
    "Wilt": {
      "holdings": 15.0,
      "legitimate_title": true,
      "proviso_violated": false
    }
  },
  "history": [
    {
      "epoch": 1,
      "event": "WILT_CHAMBERLAIN_TRANSACTION",
      "status": "CHAMBERLAIN_TRANSACTION_SUCCESS",
      "is_just_entitlement": true,
      "is_patterned_equal": false,
      "min_holding": 5.0,
      "max_holding": 30.0,
      "detail": "4 spectators voluntarily paid 5.0 each. Star Wilt received 20.0."
    }
  ]
}
```

*참고*: 모든 부동소수점 수치는 `round(val, 2)`를 적용합니다.

## 🎯 채점 기준 및 제약 조건

1. 정확성 100%: 8개 모든 테스트케이스의 수치 및 소유 권리 정당성 플래그가 완벽히 일치해야 합니다.
2. 노직의 역사적 원리(Historical Principle)와 비정형적(Non-patterned) 권리 추적을 정확히 수행해야 합니다.
3. Windows 환경에서의 UTF-8 입출력을 준수해야 합니다.
