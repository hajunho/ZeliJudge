# 질 들뢰즈 & 펠릭스 과타리: 리좀, 아상블라주 및 탈영토화 철학 백서 (Theoretical Background)

## 1. 개요: 수목형 사유의 감옥에서 리좀적 다양체로

서양 철학은 플라톤과 데카르트 이래 모든 지식과 존재를 단일한 뿌리(근거, 제1원리)에서 파생되는 **'나무(Arbre)'**의 형상으로 모델링해 왔습니다. 
- 지식의 나무, 계통수(Phylogenetic tree), 촘스키 통사 수형도, 관료제 피라미드 조직.
- 나무 모델은 항상 위계적이고, 이분법적 분기(Yes/No)에 의존하며, 중앙 통제자를 전제합니다.

프랑스의 철학자 **질 들뢰즈**와 정신과의사 **펠릭스 과타리**는 1980년 저서 『천 개의 고원』의 서론인 「리좀(Rhizome)」에서, 자연과 사유의 진정한 본성은 나무가 아니라 **리좀(땅속줄기)**임을 선언했습니다.

```
       [ 수목형 위계 구조 (Tree) ]                 [ 리좀형 탈중앙화 망 (Rhizome) ]
                 ROOT                                   o-------o
                /    \                                 / \     / \
               A      B                               o   o---o   o
              / \    / \                             /     \ /     \
             C   D  E   F                           o-------o-------o
     - 단일 중심, 하향식 명령                     - 중심 없음, 어디서나 접속 가능
     - 이분법적 분기 (Binary)                      - n-1의 다양체 (Multiplicity)
     - 홈패인 공간 (Striated)                      - 매끄러운 공간 (Smooth Space)
```

## 2. 말벌과 난초: 공생과 생성-되기(Devenir, Becoming)

들뢰즈와 과타리는 리좀적 접속의 대표적 실례로 **말벌(Wasp)**과 **난초(Orchid)**의 공생을 듭니다:
- 지중해의 오프리스(Ophrys) 난초는 암벌의 엉덩이 모양과 페로몬 냄새를 흉내 내어 수벌을 유인합니다.
- 수벌은 짝짓기를 시도하다가 난초의 꽃가루를 몸에 묻혀 다른 난초로 나릅니다.
- **모방이나 유전적 복제가 아님**: 난초는 말벌의 상징을 전유하여 '말벌-되기'를 수행하고, 말벌은 난초의 번식 기구가 됨으로써 '난초-되기'를 수행합니다.
- 두 이질적인 종이 하나의 기계적 아상블라주(Machinic Assemblage)를 형성하며, 고정된 유전학적 계통수를 탈주하여 수평적 유전자 전달처럼 새로운 생명 네트워크를 엮어냅니다.

## 3. 영토화, 탈영토화, 그리고 재영토화의 삼박자

들뢰즈 철학에서 모든 사회, 조직, 텍스트, 주체는 고정된 실체가 아니라 **아상블라주(배치, Assemblage)**입니다:

1. **영토화 (Territorialization)**:
   - 특정 집단이 공간에 경계를 긋고 규칙, 법률, 금기를 설정하여 엔트로피를 낮추는 과정입니다.
   - 예: 국가의 국경, 사유재산권, 문법 규칙, 기업의 사규.
2. **탈영토화 (Deterritorialization)**:
   - 아상블라주 내부의 긴장이나 외부 유목민의 충격에 의해 기존 경계가 찢어지고 흩어지는 과정입니다.
   - 억압된 욕망이나 혁신이 기존 지층을 뚫고 터져 나오는 통로를 **'탈주선(Line of Flight, Ligne de fuite)'**이라고 부릅니다.
3. **재영토화 (Reterritorialization)**:
   - 탈영토화된 에너지가 무한히 방출되지 않고, 새로운 권력이나 자본, 습관에 의해 다시 포획되어 새로운 질서로 고착되는 과정입니다.
   - 예: 록 음악이나 힙합 등 반체제 저항 문화가 거대 음반 자본에 흡수되어 상업적 상품으로 소비되는 현상.

## 4. 현대 컴퓨터 과학 및 복잡계 네트워크에의 함의

들뢰즈의 리좀 이론은 현대 정보기술의 패러다임 전환과 완벽하게 일치합니다:
- **인터넷과 P2P 프로토콜 (BitTorrent, IPFS)**:
  - 중앙 서버(Root)가 마비되어도 망 전체가 살아남는 비의미적 단절(Asignifying Rupture)과 결함 허용(Fault Tolerance).
- **탈중앙화 자율조직(DAO)과 블록체인**:
  - 국가(Appareil d'État)의 화폐 주권을 탈주하는 유목민적 전쟁기계(Nomadic War Machine).
- **생성형 AI와 멀티모달 지식 그래프**:
  - 텍스트, 이미지, 오디오, 코드가 융합되어 도메인 간 벽을 허무는 이질적 접속의 고원(Plateau).
