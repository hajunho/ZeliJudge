# 고문서 금석학(Epigraphy)과 계산 고고학: 부스트로페돈·스토이케돈 비문 서학 및 텍스트 복원 알고리즘

## 1. 고대 그리스 금석학(Epigraphy)의 서사 전통

고대 지중해 세계에서 돌이나 청동에 새겨진 비문(Inscription)은 후대의 필사 과정에서 왜곡되거나 소실되지 않은 채 당대의 문자와 언어를 그대로 보존하고 있는 가장 신뢰할 수 있는 역사적 1차 사료(Primary Source)입니다.

### (1) 부스트로페돈 (Boustrophedon, βουστροφηδόν)
- 어원: 소(βούς, bous) + 돌다/이랑(στροφή, strophe) = "소가 밭을 갈며 이랑을 왕복하듯".
- 기원전 7세기부터 5세기 초까지 아르카익(Archaic) 그리스 전역(솔론의 법률 비석, 크레타 고르틴 법전 등)에서 광범위하게 사용되었습니다.
- **읽기 및 음각 기제**:
  - 1행: 좌 $\to$ 우 ($L \to R$)
  - 2행: 우 $\to$ 좌 ($R \to L$, 문자의 좌우 모양도 반대로 음각되거나 읽기 순서가 반전됨)
  - 3행: 좌 $\to$ 우 ($L \to R$)
- **인체공학적 의의**:
  비석의 크기가 수 미터에 달할 때, 긴 줄을 읽고 다음 줄을 읽기 위해 눈과 몸을 비석 반대편 끝으로 되돌릴 필요 없이, 현재 줄이 끝난 바로 그 자리에서 다음 줄을 즉시 이어서 읽을 수 있도록 고안된 고대 서사 기술의 지혜입니다.

```
Row 0: [E] -> [D] -> [O] -> [X] -> [S] -> [E] -> [N] -> [T] -> [E] -> [I]
                                                                        |
                                                                        v (내려감)
Row 1: [I] <- [A] <- [K] <- [I] <- [E] <- [L] <- [O] <- [B] <- [I] <- (우->좌 독서)
```

### (2) 스토이케돈 (Stoichedon, στοιχηδόν)
- 어원: 군대의 대열(στοῖχος, stoichos)처럼 줄지어 반듯하게 정렬된.
- 기원전 5세기 페리클레스 시대의 아테네 델로스 동맹 조세 명부(Athenian Tribute Lists) 및 민회 결의문(Decrees)에서 표준화되었습니다.
- **기하학적 격자(Grid) 특성**:
  - 모든 글자는 폭과 높이가 일정한 정사각 격자(Quadrangular grid)에 배치됩니다.
  - 가로 행(Row)과 세로 열(Column)이 완벽하게 일치하여 비석 전체가 바둑판 형태를 이룹니다.
  - **연속 서법(*Scriptio continua*)**: 단어 간 띄어쓰기가 없으며, 단어가 행의 끝($C-1$번째 열)에 도달하면 하이픈 없이 다음 행의 첫 번째 칸($0$번째 열 또는 부스트로페돈의 경우 $C-1$번째 칸)으로 곧바로 이어집니다.

## 2. 계산 고고학과 결손 복원(Lacuna Restoration)

자연 풍화나 파손으로 비문의 일부 글자가 소실된 것을 **결손(Lacuna, 缺損)**이라고 부릅니다. 현대 디지털 인문학과 계산 고고학(Computational Archaeology, e.g. DeepMind/Oxford의 *Ithaca* 신경망 모델)에서는 금석학자의 수작업 복원을 자동화하고 무결성을 검증하기 위해 다음과 같은 전산 알고리즘을 활용합니다:

### (1) 2차원 공간 격자 좌표계와 1차원 독서 스트림 변환
격자 크기가 $R \times C$일 때, 물리적 좌표 $(r, c)$와 독서 스트림의 인덱스 $i \in [0, R \cdot C - 1]$ 사이의 전단사 사상(Bijection):

- **부스트로페돈 모드**:
  $$i(r, c) = \begin{cases} r \cdot C + c & \text{if } r \text{ is even} \\ r \cdot C + (C - 1 - c) & \text{if } r \text{ is odd} \end{cases}$$
- **역변환 (독서 스트림 $i$로부터 물리적 좌표 복원)**:
  $$r = \lfloor i / C \rfloor, \quad k = i \pmod{C}$$
  $$c = \begin{cases} k & \text{if } r \text{ is even} \\ C - 1 - k & \text{if } r \text{ is odd} \end{cases}$$

### (2) 와일드카드 단어 분할 (Wildcard Word Break Algorithm)
비문 스트림 $S[0 \dots N-1]$에는 보존된 문자뿐 아니라 와일드카드 `?`가 포함되어 있습니다.
어휘 사전 $D$가 주어졌을 때, $S = W_1 W_2 \dots W_k$ ($W_j \in D$)를 만족하는 단어 분할을 탐색하는 것은 **제약 충족 문제(Constraint Satisfaction Problem, CSP)**이자 동적 계획법(DP) / 메모이제이션 깊이 우선 탐색(DFS)으로 해결됩니다.

- 매칭 조건:
  $$\text{match}(P[0 \dots m-1], W[0 \dots m-1]) \iff \forall j, (P[j] = \text{'?'} \lor P[j] = W[j])$$
- 상태 전이:
  $$\text{memo}[idx] = \bigcup_{W \in D, \text{match}(S[idx \dots idx+|W|-1], W)} \{ [W] + \text{sub} \mid \text{sub} \in \text{dfs}(idx + |W|) \}$$
- 복잡도: 어휘 사전 크기 $|D|$와 최대 단어 길이 $L$에 대해 시간 복잡도 $O(N \cdot |D| \cdot L)$로 매우 빠르고 결정론적으로 해를 탐색합니다.

## 3. 고대 비문의 역사적 관용구(Formulaic Language)

고대 그리스의 공공 비문은 엄격한 법률적 관용 표현을 따랐습니다:

- **아테네 민회 결의문 서두 (Decree Header)**:
  - $\text{ΕΔΟΧΣΕΝ ΤΕΙ ΒΟΛΕΙ ΚΑΙ ΤΟΙ ΔΕΜΟΙ}$
  - 번역: "평의회(Βουλή)와 민회(Δῆμος)가 결의하였다."
  - 고대 아티카 방언(기원전 403년 이전 아테네 철자 개혁 전)에서는 $\Xi$ 대신 $\mathrm{X\Sigma}$를, $\mathrm{H}$는 기식음으로, $\mathrm{E}$는 $\epsilon$과 $\eta$ 겸용, $\mathrm{O}$는 $o$와 $\omega$ 겸용으로 표기되었습니다.
- **성소 봉헌문 (Dedication)**:
  - $\text{ΑΘΕΝΑΙΑΙ ΠΟΛΙΑΔΙ ΑΝΕΘΕΚΕΝ}$
  - 번역: "도시의 수호신 아테나 폴리아스 여신께 봉헌하다."

본 문제는 이러한 역사적 사료의 실측 데이터를 바탕으로, 고대 문자학과 컴퓨터 과학의 제약 충족 격자 복원 알고리즘을 100% 융합하여 구현되었습니다.
