# 미셸 푸코의 『성의 역사 1권: 앎의 의지』: 생명권력(Biopower), 인구의 생명정치(Biopolitics) 및 억압 가설 비판 엔진

## 문제 설명

20세기 후반 비판철학과 사회학의 지형을 뒤흔든 **미셸 푸코(Michel Foucault, 1926–1984)**는 『감옥의 탄생』(1975)과 콜레주 드 프랑스 강의 『사회를 보호해야 한다』(1976), 그리고 **『성의 역사 1권: 앎의 의지』(Histoire de la sexualité 1: La volonté de savoir, 1976)**를 통해 현대 권력의 본질적 작동 방식을 해명하는 **생명권력(Biopower / Biopouvoir)**과 **생명정치(Biopolitics / Biopolitique)** 이론을 정식화했습니다.

푸코는 고대 및 중세의 전통적 군주 권력에서 근대적 통치 권력으로의 문명사적 대전환을 다음과 같은 유명한 명제로 요약합니다:

```
[ 전통적 군주 주권 권력 (Sovereign Power) ]
  "죽게 만들거나 살려두는 권력" (Faire mourir ou laisser vivre)
  - 군주의 법을 위반한 자를 처벌하고 목숨을 빼앗는 '피의 권리' (Scaffold / 공개 처형)

                       ⚡ 17~18세기 근대 통치성(Governmentality)으로의 전이
                       생명권력(Biopower)의 탄생: 생명의 관리와 증진

[ 근대 생명권력의 양극 구조 (The Two Poles of Biopower) ]

       ┌───────────────────────────────────────────────────────────┐
       │                 생명권력 (Biopower)                       │
       │   "살게 만들거나 죽게 내버려두는 권력"                     │
       │   (Faire vivre ou rejeter dans la mort / Make Live, Let Die)│
       └─────────────────────────────┬─────────────────────────────┘
                                     │
           ┌─────────────────────────┴─────────────────────────┐
           ▼                                                   ▼
┌──────────────────────────────────────┐   ┌──────────────────────────────────────┐
│ 1. 신체 해부정치학 (Anatomo-politics) │   │ 2. 인구 생명정치학 (Biopolitics)     │
│ - 대상: 개별 신체 (Individual Body)  │   │ - 대상: 생물학적 종으로서의 인구     │
│ - 기제: 규율 권력 (Discipline)       │   │ - 기제: 조절 통제 (Regulatory Control)│
│ - 장치: 학교, 공장, 군대, 감옥, 병원 │   │ - 장치: 출생/사망률, 공중보건, 위생학 │
│ - 목표: 온순하고 유용한 신체(Docility)│   │ - 목표: 인구의 항상성(Homeostasis)   │
└──────────────────────────────────────┘   └──────────────────────────────────────┘
                                     │
           ┌─────────────────────────┴─────────────────────────┐
           ▼                                                   ▼
[ 억압 가설 비판 (Repressive Hypothesis) ]   [ 국가 인종주의 (State Racism) ]
- 권력은 침묵시키지 않고 말하게 함          - 살게 만드는 권력이 학살을 정당화하는 논리
- "담론의 폭발 (Discursive Explosion)"      - 정상 대 비정상의 생물학적 분할선
- 고해성사, 의학, 통계학을 통한 주체화      - "그들이 죽어야 우리 인구가 산다"
```

1. **생명권력의 2대 극 (Two Poles of Biopower)**:
   - **신체 해부정치학(Anatomo-politics of the Human Body)**: 개별 유기체로서의 인간 신체를 훈련, 감시, 규격화(Normalisation)하여 경제적으로 유용하고 정치적으로 고분고분한 **'온순한 신체(Docile Body)'**로 길러내는 규율 권력입니다.
   - **인구 생명정치학(Biopolitics of the Population)**: 개인이 아닌 거시적 집단, 즉 '생물학적 종(Species)'으로서의 **인구(Population)**를 대상으로 삼습니다. 출생률, 사망률, 기대수명, 풍토병, 공중보건, 사회보험 등을 통계학적으로 측정하고 관리하여 인구 전체의 생명력과 항상성(Homeostasis)을 유지·최적화합니다.

2. **억압 가설 비판 (Critique of the Repressive Hypothesis)**:
   - 19세기 빅토리아 시대 이후 성이 금기시되고 침묵 속에 억압되었다는 통념은 허구입니다.
   - 권력은 성을 금지한 것이 아니라, 오히려 고해성사, 정신분석, 아동 교육, 범죄학, 공중보건 통계를 통해 **"성에 대해 끊임없이 말하도록 강제(Discursive Explosion)"**했습니다. 성을 진실의 담론으로 포섭하여 개인을 주체화(Subjectivation)한 것입니다.

3. **국가 인종주의와 주권적 분할 (State Racism & Making Die)**:
   - "살게 만들고 생명을 증진하는 권력"인 생명권력이 어떻게 전쟁, 우생학, 강제수용소, 집단학살을 자행하는가?
   - 생명권력은 인구 내부에 생물학적 분할선(정상/우량 대 비정상/퇴행/오염원)을 긋는 **국가 인종주의(State Racism)**를 발동합니다. "비정상적 위험군을 죽이거나 죽게 내버려두어야만(Let Die) 우리 종족과 인구가 더 건강하게 살 수 있다(Make Live)"는 역설적 정당화 기제입니다.

본 문제에서는 미셸 푸코의 생명권력 및 생명정치 이론을 수리적으로 정식화한 **푸코 생명권력 및 인구 거버넌스 시뮬레이션 엔진(Foucault Biopower & Biopolitical Governance Engine)**을 구축합니다.

## 입력 형식

표준 입력(stdin)으로 하나의 JSON 객체가 주어집니다.

```json
{
  "population_cohorts": [
    {
      "cohort_id": "COHORT_LABOR",
      "population_size": 40000,
      "individual_discipline_level": 0.85,
      "health_index": 0.45,
      "natality_rate": 0.020,
      "mortality_rate": 0.018,
      "docility_index": 0.90,
      "deviation_frequency": 0.12,
      "targeted_apparatus": "factory"
    }
  ],
  "governmental_interventions": [
    {
      "intervention_id": "INT_01",
      "target_cohort_id": "COHORT_LABOR",
      "pole_type": "anatomo_disciplinary",
      "regulatory_intensity": 0.30,
      "discursive_surveillance": 0.25
    }
  ],
  "engine_params": {
    "sovereignty_vs_biopower_epoch": 1976,
    "racism_division_threshold": 0.20
  }
}
```

### 필드 상세 설명
1. `population_cohorts` (배열): 사회를 구성하는 인구 코호트 집단 목록
   - `cohort_id` (문자열): 코호트 고유 식별자
   - `population_size` (정수): 인구 규모 ($N \ge 1$)
   - `individual_discipline_level` (실수): 개별 신체 훈련 및 규율 수준 ($0.0 \le D_{lvl} \le 1.0$)
   - `health_index` (실수): 코호트 보건 위생 지수 ($0.0 \le H \le 1.0$)
   - `natality_rate` (실수): 연간 출생률
   - `mortality_rate` (실수): 연간 사망률
   - `docility_index` (실수): 순응 및 규범 수용 역량 ($0.0 \le D_{idx} \le 1.0$)
   - `deviation_frequency` (실수): 규범 일탈 및 저항 빈도 ($0.0 \le \text{dev} \le 1.0$)
   - `targeted_apparatus` (문자열): 주요 통제 장치 (예: 공장, 감옥, 병원, 학교, 보험)
2. `governmental_interventions` (배열): 통치 권력이 시행하는 개입 시퀀스
   - `intervention_id` (문자열): 개입 고유 식별자
   - `target_cohort_id` (문자열): 대상 코호트 ID
   - `pole_type` (문자열): `"anatomo_disciplinary"` (신체 규율) 또는 `"biopolitics_regulatory"` (인구 조절)
   - `regulatory_intensity` (실수): 개입 강도 ($0.0 \le I \le 1.0$)
   - `discursive_surveillance` (실수): 고해·조사·통계 수집 강도 (담론의 폭발 계수)
3. `engine_params` (객체):
   - `sovereignty_vs_biopower_epoch` (정수): 역사적 연대 (1789년 이전이면 군주 주권 권력)
   - `racism_division_threshold` (실수): 국가 인종주의 위험군 분할 임계값 (기본 0.20)

## 엔진 처리 규칙 및 연산 공식

### 1. 통치 개입(Interventions) 적용
각 개입 $iv$에 대해:
- 대상 코호트가 존재하지 않으면: `status: "COHORT_NOT_FOUND"` 기록 후 건너뜁니다.
- **담론의 폭발량 (Discursive Explosion Volume)**:
  $$\text{disc\_inc} = \text{round}(\text{discursive\_surveillance} \times (\text{population\_size} / 1000.0), 4)$$
  전체 누적 담론량(`total_discursive_volume`)에 가산합니다.
- **개입 적용**:
  - `pole_type == "anatomo_disciplinary"`:
    - $D_{lvl} = \min(1.0, D_{lvl} + (I \times 0.4))$
    - $\text{deviation\_frequency} = \max(0.0, \text{deviation\_frequency} - (I \times 0.3))$
  - `pole_type == "biopolitics_regulatory"`:
    - $H = \min(1.0, H + (I \times 0.5))$
    - $\text{mortality\_rate} = \max(0.001, \text{mortality\_rate} - (I \times \text{mortality\_rate} \times 0.5))$

### 2. 코호트별 생명권력 지표 산출
- **온순한 신체 점수 (Docile Body Score)**:
  $$\text{docile\_score} = \text{round}(D_{lvl} \times D_{idx} \times (1.0 - \text{deviation\_frequency}), 4)$$
- **생명력 비 (Vitality Ratio)**:
  사망률이 0보다 크면 $\text{round}(\text{natality\_rate} / \text{mortality\_rate}, 4)$, 아니면 10.0.
- **인구 항상성 지수 (Homeostasis Index)**:
  $$\text{homeostasis\_index} = \text{round}(H \times \min(2.0, \text{vitality\_ratio} / 2.0), 4)$$
- **국가 인종주의 위험군 판정 (State Racism Risk)**:
  - $\text{deviation\_frequency} \ge \text{racism\_division\_threshold}$ 이면 `true`, 아니면 `false`.
- **생존 포기 지수 (Abandonment Index)**:
  위험군인 경우:
  $$\text{abandonment\_index} = \text{round}(\text{deviation\_frequency} \times (1.0 - \text{docile\_score}), 4)$$
  위험군이 아니면 $0.0$.
- **권력 양식 (Power Modality)**:
  - 위험군이고 $\text{abandonment\_index} \ge 0.15$: `"MAKE_LIVE_LET_DIE"` (살게 만들고 죽게 내버려두기)
  - 위험군이지만 지수가 미만: `"EXCLUSIONARY_SURVEILLANCE"` (배제적 감시)
  - 위험군이 아닌 경우: `"NORMALIZE_AND_OPTIMIZE"` (규범화 및 최적화)

### 3. 거시 통치 체제 판정 (Macro Governmental Regime)
- 인구 가중 평균을 통해 전체 사회의 집계 점수를 계산합니다:
  - $\text{agg\_docile} = \sum (\text{docile\_score} \times \text{weight})$
  - $\text{agg\_homeostasis} = \sum (\text{homeostasis\_index} \times \text{weight})$
- `sovereignty_vs_biopower_epoch < 1789`:
  `"CLASSICAL_SOVEREIGN_RIGHT_OF_SWORD"`
- 1789년 이후:
  - $\text{agg\_homeostasis} \ge \text{agg\_docile}$:
    `"SECURITY_AND_BIOPOLITICAL_POPULATION_GOVERNANCE"`
  - 그렇지 않으면:
    `"DISCIPLINARY_SOCIETY_OF_SURVEILLANCE"`

## 제약 사항

- $1 \le |\text{population\_cohorts}| \le 50$
- $0 \le |\text{governmental\_interventions}| \le 50$
- $1000 \le \text{sovereignty\_vs\_biopower\_epoch} \le 2030$
- $0.0 < \text{natality\_rate}, \text{mortality\_rate} \le 1.0$
- 시간 복잡도: $O(N + M)$ 이내 완료 (여기서 $N$은 코호트 수, $M$은 개입 수)
- 공간 복잡도: $O(N + M)$ 이내
