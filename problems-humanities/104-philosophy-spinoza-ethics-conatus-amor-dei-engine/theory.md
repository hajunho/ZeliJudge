# 스피노자의 에티카(Ethica)와 코나투스(Conatus) 수리·존재론적 심층 분석

## 1. 기하학적 방식(Mos Geometricus)과 실체일원론

바뤼흐 스피노자의 『에티카(Ethica)』는 철학사상 유례를 찾아볼 수 없을 만큼 엄격한 수학적 연역 체계인 **기하학적 방식(Ordine Geometrico)**으로 저술되었습니다. 데카르트가 확립한 이원론(생각하는 실체인 정신과 연장을 지닌 실체인 물질)은 "정신과 신체는 어떻게 상호작용하는가?"라는 송과선(Pineal Gland)의 아포리아에 봉착했습니다.

스피노자는 이 모순을 근본적으로 해체합니다:
- **실체(Substantia)**: "자신 안에 있으며 자신을 통하여 파악되는 것, 곧 그 개념을 형성하기 위해 다른 사물의 개념을 필요로 하지 않는 것 (Definitio 3)."
- **속성(Attributum)**: "지성이 실체에 대하여 그 본질을 구성하고 있다고 지각하는 것 (Definitio 4)."
- **양태(Modus)**: "실체의 변용(Affectiones), 곧 다른 것 안에 있으며 다른 것을 통하여 파악되는 것 (Definitio 5)."

만약 두 개 이상의 서로 다른 실체가 존재한다면, 그들은 서로 구별되는 속성을 가져야 하며, 서로를 제한(Limit)하게 됩니다. 그러나 무한한 것은 어떠한 외적 제한도 가질 수 없습니다. 따라서 무한하고 불가분하며 자기원인(*causa sui*)인 실체는 **오직 하나**만 존재할 수 있으며, 이 유일무이한 전체가 바로 **'신 또는 자연(Deus sive Natura)'**입니다.

## 2. 심신 평행론(Psychophysical Parallelism)

신은 무한한 속성을 지니지만, 인간의 지성이 인식할 수 있는 속성은 **사유(Cogitatio)**와 **연장(Extensio)** 두 가지뿐입니다. 인간의 마음(Mens)은 사유 속성 아래서 파악된 신의 양태이며, 인간의 신체(Corpus)는 연장 속성 아래서 파악된 동일한 하나의 양태입니다.

> "관념들의 질서와 연결은 사물들의 질서와 연결과 동일하다 (*Ordo et connexio idearum idem est ac ordo et connexio rerum*, Part II, Prop 7)."

신체가 물질적 마주침을 통해 자극을 받으면, 마음 역시 정확히 일치하는 관념을 형성합니다. 따라서 정신이 신체를 지배하거나 신체가 정신을 지배하는 것이 아니라, 두 속성은 하나의 단일한 우주적 인과망 안에서 완전한 평행을 이룹니다.

## 3. 코나투스(Conatus)와 활동역량(Potentia Agendi)

스피노자 형이상학에서 모든 개별 사물은 고정된 정적 실체가 아니라 끊임없이 약동하는 **역능(Potentia)**입니다.

> "각각의 사물은 자신 안에 있는 한, 자신의 존재 안에 존속하고자 노력한다 (*Unaquaeque res, quantum in se est, in suo esse perseverare conatur*, Part III, Prop 6)."

이것이 바로 유명한 **코나투스(Conatus)**입니다. 코나투스는 인간의 외부에서 주어지는 인위적 의무가 아니라, 존재의 본질 그 자체(*ipsa rei essentia*)입니다.

- **활동역량($P$, Potentia Agendi)**:
  - 인간이 세계와 마주칠 때, 외부 신체와의 결합은 인간의 활동역량을 증대시키거나 감소시킵니다.
  - 활동역량이 증대되는 이행(Transition)을 **기쁨(Laetitia, Joy)**이라 부릅니다:
    $$\Delta P > 0 \implies \text{Laetitia}$$
  - 활동역량이 감소되는 이행을 **슬픔(Tristitia, Sadness)**이라 부릅니다:
    $$\Delta P < 0 \implies \text{Tristitia}$$
  - **욕망(Cupiditas)**은 자신의 코나투스를 인식하면서 활동역량을 보존하고 확장하려는 원초적 추동력입니다.

## 4. 3대 인식(Genera Cognitionis)과 인간의 예속 vs 자유

인간이 세계를 인식하는 깊이에 따라 정념의 성격과 삶의 자유가 근본적으로 분기합니다:

```
+-------------------------------------------------------------------------+
|                  제1종 인식: 상상/의견 (Imaginatio / Opinio)            |
|  - 감각적·단편적·불완전한 관념 (Inadequate Ideas)                       |
|  - 외적 원인에 지배당함 -> 수동적 정념(Passio)                         |
|  - 결과: 사랑, 미움, 희망, 공포, 질투, 분노 -> 인간의 예속(De Servitute)|
+------------------------------------+------------------------------------+
                                     |  이성적 사유의 발현
                                     v
+-------------------------------------------------------------------------+
|                  제2종 인식: 이성 (Ratio / Notiones Communes)           |
|  - 사물들의 공통 성질에 대한 적합한 관념 (Common Notions)               |
|  - 자연의 보편 법칙과 필연성(Necessitas) 이해                           |
|  - 결과: 수동적 슬픔 극복, 능동적 기쁨(Laetitia Activa), 정신의 견고함  |
+------------------------------------+------------------------------------+
                                     |  본질의 직관적 파악
                                     v
+-------------------------------------------------------------------------+
|             제3종 인식: 직관지 (Scientia Intuitiva)                     |
|  - 신/자연의 영원한 속성으로부터 사물의 개별적 본질을 직접 통찰         |
|  - 만물을 '영원의 상 아래(Sub Specie Aeternitatis)'에서 조망            |
|  - 결과: 신에 대한 지적 사랑 (Amor Dei Intellectualis) & 지복(Beatitudo) |
+-------------------------------------------------------------------------+
```

1. **인간의 예속 (De Servitute Humana, Part IV)**:
   - 제1종 인식에 머무르는 자는 외적 대상의 우연성에 마음이 얽매여, 미래의 불확실성에 따라 **희망(Spes)**과 **공포(Metus)** 사이를 시계추처럼 진동하는 **마음의 동요(Fluctuatio Animi)**를 겪습니다.
2. **이성의 해방 (Part IV & V)**:
   - "정념은 우리가 그것에 대해 명석판명한 관념을 형성하는 순간, 수동이기를 멈추고 능동이 된다 (Part V, Prop 3)."
   - 지진, 질병, 배신 등 외적 고통이 신/자연의 필연적 인과법칙의 일부임을 이성으로 명료하게 파악할 때, 맹목적인 분노와 슬픔은 자연에 대한 적합한 이해와 내적 평정(Animi Acquiescentia)으로 승화됩니다.
3. **신에 대한 지적 사랑과 지복 (Amor Dei Intellectualis & Beatitudo, Part V)**:
   - 제3종 직관지는 우주 전체의 통일성과 내재성을 한눈에 꿰뚫어 봅니다.
   - 이때 신을 인과율의 원천이자 만물의 내재적 실체로 통찰하며 생겨나는 최고의 순수한 기쁨이 바로 **신에 대한 지적 사랑(Amor Dei Intellectualis)**입니다.
   - 이는 신이 인간에게 보상으로 내리는 사후의 상벌이 아니라, 덕의 실천 그 자체가 곧 최상의 행복인 **지복(Beatitudo)**입니다.
