# #124 - 토마스 쿤의 과학혁명의 구조: 정상과학, 변칙 사례의 위기, 공약불가능성 및 패러다임 전환 엔진

## 📖 문제 배경과 역사적 맥락

> *"과학의 발전은 지식의 점진적이고 누적적인 축적 과정이 아니다. 그것은 하나의 지배적 세계관(패러다임) 하에서 수수께끼를 푸는 '정상과학'의 안정기, 미해결 '변칙 사례'의 폭발로 초래되는 '위기', 그리고 사물의 지각 자체가 통째로 뒤바뀌는 비연속적이고 혁명적인 '패러다임 전환(Paradigm Shift)'의 순환이다."*  
> — **토마스 S. 쿤 (Thomas S. Kuhn, 1922–1996), 『과학혁명의 구조』(The Structure of Scientific Revolutions, 1962)**

20세기 과학철학 및 사상사의 흐름을 완전히 뒤바꾼 미국의 물리학자이자 과학사학자 **토마스 S. 쿤(Thomas S. Kuhn)**은 1962년 불후의 고전 **『과학혁명의 구조(The Structure of Scientific Revolutions)』**를 통해 논리실증주의(Logical Positivism)와 칼 포퍼(Karl Popper)의 반증주의(Falsificationism)가 지배하던 전통적 과학관을 근본적으로 뒤흔들었습니다.

전통 철학은 과학을 "관찰 데이터를 통해 객관적 진리를 벽돌 쌓듯 하나씩 쌓아 올리는 선형적 누적 과정"으로 보았습니다. 그러나 쿤은 실제 역사적 과학사(천문학, 화학, 물리학 등)를 면밀히 분석한 결과, 과학 활동의 대다수는 검증된 표준 문제 풀이 모범인 **패러다임(Paradigm)**을 무비판적으로 신봉하며 규칙에 맞추어 퍼즐을 맞추는 **정상과학(Normal Science)**임을 밝혔습니다.

### 쿤 과학철학의 핵심 개념들
1. **정상과학과 수수께끼 풀이(Puzzle-Solving)**: 정상과학 연구자들은 자연의 새로운 기본 원리를 발견하려 하지 않습니다. 이미 주어진 패러다임의 규칙과 기구를 정교화하여 패러다임이 예측한 바를 정밀하게 확인하는 퍼즐 맞추기를 수행합니다.
2. **변칙 사례(Anomaly)와 위기(Crisis)**: 패러다임의 예측과 맞지 않는 관측이 나오면 초기에는 실험자의 미숙이나 장비 오차로 치부됩니다. 그러나 천문학의 역행 궤도나 물리학의 흑체복사 자외선 파탄처럼 핵심 원리를 뒤흔드는 변칙 사례들이 한계치(Crisis Threshold)를 넘어 누적되면 학계는 극심한 위기에 빠집니다.
3. **공약불가능성(Incommensurability / 통약불가능성)**: 구 패러다임(아리스토텔레스-프톨레마이오스)과 신 패러다임(갈릴레오-뉴턴)은 개념(예: '질량', '공간', '운동')의 정의와 문제의 가치 기준 자체가 다릅니다. 따라서 객관적이고 중립적인 단 하나의 논리적 잣대로 두 패러다임을 환원 비교할 수 없습니다.
4. **게슈탈트 전환(Gestalt Switch)과 플랑크의 원리(Planck's Principle)**:
   - 과학자가 신 패러다임을 받아들이는 것은 논리적 설득이라기보다 토끼-오리 착시처럼 세계 전체가 다르게 보이는 '지각적 개종(Conversion)'입니다.
   - 막스 플랑크는 *"새로운 과학적 진리는 반대자들을 설득하여 승리하는 것이 아니라, 반대자들이 서서히 사망하고 새로운 진리에 익숙한 젊은 세대가 자라남으로써 승리한다"*고 통찰했습니다.

본 과제에서는 토마스 쿤의 과학철학 모델을 엄밀한 패러다임 동역학, 연구자 세대별 개종 전이, 그리고 공약불가능성 저항을 반영한 시뮬레이션 엔진으로 구현합니다.

## 📥 입력 형식 (Input Specification)

입력은 표준 입력(Standard Input)으로 단일 JSON 객체가 주어집니다:

```json
{
  "config": {
    "crisis_threshold": 60.0,
    "revolution_threshold": 50.0,
    "dominant_paradigm": "ptolemaic"
  },
  "community": {
    "senior_count": 30,
    "mid_count": 40,
    "junior_count": 30
  },
  "paradigms": {
    "ptolemaic": {
      "name": "프톨레마이오스 천동설 체계",
      "explanatory_power": 85.0,
      "exemplar_reputation": 95.0,
      "solved_puzzles": 120,
      "incommensurability": 0.0
    }
  },
  "events": [
    {
      "type": "PUZZLE_SOLVING",
      "params": {
        "paradigm": "ptolemaic",
        "puzzles": 10
      }
    },
    {
      "type": "OBSERVE_ANOMALY",
      "params": {
        "paradigm": "ptolemaic",
        "severity": 25.0,

      }
    },
    {
      "type": "CRITICAL_ANOMALY_CRISIS",
      "params": {
        "paradigm": "ptolemaic",
        "crisis_surge": 35.0
      }
    },
    {
      "type": "PROPOSE_RIVAL_PARADIGM",
      "params": {
        "id": "copernican",
        "name": "코페르니쿠스-갈릴레오 지동설 체계",
        "explanatory_power": 90.0,
        "exemplar_reputation": 60.0,

        "initial_vanguard": 8
      }
    },
    {
      "type": "GESTALT_CONVERSION_WAVE"
    },
    {
      "type": "TEXTBOOK_REWRITE",
      "params": {
        "paradigm": "copernican"
      }
    }
  ]
}
```

### 제약조건 및 파라미터 규칙:
1. `config`:
   - `crisis_threshold`: 패러다임 위기 진입 임계치 (기본값 `60.0`).
   - `revolution_threshold`: 과학 혁명기 진입 신 패러다임 지지율 임계치 (기본값 `50.0`, %).
   - `dominant_paradigm`: 초기 지배 패러다임 ID.
2. `community`:
   - `senior_count`: 보수적 원로 과학자 수 (양의 정수).
   - `mid_count`: 실용적 중견 과학자 수 (양의 정수).
   - `junior_count`: 혁신적 소장 과학자 수 (양의 정수).
   - 총 과학자 수 $N = \text{seniors} + \text{mids} + \text{juniors}$.
3. `paradigms`: 패러다임 맵:
   - `name`: 패러다임 명칭.
   - `explanatory_power`: 설명력/정확도 ($[0, 100]$, 기본값 `80.0`).
   - `exemplar_reputation`: 모범적 예제 및 학술 권위 ($[0, 100]$, 기본값 `90.0`).
   - `solved_puzzles`: 해결된 퍼즐 수 (기본값 `100`).
   - `incommensurability`: 구 패러다임과의 개념적 공약불가능성 지수 ($\Psi \in [0.0, 1.0]$, 기본값 `0.0`).
4. `events`: 다음 6가지 사건이 순서대로 발생합니다:
   - `PUZZLE_SOLVING`:
     - 파라미터: `paradigm`, `puzzles` ($K$).
     - 효과: 해당 패러다임의 `solved_puzzles += K`, `explanatory_power = min(100.0, power + K * 0.5)`. 만약 해당 패러다임에 변칙 사례가 존재하고 심각도가 가장 낮은 변칙 사례의 심각도 $\le K \times 2.0$이면 해당 변칙 사례를 해결하여 목록에서 제거하고 누적 심각도에서 차감.
   - `OBSERVE_ANOMALY`:
     - 파라미터: `paradigm`, `severity` ($S$), `description`.
     - 효과: 변칙 사례 목록에 추가, `anomaly_severity_sum += S`, `exemplar_reputation = max(10.0, rep - S * 0.2)`.
   - `CRITICAL_ANOMALY_CRISIS`:
     - 파라미터: `paradigm`, `crisis_surge` ($C$).
     - 효과: `anomaly_severity_sum += C`, `exemplar_reputation = max(5.0, rep - C * 0.5)`.
   - `PROPOSE_RIVAL_PARADIGM`:
     - 파라미터: `id`, `name`, `explanatory_power`, `exemplar_reputation`, `solved_puzzles`, `incommensurability`, `initial_vanguard` ($V$).
     - 효과: 신규 경쟁 패러다임 등록. 기존 지배 패러다임의 소장 과학자 중 $\min(V, \text{junior\_affil})$명이 즉시 신 패러다임의 선봉대(Vanguard)로 이동.
   - `GESTALT_CONVERSION_WAVE`:
     - 효과: 지배 패러다임의 위기와 신 패러다임의 설명력, 공약불가능성 저항에 기반한 개종 동학 계산.
       1. 지배 패러다임 위기 지수:
          $$
          \text{Crisis} = \min\left(100.0, \frac{\text{anomaly\_severity\_sum} \times 100}{\frac{\text{explanatory\_power} \times \text{exemplar\_reputation}}{100}}\right)
          $$
       2. 개종 압력:
          $$
          P_{\text{conv}} = \left(\frac{\text{Crisis}}{100}\right) \times \left(\frac{\text{Rival.explanatory\_power}}{100}\right) \times (1.0 - 0.4 \times \Psi)
          $$
       3. 플랑크 세대별 전이 (소장파 > 중견파 > 원로파):
          - $\Delta J = \text{int}(\text{round}(\text{junior\_affil} \times P_{\text{conv}} \times 0.70))$
          - $\Delta M = \text{int}(\text{round}(\text{mid\_affil} \times P_{\text{conv}} \times 0.40))$
          - $\Delta S = \text{int}(\text{round}(\text{senior\_affil} \times P_{\text{conv}} \times 0.15))$
          (지배 패러다임에서 차감하여 경쟁 패러다임으로 가산).
   - `TEXTBOOK_REWRITE`:
     - 파라미터: `paradigm`.
     - 효과: 지정된 패러다임의 `exemplar_reputation = min(100.0, rep + 30.0)`. 다른 모든 패러다임의 소속 과학자 중 각각 80%($\text{int}(\text{count} \times 0.8)$)가 제도적 교육과 교과서 재작성에 의해 지정된 패러다임으로 강제 통합. 활성 지배 패러다임을 해당 패러다임으로 변경.

### 체제 상태 (`regime`) 판정 규칙 (매 사건 처리 직후):
1. 만약 경쟁 패러다임이 존재하고 경쟁 패러다임의 지지율(점유율)이 $\ge 80.0\%$ 이면: `"NEW_NORMAL_SCIENCE"` (새로운 정상과학의 확립, 활성 지배 패러다임이 경쟁 패러다임으로 전환).
2. 만약 경쟁 패러다임이 존재하고 지지율이 $\ge \text{revolution\_threshold}$ 이면: `"SCIENTIFIC_REVOLUTION"` (과학 혁명기).
3. 만약 지배 패러다임의 위기 지수 $\text{Crisis} \ge \text{crisis\_threshold}$ 이면: `"PARADIGM_CRISIS"` (패러다임의 위기).
4. 그 외의 경우: `"NORMAL_SCIENCE"` (정상과학).

## 🎯 채점 기준 및 제약 조건

1. 정확성 100%: 8개 모든 테스트케이스가 오차 없이 완벽히 일치해야 합니다.
2. 모든 사건은 순차적으로 처리되며, 세대별 정수 인원 전이 공식 `int(round(...))`를 엄격히 준수해야 합니다.
3. 지배 패러다임의 변화와 위기 지수 전이 타이밍이 정확해야 합니다.
