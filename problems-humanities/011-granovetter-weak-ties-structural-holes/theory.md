# [이론 및 배경] 사회연결망분석(SNA): 약한 유대의 힘과 구조적 공백 이론

## 1. 관계주의 사회학(Relational Sociology)과 네트워크 과학의 태동

전통적인 사회과학 연구가 행위자 개인의 속성(Attribute) — 성별, 연령, 교육 수준, 소득 등 — 에 주목했다면, 1970년대 이후 등장한 **관계주의 사회학(Relational Sociology)**은 행위자들이 맺고 있는 **관계의 구조(Structure of Ties)**가 사회적 기회와 행동을 결정한다는 패러다임 전환을 이끌어냈습니다.

사회연결망분석(SNA)은 그래프 이론(Graph Theory)과 통계물리학의 복잡계 네트워크를 사회학적 가설과 결합하여 사회 구조를 수학적으로 정량화합니다.

## 2. 마크 그라노베터의 약한 유대의 힘 (The Strength of Weak Ties, 1973)

### 2.1 삼항 폐쇄(Triadic Closure)의 저주
만약 $A$가 $B$와 강한 유대(Strong Tie)를 맺고 있고, $A$가 $C$와도 강한 유대를 맺고 있다면, $B$와 $C$가 서로 만날 확률은 매우 높아집니다.
결과적으로 강한 유대들로 이루어진 관계망은 삼각형 모양의 닫힌 루프(Triads)를 무수히 형성합니다.
- **정보의 폐쇄성**: 친한 친구들끼리는 서로 아는 정보가 99% 겹치기 때문에, 새로운 취업 정보, 최신 기술 트렌드, 사업 기회 같은 **비중복성 신규 정보(Non-Redundant Information)**가 생성되지 못합니다.

### 2.2 약한 유대의 브릿지(Bridge) 기능
그라노베터는 보스턴 교외 전문직 종사자 수백 명의 이직 경로를 조사하여 충격적인 사실을 발견했습니다:
> *"대다수의 사람들은 절친이나 가족(강한 유대)이 아니라, 일 년에 한두 번 볼까 말까 한 지인이나 옛 직장 동료(약한 유대)를 통해 양질의 취업 기회를 얻었다."*

- **이유**: 약한 유대는 자신이 속하지 않은 **완전히 다른 이종 집단(Disjoint Community)으로 통하는 유일한 지름길(Local Bridge)** 역할을 수행하기 때문입니다.
- **이웃 중복도(Neighborhood Overlap)**:
  $$O(u, v) = rac{|N(u) \cap N(v)|}{|N(u) \cup N(v)| - 2}$$
  - $O(u, v) 	o 1$: 두 사람이 공유하는 친구가 많음 $\implies$ 강한 유대, 내부 순환.
  - $O(u, v) = 0$: 두 사람 사이에 겹치는 친구가 전무함 $\implies$ 진정한 **로컬 브릿지(Local Bridge)**.

## 3. 로널드 버트의 구조적 공백(Structural Holes) 이론 (1992)

마크 그라노베터가 유대의 강도(Tie Strength)에 집중했다면, 로널드 버트(Ronald Burt)는 **네트워크 토폴로지의 결손(Holes in Network Topology)**에 주목했습니다.

```
       [ Cluster A: Engineering ]         [ Cluster B: Marketing ]
            (A1) --- (A2)                      (B1) --- (B2)
              \      /                           \      /
                (A3)                               (B3)
                  \                                 /
                   \                               /
                    -----> [ BROKER (You) ] <-----
                                   |
                                   |
                                  (C1) --- (C2)
                         [ Cluster C: Finance ]
```

### 3.1 구조적 공백의 3대 경쟁 우위
1. **정보 우위 (Information Advantage)**: 서로 다른 세 집단의 새로운 아이디어를 가장 먼저 접하고 교차 결합(Cross-Pollination)할 수 있음.
2. **시점 우위 (Timing Advantage)**: 정보가 다른 집단으로 전파되기 전에 선점할 수 있음.
3. **조정 우위 (Tertius Gaudens, '즐기는 제3자')**: 서로 직접 소통하지 못하는 집단 사이에서 협상력과 재량권을 행사할 수 있음.

### 3.2 네트워크 제약도 (Network Constraint)
$$C_i = \sum_{j} c_{ij} = \sum_{j} \left( p_{ij} + \sum_{q} p_{iq} p_{qj} ight)^2$$
- $p_{ij}$: $i$가 $j$에게 쏟는 시간/자원의 비중.
- $\sum_q p_{iq} p_{qj}$: $i$의 다른 친구 $q$를 통해 $j$로 우회 연결되는 간접 종속도.
- **해석**:
  - $C_i$가 $1.0$에 가까우면: $i$의 모든 이웃이 서로 긴밀히 연결되어 있어 $i$는 독자적인 발언권이 없는 닫힌 조직의 부품에 불과합니다.
  - $C_i$가 $0.35$ 이하로 낮으면: $i$의 이웃들이 서로 전혀 모르는 독립된 집단들이므로, $i$는 구조적 공백을 독점 지배하는 **핵심 브로커(Key Broker)**가 됩니다.

## 4. 현대 기업 및 소셜 플랫폼에서의 실무 응용

1. **조직 네트워크 분석 (ONA, Organizational Network Analysis)**:
   - 사내 이메일, 슬랙(Slack), 협업 툴 로그를 바탕으로 고립된 부서 간에 로컬 브릿지 역할을 하는 '숨은 핵심 인재(Hidden Champions)' 발굴.
   - 단절된 부서 간의 구조적 공백을 채우는 사내 TF 및 크로스 펑셔널 팀(CFT) 설계.
2. **링크드인(LinkedIn) 1촌-2촌-3촌 네트워크**:
   - '알 수도 있는 사람' 추천 알고리즘에서 약한 유대 브릿지 노드를 매개로 추천 풀을 확장.
